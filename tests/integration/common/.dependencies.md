Provides a reusable dependency-checking harness for integration tests, allowing tests to be gracefully skipped when required external tools (Docker, k3d, kubectl, Helm) are not available on the host.

## Key Components

### `Dependency` Struct
Represents an external tool dependency with:
- `Name` — human-readable identifier
- `CheckCmd` — command slice used to probe availability (e.g., `["docker", "info"]`)
- `InstallMsg` — guidance message shown when the dependency is missing

### Methods
| Method | Description |
|---|---|
| `IsAvailable() bool` | Runs `CheckCmd` and returns `true` if exit code is 0 |
| `RequireOrSkip(t, skipMsg)` | Skips the test (not passes) if the dependency is unavailable, logging the install hint |

### Predefined Dependencies
| Variable | Tool | Check Command |
|---|---|---|
| `Docker` | Docker daemon | `docker info` |
| `K3d` | k3d cluster manager | `k3d version` |
| `Kubectl` | Kubernetes CLI | `kubectl version --client` |
| `Helm` | Helm package manager | `helm version` |

### Convenience Functions
- `RequireClusterDependencies(t)` — requires Docker + k3d
- `RequireK8sDependencies(t)` — requires kubectl + Helm
- `RequireAllDependencies(t)` — requires all four tools

## Usage Example

```go
func TestClusterProvisioning(t *testing.T) {
    // Skip the test if Docker or k3d are unavailable
    common.RequireClusterDependencies(t)

    // Test body only runs when all dependencies are present
    // ...
}

func TestHelmDeploy(t *testing.T) {
    common.RequireAllDependencies(t)

    // Runs only when Docker, k3d, kubectl, and Helm are all available
    // ...
}

// Using a custom dependency
myTool := &common.Dependency{
    Name:       "mytool not available",
    CheckCmd:   []string{"mytool", "--version"},
    InstallMsg: "Install mytool from https://example.com",
}
myTool.RequireOrSkip(t, "mytool missing, skipping test")
```
