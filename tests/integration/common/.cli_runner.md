Test harness utility for building, executing, and inspecting the `openframe` CLI binary during integration tests.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `InitializeCLI()` | `func error` | Builds the CLI binary into `build/openframe`, with mod-time caching to skip unnecessary rebuilds |
| `CleanupCLI()` | `func` | Removes the compiled test binary and resets state |
| `GetProjectRoot()` | `func string` | Walks up the directory tree to locate `go.mod`, with a fallback for known test directory layouts |
| `RunCLI(args ...string)` | `func *CLIResult` | Executes the built binary with the given arguments, capturing stdout, stderr, and exit code |
| `CLIResult` | `struct` | Holds the full output of a CLI invocation: `Stdout`, `Stderr`, `ExitCode`, `Error` |
| `CLIResult.Success()` | `method bool` | Returns `true` when `ExitCode == 0` and `Error == nil` |
| `CLIResult.Failed()` | `method bool` | Inverse of `Success()` |
| `CLIResult.Output()` | `method string` | Concatenates `Stdout` and `Stderr` |
| `CLIResult.ErrorMessage()` | `method string` | Extracts the first `Error: …` line from stderr, skipping usage/flag text |

## Usage Example

```go
func TestMain(m *testing.M) {
    if err := common.InitializeCLI(); err != nil {
        log.Fatalf("setup failed: %v", err)
    }
    defer common.CleanupCLI()
    os.Exit(m.Run())
}

func TestClusterCreate(t *testing.T) {
    result := common.RunCLI("cluster", "create", "--name", "test")

    if result.Failed() {
        t.Fatalf("expected success, got: %s", result.ErrorMessage())
    }

    if !strings.Contains(result.Stdout, "created") {
        t.Errorf("unexpected output: %s", result.Output())
    }
}
```

## Notes

- The binary is cached at `build/openframe` relative to the project root; `InitializeCLI()` skips a rebuild when the binary is newer than `main.go`.
- `RunCLI` inherits the current process environment (`os.Environ()`), so any environment variables set in the test process are forwarded to the binary.
- A result with no stdout, no stderr, and no error is treated as an error to catch silent failures early.
