Provides test harness utilities for managing k3d Kubernetes clusters during integration testing, including lifecycle operations (create, stop, delete) and Docker resource cleanup.

## Key Components

| Function | Description |
|---|---|
| `GenerateTestClusterName()` | Returns a unique cluster name using a Unix timestamp (e.g., `integration-test-1234567890`) |
| `CreateTestCluster(name)` | Creates a k3d cluster with 1 agent and a 60s timeout |
| `DeleteTestCluster(name)` | Deletes a named k3d cluster |
| `ClusterExists(name)` | Checks if a cluster exists by running `k3d cluster list` |
| `StopTestCluster(name)` | Stops (without deleting) a named k3d cluster |
| `CleanupTestCluster(name)` | Deletes a cluster and purges its Docker networks/containers |
| `CleanupAllTestClusters()` | Scans all k3d clusters and removes any with test-related names |
| `cleanupDockerResources()` | Removes leftover k3d Docker networks, containers, and registries |
| `cleanupClusterSpecificResources(name)` | Removes Docker resources scoped to a specific cluster |

## Usage Example

```go
// Create a uniquely named cluster for a test
name := common.GenerateTestClusterName()
if err := common.CreateTestCluster(name); err != nil {
    t.Fatalf("failed to create cluster: %v", err)
}
defer common.CleanupTestCluster(name)

// Check if the cluster is running
exists, err := common.ClusterExists(name)
if err != nil || !exists {
    t.Fatal("cluster should exist after creation")
}

// Teardown all test clusters between test suites
common.CleanupAllTestClusters()
```

## Notes

- All `exec.Command` calls are annotated with `// #nosec G204` since inputs are controlled by the test harness, not user input.
- `CleanupAllTestClusters` matches clusters by name patterns: `test`, `integration`, `stress`, `collision`, `interrupt`, `multi-`, `debug`, and common command prefixes.
