Provides shared test setup utilities for initializing environments, creating mock executors, and configuring flag containers used across unit and integration tests.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `InitializeTestMode` | func | Sets `ui.TestMode = true` to enable test-safe UI rendering |
| `NewTestMockExecutor` | func | Returns a new `*executor.MockCommandExecutor` |
| `CreateStandardTestFlags` | func | Builds a `*cluster.FlagContainer` with mocked k3d executor and manager for unit tests |
| `CreateIntegrationTestFlags` | func | Builds a `*cluster.FlagContainer` using real dependencies for integration tests |
| `SetVerboseMode` | func | Toggles the verbose flag on a given `FlagContainer` |

## Usage Example

```go
// Unit test setup
func TestMyCommand(t *testing.T) {
    testutil.InitializeTestMode()

    flags := testutil.CreateStandardTestFlags()
    testutil.SetVerboseMode(flags, true)

    // flags.Executor is a mock — no external k3d dependency required
    result, err := mycommand.Run(flags)
    // assert...
}

// Integration test setup
func TestMyCommandIntegration(t *testing.T) {
    flags := testutil.CreateIntegrationTestFlags()
    // Uses real executor and real k3d manager
    result, err := mycommand.Run(flags)
    // assert...
}

// Direct mock executor usage
func TestExecutorResponse(t *testing.T) {
    mock := testutil.NewTestMockExecutor()
    mock.SetResponse("k3d cluster list", &executor.CommandResult{
        ExitCode: 0,
        Stdout:   `[{"name":"my-cluster"}]`,
    })
}
```

## Notes

- `CreateStandardTestFlags` pre-configures mock responses for `k3d cluster list` (empty array) and `k3d cluster get` (not found), covering the most common test paths without requiring a live cluster.
- `CreateIntegrationTestFlags` omits `TestManager` injection, causing the real k3d manager to be resolved at runtime — suitable for CI environments with k3d installed.
