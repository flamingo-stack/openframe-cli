Shared test utility helpers for validating Cobra CLI commands and creating flag containers used across the `openframe-cli` test suite.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `TestCommandStructure` | `func` | Asserts a `cobra.Command` has the expected `Use`, `Short`, `Long`, and `RunE` fields |
| `TestCLICommand` | `func` | Executes a command with given args and validates error state and output substrings |
| `TestFlags` | `func` | Returns a standard `cluster.FlagContainer` for unit tests |
| `IntegrationFlags` | `func` | Returns a `cluster.FlagContainer` pre-configured for integration tests |

## Usage Example

```go
func TestMyCommand(t *testing.T) {
    cmd := NewMyCommand()

    // Validate command metadata
    testutil.TestCommandStructure(t, cmd,
        "my-command",
        "Short description here",
    )

    // Execute with args and assert output
    testutil.TestCLICommand(t, cmd,
        []string{"--flag", "value"},
        false,            // expectErr
        "expected output", // output substrings
    )
}

func TestWithFlags(t *testing.T) {
    flags := testutil.TestFlags()
    // use flags in unit test setup

    integrationFlags := testutil.IntegrationFlags()
    // use integrationFlags in integration test setup
}
```

## Notes

- All helpers call `t.Helper()` so failures are reported at the call site, not inside the utility.
- `TestCLICommand` redirects both stdout and stderr to a shared buffer for unified output assertion.
- `TestFlags` and `IntegrationFlags` delegate to `CreateStandardTestFlags()` and `CreateIntegrationTestFlags()` respectively — see [`internal/cluster`](https://github.com/flamingo-stack/openframe-cli/blob/main/internal/cluster) for flag definitions.
