Provides a fluent, chainable assertion API for validating CLI command output (stdout, stderr, and errors) in Go tests.

## Key Components

### `AssertCommandOutput` struct
Holds the test context (`*testing.T`), captured `stdout`, `stderr`, and `err` from a command execution. All methods return `*AssertCommandOutput` for chaining.

### Constructor
- **`NewAssertCommandOutput(t, stdout, stderr, err)`** — Creates a new asserter instance.

### Assertion Methods
| Method | Description |
|---|---|
| `NoError()` | Asserts no error occurred |
| `HasError()` | Asserts an error was returned |
| `ErrorContains(text)` | Asserts error message contains `text` |
| `StdoutContains(text)` | Asserts stdout contains `text` |
| `StdoutEmpty()` | Asserts stdout is empty |
| `StderrContains(text)` | Asserts stderr contains `text` |
| `StderrContainsAny(texts...)` | Asserts stderr contains at least one of the given strings |
| `StderrEmpty()` | Asserts stderr is empty |
| `OutputContains(text)` | Asserts combined stdout+stderr contains `text` |
| `ContainsAll(texts...)` | Asserts stdout contains all specified strings |

### Helper Functions
- **`AssertCommandSuccess`** — Shorthand: asserts no error and empty stderr.
- **`AssertCommandFailure`** — Shorthand: asserts an error occurred.

## Usage Example

```go
func TestMyCommand(t *testing.T) {
    stdout, stderr, err := runCommand("openframe", "version")

    // Using helper shorthand
    AssertCommandSuccess(t, stdout, stderr, err).
        StdoutContains("openframe").
        ContainsAll("version", "build")

    // Asserting failure with error message
    _, stderr, err = runCommand("openframe", "invalid-cmd")
    AssertCommandFailure(t, "", stderr, err).
        StderrContainsAny("unknown command", "invalid-cmd")
}
```
