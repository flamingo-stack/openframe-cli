Provides reusable test pattern helpers for validating Cobra CLI command structure, flags, CLI arguments, and execution behavior in a standardized test suite.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `TestClusterCommand` | Public function | Entry point that runs all four standard sub-tests (`Structure`, `Flags`, `CLI`, `Execution`) for a given cluster command |
| `testCommandStructure` | Internal function | Verifies command name, short/long descriptions, presence of `RunE`, and that the long description references the command |
| `testCommandFlags` | Internal function | Validates `--help` succeeds and unrecognized flags return an error |
| `testCommandCLI` | Internal function | Exercises `cmd.Args` validation with valid, excess, and edge-case argument counts |
| `testCommandExecution` | Internal function | Checks `--dry-run` behavior (when supported) and confirms `--help` always exits cleanly |

## Usage Example

```go
package cluster_test

import (
    "testing"
    "github.com/flamingo-stack/openframe-cli/internal/testutil"
)

func TestCreateCommand(t *testing.T) {
    testutil.TestClusterCommand(
        t,
        "create",
        NewCreateCommand, // func() *cobra.Command
        func() {          // setupFunc: configure mocks/env
            // e.g. mock API client
        },
        func() {          // teardownFunc: cleanup
            // e.g. reset mocks
        },
    )
}
```

`TestClusterCommand` calls four sub-tests automatically:

| Sub-test | What it checks |
|----------|---------------|
| `Structure` | Name, descriptions, `RunE` presence |
| `Flags` | `--help` passes, unknown flags fail |
| `CLI` | Argument count validation via `cmd.Args` |
| `Execution` | `--dry-run` (if registered), `--help` always succeeds |

> **Note:** `testCommandStructure` skips the `RunE` and long-description assertions for the root `cluster` command, since parent commands typically act as group containers rather than executable commands.
