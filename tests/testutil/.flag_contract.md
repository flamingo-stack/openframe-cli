Contract testing utilities for validating CLI flag specifications and subcommand structure in Cobra-based commands, ensuring any silent breaking changes to the CLI surface are caught immediately.

## Key Components

- **`FlagSpec`** — Struct describing the frozen contract of a single CLI flag: its name, shorthand, type, and default value.
- **`AssertFlag`** — Verifies a single flag on a `cobra.Command` matches a given `FlagSpec` exactly (existence, shorthand, type, and default).
- **`AssertFlags`** — Iterates a slice of `FlagSpec` and calls `AssertFlag` for each, validating the full flag contract of a command.
- **`FindSubcommand`** — Looks up an immediate subcommand by name or fails the test if not found.
- **`AssertSubcommands`** — Verifies a parent command exposes exactly the named subcommands (order-independent), failing on any extra or missing entries.

## Usage Example

```go
func TestRootCommandContract(t *testing.T) {
    cmd := NewRootCmd()

    // Verify expected subcommands exist
    testutil.AssertSubcommands(t, cmd, "install", "upgrade", "version")

    // Locate a subcommand and verify its flags
    installCmd := testutil.FindSubcommand(t, cmd, "install")
    testutil.AssertFlags(t, installCmd, []testutil.FlagSpec{
        {Name: "namespace", Shorthand: "n", Type: "string", Default: "default"},
        {Name: "dry-run",   Shorthand: "",  Type: "bool",   Default: "false"},
        {Name: "timeout",   Shorthand: "t", Type: "int",    Default: "30"},
    })
}
```

Any renamed flag, dropped shorthand, changed default, or added/removed subcommand will cause the test to fail loudly, protecting the CLI's public contract.
