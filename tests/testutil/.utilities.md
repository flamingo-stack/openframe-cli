Provides a helper function for creating pre-configured test cluster configuration objects in unit tests.

## Key Components

- **`TestClusterConfig(name string) *models.ClusterConfig`** — Returns a `*models.ClusterConfig` populated with sane defaults: `K3d` cluster type, 3 nodes, and Kubernetes version `v1.28.0`.

## Usage Example

```go
import "github.com/flamingo-stack/openframe-cli/internal/testutil"

func TestMyFeature(t *testing.T) {
    cfg := testutil.TestClusterConfig("my-test-cluster")
    // cfg.Name       == "my-test-cluster"
    // cfg.Type       == models.ClusterTypeK3d
    // cfg.NodeCount  == 3
    // cfg.K8sVersion == "v1.28.0"
}
```
