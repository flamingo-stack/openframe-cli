Implements the `openframe app access` CLI subcommand, which retrieves and displays ArgoCD admin credentials along with instructions for accessing the ArgoCD UI locally.

## Key Components

- **`getAccessCmd()`** - Constructs the `access` Cobra subcommand, registering the `--context` flag (kube-context selection) and the shared output-format flag. Marked read-only via annotations.
- **`runAccessCommand(cmd, args)`** - Command handler that resolves the output format, builds an ArgoCD manager for the target context, fetches the admin password, and either renders it as structured output (JSON/YAML) or prints it as formatted text.
- **`resolveRestConfig(contextName)`** - Builds a `rest.Config` for the specified kube-context (or the current context if empty). Shared with the `status` command.
- **`newArgoCDManager(contextName, verbose)`** - Constructs an `argocd.Manager` bound to a Kubernetes REST config and a real command executor.
- **`printAccess(password)`** - Prints the ArgoCD username/password and step-by-step port-forward instructions using `pterm`, ensuring output respects silent mode.

## Usage Example

```go
// CLI usage:
//   openframe app access
//   openframe app access --context k3d-openframe-dev
//   openframe app access --output json

// Programmatic wiring (as done in the parent command file):
accessCmd := getAccessCmd()
rootCmd.AddCommand(accessCmd)
```

Example text output:

```text
ArgoCD access
  Username: admin
  Password: <generated-password>
Open the ArgoCD UI:
  1. kubectl port-forward -n argocd svc/argocd-server 8080:443
  2. open https://localhost:8080
```

**Note:** Machine-readable output (`--output json`) returns a struct with `username` and `password` fields instead of the formatted text above.
