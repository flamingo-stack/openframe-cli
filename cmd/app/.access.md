Implements the `openframe app access` CLI command, which retrieves and displays ArgoCD admin credentials along with instructions for opening the ArgoCD UI locally.

## Key Components

- **`getAccessCmd()`** – Constructs the `access` cobra subcommand, registering the `--context` flag (kube-context override) and a shared output-format flag; marked read-only via annotations.
- **`runAccessCommand(cmd, args)`** – The command's `RunE` handler. Resolves the kube-context, builds an ArgoCD manager, fetches the admin password, and either renders it as structured output (JSON/YAML via `renderMachine`) or prints human-readable text.
- **`resolveRestConfig(contextName)`** – Builds a `*rest.Config` for the given kube-context (or the current context if empty). Shared with the `status` command.
- **`newArgoCDManager(contextName, verbose)`** – Creates an `argocd.Manager` bound to the resolved REST config, using a real command executor.
- **`printAccess(password)`** – Prints the ArgoCD username/password and port-forward instructions using `pterm` printers (ensures output respects `--silent` mode, unlike raw stdout writes).

## Usage Example

```go
// Registering the access command under the "app" command group
rootCmd := &cobra.Command{Use: "app"}
rootCmd.AddCommand(getAccessCmd())
```

CLI usage:

```bash
# Show ArgoCD credentials for the current kube-context
openframe app access

# Show credentials for a specific context
openframe app access --context k3d-openframe-dev

# Output as JSON
openframe app access --output json
```

Example text output:

```text
ArgoCD access
  Username: admin
  Password: <redacted>

Open the ArgoCD UI:
  1. kubectl port-forward -n argocd svc/argocd-server 8080:443
  2. open https://localhost:8080
```
