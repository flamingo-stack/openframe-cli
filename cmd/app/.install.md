## install.go

Defines the `openframe app install` CLI subcommand, which installs ArgoCD and the app-of-apps configuration onto a target Kubernetes cluster. It handles flag parsing, target cluster resolution (explicit context, named cluster, or interactive selection), and delegates the actual installation work to the chart services layer.

## Key Components

- **`getInstallCmd()`** — Builds and returns the `cobra.Command` for `install`, wiring up help text, flags, and the `RunE` handler.
- **`runInstallCommand(cmd, args)`** — Entry point executed when the command runs; extracts flags, builds the installation request, and invokes `services.InstallChartsWithConfigContext`.
- **`buildInstallRequest(cmd, args, flags, verbose, action)`** — Assembles a `types.InstallationRequest`, resolving the cluster's `rest.Config` via explicit `--context`, interactive prompt selection (bare interactive run), or leaving it nil for the service layer to resolve (named cluster / `--non-interactive` / `--dry-run`).
- **`recommendedRequirements()`** — Returns advisory minimum cluster capacity (`recommendedCPUCores`, `recommendedMemGB`) used to warn users about undersized clusters.
- **`InstallFlags`** — Struct holding parsed CLI flags: `Force`, `DryRun`, `GitHubRepo`, `Ref`, `CertDir`, `NonInteractive`.
- **`(*InstallFlags).resolvedRef()`** — Returns the effective git ref to deploy (`--ref` value or `chartmodels.DefaultGitBranch`).
- **`extractInstallFlags(cmd)`** — Parses all install-related flags from the `cobra.Command` into an `InstallFlags` struct.
- **`getVerboseFlag(cmd)`** — Resolves the `--verbose` flag, checking root persistent flags first, then local flags.
- **`addInstallFlags(cmd)`** — Registers all install flags (`--force`, `--dry-run`, `--github-repo`, `--ref`, `--cert-dir`, `--non-interactive`, `--context`) on the command.

## Usage Example

```go
package app

import "github.com/spf13/cobra"

func RegisterAppCommands(root *cobra.Command) {
    appCmd := &cobra.Command{Use: "app"}
    appCmd.AddCommand(getInstallCmd())
    root.AddCommand(appCmd)
}
```

Command-line usage:

```bash
# Interactive install (prompts for cluster/context selection)
openframe app install

# Install on a specific cluster
openframe app install my-cluster

# Non-interactive install using existing openframe-helm-values.yaml (CI/CD)
openframe app install --non-interactive

# Deploy a specific branch or release tag
openframe app install --ref develop
openframe app install --ref 1.0.48
```
