## install.go

Implements the `openframe app install` CLI subcommand, which installs ArgoCD and the app-of-apps configuration onto a Kubernetes cluster. It defines the command's flags, resolves the target cluster context (interactively or explicitly), and delegates the actual chart installation to the chart services layer.

## Key Components

- **`getInstallCmd()`** — Constructs the `cobra.Command` for `install`, wiring up usage text, examples, and flags.
- **`runInstallCommand(cmd, args)`** — Entry point executed by Cobra; extracts flags, builds the installation request, and invokes `services.InstallChartsWithConfigContext`.
- **`buildInstallRequest(cmd, args, flags, verbose, action)`** — Assembles a `types.InstallationRequest`, resolving the target cluster via `--context` flag or interactive selection (`target.NewSelector`) when no cluster name is given and not in non-interactive/dry-run mode.
- **`InstallFlags`** — Struct holding parsed flag values (`Force`, `DryRun`, `GitHubRepo`, `Ref`, `CertDir`, `NonInteractive`), with `resolvedRef()` to determine the git ref to deploy (falls back to `chartmodels.DefaultGitBranch`).
- **`extractInstallFlags(cmd)`** — Parses install-related flags from the Cobra command into an `InstallFlags` struct.
- **`getVerboseFlag(cmd)`** — Resolves the `--verbose` flag from root or local command, defaulting to `false`.
- **`addInstallFlags(cmd)`** — Registers all install-specific flags (`--force`, `--dry-run`, `--github-repo`, `--ref`, `--cert-dir`, `--non-interactive`, `--context`).
- **`recommendedRequirements()`** — Returns advisory minimum cluster capacity (6 CPU cores / 24GB RAM) used to warn users about undersized clusters.

## Usage Example

```go
// Registering the install command under the "app" parent command
appCmd := &cobra.Command{Use: "app"}
appCmd.AddCommand(getInstallCmd())
```

Typical CLI usage:

```bash
openframe app install                      # Interactive cluster selection
openframe app install my-cluster           # Install on a named cluster
openframe app install --non-interactive    # CI/CD mode using existing values file
openframe app install --ref 1.0.48         # Deploy a specific release tag
```
