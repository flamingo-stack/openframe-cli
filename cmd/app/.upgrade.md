## upgrade.go

Implements the `openframe app upgrade` subcommand, which upgrades an already-installed OpenFrame platform. It supports two mutually exclusive modes: changing the deployed git ref (re-deploy at a new branch/tag) or force-syncing ArgoCD against the current ref.

## Key Components

- **`getUpgradeCmd()`** — Builds the `upgrade` Cobra command, registering shared install flags plus `--sync` and `--prune`.
- **`runUpgradeCommand(cmd, args)`** — Entry point that validates flag combinations (`--ref` and `--sync` are mutually exclusive) and dispatches to the correct mode.
- **`upgradeIsChangeRef(refChanged, sync)`** — Determines whether Mode 1 (change ref) applies.
- **`runUpgradeChangeRef(cmd, args, flags, verbose)`** — Mode 1: re-deploys the app-of-apps at a new ref non-interactively, reusing existing `openframe-helm-values.yaml`, requiring existing values, and syncing stalled children.
- **`runUpgradeForceSync(cmd, args, flags, verbose)`** — Mode 2: resolves the target cluster, refreshes/syncs ArgoCD applications (optionally with `--prune`), and waits for rollout with a 15-minute timeout.
- **`previewOutOfSync(ctx, manager, verbose, prune)`** — Dry-run helper that reports out-of-sync applications without triggering an actual sync.
- **`resolveUpgradeTarget(cmd, args, flags, verbose)`** — Resolves the Kubernetes `rest.Config` and cluster name via `--context`, positional cluster name, current context (non-interactive), or interactive prompt.
- **`clusterNameArg(args)`** — Extracts the first positional argument as the cluster name.

## Usage Example

```go
// Register the upgrade command with the parent "app" command
appCmd.AddCommand(getUpgradeCmd())
```

Typical CLI usage:

```bash
# Force re-sync current ref (default)
openframe app upgrade

# Force re-sync with pruning of removed resources
openframe app upgrade --sync --prune

# Upgrade to a specific release tag
openframe app upgrade --ref v1.3.0

# Preview a ref change without applying it
openframe app upgrade --ref main --dry-run

# Target a specific cluster/context
openframe app upgrade my-cluster --context k3d-my-cluster
```
