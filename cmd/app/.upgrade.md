## upgrade.go

Implements the `openframe app upgrade` command, which upgrades an already-installed OpenFrame platform in one of two mutually exclusive modes: changing the deployed git ref, or forcing ArgoCD to re-sync the current ref.

## Key Components

- **`getUpgradeCmd()`** - Builds the `upgrade` cobra command, registering install flags plus `--sync` and `--prune`, with detailed usage examples.
- **`runUpgradeCommand()`** - Entry point that validates `--ref` and `--sync` are not both set, then dispatches to Mode 1 or Mode 2.
- **`upgradeIsChangeRef()`** - Determines which mode to run based on whether `--ref` changed and `--sync` was passed.
- **`runUpgradeChangeRef()`** - Mode 1: re-deploys the app-of-apps at a new ref non-interactively, reusing existing `openframe-helm-values.yaml`, requiring existing values, and forcing straggler sync on stall.
- **`runUpgradeForceSync()`** - Mode 2: refreshes and force-syncs the current ref via ArgoCD, with a 15-minute wait timeout and optional `--prune` for deleting resources removed from git.
- **`previewOutOfSync()`** - Supports `--dry-run` for Mode 2 by listing ArgoCD applications and reporting out-of-sync status without triggering an actual sync.
- **`resolveUpgradeTarget()`** - Resolves the Kubernetes `rest.Config` and cluster name via `--context` flag, positional cluster name, current context (non-interactive), or an interactive cluster selector.
- **`clusterNameArg()`** - Helper to extract the first positional argument as the cluster name.

## Usage Example

```go
// Registering the upgrade command under the app root command
rootCmd := &cobra.Command{Use: "app"}
rootCmd.AddCommand(getUpgradeCmd())
```

Typical CLI usage:

```bash
# Force re-sync the current ref (default)
openframe app upgrade

# Force re-sync and delete resources removed from git
openframe app upgrade --sync --prune

# Deploy a new ref (release tag) non-interactively
openframe app upgrade --ref v1.3.0

# Preview a ref change without applying it
openframe app upgrade --ref main --dry-run

# Target a specific cluster/context
openframe app upgrade my-cluster --context k3d-my-cluster
```
