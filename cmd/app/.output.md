Provides output format utilities for CLI commands, handling `--output` flag validation and rendering structured data as text, JSON, or YAML.

## Key Components

| Function | Description |
|---|---|
| `outputFormat(cmd)` | Reads and validates the `--output` flag; returns `"text"`, `"json"`, or `"yaml"` |
| `isMachineOutput(cmd)` | Returns `true` if output is `json` or `yaml`; used in `PersistentPreRunE` to suppress logo/prompts for scripting |
| `addOutputFlag(cmd)` | Registers the shared `--output`/`-o` flag on a command |
| `printJSON(v)` | Marshals any value to indented JSON and writes to stdout |
| `printYAML(v)` | Marshals any value to YAML via `sigs.k8s.io/yaml` (reuses `json:` struct tags) |
| `renderMachine(format, v)` | Dispatches to `printYAML` or `printJSON` based on format string |

## Usage Example

```go
// Register the flag on your command
addOutputFlag(myCmd)

// In PersistentPreRunE — suppress interactive output for scripts
if isMachineOutput(cmd) {
    disableLogo()
}

// In RunE — resolve format and render
format, err := outputFormat(cmd)
if err != nil {
    return err
}

result := MyResult{Name: "openframe", Status: "ok"}

if format == "text" {
    fmt.Printf("Name: %s  Status: %s\n", result.Name, result.Status)
} else {
    return renderMachine(format, result)
}
```

> **Note:** `printYAML` uses `sigs.k8s.io/yaml`, which round-trips through JSON internally — `json:` struct tags control field names in both JSON and YAML output.
