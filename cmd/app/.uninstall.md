## Overview

Defines the `openframe app uninstall` CLI subcommand, which removes the OpenFrame application (ArgoCD applications and Helm releases) from a Kubernetes cluster while leaving the cluster itself intact. It supports interactive confirmation, non-interactive automation, and optional namespace cleanup.

## Key Components

- **`getUninstallCmd() *cobra.Command`** — Builds the `uninstall` subcommand with flags:
  - `--context` / `-c`: target kube-context (defaults to current context)
  - `--yes` / `-y`: skip confirmation prompt
  - `--delete-namespace`: also delete the `argocd` namespace
- **`runUninstallCommand(cmd *cobra.Command, _ []string) error`** — Command handler that:
  1. Resolves flags (context, verbose, skip-confirm, delete-namespace)
  2. Prompts for confirmation via `ui.RequireConfirmation` unless `--yes` is set (fails fast in non-interactive sessions)
  3. Resolves the kube REST config via `resolveRestConfig`
  4. Creates an ArgoCD manager (`newArgoCDManager`) and Helm manager (`helm.NewHelmManager`)
  5. Invokes `appuninstall.NewService(...).Uninstall(...)` to perform the actual removal
  6. Reports results (apps deleted, releases removed, namespace deletion status) via `pterm`

## Usage Example

```go
// Registering the uninstall command with the parent "app" command
appCmd := &cobra.Command{Use: "app"}
appCmd.AddCommand(getUninstallCmd())
```

CLI usage:

```bash
# Interactive uninstall (prompts for confirmation)
openframe app uninstall

# Target a specific kube-context
openframe app uninstall --context k3d-openframe-dev

# Non-interactive uninstall with namespace cleanup
openframe app uninstall --yes --delete-namespace
```

**Note:** This command only removes ArgoCD and OpenFrame applications/releases — it does **not** delete the cluster. Use `openframe cluster delete` to remove the cluster itself.
