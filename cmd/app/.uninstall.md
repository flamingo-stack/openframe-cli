## Overview

Defines the `openframe app uninstall` CLI subcommand, which removes OpenFrame (ArgoCD applications and Helm releases) from a Kubernetes cluster while leaving the cluster itself intact. This is the counterpart to `openframe cluster delete`, targeting only application-layer resources.

## Key Components

- **`getUninstallCmd() *cobra.Command`** — Builds the `uninstall` Cobra command with flags:
  - `--context` / `-c`: kube-context to target (defaults to current context)
  - `--yes` / `-y`: skip confirmation prompt (for automation)
  - `--delete-namespace`: also remove the `argocd` namespace

- **`runUninstallCommand(cmd *cobra.Command, _ []string) error`** — Command handler that:
  1. Resolves flags (`context`, `yes`, `delete-namespace`) and verbose mode
  2. Prompts for destructive confirmation via `ui.RequireConfirmation` unless `--yes` is passed (fails fast instead of blocking in non-interactive sessions)
  3. Resolves the Kubernetes REST config and constructs an ArgoCD manager and Helm manager
  4. Delegates the actual removal work to `appuninstall.NewService(...).Uninstall(...)`
  5. Reports results (apps deleted, Helm releases removed, namespace deletion status) via `pterm`

## Usage Example

```go
// Registering the uninstall command under the app command group
rootCmd := &cobra.Command{Use: "app"}
rootCmd.AddCommand(getUninstallCmd())
```

CLI usage:

```bash
# Interactive uninstall with confirmation prompt
openframe app uninstall

# Uninstall from a specific context
openframe app uninstall --context k3d-openframe-dev

# Fully automated, also removing the argocd namespace
openframe app uninstall --yes --delete-namespace
```

## Notes

- Relies on `appuninstall.Service` (business logic), `helm.NewHelmManager` (Helm operations), and `sharedErrors.HandleGlobalError` for consistent error handling across the CLI.
- Does not delete the underlying cluster — reinstalling is suggested via `openframe app install` in the success message.
