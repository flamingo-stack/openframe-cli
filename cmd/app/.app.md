Registers the `app` command group for the OpenFrame CLI, wiring together all application lifecycle subcommands under a single `cobra.Command`.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `GetAppCmd()` | `func` | Constructs and returns the `app` parent command with all subcommands attached |

### Subcommands Registered

| Subcommand | Source |
|------------|--------|
| `install` | `getInstallCmd()` |
| `upgrade` | `getUpgradeCmd()` |
| `status` | `getStatusCmd()` |
| `access` | `getAccessCmd()` |
| `uninstall` | `getUninstallCmd()` |

### Behavior Notes

- **`PersistentPreRunE`**: Runs before any subcommand; honors `--silent` flag via `ui.SetSilent()` and suppresses the logo for machine-readable output (`--output json/yaml`). The logo is shown for subcommands but not for the bare `app` command itself.
- **Prerequisites**: Intentionally not checked here — delegated to `InstallChartsWithConfigContext` inside the install/upgrade flow to avoid redundant checks.
- **`RunE`**: Falls back to displaying help when `app` is invoked without a subcommand.

## Usage Example

```go
// Registering the app command group on the root command
rootCmd.AddCommand(app.GetAppCmd())
```

```bash
# Deploy OpenFrame onto an existing cluster
openframe app install

# Target a named cluster
openframe app install my-cluster

# List available subcommands
openframe app --help
```
