## Overview

Defines the `app` Cobra command group for the OpenFrame CLI, which deploys and manages the OpenFrame application (ArgoCD + app-of-apps) on an existing Kubernetes cluster. It wires together the `install`, `upgrade`, `status`, `access`, and `uninstall` subcommands and enforces consistent output/logo behavior across them.

## Key Components

- **`noPositionalArgs(cmd *cobra.Command, args []string) error`** — Validation helper that rejects stray positional arguments, returning a clear error instructing users to use `--context` instead. Prevents commands (especially `uninstall`) from silently targeting the wrong cluster.
- **`GetAppCmd() *cobra.Command`** — Constructs the `app` parent command:
  - Sets `Use`, `Short`, and `Long` help text describing the command group.
  - Defines a `PersistentPreRunE` that:
    - Applies global `--silent`/`--verbose` flags via `ui.ApplyGlobalOutputFlags` (must be repeated here since defining a group-level `PersistentPreRunE` shadows the root's).
    - Skips logo/context output for machine-readable formats (JSON/YAML).
    - Shows the ASCII logo and current kube-context header for subcommands (not the bare `app` command).
  - Defines `RunE` to print the logo and help text when invoked without a subcommand.
  - Registers subcommands: `install`, `upgrade`, `status`, `access`, `uninstall`.

## Usage Example

```go
package main

import (
	"github.com/flamingo-stack/openframe-cli/internal/app"
	"github.com/spf13/cobra"
)

func main() {
	rootCmd := &cobra.Command{Use: "openframe"}
	rootCmd.AddCommand(app.GetAppCmd())

	if err := rootCmd.Execute(); err != nil {
		panic(err)
	}
}
```

Command-line usage:

```bash
# Install ArgoCD and the app-of-apps on the current cluster
openframe app install

# Target a specific cluster context
openframe app install --context my-cluster

# View app status without extra logo/context noise (machine output)
openframe app status --output json
```
