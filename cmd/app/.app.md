Defines the `app` command group for the OpenFrame CLI, which deploys and manages the OpenFrame application (ArgoCD + app-of-apps) on an existing Kubernetes cluster.

## Key Components

- **`noPositionalArgs(cmd, args)`** — Validation function used by subcommands to reject stray positional arguments, forcing users to target clusters explicitly via `--context` instead of relying on ambiguous defaults. Returns a descriptive error naming the offending arguments and the correct flag to use.
- **`GetAppCmd()`** — Constructs and returns the top-level `app` `*cobra.Command`, wiring up its `PersistentPreRunE` hook and registering all subcommands: `install`, `upgrade`, `status`, `access`, and `uninstall`.

The command's `PersistentPreRunE` handles three responsibilities that would otherwise be inherited from the root command but are shadowed because `app` defines its own hook:
1. Applies global `--silent`/`--verbose` output flags via `ui.ApplyGlobalOutputFlags`.
2. Skips logo/banner output for machine-readable formats (JSON/YAML) to keep stdout script-friendly.
3. Shows the CLI logo and a context header (current kube-context) for subcommands, helping prevent accidental operations against the wrong cluster.

## Usage Example

```go
package main

import (
	"github.com/flamingo-stack/openframe-cli/internal/app"
	"github.com/spf13/cobra"
)

func main() {
	rootCmd := &cobra.Command{Use: "openframe"}
	rootCmd.AddCommand(app.GetAppCmd())
	_ = rootCmd.Execute()
}
```

Typical CLI usage:

```bash
# Install ArgoCD and the app-of-apps onto the current kube-context
openframe app install

# Target a specific cluster explicitly
openframe app install my-cluster

# Check status (rejects stray positional args)
openframe app status --context my-cluster
```
