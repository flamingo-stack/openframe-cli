# status.go

Implements the `openframe app status` subcommand, which reports whether the OpenFrame platform is up and running on a Kubernetes cluster. It checks cluster reachability, lists ArgoCD application sync/health states, summarizes overall readiness, and supports one-shot, watch (auto-refreshing), interactive, and machine-readable (JSON/YAML) output modes.

## Key Components

- **`getStatusCmd()`** — Builds the `cobra.Command` for `status`, registering `--context`, `--watch`/`-w`, `--interactive`/`-i`, and the shared output-format flag.
- **`runStatusCommand(cmd, args)`** — Main entry point: validates flag combinations (e.g. `--watch`/`--interactive` require a text, terminal output), resolves the kube config, builds the ArgoCD manager and Kubernetes accessor, and dispatches to interactive, watch, or single-report rendering.
- **`watchStatus(ctx, svc, verbose)`** — Polls `svc.Report` every 3 seconds and re-renders the status in place (like `kubectl get -w`), stopping cleanly on context cancellation.
- **`renderWatchFrame(rep, rerr)`** — Builds one frame of the watch view: header timestamp, reachability line, application table, and readiness summary.
- **`statusAppJSON` / `statusJSON`** — Machine-readable structs for a single application and the full status report, used for `--output json`/`yaml`.
- **`statusToJSON(rep)`** — Converts an `appstatus.Report` into `statusJSON`.
- **`renderStatus(rep)`** — Renders the human-readable text view: reachability, warnings/errors, application table, readiness summary, and access/admin password info.

## Usage Example

```go
// Registering the status command with a parent app command
appCmd.AddCommand(getStatusCmd())
```

```bash
# One-shot status check
openframe app status

# Use a specific kube-context
openframe app status --context k3d-openframe-dev

# Auto-refreshing watch view
openframe app status --watch

# Interactive TUI: navigate apps, inspect details, trigger syncs
openframe app status --interactive

# Machine-readable output
openframe app status --output json
```

The command resolves the REST config for the target context, builds an ArgoCD manager and Kubernetes accessor, and delegates reporting to `appstatus.Service.Report`, which returns an `appstatus.Report` consumed by either the text renderer, JSON/YAML encoder, watch loop, or the interactive TUI (`statustui.Run`).
