## Purpose

Implements the `openframe app status` CLI subcommand, which reports on OpenFrame platform health: cluster reachability, ArgoCD application sync/health state, and overall readiness. Supports one-shot text/JSON output, a live-refreshing `--watch` view, and a fully `--interactive` TUI.

## Key Components

- **`getStatusCmd() *cobra.Command`** — Builds the `status` subcommand with `--context`, `--watch`, `--interactive`, and output-format flags.
- **`runStatusCommand(cmd *cobra.Command, _ []string) error`** — Main entry point; validates flag combinations, resolves the Kubernetes config, builds the status service, and dispatches to interactive, watch, or one-shot rendering.
- **`watchStatus(ctx, svc, verbose) error`** — Polls the status service every 3 seconds and re-renders in place using `pterm.DefaultArea`, until the context is cancelled (Ctrl+C).
- **`renderWatchFrame(rep, rerr) string`** — Builds a single frame of the watch view (header, reachability, app table, summary).
- **`statusAppJSON` / `statusJSON`** — Machine-readable JSON structs for a single app and the full status report.
- **`statusToJSON(rep appstatus.Report) statusJSON`** — Converts an internal `Report` into its JSON representation.
- **`renderStatus(rep appstatus.Report)`** — Renders the one-shot text output: reachability, app table, readiness summary, and optional admin access info.

## Usage Example

```go
// Registering the status command within the app command group
statusCmd := getStatusCmd()
rootCmd.AddCommand(statusCmd)
```

```bash
# One-shot status check
openframe app status

# Use a specific kube-context
openframe app status --context k3d-openframe-dev

# Live-refreshing view (every 3s)
openframe app status --watch

# Full interactive TUI
openframe app status --interactive

# Machine-readable output
openframe app status --output json
```

Note: `--watch` and `--interactive` require an interactive terminal and are incompatible with `--output` other than `text` or with `--plain` mode.
