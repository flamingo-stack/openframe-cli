This file defines the root Cobra command for the OpenFrame CLI, wiring together version metadata, global flags, subcommands, and the top-level execution lifecycle (signal handling, self-update, WSL forwarding).

## Key Components

- **`VersionInfo`** — struct holding `Version`, `Commit`, and `Date`, populated at build time via linker `-X` flags.
- **`DefaultVersionInfo`** — package-level default, resolved via `resolveVersionInfo`.
- **`resolveVersionInfo` / `backfillFromVCS`** — fall back to Go's embedded VCS build info (commit/timestamp) when release ldflags weren't applied, so dev builds still show a meaningful identifier while keeping `version == "dev"` (which disables self-update).
- **`GetRootCmd(versionInfo)`** — builds and returns the fully configured root `*cobra.Command`.
- **`buildRootCommand(versionInfo)`** — constructs the `openframe` root command: description, version string (including pinned dependency versions), persistent flags (`--verbose`, `--silent`, `--plain`), custom usage/version templates, and registers subcommands (`cluster`, `app`, `bootstrap`, `prerequisites`, `update`).
- **`pinnedDependencies()`** — renders the exact pinned versions of tools the CLI installs/deploys (terraform, helm, k3d, mkcert, infracost, argo-cd chart), shown in `--version` output.
- **`Execute()` / `ExecuteWithVersion(versionInfo)`** — top-level entry points: handle Windows→WSL forwarding, initialize shared config, ensure the CLI-managed bin directory is on `PATH`, run the command under a signal-cancellable context (Ctrl-C/SIGTERM), then perform best-effort post-command self-update checks/notifications.
- **`getClusterCmd`, `getAppCmd`, `getBootstrapCmd`, `getPrerequisitesCmd`, `getUpdateCmd`** — thin accessors delegating to each subcommand package.

## Usage Example

```go
package main

import (
	"fmt"
	"os"

	"github.com/flamingo-stack/openframe-cli/cmd"
)

func main() {
	if err := cmd.Execute(); err != nil {
		fmt.Fprintln(os.Stderr, err)
		os.Exit(1)
	}
}
```

To run with explicit version info (e.g., from `main.go` build-time variables):

```go
versionInfo := cmd.VersionInfo{
	Version: "1.2.3",
	Commit:  "abc1234",
	Date:    "2024-01-01T00:00:00Z",
}
if err := cmd.ExecuteWithVersion(versionInfo); err != nil {
	os.Exit(1)
}
```
