# root.go

Defines the root Cobra command for the OpenFrame CLI, wiring together all subcommands (`cluster`, `app`, `bootstrap`, `prerequisites`, `update`), global flags, version reporting, and top-level execution flow (including WSL forwarding on Windows and post-command self-update handling).

## Key Components

- **`VersionInfo`** — Struct holding `Version`, `Commit`, and `Date` build metadata.
- **`version`, `commit`, `date`** — Package-level string vars set via `-ldflags -X` at release time (must remain package-level for the linker to populate them).
- **`DefaultVersionInfo`** — Resolved `VersionInfo` for the current build, backfilled from Go's embedded VCS info on dev builds.
- **`resolveVersionInfo` / `backfillFromVCS`** — Populate commit/date from `debug.ReadBuildInfo()` when release ldflags weren't applied, so dev builds show a real revision instead of "none"/"unknown".
- **`pinnedDependencies()`** — Renders the exact versions of pinned tools (terraform, helm, k3d, mkcert, infracost, argo-cd chart) installed/deployed by this build, shown in `--version` output.
- **`GetRootCmd(versionInfo VersionInfo) *cobra.Command`** — Public entry point returning the fully constructed root command.
- **`buildRootCommand(versionInfo VersionInfo) *cobra.Command`** — Builds the root `cobra.Command`: description, version string, global flags (`--verbose`, `--silent`, `--plain`), usage/version templates, and attaches all subcommands.
- **`Execute()`** — Runs the CLI using `DefaultVersionInfo`.
- **`ExecuteWithVersion(versionInfo VersionInfo) error`** — Full execution flow: WSL forwarding, config initialization, PATH setup for CLI-managed binaries, signal-cancellable context (Ctrl-C/SIGTERM), command execution, and post-run self-update/notify logic.
- **`getClusterCmd`, `getAppCmd`, `getBootstrapCmd`, `getPrerequisitesCmd`, `getUpdateCmd`** — Helper functions returning each subcommand from its respective package.

## Usage Example

```go
package main

import (
	"os"

	"github.com/flamingo-stack/openframe-cli/cmd"
)

func main() {
	if err := cmd.Execute(); err != nil {
		os.Exit(1)
	}
}
```

To inject version info at build time (see `.goreleaser.yml`):

```bash
go build -ldflags "-X github.com/flamingo-stack/openframe-cli/cmd.version=v1.2.3 \
  -X github.com/flamingo-stack/openframe-cli/cmd.commit=abc1234 \
  -X github.com/flamingo-stack/openframe-cli/cmd.date=2025-01-01T00:00:00Z" \
  -o openframe .
```
