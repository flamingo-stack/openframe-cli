Registers the `bootstrap` Cobra CLI command, which orchestrates a full OpenFrame environment setup by sequentially running cluster creation and ArgoCD/OpenFrame chart installation.

## Key Components

- **`GetBootstrapCmd()`** — Constructs and returns the `bootstrap` `*cobra.Command`. Validates the optional `[cluster-name]` argument against RFC1123 rules before delegating execution to `bootstrap.NewService().Execute()`.

## Flags

| Flag | Default | Description |
|---|---|---|
| `--non-interactive` | `false` | Skip all prompts; use an existing `openframe-helm-values.yaml` (suited for CI/CD) |
| `--verbose` / `-v` | `false` | Inherited root flag; surfaces detailed logs including ArgoCD sync progress |

## Usage Example

```bash
# Interactive mode (default)
openframe bootstrap

# Bootstrap with a custom cluster name
openframe bootstrap my-cluster

# Non-interactive / CI-CD mode
openframe bootstrap --non-interactive

# Verbose output
openframe bootstrap --verbose
```

```go
// Registering the command on the root Cobra command
rootCmd.AddCommand(bootstrap.GetBootstrapCmd())
```

## Notes

- Cluster name validation (`clustermodels.ValidateClusterName`) is enforced at the command boundary so no unsafe input reaches downstream shell-outs.
- Error handling delegates to `sharedErrors.HandleGlobalError`, which respects the `--verbose` flag for formatted output.
