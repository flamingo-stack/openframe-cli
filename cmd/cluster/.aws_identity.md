## Overview

Resolves and confirms the AWS identity (account/ARN) that an EKS cluster operation will run under, guarding against provisioning resources under the wrong AWS account. It calls `aws sts get-caller-identity` with an optional profile, then interactively confirms the identity with the user (or logs it in non-interactive/CI sessions). This is the AWS counterpart to the GKE authentication flow in `discovery.AuthFlow`.

## Key Components

- **`awsIdentity`** — struct mapping the JSON output of `aws sts get-caller-identity` (`Account`, `Arn`).
- **`awsConfigDocsURL`** — constant link to AWS's official credential configuration guide, surfaced in error messages.
- **`describeAWSSelection(profile string) string`** — formats a human-readable description of the credential source (named profile or default chain).
- **`confirmAWSIdentity(ctx, exec, profile) error`** — main entry point:
  - Runs `aws sts get-caller-identity` (with `--profile` if provided).
  - On failure, distinguishes "no AWS config at all" (points to setup docs) from "this profile/chain is broken" (lists available profiles as alternatives).
  - On success, parses the identity for display (parse failures are non-fatal since auth already succeeded).
  - In non-interactive mode, logs the identity via `pterm.Info` and proceeds.
  - In interactive mode, prompts the user to confirm via `confirmAWSIdentityFn`; declining aborts the operation with a hint to use `--profile`.
- **`confirmAWSIdentityFn`** / **`awsInteractiveFn`** — package-level function variables (test seams) wrapping `sharedUI.ConfirmActionInteractive` and `sharedUI.IsNonInteractive`.

## Usage Example

```go
import (
    "context"

    "github.com/flamingo-stack/openframe-cli/internal/shared/executor"
)

func provisionEKSCluster(ctx context.Context, exec executor.CommandExecutor, profile string) error {
    if err := confirmAWSIdentity(ctx, exec, profile); err != nil {
        return err // aborts before any billed AWS resources are created
    }

    // proceed with EKS cluster creation using the confirmed identity
    return nil
}
```

Tests can override the seams to avoid real terminal/stdin interaction:

```go
confirmAWSIdentityFn = func(msg string, defaultVal bool) (bool, error) { return true, nil }
awsInteractiveFn = func() bool { return true }
```
