Prerequisites installation for cluster creation, integrating the interactive configuration wizard, non-interactive flag-based setup, cloud dry-run plan previews (via Terraform), and optional infracost-based cost estimation.

## Key Components

- **`getCreateCmd()`** — Builds the `cluster create` Cobra command, wires up flags, validation (`PreRunE`), and execution (`RunE`).
- **`runCreateCluster(cmd, args)`** — Main command handler. Resolves cluster configuration either through the interactive wizard (`ui.NewConfigurationHandler`) or from CLI flags/args, validates node counts and min/max node bounds, and dispatches to dry-run or actual creation.
- **`planPreviewFn` / `cloudPlanPreview(ctx, config)`** — Package-level seam (for test stubbing) that runs a real Terraform plan against a cloud cluster config, authenticates against GCP/AWS as needed, renders the plan diff, and shows a cost estimate. Skips gracefully if Terraform isn't installed.
- **`showCostEstimate(ctx, exec, config, summary)`** — Best-effort monthly cost estimate using `infracost`; offers to install/login interactively, falls back to a generic cost hint (`ui.CostHint`) if unavailable.
- **`offerInfracostInstall()` / `offerInfracostLogin()`** — Interactive prompts that install `infracost` (verified download) and run its one-time browser-based `auth login`, respectively. No-ops in non-interactive sessions.
- **`infracostAvailableFn`, `infracostOfferFn`, `infracostLoginFn`** — Package variables acting as test seams for infracost integration.

## Usage Example

```go
// Registering the create command under the cluster root command
rootCmd := &cobra.Command{Use: "cluster"}
rootCmd.AddCommand(getCreateCmd())
```

Typical CLI usage this file implements:

```bash
# Interactive wizard
openframe cluster create

# Quick local k3d cluster with defaults
openframe cluster create my-cluster --skip-wizard

# Cloud GKE cluster with dry-run plan preview
openframe cluster create my-gke --type gke --project my-project \
  --region us-central1 --dry-run

# Cloud EKS cluster, non-interactive
openframe cluster create my-eks --type eks --region us-east-1 \
  --profile staging --skip-wizard
```
