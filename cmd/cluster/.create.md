## create.go

Implements the `openframe cluster create` CLI command, handling both interactive (wizard) and non-interactive (flag-based) cluster configuration, dry-run terraform plan previews, and optional infracost cost estimation for cloud clusters (GKE/EKS) before delegating to the actual cluster provisioning service.

## Key Components

- **`getCreateCmd()`** — Builds the Cobra `create` command, wires flag validation in `PreRunE`, and attaches create-specific flags.
- **`runCreateCluster(cmd, args)`** — Main command handler: resolves cluster config from wizard or CLI flags, validates node counts/cluster name, and triggers dry-run or actual creation.
- **`cloudPlanPreview(ctx, config)`** — Runs a real `terraform plan` for cloud cluster types and renders the resource diff; skips gracefully if terraform isn't installed.
- **`planPreviewFn`** — Package-level variable pointing to `cloudPlanPreview`, overridable in tests to avoid shelling out to terraform.
- **`showCostEstimate(ctx, exec, config, summary)`** — Prints a monthly cost estimate via infracost if available, offering interactive install/login, otherwise falls back to a generic cost hint.
- **`offerInfracostInstall()` / `offerInfracostLogin()`** — Interactive prompts to install infracost and run its one-time `auth login` browser flow.
- **`infracostAvailableFn`, `infracostOfferFn`, `infracostLoginFn`** — Test seams for infracost availability/install/login behavior.

## Usage Example

```go
package cluster

import "github.com/spf13/cobra"

func RegisterClusterCommands(root *cobra.Command) {
    root.AddCommand(getCreateCmd())
}
```

Command-line usage:

```bash
# Interactive selection menu
openframe cluster create

# Non-interactive k3d cluster
openframe cluster create my-cluster --skip-wizard --nodes 3

# Cloud cluster with dry-run plan preview and cost estimate
openframe cluster create my-gke --type gke --project my-project \
  --region us-central1 --dry-run
```
