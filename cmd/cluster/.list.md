# list.go

Implements the `openframe cluster list` command, which displays all Kubernetes clusters managed by OpenFrame CLI. Supports optional discovery of unmanaged cloud clusters (GKE and EKS) and multiple output formats (text, JSON, YAML).

## Key Components

- **`getListCmd()`** — Builds the Cobra `list` subcommand, wiring up flags (`--all`, `--output`, `--quiet`, `--verbose`) and validation via `PreRunE`.
- **`runListClusters(cmd, args)`** — Main command handler: fetches managed clusters, optionally merges in externally discovered clusters, and dispatches to the appropriate output printer based on `--output`.
- **`discoverExternalClusters(ctx, managed)`** — Orchestrates GKE and EKS discovery, filtering out clusters that are already tracked (matched by name, type, and project) so only unmanaged external clusters are returned.
- **`discoverGKE(ctx)` / `discoverEKS(ctx)`** — Provider-specific discovery routines. Both degrade gracefully on missing CLIs or auth issues, returning human-readable notices instead of hard errors. GKE offers an interactive login flow when not authenticated; EKS cannot, and just returns guidance.
- **`clusterJSON`** — Machine-readable struct representation of a cluster (name, type, status, node count, Kubernetes version).
- **`clustersToJSON(clusters)`** — Converts internal `models.ClusterInfo` slices into `clusterJSON` for serialization.
- **`printClustersJSON(clusters)` / `printClustersYAML(clusters)`** — Serialize and print the cluster list in JSON or YAML format, respectively.

## Usage Example

```go
// Registering the list command under the parent "cluster" command
clusterCmd.AddCommand(getListCmd())
```

Example CLI invocations:

```bash
# List locally managed clusters
openframe cluster list

# Include externally discovered GKE/EKS clusters
openframe cluster list --all

# Output as JSON or YAML for scripting
openframe cluster list --output json
openframe cluster list --output yaml

# Suppress non-essential output
openframe cluster list --quiet
```

Discovery errors (e.g., missing `gcloud`/`aws` CLI or expired credentials) never fail the command—they are surfaced as informational notices after the cluster table is printed.
