Implements the `openframe cluster list` subcommand, which displays all Kubernetes clusters managed by OpenFrame CLI, with optional discovery of unmanaged external GKE/EKS clusters and support for text, JSON, and YAML output formats.

## Key Components

- **`getListCmd()`** – Builds the `cobra.Command` for `cluster list`, wiring up global/list-specific flags, an `--output` flag (`text`, `json`, `yaml`), flag validation in `PreRunE`, and dispatching to `runListClusters` via `utils.WrapCommandWithCommonSetup`.
- **`runListClusters(cmd, args)`** – Core command handler: fetches managed clusters from the command service, optionally merges in externally discovered clusters (when `--all` is set), and renders output in the requested format.
- **`discoverExternalClusters(ctx, managed)`** – Runs GKE and EKS discovery concurrently in effect, filters out clusters already tracked in the registry (matched by name, type, and project), and aggregates non-fatal notices (e.g., auth issues).
- **`discoverGKE(ctx)` / `discoverEKS(ctx)`** – Provider-specific discovery helpers. GKE offers an interactive login flow when unauthenticated; EKS surfaces a notice instructing the user to run `aws configure`/`aws sso login` since no CLI-driven login exists. Both convert missing CLI tools or auth failures into informational notices rather than errors.
- **`clusterJSON`** – Serializable DTO (`name`, `type`, `status`, `nodeCount`, `k8sVersion`) used for JSON/YAML output.
- **`clustersToJSON`, `printClustersJSON`, `printClustersYAML`** – Convert and print `models.ClusterInfo` slices to the machine-readable formats.

## Usage Example

```go
// Registering the list command under the parent "cluster" command
clusterCmd.AddCommand(getListCmd())
```

Command-line usage:

```bash
openframe cluster list
openframe cluster list --all
openframe cluster list --output json
openframe cluster list --output yaml
openframe cluster list --verbose
```

Discovery failures (e.g., missing `gcloud`/`aws` CLI or expired credentials) never abort the command—they are reported as informational notices printed after the cluster table, ensuring `list` remains resilient even when cloud provider auth is misconfigured.
