## cleanup.go

Defines the `openframe cluster cleanup` CLI subcommand, which prunes unused (dangling/unreferenced) container images from cluster nodes to reclaim disk space, without touching installed applications, Helm releases, namespaces, or the cluster itself.

## Key Components

- **`getCleanupCmd() *cobra.Command`** — Builds the `cleanup` Cobra command, including usage text, examples, argument validation (`cobra.MaximumNArgs(1)`), the `c` alias, `PreRunE` flag synchronization/validation, and registration of cleanup-specific flags (e.g. `--force`).
- **`runCleanupCluster(cmd *cobra.Command, args []string) error`** — The command's `RunE` handler (wrapped via `utils.WrapCommandWithCommonSetup`). It:
  1. Lists available clusters via the command service.
  2. Uses `ui.OperationsUI.SelectClusterForCleanup` to resolve the target cluster (with confirmation prompt unless `--force` is set).
  3. Detects the cluster type (`service.DetectClusterType`).
  4. Runs a type-aware prerequisite check — only for `k3d` clusters — via `prerequisites.CheckForClusterType`, deferring rejection of cloud clusters to the service layer.
  5. Calls `service.CleanupCluster` to perform the actual image pruning.
  6. Reports results via `operationsUI.ShowOperationStart` / `ShowOperationError` / `ShowCleanupSummary`.

## Usage Example

```go
// Wiring the cleanup subcommand into the parent "cluster" command
clusterCmd.AddCommand(getCleanupCmd())
```

CLI usage:

```bash
openframe cluster cleanup
openframe cluster cleanup my-cluster
openframe cluster cleanup my-cluster --force
```

Note that a `nil` error from `runCleanupCluster` does not guarantee full success — the operation can partially fail (some phases succeed, others don't), in which case `ShowCleanupSummary` reports what was left behind.
