# cleanup.go

Defines the `openframe cluster cleanup` command, which prunes unused container images from cluster nodes to reclaim disk space without affecting installed applications, Helm releases, or namespaces.

## Key Components

- **`getCleanupCmd()`** — Builds the `cobra.Command` for `cluster cleanup`, wiring up global flag initialization/sync/validation, cleanup-specific flags, and the run handler.
- **`runCleanupCluster(cmd, args)`** — Core command logic:
  - Lists available clusters via the command service.
  - Uses `ui.OperationsUI.SelectClusterForCleanup` to resolve the target cluster (with confirmation prompts unless `--force` is set).
  - Detects the cluster type (`models.ClusterTypeK3d` vs. cloud-managed).
  - Runs a type-aware prerequisite check (Docker tooling required only for k3d clusters).
  - Delegates the actual pruning to `service.CleanupCluster`, then displays a summary via `operationsUI.ShowCleanupSummary`.

## Usage Example

```bash
# Interactively pick a cluster to clean up
openframe cluster cleanup

# Clean up a specific cluster
openframe cluster cleanup my-cluster

# Skip confirmation prompt
openframe cluster cleanup my-cluster --force
```

```go
// Registering the cleanup command with a parent command
cleanupCmd := getCleanupCmd()
parentCmd.AddCommand(cleanupCmd)
```

**Notes:**
- Only dangling/unreferenced container images are removed; running workloads and applications are untouched.
- To remove the OpenFrame platform itself, use `openframe app uninstall`.
- To delete an entire cluster, use `openframe cluster delete`.
- Cloud clusters bypass the Docker prerequisite check since cleanup is rejected by the service layer with guidance to use `cluster delete` instead.
