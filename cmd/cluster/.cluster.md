## cluster.go

Defines the root `cluster` Cobra command for the OpenFrame CLI, wiring together all cluster lifecycle subcommands (create, delete, list, status, use, cleanup) and enforcing shared pre-run behavior such as output flag handling, logo display, context reporting, and prerequisite checks.

## Key Components

- **`GetClusterCmd() *cobra.Command`** — Builds and returns the `cluster` command tree, including:
  - Global flag initialization via `utils.InitGlobalFlags()`
  - A `PersistentPreRunE` hook that:
    - Applies global `--silent`/`--verbose` flags (`ui.ApplyGlobalOutputFlags`)
    - Skips logo/prerequisite checks for machine-readable output (`json`/`yaml`)
    - Shows the CLI logo and current kube-context header for subcommands
    - Runs `prerequisites.CheckPrerequisites()` unless the subcommand opts out
  - A default `RunE` that shows the logo and help text when no subcommand is given
  - Registration of all subcommands (`getCreateCmd`, `getDeleteCmd`, `getListCmd`, `getStatusCmd`, `getUseCmd`, `getCleanupCmd`)
  - Global flag binding via `models.AddGlobalFlags`

- **`skipsGenericPrerequisiteGate(name string) bool`** — Determines which subcommands bypass the generic k3d/Docker/Helm prerequisite gate. Currently all listed subcommands (`create`, `use`, `status`, `list`, `delete`, `cleanup`) skip it, since they perform their own type-aware (local vs. cloud) or read-only checks instead.

## Usage Example

```go
package main

import (
	"github.com/flamingo-stack/openframe-cli/internal/cluster"
	"github.com/spf13/cobra"
)

func main() {
	rootCmd := &cobra.Command{Use: "openframe"}
	rootCmd.AddCommand(cluster.GetClusterCmd())

	if err := rootCmd.Execute(); err != nil {
		panic(err)
	}
}
```

Running `openframe cluster create` will trigger the `PersistentPreRunE` hook (showing the logo/context header) before delegating to the `create` subcommand's own type-aware prerequisite checks.
