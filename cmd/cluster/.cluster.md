## cluster.go

Defines the top-level `cluster` Cobra command for the OpenFrame CLI, wiring together all cluster lifecycle subcommands (create, delete, list, status, use, cleanup) and enforcing shared pre-run behavior such as output-flag handling, logo display, context headers, and prerequisite checks.

## Key Components

- **`GetClusterCmd() *cobra.Command`** — Constructs and returns the `cluster` command, including:
  - `PersistentPreRunE`: applies global `--silent`/`--verbose` flags, skips UI/prerequisite steps for machine-readable output (`json`/`yaml`), shows the logo and kube-context header for subcommands, and runs the generic prerequisite gate unless the subcommand opts out.
  - `RunE`: shows the logo and prints help when no subcommand is given.
  - Registers subcommands: `create`, `delete`, `list`, `status`, `use`, `cleanup`.
  - Adds global flags via `models.AddGlobalFlags`.

- **`skipsGenericPrerequisiteGate(name string) bool`** — Determines which subcommands bypass the group's generic k3d prerequisite check (Docker, k3d, helm). Currently all listed subcommands (`create`, `use`, `status`, `list`, `delete`, `cleanup`) skip the generic gate because they either perform their own type-aware checks (local vs. cloud clusters) or are read-only/best-effort operations that must work even without local tooling.

## Usage Example

```go
package main

import (
	"github.com/flamingo-stack/openframe-cli/internal/cluster"
)

func main() {
	rootCmd := cluster.GetClusterCmd()
	if err := rootCmd.Execute(); err != nil {
		// handle error
	}
}
```

Typical CLI usage once wired into the root command:

```bash
openframe cluster create
openframe cluster status
openframe cluster delete --output json
```
