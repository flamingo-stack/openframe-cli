# delete.go

Implements the `openframe cluster delete` CLI command, which removes a Kubernetes cluster and cleans up its associated resources (Docker containers, cluster configuration, and cloud infrastructure where applicable).

## Key Components

- **`getDeleteCmd()`** — Builds the Cobra command for `cluster delete`, wiring up flag initialization, validation (`PreRunE`), and execution (`RunE`). Supports an optional `[NAME]` argument and delete-specific flags (e.g., `--force`).
- **`confirmCloudDeletion(clusterType, clusterName, force)`** — Extra safety gate for cloud clusters (EKS/GKE). Requires the user to re-type the cluster name unless `--force` is passed. In non-interactive sessions without `--force`, it refuses to proceed rather than hang. Local clusters skip this gate entirely.
- **`runDeleteCluster(cmd, args)`** — Main execution flow:
  1. Lists available clusters and resolves the target via interactive selection or argument.
  2. Detects the cluster type (local vs. cloud).
  3. Applies the cloud confirmation gate for destructive cloud operations.
  4. Runs type-aware prerequisite checks (only after confirmation, so a declined delete never triggers tool installation).
  5. Delegates actual deletion to the service layer and reports success/failure via friendly UI messages.

## Usage Example

```bash
# Interactive selection
openframe cluster delete

# Delete a specific cluster
openframe cluster delete my-cluster

# Skip confirmation prompts (CI-friendly)
openframe cluster delete my-cluster --force
```

Programmatic registration within the cluster command group:

```go
func init() {
    clusterCmd.AddCommand(getDeleteCmd())
}
```

Internally, deletion safety is layered: a generic confirmation prompt runs first, followed by `confirmCloudDeletion` for cloud clusters, ensuring destructive, billed infrastructure changes require explicit intent before prerequisite checks or the actual `service.DeleteCluster` call execute.
