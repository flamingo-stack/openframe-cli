# delete.go

Implements the `openframe cluster delete` CLI command, which removes a Kubernetes cluster and cleans up its associated resources (intercepts, Docker resources, and configuration). Includes special safeguards for destructive operations on cloud clusters (EKS/GKE).

## Key Components

- **`getDeleteCmd()`** — Builds and returns the `cobra.Command` for `cluster delete`, wiring up global flag initialization, flag validation via `PreRunE`, and command-specific flags.
- **`confirmCloudDeletion(clusterType, clusterName, force)`** — Additional confirmation gate for cloud clusters (EKS/GKE), requiring the user to re-type the cluster name unless `--force` is passed. Refuses to proceed in non-interactive sessions without `--force`, preventing accidental destruction of billed infrastructure.
- **`runDeleteCluster(cmd, args)`** — Main `RunE` handler that:
  1. Lists available clusters and resolves the target cluster (via args or interactive selection).
  2. Detects the cluster type.
  3. Applies the stronger cloud-deletion confirmation gate.
  4. Runs type-aware prerequisite checks (only after confirmation, to avoid installing tools on a declined delete).
  5. Executes the deletion through the service layer and reports success/failure via the operations UI.

## Usage Example

```go
// Registering the delete command with the parent cluster command
func init() {
    clusterCmd.AddCommand(getDeleteCmd())
}
```

Command-line usage:

```bash
# Delete a specific cluster
openframe cluster delete my-cluster

# Skip confirmation prompts (CI-friendly)
openframe cluster delete my-cluster --force

# Interactive cluster selection
openframe cluster delete
```

For cloud clusters (EKS/GKE), deletion requires re-typing the cluster name for confirmation unless `--force` is supplied, providing an extra safety layer against irreversible infrastructure loss.
