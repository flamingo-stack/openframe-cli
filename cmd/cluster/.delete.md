Implements the `cluster delete` subcommand, which deletes a named (or interactively selected) Kubernetes cluster and cleans up all associated resources.

## Key Components

- **`getDeleteCmd() *cobra.Command`** — Constructs and returns the Cobra command definition for `openframe cluster delete [NAME]`, registering delete-specific flags and wiring `PreRunE` validation with `RunE` execution.
- **`runDeleteCluster(cmd, args)`** — Core handler that lists available clusters, prompts for selection (if no name is provided), detects the cluster type, and delegates deletion to the service layer with optional `--force` support.

## Usage Example

```bash
# Delete a named cluster
openframe cluster delete my-cluster

# Delete without confirmation prompt
openframe cluster delete my-cluster --force

# Interactive cluster selection
openframe cluster delete
```

```go
// Registered on the parent cluster command (internal wiring)
clusterCmd.AddCommand(getDeleteCmd())
```

The command follows a three-phase flow:

1. **Selection** — resolves a cluster name from CLI args or an interactive UI picker via `operationsUI.SelectClusterForDelete`.
2. **Detection** — calls `service.DetectClusterType` to determine the provider (e.g., kind, k3d).
3. **Deletion** — calls `service.DeleteCluster`, forwarding context, cluster name, type, and the `--force` flag; errors are surfaced through `sharedErrors.HandleGlobalError` with optional verbose output.
