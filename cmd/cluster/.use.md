Implements the `openframe cluster use` command, which switches the local kubectl context (and, for GKE, the active gcloud configuration) to a named cluster. It resolves clusters known to the CLI (local k3d, openframe-managed) as well as external GKE/EKS clusters discovered via `gcloud`/`aws` CLIs, fetching credentials automatically when no kubeconfig entry exists yet.

## Key Components

- **`getUseCmd()`** – Builds the Cobra command definition for `cluster use [NAME]`, including help text, argument validation, and global flag setup.
- **`runUseCluster(cmd, args)`** – Main command handler: resolves the target cluster name (explicit arg or interactive selection), detects if it's a known cluster type (k3d/GKE), and switches context; otherwise delegates to external cluster lookup.
- **`useExternalCluster(ctx, exec, kubeconfig, name)`** – Searches external GKE then EKS clusters by name, aggregating which clouds were searched for error reporting.
- **`useExternalGKE(...)`** – Discovers external GKE clusters, handles gcloud auth flow (interactive login if needed), fetches credentials via `gcloud container clusters get-credentials` if missing, and aligns the gcloud configuration.
- **`useExternalEKS(...)`** – AWS twin of the GKE flow; discovers EKS clusters and fetches credentials via `aws eks update-kubeconfig` (no interactive login, since AWS auth relies on profiles/SSO).
- **`switchTo(kubeconfig, contextName, clusterName)`** – Validates the kubeconfig context exists and performs the actual `kubectl` context switch, printing a success message.
- **`alignGcloudConfiguration(ctx, exec, project)`** – Best-effort helper that activates the matching gcloud configuration for a given GCP project.

## Usage Example

```go
// Register the "use" subcommand under "cluster"
clusterCmd.AddCommand(getUseCmd())
```

Command-line usage:

```bash
# Switch to a local k3d cluster
openframe cluster use openframe-dev

# Switch to an openframe-managed GKE cluster
openframe cluster use my-gke

# Switch to an externally discovered GKE/EKS cluster
openframe cluster use tenant-cluster-1

# Interactive selection when no name is given
openframe cluster use
```
