## use.go

Implements the `openframe cluster use` command, which switches the active kubectl context (and, for GKE, the active gcloud configuration) to a target cluster. It transparently handles locally known clusters (k3d, registry-managed) as well as external GKE/EKS clusters discovered via `gcloud` and `aws` CLIs, fetching credentials on demand when no kubeconfig entry exists yet.

## Key Components

- **`getUseCmd()`** – Builds the `cobra.Command` for `cluster use [NAME]`, wiring flag validation and the `runUseCluster` handler.
- **`runUseCluster(cmd, args)`** – Resolves the target cluster name (from args or interactive selection), then dispatches to local cluster handling or external cloud discovery.
- **`useExternalCluster(ctx, exec, kubeconfig, name)`** – Searches GKE then EKS for a named external cluster, aggregating which clouds were searched for error reporting.
- **`useExternalGKE(ctx, exec, kubeconfig, name)`** – Discovers GKE clusters, optionally triggers an interactive `gcloud` login, fetches credentials via `gcloud container clusters get-credentials` if needed, and switches context.
- **`useExternalEKS(ctx, exec, kubeconfig, name)`** – Discovers EKS clusters and fetches credentials via `aws eks update-kubeconfig` if needed, then switches context.
- **`switchTo(kubeconfig, contextName, clusterName)`** – Verifies the kubeconfig context exists and performs the actual `kubectl` context switch.
- **`alignGcloudConfiguration(ctx, exec, project)`** – Best-effort activation of the matching gcloud configuration for a given GCP project.

## Usage Example

```go
// Register the "use" subcommand under the cluster command tree
clusterCmd.AddCommand(getUseCmd())
```

CLI usage:

```bash
# Switch to a local k3d cluster
openframe cluster use openframe-dev

# Switch to an openframe-managed GKE cluster
openframe cluster use my-gke

# Switch to an external GKE/EKS cluster discovered via gcloud/aws
openframe cluster use tenant-cluster-1

# Interactively select a cluster to switch to
openframe cluster use
```
