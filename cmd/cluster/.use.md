# use.go

Implements the `openframe cluster use` command, which switches the local kubectl context (and, when relevant, the active gcloud configuration) to a target cluster. It supports local k3d clusters, openframe-managed clusters, and external GKE/EKS clusters discovered dynamically via `gcloud`/`aws` CLIs, fetching credentials automatically when no kubeconfig entry exists yet.

## Key Components

- **`getUseCmd()`** – Builds the Cobra command `use [NAME]`, supporting an optional cluster name argument or interactive selection.
- **`runUseCluster(cmd, args)`** – Main command handler. Resolves the target cluster name (arg or interactive prompt), checks known clusters (k3d/GKE via `service.DetectClusterType`), and falls back to external cloud discovery if not found locally.
- **`useExternalCluster(ctx, exec, kubeconfig, name)`** – Searches external clouds (GKE, then EKS) for a cluster by name, aggregating which clouds were searchable for error reporting.
- **`useExternalGKE(ctx, exec, kubeconfig, name)`** – Discovers GKE clusters, handles interactive gcloud login if unauthenticated, fetches credentials via `gcloud container clusters get-credentials` if needed, and switches context.
- **`useExternalEKS(ctx, exec, kubeconfig, name)`** – AWS equivalent; skips (rather than prompts) if credentials are unusable, fetches credentials via `aws eks update-kubeconfig --alias`, and switches context.
- **`switchTo(kubeconfig, contextName, clusterName)`** – Validates the kubeconfig context exists and switches `current-context`, reporting success via `pterm`.
- **`alignGcloudConfiguration(ctx, exec, project)`** – Best-effort activation of the matching gcloud configuration for a GKE cluster's project.

## Usage Example

```go
// Registering the command within the cluster command tree
func NewClusterCmd() *cobra.Command {
	clusterCmd := &cobra.Command{Use: "cluster"}
	clusterCmd.AddCommand(getUseCmd())
	return clusterCmd
}
```

Command-line usage:

```bash
# Switch to a local k3d cluster
openframe cluster use openframe-dev

# Switch to an openframe-managed GKE cluster
openframe cluster use my-gke

# Switch to an externally discovered GKE/EKS cluster
openframe cluster use tenant-cluster-1

# Interactive selection when no name is given
openframe cluster use
```
