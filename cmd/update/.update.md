## update.go

Implements the `openframe update` command, which checks for and installs newer CLI releases, replacing the running binary in place with checksum verification. Supports updating to the latest release, switching to a specific version, checking availability without changes, and rolling back to the previous version.

### Key Components

- **`GetUpdateCmd(currentVersion string) *cobra.Command`** — Builds the root `update` command tree with `--yes` and `--force` flags, and registers the `check` and `rollback` subcommands.
- **`newCheckCmd(current string) *cobra.Command`** — Implements `openframe update check`, reporting update availability without modifying anything. Supports `--output text|json|yaml`.
- **`newRollbackCmd(current string) *cobra.Command`** — Implements `openframe update rollback`, reverting to the previously installed binary offline (no download).
- **`run(ctx, current, target string, assumeYes, force bool) error`** — Core update flow: checks for updates, prompts for confirmation (unless `--yes`), then applies the update within a 15-minute timeout.
- **`runRollback(ctx, current string, assumeYes bool) error`** — Reverts to the binary retained from the last successful update.
- **`reportStatus(cmd, st) error`** — Renders update status as text, JSON, or YAML.
- **`validateOutputFormat(format string) error`** — Validates the `--output` flag value; shared by `check` and `reportStatus` to keep error messages consistent.

Relies on `internal/shared/selfupdate` (`Updater`, `Client`, `Status`, `PreviousVersion`, `ChangeVerb`) for the update/rollback logic and `internal/shared/ui`/`spinner` for prompts and progress feedback.

## Usage Example

```go
package main

import (
	"os"

	"github.com/flamingo-stack/openframe-cli/internal/commands/update"
	"github.com/spf13/cobra"
)

func main() {
	root := &cobra.Command{Use: "openframe"}
	root.AddCommand(update.GetUpdateCmd("v1.3.0"))
	if err := root.Execute(); err != nil {
		os.Exit(1)
	}
}
```

Command-line usage:

```bash
openframe update             # update to the latest release
openframe update v1.4.0      # switch to a specific release
openframe update check -o json  # check availability, machine-readable output
openframe update rollback -y # revert to previous version, no prompt
```
