# update.go

Implements the `openframe update` command, which checks for newer CLI releases and replaces the running binary in place with checksum verification, backup/rollback support, and multiple output formats.

## Key Components

- **`GetUpdateCmd(currentVersion string) *cobra.Command`** — Builds the top-level `update` command tree, supporting three modes: update to latest, switch to a specific version, or subcommands `check` and `rollback`. Accepts `--yes`/`-y` (skip confirmation) and `--force` (reinstall even if up to date).
- **`newCheckCmd(current string) *cobra.Command`** — Implements `openframe update check`, which reports update availability without making changes. Supports `--output`/`-o` for `text`, `json`, or `yaml`.
- **`newRollbackCmd(current string) *cobra.Command`** — Implements `openframe update rollback`, reverting to the previously installed binary offline (no network access).
- **`run(ctx, current, target, assumeYes, force) error`** — Core update flow: checks for updates, prompts for confirmation (unless `--yes`), then downloads and applies the release with a 15-minute timeout.
- **`runRollback(ctx, current, assumeYes) error`** — Core rollback flow: confirms with the user, then restores the previously saved binary via `selfupdate.Updater.Rollback`.
- **`reportStatus(cmd, st) error`** — Renders a `selfupdate.Status` as text, JSON, or YAML.
- **`validateOutputFormat(format string) error`** — Single source of truth for validating the `--output` flag, used both as a pre-flight check (before network calls) and as the renderer's fallback.

## Usage Example

```go
package main

import (
	"github.com/flamingo-stack/openframe-cli/internal/commands/update"
	"github.com/spf13/cobra"
)

func main() {
	rootCmd := &cobra.Command{Use: "openframe"}
	rootCmd.AddCommand(update.GetUpdateCmd("v1.3.0"))
	_ = rootCmd.Execute()
}
```

Typical CLI usage:

```bash
openframe update             # update to the latest release
openframe update v1.4.0      # switch to a specific release (up or down)
openframe update check -o json  # check availability, machine-readable output
openframe update rollback -y # revert to the previous version, no prompt
```

Automatic background updates can be enabled by setting `OPENFRAME_AUTO_UPDATE=1`, which checks once daily, skips major version bumps, and never runs in CI or non-interactive shells.
