# prerequisites.go

Defines the `openframe prerequisites` CLI command, which lets users check and install the OS-level tools required by OpenFrame (Docker, k3d, helm, terraform, AWS CLI, gcloud, etc.), scoped to the selected cluster type.

## Key Components

- **`GetPrerequisitesCmd()`** - Builds the root `prerequisites` cobra command (aliases: `prereq`, `prereqs`) and attaches the `check` and `install` subcommands.
- **`addTypeFlag(cmd, clusterType)`** - Registers the shared `--type`/`-t` flag (default `k3d`, supports `eks`, `gke`, and aliases `aws`/`gcp`), mirroring the flag used on `cluster create`.
- **`installCommandFor(clusterType)`** - Builds the suggested recovery command shown after a failed check, preserving the non-default `--type` so users don't accidentally reinstall the wrong toolset.
- **`checkCmd()`** - Returns the `check` subcommand, which reports installed/missing prerequisites for the selected cluster type without making changes. Exits with an error listing the install command if anything is missing.
- **`installCmd()`** - Returns the `install` subcommand, which attempts to install missing prerequisites automatically on macOS/Linux, or warns and prints manual install links on unsupported OSes.
- **`printResult(res fw.Result)`** - Renders a user-friendly, colorized summary (via `pterm`) of satisfied, installed, and missing prerequisites, including docs links and error details.

## Usage Example

```go
import "github.com/flamingo-stack/openframe-cli/internal/commands/prerequisites"

func main() {
	rootCmd := &cobra.Command{Use: "openframe"}
	rootCmd.AddCommand(prerequisites.GetPrerequisitesCmd())
	_ = rootCmd.Execute()
}
```

Corresponding CLI usage:

```bash
# Check prerequisites for the default k3d cluster type
openframe prerequisites check

# Check prerequisites for an EKS cluster
openframe prerequisites check --type eks

# Install missing prerequisites for GKE
openframe prerequisites install --type gke
```
