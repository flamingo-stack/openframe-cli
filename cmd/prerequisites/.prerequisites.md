# prerequisites.go

Implements the `openframe prerequisites` command, which lets users check and install the tools OpenFrame needs before creating a cluster (Docker, k3d, helm, terraform, AWS CLI, gcloud, etc.), scoped to a specific cluster type via `--type`.

## Key Components

- **`GetPrerequisitesCmd()`** - Builds the top-level `prerequisites` (aliases: `prereq`, `prereqs`) Cobra command and registers its `check` and `install` subcommands.
- **`addTypeFlag(cmd, *string)`** - Registers the shared `--type`/`-t` flag (default `k3d`), matching the flag used by `cluster create` for consistency.
- **`installCommandFor(clusterType)`** - Builds the recovery command hint shown after a failed check, preserving the `--type` value (unless it's the default `k3d`).
- **`checkCmd()`** - Returns the `check` subcommand: reports installed/missing tools for the resolved cluster type without making any changes; exits with an error listing missing prerequisites.
- **`installCmd()`** - Returns the `install` subcommand: attempts to auto-install missing tools on macOS/Linux, or warns and prints manual install links on unsupported OSes (e.g. Windows).
- **`printResult(res fw.Result)`** - Renders a human-friendly, colorized (via `pterm`) summary of satisfied, installed, and missing prerequisites, including doc links and error reasons.

## Usage Example

```go
import (
	"github.com/spf13/cobra"
	"github.com/flamingo-stack/openframe-cli/internal/prerequisites"
)

func main() {
	rootCmd := &cobra.Command{Use: "openframe"}
	rootCmd.AddCommand(prerequisites.GetPrerequisitesCmd())
	rootCmd.Execute()
}
```

Typical CLI usage:

```bash
# Report status of tools needed for the default k3d cluster type
openframe prerequisites check

# Check prerequisites for an EKS cluster
openframe prerequisites check --type eks

# Install missing tools for a GKE cluster (macOS/Linux only)
openframe prerequisites install --type gke
```

Both subcommands rely on `models.ParseClusterType` to normalize `--type` (supporting aliases like `aws`/`gcp`) and `clusterprereq.SetForClusterType` to resolve the required tool set before delegating to the shared `fw.Runner` from `internal/prerequisites`.
