Entry point for the OpenFrame CLI application. Executes the root command and handles error reporting and exit code propagation.

## Key Components

- **`main()`** — Calls `cmd.Execute()` and manages error output. Suppresses duplicate error messages for errors already handled via `AlreadyHandledError` sentinel, printing unhandled errors to `stderr`.
- **`exitCode()`** — Extracts the original exit code from a `CommandError` (failed external process) if it falls within a valid Unix range (1–255), falling back to `1` for all other errors.

## Usage Example

```go
// The binary is invoked directly; no public API is exported.
// Error flow example:

if err := cmd.Execute(); err != nil {
    var handled *sharederrors.AlreadyHandledError
    if !stderrors.As(err, &handled) {
        fmt.Fprintf(os.Stderr, "Error: %v\n", err)
    }
    os.Exit(exitCode(err)) // preserves exit code fidelity for automation
}
```

## Error Handling Strategy

| Error Type | Behavior |
|---|---|
| `AlreadyHandledError` | Silent exit — error already displayed upstream |
| `CommandError` (exit 1–255) | Exits with the original process exit code |
| All other errors | Prints to `stderr`, exits with code `1` |
