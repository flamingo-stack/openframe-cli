Provides secret redaction utilities for sanitizing sensitive values (credentials, tokens) from log and debug output before printing.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `RegisterSecret` | `func(string)` | Registers a sensitive value for redaction; ignores strings shorter than 4 characters |
| `ClearSecrets` | `func()` | Removes all registered secrets; intended for test teardown |
| `Redact` | `func(string) string` | Scrubs all registered secrets and URL-embedded credentials from a string |
| `urlCredentialPattern` | `*regexp.Regexp` | Regex that matches `user:pass@` segments in URLs to catch unregistered inline credentials |
| `redactionMarker` | `const string` | Replacement token (`***`) substituted in place of redacted values |

## Usage Example

```go
package main

import (
    "fmt"
    "github.com/flamingo-stack/openframe-cli/internal/redact"
)

func main() {
    redact.RegisterSecret("supersecrettoken")
    redact.RegisterSecret("mypassword")

    // Redact explicit secrets
    cmd := "helm upgrade --set auth.token=supersecrettoken --set pass=mypassword"
    fmt.Println(redact.Redact(cmd))
    // Output: helm upgrade --set auth.token=*** --set pass=***

    // Redact URL-embedded credentials (no explicit registration needed)
    url := "https://user:mypassword@registry.example.com/charts"
    fmt.Println(redact.Redact(url))
    // Output: https://user:***@registry.example.com/charts
}
```

## Notes

- Longer secrets are replaced before shorter ones, preventing a secret that is a substring of another from being partially unmasked.
- URL credential scrubbing via `urlCredentialPattern` runs unconditionally, catching tokens that were never explicitly registered.
- Thread-safe via `sync.RWMutex`; safe to call `RegisterSecret` and `Redact` concurrently.
