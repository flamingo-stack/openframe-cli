Handles automatic installation of the OpenFrame binary inside WSL (Windows Subsystem for Linux), supporting both release downloads with full trust-chain verification and local dev/CI binary injection.

## Key Components

- **`isReleaseVersion(version string) bool`** — Determines if a version string represents a published release (clean semver) versus a dev/snapshot build.
- **`stdinInstallScript() string`** — Generates a bash script that installs an OpenFrame binary streamed via stdin into `~/.openframe/bin` inside WSL.
- **`localInstallScript(windowsPath string) string`** — Generates a bash script that copies a local Windows-path binary into WSL using `wslpath`.
- **`ensureOpenframeInWSL(version, goarch string) error`** — Orchestrates the full install flow: checks if binary is already present, handles `OPENFRAME_WSL_BINARY` dev override, or auto-downloads a verified release.
- **`installOpenframeInWSL(version, goarch string) error`** — Downloads and cosign/SHA256-verifies the Linux release binary on the Windows side via `selfupdate.FetchVerifiedLinuxBinary`, then streams it into WSL via stdin.
- **`installLocalBinaryInWSL(windowsPath string) error`** — Copies a local Linux binary into WSL for dev/CI use.
- **`shellSingleQuote(s string) string`** — Safely single-quotes a string for embedding in bash scripts.
- **`localBinaryEnv`** (`OPENFRAME_WSL_BINARY`) — Environment variable override for dev/CI to inject a local binary instead of downloading a release.

## Usage Example

```go
// Auto-install the matching Linux release into WSL (called during launcher startup)
err := ensureOpenframeInWSL("1.4.2", "amd64")
if err != nil {
    // Falls back to showing manual installation guidance
    log.Fatal(err)
}

// Dev/CI: set OPENFRAME_WSL_BINARY=C:\builds\openframe-linux-amd64
// ensureOpenframeInWSL will copy that binary into WSL instead of downloading
```

> **Security note:** The release path verifies the binary via cosign identity and SHA256 on the Windows side before it enters WSL — no unverified bytes are executed inside the distro.
