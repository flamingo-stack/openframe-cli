Handles transparent forwarding of the OpenFrame CLI from native Windows processes into a WSL2 Linux environment, where the Kubernetes/Docker cluster tooling operates natively.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ShouldForward()` | `func bool` | Returns `true` when running on Windows without `OPENFRAME_NO_WSL_FORWARD` set |
| `Forward(version, args)` | `func (int, error)` | Re-executes `openframe <args>` inside WSL, auto-installing the binary if missing |
| `CommandAvailable(binary)` | `func bool` | Checks if a command exists on `PATH` inside the target WSL distro (5s timeout) |
| `BinaryInWSL` | `const string` | Expected executable name (`"openframe"`) inside WSL |

**Environment Variables**

| Variable | Purpose |
|----------|---------|
| `OPENFRAME_WSL_DISTRO` | Targets a specific WSL distro; defaults to the WSL default |
| `OPENFRAME_NO_WSL_FORWARD` | Disables forwarding and runs natively (unsupported) |
| `GITHUB_TOKEN` / `OPENFRAME_GITHUB_TOKEN` | Forwarded into WSL via `WSLENV` |

## Usage Example

```go
// Typical entry point in main()
if wsllauncher.ShouldForward() {
    code, err := wsllauncher.Forward(version, os.Args[1:])
    if err != nil {
        fmt.Fprintln(os.Stderr, err)
    }
    os.Exit(code)
}

// Check if docker is available in WSL (used by prerequisite checks)
if !wsllauncher.CommandAvailable("docker") {
    fmt.Fprintln(os.Stderr, "docker not found in WSL")
}
```

> **Note:** The Linux build (`runtime.GOOS == "linux"`) never forwards, preventing infinite recursion. Only `Forward` can auto-install the matching release; use `OPENFRAME_WSL_DISTRO` when your distro isn't the WSL default (list with `wsl -l -q`).
