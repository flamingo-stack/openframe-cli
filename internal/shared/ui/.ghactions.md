Provides GitHub Actions workflow-command helpers for the `ui` package, enabling structured CI output such as foldable log groups, error/warning annotations, and Step Summary entries. All functions are safe no-ops when run outside a GitHub Actions job, so callers can invoke them unconditionally regardless of execution environment.

## Key Components

- **`InGitHubActions() bool`** — Detects whether the process is running inside a GitHub Actions job (checks `GITHUB_ACTIONS` env var).
- **`GroupStart(title string)`** / **`GroupEnd()`** — Open/close a foldable `::group::` log section in the Actions log viewer.
- **`ErrorAnnotation(title, message string)`** — Emits an `::error::` workflow command, surfaced in the job summary and PR checks.
- **`WarningAnnotation(title, message string)`** — Emits a `::warning::` workflow command, similarly surfaced.
- **`AppendStepSummary(markdown string)`** — Appends a markdown fragment to the file referenced by `$GITHUB_STEP_SUMMARY`, rendered in the job's Step Summary panel. Fails silently if the file is missing or unwritable.
- **`escapeAnnotationData` / `escapeAnnotationProperty`** — Internal helpers that percent-encode reserved characters (`%`, `\r`, `\n`, and for properties also `:`/`,`) per the Actions workflow-command escaping rules.

## Usage Example

```go
package main

import "github.com/flamingo-stack/openframe-cli/internal/ui"

func main() {
	ui.GroupStart("Build step")
	defer ui.GroupEnd()

	if err := runBuild(); err != nil {
		ui.ErrorAnnotation("Build failed", err.Error())
		return
	}

	ui.WarningAnnotation("Deprecated flag", "the --legacy flag will be removed in v2")
	ui.AppendStepSummary("## Build Result\n\n✅ Build completed successfully")
}

func runBuild() error {
	// build logic
	return nil
}
```

When executed locally (outside GitHub Actions), all calls become no-ops, so the same code path works in both CI and local development without conditional checks.
