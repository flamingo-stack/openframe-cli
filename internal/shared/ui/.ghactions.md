Provides helper functions for emitting GitHub Actions workflow commands (log groups, error/warning annotations, and step summaries). All functions are safe no-ops when run outside a GitHub Actions job, so callers can use them unconditionally without environment checks.

## Key Components

- **`InGitHubActions() bool`** — Detects whether the process is running inside a GitHub Actions job by checking the `GITHUB_ACTIONS` environment variable.
- **`GroupStart(title string)`** / **`GroupEnd()`** — Open and close a foldable `::group::` log section in the Actions log viewer.
- **`ErrorAnnotation(title, message string)`** — Emits an `::error::` workflow command, surfacing a failure in the job summary and PR checks.
- **`WarningAnnotation(title, message string)`** — Emits a `::warning::` workflow command for non-fatal issues.
- **`AppendStepSummary(markdown string)`** — Appends a markdown fragment to the file referenced by `GITHUB_STEP_SUMMARY`, rendering it in the job's Step Summary panel. Fails silently if the file is missing or unwritable.
- **`escapeAnnotationData` / `escapeAnnotationProperty`** — Internal helpers that percent-encode special characters (`%`, `\r`, `\n`, and for properties `:` and `,`) per the Actions workflow-command spec.

## Usage Example

```go
package main

import "yourmodule/ui"

func main() {
	ui.GroupStart("Build step")
	defer ui.GroupEnd()

	if err := runBuild(); err != nil {
		ui.ErrorAnnotation("Build failed", err.Error())
		ui.AppendStepSummary("## ❌ Build failed\n\nSee logs above for details.")
		return
	}

	ui.WarningAnnotation("Deprecated flag", "The --legacy flag will be removed in v2.0")
	ui.AppendStepSummary("## ✅ Build succeeded")
}

func runBuild() error {
	// build logic
	return nil
}
```

These calls are safe to leave in local/CI-agnostic code paths — outside of GitHub Actions, `InGitHubActions()` returns `false` and every function becomes a no-op.
