Provides helpers for emitting GitHub Actions workflow commands (log groups, error/warning annotations, and Step Summary output). All functions are no-ops when the process isn't running inside a GitHub Actions job, so callers can invoke them unconditionally regardless of execution environment.

## Key Components

- **`InGitHubActions() bool`** — Detects whether the current process is running inside a GitHub Actions job by checking the `GITHUB_ACTIONS` environment variable.
- **`GroupStart(title string)` / `GroupEnd()`** — Open and close a foldable `::group::` log section in the Actions UI.
- **`ErrorAnnotation(title, message string)`** — Emits an `::error::` workflow command, surfaced in the job summary and on PRs.
- **`WarningAnnotation(title, message string)`** — Emits a `::warning::` workflow command, similarly surfaced.
- **`AppendStepSummary(markdown string)`** — Appends a markdown fragment to the file referenced by `$GITHUB_STEP_SUMMARY`, rendering rich content in the job's Step Summary panel. Best-effort: silently skips on missing file or write errors.
- **`escapeAnnotationData` / `escapeAnnotationProperty`** — Internal helpers that percent-encode special characters (`%`, `\r`, `\n`, and for properties also `:`, `,`) per the Actions runner's workflow-command escaping rules.

## Usage Example

```go
package main

import "github.com/flamingo-stack/openframe-cli/internal/ui"

func runStage() {
    ui.GroupStart("Build stage")
    defer ui.GroupEnd()

    if err := doWork(); err != nil {
        ui.ErrorAnnotation("Build failed", err.Error())
        ui.AppendStepSummary("### ❌ Build failed\n\nSee logs above for details.")
        return
    }

    ui.WarningAnnotation("Deprecation notice", "Old config format detected")
    ui.AppendStepSummary("### ✅ Build succeeded")
}
```

Outside of GitHub Actions (e.g., local development), all calls are silent no-ops, making these helpers safe to sprinkle throughout CLI stages without environment checks.
