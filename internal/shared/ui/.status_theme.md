## Overview

`status_theme.go` re-themes pterm's package-level status printers (`Info`, `Warning`, `Error`, `Success`, `Debug`) so every call site across the CLI prints with consistent, context-aware styling — quiet glyph prefixes for interactive terminals, and lowercase, column-aligned, grep-friendly word tags for non-interactive output (CI, pipes, `--plain`). It also wires GitHub Actions annotations for warnings.

## Key Components

- **`ApplyStatusPrefixTheme()`** — Mutates the shared pterm printers in place. Detects interactive vs. non-interactive mode (via `IsTerminal()`/`IsPlain()`), applies glyphs from `Glyphs()` for interactive terminals, or column-aligned colored word tags otherwise. In GitHub Actions (and unless `--silent`), tees `pterm.Warning`'s writer through an annotation writer so warnings surface as `::warning::` job annotations. Errors are intentionally excluded here since a richer `::error::` annotation is emitted elsewhere by the shared error handler.
- **`annotationWriter`** — An `io.Writer` wrapper that tees printed output into GitHub Actions workflow commands (`::warning::`/`::error::`). Strips ANSI codes and the printer's own prefix/severity tag before annotating, and deduplicates identical messages per process (since GitHub Actions caps annotations per step at 10, and repeating messages would flood the log).
- **`newAnnotationWriter(inner io.Writer, level string) io.Writer`** — Constructor for `annotationWriter`; defaults `inner` to `os.Stdout` if nil.
- **`ansiSeq`** — Package-level regexp used to strip ANSI escape sequences from captured output before annotation.

## Usage Example

```go
package main

import "yourmodule/ui"

func main() {
    // Apply --plain/--silent flags first, then theme the printers once,
    // early in startup — mirrors ApplyGlobalOutputFlags ordering.
    ui.ApplyGlobalOutputFlags()
    ui.ApplyStatusPrefixTheme()

    // From here on, every pterm.Info/Warning/Error/Success/Debug call
    // across the codebase uses the themed prefixes automatically.
    pterm.Warning.Println("ArgoCD app stuck in Progressing state")
}
```

This function is called once during CLI startup (typically inside `ApplyGlobalOutputFlags`) and requires no further invocation — subsequent calls to pterm's status printers throughout the codebase automatically pick up the new theme.
