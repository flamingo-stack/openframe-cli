Provides terminal UI helper functions for displaying user-friendly messages when operations fail or no resources are available, using `pterm` for styled, colorized output.

## Key Components

| Name | Type | Description |
|---|---|---|
| `ShowNoResourcesMessage` | Function | Displays a styled warning box when no resources exist, with hints for create/list commands |
| `ShowOperationError` | Function | Displays a formatted error message with optional numbered troubleshooting steps |
| `TroubleshootingTip` | Struct | Holds a `Description` and `Command` pair used in error troubleshooting output |

## Usage Example

```go
// Show empty-state message when no environments are found
ui.ShowNoResourcesMessage(
    "environments",
    "deploy",
    "openframe env create",
    "openframe env list",
)

// Show a structured error with troubleshooting tips
ui.ShowOperationError(
    "connect",
    "prod-server",
    err,
    []ui.TroubleshootingTip{
        {
            Description: "Check your connection:",
            Command:     "openframe status",
        },
        {
            Description: "Verify credentials:",
            Command:     "openframe auth login",
        },
    },
)
```

## Notes

- `ShowNoResourcesMessage` renders a bordered `pterm` box with color-coded commands: green for create, cyan for list, gray for `--help`
- `ShowOperationError` attempts a table layout for tips and falls back to plain-text if rendering fails
- Both functions append a trailing blank line for consistent terminal spacing
