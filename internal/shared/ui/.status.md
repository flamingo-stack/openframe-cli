Provides a color-coding utility for terminal status output, mapping service/container state strings to `pterm` color functions.

## Key Components

### `GetStatusColor(status string) func(string) string`

Returns a `pterm`-based color function based on the provided status string (case-insensitive):

| Status | Color |
|--------|-------|
| `running`, `ready` | Green |
| `stopped`, `not ready`, `pending` | Yellow |
| `error`, `failed`, `unhealthy` | Red |
| *(any other)* | Gray |

## Usage Example

```go
colorFn := ui.GetStatusColor("running")
fmt.Println(colorFn("running")) // prints "running" in green

colorFn = ui.GetStatusColor("failed")
fmt.Println(colorFn("failed")) // prints "failed" in red

colorFn = ui.GetStatusColor("unknown")
fmt.Println(colorFn("unknown")) // prints "unknown" in gray
```
