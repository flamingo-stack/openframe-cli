## osc.go

Implements terminal OSC (Operating System Command) escape sequence helpers for clickable hyperlinks and desktop notifications, with safe fallbacks for non-interactive or unsupported terminals.

## Key Components

- **`hyperlinksSupported() bool`** — Unexported helper that determines whether the current terminal is known to render OSC 8 hyperlinks. Uses an allowlist approach (checking `TERM_PROGRAM`, `KONSOLE_VERSION`, `VTE_VERSION`) rather than assuming support, since unsupported terminals may print raw escape bytes instead of a link.
- **`Hyperlink(url, text string) string`** — Renders `text` as a clickable OSC 8 hyperlink when the terminal supports it. Falls back to plain text with the URL appended in parentheses when unsupported, or to the bare URL if no distinct text is given.
- **`Notify(message string)`** — Emits an OSC 9 desktop notification (supported by iTerm2, WezTerm, ghostty, Konsole) plus a BEL character, useful for alerting users after long-running operations complete. No-op when output isn't a terminal, `--silent` mode is active, or `TERM=dumb`.

## Usage Example

```go
package main

import "openframe-cli/internal/ui"

func main() {
    // Render a clickable link (or plain text fallback)
    link := ui.Hyperlink("https://openframe.ai", "OpenFrame Docs")
    println(link)

    // Notify the user after a long operation
    doLongInstall()
    ui.Notify("Installation complete!")
}
```

Both functions are safe to call unconditionally: they detect terminal capabilities internally and silently degrade to plain output (or no output, for `Notify`) when running in non-interactive contexts such as CI logs, pipes, or redirected output.
