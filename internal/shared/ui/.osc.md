## osc.go

Provides terminal OSC (Operating System Command) escape sequence helpers for clickable hyperlinks and desktop notifications. It safely degrades to plain text or no-ops when the output isn't an interactive terminal, preventing raw escape codes from polluting logs or piped output.

## Key Components

- **`hyperlinksSupported() bool`** — Internal helper that checks whether the current terminal is known to render OSC 8 hyperlinks correctly. Uses an allowlist approach (`iTerm.app`, `WezTerm`, `ghostty`, `vscode`, `Hyper`, `Tabby`, Konsole, VTE-based terminals) rather than assuming support, since unsupported terminals may print raw escape bytes.
- **`Hyperlink(url, text string) string`** — Renders `text` as a clickable OSC 8 hyperlink when the terminal supports it. Falls back to plain text with the URL appended in parentheses when unsupported, or just the URL if no separate text is given.
- **`Notify(message string)`** — Sends an OSC 9 desktop notification plus a BEL character to alert users when a long-running operation finishes. No-ops when output isn't a terminal, `--silent` mode is active, or `TERM=dumb`.

## Usage Example

```go
package main

import "openframe-cli/internal/ui"

func main() {
    // Render a clickable link (falls back gracefully on unsupported terminals)
    link := ui.Hyperlink("https://openframe.ai", "OpenFrame Docs")
    fmt.Println("Learn more:", link)

    // Notify the user after a long operation completes
    doLongInstall()
    ui.Notify("OpenFrame installation complete")
}
```

Both functions rely on terminal-detection logic (`isTerminalEnvironment()`) and silent-mode checks (`IsSilent()`) defined elsewhere in the `ui` package, ensuring consistent behavior across CLI commands that use interactive output.
