## osc.go

Provides terminal OSC (Operating System Command) escape sequence helpers for clickable hyperlinks (OSC 8) and desktop notifications (OSC 9), with safe fallback behavior for non-interactive or unsupported terminals.

## Key Components

- **`hyperlinksSupported() bool`** — Unexported helper that determines whether the current terminal is known to render OSC 8 hyperlinks correctly. Uses an allowlist approach (checking `TERM_PROGRAM`, `KONSOLE_VERSION`, `VTE_VERSION`) rather than assuming support, since printing raw escape codes on unsupported terminals is worse than a plain link.
- **`Hyperlink(url, text string) string`** — Renders `text` as a clickable OSC 8 hyperlink when the terminal supports it. Falls back to plain text (with the URL appended in parentheses if different from the text) when hyperlinks aren't supported.
- **`Notify(message string)`** — Emits an OSC 9 desktop notification plus a BEL character to alert the user when a long-running operation completes. No-op when output isn't a terminal, `--silent` mode is active, or `TERM=dumb`.

## Usage Example

```go
package main

import (
	"fmt"
	"openframe-cli/internal/ui"
)

func main() {
	// Render a clickable link (falls back to "text (url)" if unsupported)
	link := ui.Hyperlink("https://openframe.ai", "OpenFrame Docs")
	fmt.Println(link)

	// Notify the user after a long install completes
	doLongInstall()
	ui.Notify("OpenFrame installation complete")
}

func doLongInstall() {
	// ... lengthy operation ...
}
```

Both functions rely on `isTerminalEnvironment()` and `IsSilent()` (defined elsewhere in the `ui` package) to detect interactive terminals and respect silent/quiet flags, ensuring escape sequences never leak into logs, CI output, or piped commands.
