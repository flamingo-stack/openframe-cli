## heartbeat.go

Implements a periodic progress-message emitter for long-running, output-less operations in non-interactive sessions (CI, piped output, or `--non-interactive` mode). It serves as the non-animated counterpart to the interactive spinner, ensuring users don't mistake a slow operation for a hang when no TTY is available to render animation.

## Key Components

- **`Heartbeat`** — struct managing a background goroutine that periodically writes progress lines to a writer; supports safe, idempotent `Stop()`.
- **`StartHeartbeat(label string, interval time.Duration) *Heartbeat`** — public entry point. Starts emitting `"<label> (<elapsed>)"` to stderr every `interval`. Becomes a no-op when `ui.IsSilent()` or `ui.Animated()` is true (silent mode suppresses non-error output; animated mode already shows liveness via the spinner).
- **`startHeartbeat(w io.Writer, label string, interval time.Duration) *Heartbeat`** — injectable core used internally and in tests, allowing a custom writer and short interval instead of `os.Stderr` and the 30-second default.
- **`defaultHeartbeatInterval`** — 30 seconds, used when `interval <= 0`.
- **`(*Heartbeat).Stop()`** — signals the goroutine to stop and blocks until it exits, guaranteeing no further output after return. Safe to call multiple times and safe on a no-op `Heartbeat`.

## Usage Example

```go
import (
	"time"

	"github.com/flamingo-stack/openframe-cli/internal/shared/ui/spinner"
)

func installChart() error {
	hb := spinner.StartHeartbeat("Installing Helm chart", 15*time.Second)
	defer hb.Stop()

	// long-running, output-less operation (e.g., helm --wait)
	return runHelmInstall()
}
```

In CI or `--non-interactive` mode, this prints lines like:

```text
Installing Helm chart (15s elapsed)
Installing Helm chart (30s elapsed)
```

In an interactive/animated session or under `--silent`, `StartHeartbeat` returns a no-op instance, and `Stop()` remains safe to call unconditionally.
