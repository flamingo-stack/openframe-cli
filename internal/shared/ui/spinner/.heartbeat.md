## heartbeat.go

Provides a non-interactive, periodic progress indicator for long-running, output-less operations. It acts as the CI/non-TTY counterpart to the animated `Spinner`, emitting timestamped status lines to stderr so users don't mistake a quiet wait for a hang.

## Key Components

- **`Heartbeat`** – struct managing a background goroutine that emits progress messages until stopped. Uses `stop`/`done` channels and a `sync.Once` to guarantee safe, idempotent shutdown.
- **`StartHeartbeat(label string, interval time.Duration) *Heartbeat`** – public entry point. Returns a no-op `Heartbeat` when output is silent (`ui.IsSilent()`) or an animated spinner is active (`ui.Animated()`), avoiding duplicate or conflicting output. Otherwise writes to `os.Stderr`.
- **`startHeartbeat(w io.Writer, label string, interval time.Duration) *Heartbeat`** – injectable core used internally and by tests, allowing a custom writer and short interval for deterministic testing.
- **`(*Heartbeat) Stop()`** – stops the ticking goroutine and blocks until it fully exits, ensuring no message is emitted after `Stop` returns. Safe to call multiple times and on no-op instances.
- **`defaultHeartbeatInterval`** – default emission interval (30 seconds) used when `interval <= 0`.

## Usage Example

```go
package main

import (
	"time"

	"github.com/flamingo-stack/openframe-cli/internal/shared/ui/spinner"
)

func main() {
	hb := spinner.StartHeartbeat("Installing cluster components", 15*time.Second)
	defer hb.Stop()

	// Long-running, output-less operation (e.g., helm install --wait)
	performLongInstall()
}
```

In non-interactive or CI environments, this produces periodic lines like:

```text
Installing cluster components (15s elapsed)
Installing cluster components (30s elapsed)
```

No output is produced when `--silent` is set or when running in an animated interactive terminal, since the spinner already conveys liveness in that case.
