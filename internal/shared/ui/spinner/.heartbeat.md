## heartbeat.go

Implements a non-interactive progress indicator that periodically writes "still alive" messages to stderr during long-running, output-less operations. It complements the animated `Spinner` by providing liveness feedback in environments without a TTY (CI logs, piped output, `--non-interactive` mode), preventing users from mistakenly killing processes they assume have hung.

## Key Components

- **`Heartbeat`** - struct managing a background goroutine that emits periodic status lines; uses `stop`/`done` channels and `sync.Once` for safe, idempotent shutdown.
- **`StartHeartbeat(label string, interval time.Duration) *Heartbeat`** - public entry point; starts emitting `"<label> (<elapsed> elapsed)"` to stderr every `interval`. Automatically becomes a no-op under `--silent` or in an animated (interactive, non-`--plain`) session, since those cases either forbid output or already show liveness via the spinner.
- **`startHeartbeat(w io.Writer, label string, interval time.Duration) *Heartbeat`** - injectable core used internally and in tests, allowing a custom writer and short interval instead of stderr/`defaultHeartbeatInterval`.
- **`(*Heartbeat) Stop()`** - stops the ticking goroutine and blocks until it exits, guaranteeing no message is emitted after `Stop` returns. Safe to call multiple times and on a no-op `Heartbeat`.
- **`defaultHeartbeatInterval`** - default emission interval (30 seconds) used when no positive interval is supplied.

## Usage Example

```go
package main

import (
	"time"

	"github.com/flamingo-stack/openframe-cli/internal/shared/ui/spinner"
)

func installChart() {
	hb := spinner.StartHeartbeat("Installing Helm chart", 15*time.Second)
	defer hb.Stop()

	// long-running, output-less operation (e.g. helm --wait)
	runLongInstall()
}
```

In tests, use the injectable variant with a buffer and short interval to verify emitted output without waiting on real time.
