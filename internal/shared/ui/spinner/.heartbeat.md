Provides a periodic progress emitter for long-running, non-interactive operations, writing elapsed-time messages to stderr to prevent CI pipelines or piped sessions from appearing hung.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `Heartbeat` | struct | Holds the control channels and a `sync.Once` for safe shutdown |
| `defaultHeartbeatInterval` | const | Fallback tick rate (`30s`) when no interval is provided |
| `StartHeartbeat` | func | Public entry point; respects `--silent` mode and writes to `os.Stderr` |
| `startHeartbeat` | func | Injectable core used by tests; accepts any `io.Writer` and a custom interval |
| `(*Heartbeat).Stop` | method | Signals the goroutine to exit and blocks until it has fully stopped |

## Usage Example

```go
// Start a heartbeat before a long blocking call (e.g. helm --wait)
hb := spinner.StartHeartbeat("Waiting for deployment", 15*time.Second)
defer hb.Stop()

// Output on stderr every 15 s:
// Waiting for deployment (15s elapsed)
// Waiting for deployment (30s elapsed)
// ...

err := runHelmWait()
hb.Stop() // explicit stop before printing result (defer also safe)
```

## Behaviour Notes

- **Silent mode** (`--silent`): `StartHeartbeat` returns a no-op `Heartbeat`; `Stop` remains safe to call.
- **Interval ≤ 0**: falls back to `defaultHeartbeatInterval` (30 seconds).
- **Goroutine hygiene**: `Stop` closes the `stop` channel then drains `done`, so no stray emit can occur after `Stop` returns.
- **stdout safety**: all output goes to `stderr`, keeping stdout clean for machine-readable data.
