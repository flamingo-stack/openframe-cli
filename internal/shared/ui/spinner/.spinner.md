# spinner.go

Provides a race-free terminal status spinner that replaces pterm's built-in `SpinnerPrinter`, whose animation goroutine races with its own `Stop()` under `go test -race`. This implementation owns the animation goroutine directly and guarantees `Stop()`/`finish()` **joins** that goroutine before returning, ensuring no shared state is read after teardown. All mutable state is protected by a mutex.

## Key Components

- **`Spinner`** — Core struct managing spinner state, output writer, TTY detection, and animation lifecycle.
- **`New()`** — Creates a spinner writing to stdout, auto-detecting TTY and respecting `--silent`/`--plain` global UI modes.
- **`NewWithWriter(w io.Writer)`** — Creates a spinner with a custom writer (useful for tests).
- **`Start(text string)`** (package function) — Convenience one-liner: `New()` + `.Start(text)`.
- **`(*Spinner).Start(text string)`** — Begins animation with the given text; updates text if already running.
- **`(*Spinner).UpdateText(text string)`** — Changes the displayed text while running.
- **`(*Spinner).WithTimer()`** — Enables elapsed-time display next to the spinner text.
- **`(*Spinner).Stop()`** — Stops the spinner with no final message.
- **`(*Spinner).Success/Fail/Warning/Info(text string)`** — Stops the spinner and prints a styled pterm final line.
- **`AnyActive() bool`** — Reports whether any spinner is currently running process-wide, allowing other line-rewriting UI (e.g. progress bars) to coordinate cursor usage.

## Usage Example

```go
package main

import (
    "time"

    "github.com/flamingo-stack/openframe-cli/internal/shared/ui/spinner"
)

func main() {
    s := spinner.Start("Connecting to cluster")
    s.WithTimer()

    time.Sleep(2 * time.Second)
    s.UpdateText("Fetching resources")

    time.Sleep(1 * time.Second)

    if err := doWork(); err != nil {
        s.Fail("Failed to fetch resources: " + err.Error())
        return
    }
    s.Success("Resources fetched successfully")
}

func doWork() error { return nil }
```

Check whether another spinner is active before starting overlapping UI:

```go
if !spinner.AnyActive() {
    // safe to draw a progress bar on the current line
}
```
