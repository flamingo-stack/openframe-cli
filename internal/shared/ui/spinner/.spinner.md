# spinner.go

Implements a race-free terminal spinner used to show progress for long-running CLI operations, replacing pterm's `SpinnerPrinter` whose internal animation goroutine races with its own `Stop()` under `go test -race`. The spinner owns its animation goroutine directly and guarantees `Stop()`/`finish()` joins that goroutine before returning, so no shared state is read after teardown. It also respects the CLI's `--silent` and `--plain` output modes and coordinates with other line-rewriting UI via a process-wide active counter.

## Key Components

- **`Spinner`** — struct holding animation state, protected by a mutex; the zero value is unusable, so it must be created via `New()`, `NewWithWriter()`, or `Start()`.
- **`New() *Spinner`** — creates a spinner writing to stdout, auto-detecting TTY status and honoring `ui.IsSilent()`/`ui.IsPlain()`.
- **`NewWithWriter(w io.Writer) *Spinner`** — creates a spinner writing to a custom writer (useful for tests), never animated.
- **`Start(text string) *Spinner`** — package-level helper that creates and immediately starts a spinner.
- **`(*Spinner).Start(text string)`** — begins animation in a background goroutine; safe to call again to just update text.
- **`(*Spinner).UpdateText(text string)`** — updates the displayed text while running.
- **`(*Spinner).WithTimer() *Spinner`** — enables elapsed-time display next to the spinner text.
- **`(*Spinner).Stop() / Success() / Fail() / Warning() / Info()`** — stop the spinner, optionally printing a styled final line (pterm-based success/error/warning/info boxes).
- **`AnyActive() bool`** — reports whether any spinner is currently running process-wide, letting other UI (e.g., progress bars) yield the terminal line.

## Usage Example

```go
package main

import (
	"time"

	"github.com/flamingo-stack/openframe-cli/internal/shared/ui/spinner"
)

func main() {
	// One-line create + start
	sp := spinner.Start("Downloading cluster image")
	sp.WithTimer()

	// Do work...
	time.Sleep(2 * time.Second)
	sp.UpdateText("Verifying checksum")
	time.Sleep(1 * time.Second)

	if err := doWork(); err != nil {
		sp.Fail("Download failed: " + err.Error())
		return
	}
	sp.Success("Download complete")
}

func doWork() error { return nil }
```

Check `spinner.AnyActive()` before writing your own line-rewriting output (e.g., a progress bar) to avoid contention with a running spinner.
