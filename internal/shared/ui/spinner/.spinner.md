A race-free terminal spinner that replaces `pterm`'s `SpinnerPrinter`. It owns its animation goroutine and guarantees `Stop()` joins (waits for) the goroutine before returning, eliminating the data race flagged by `go test -race`.

## Key Components

| Symbol | Description |
|---|---|
| `Spinner` | Core struct; all mutable state protected by `sync.Mutex` |
| `New()` | Creates a spinner writing to stdout; auto-detects TTY and `--silent` mode |
| `NewWithWriter(w)` | Creates a spinner with a custom `io.Writer`; useful for tests |
| `Start(text)` | Package-level helper — creates and starts a spinner in one call |
| `(s) Start(text)` | Begins animation; calling again on a running spinner updates the text |
| `(s) UpdateText(text)` | Thread-safe text update while the spinner is running |
| `(s) Stop()` | Stops with no final message |
| `(s) Success/Fail/Warning/Info(text)` | Stops and prints a styled final line via `pterm` |
| `(s) WithTimer()` | Enables elapsed time display next to spinner text |

## Usage Example

```go
// Simple one-liner
s := spinner.Start("Deploying resources...")
defer s.Fail("Deployment failed")

doWork()

s.Success("Deployed successfully")

// With elapsed timer
s := spinner.New().WithTimer()
s.Start("Installing dependencies...")
installDeps()
s.Success("Done")

// Custom writer (e.g. in tests)
var buf bytes.Buffer
s := spinner.NewWithWriter(&buf)
s.Start("Working...")
s.Stop()

// Update text mid-operation
s := spinner.Start("Connecting...")
s.UpdateText("Uploading...")
s.Success("Upload complete")
```

## Concurrency Design

The `animate` goroutine is the sole writer of frame output and exits only when `stopCh` is closed. `finish()` closes `stopCh` then blocks on `<-doneCh`, ensuring the goroutine has fully exited before the final styled line is written — no shared state is read after teardown.
