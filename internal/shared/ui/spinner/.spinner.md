# spinner.go

Provides a race-free terminal status spinner that replaces `pterm.SpinnerPrinter`, whose internal animation goroutine races with its own `Stop()` under `go test -race`. This implementation owns the animation goroutine directly and guarantees `Stop()` fully joins it before returning, ensuring no shared state is read after teardown. All mutable state is protected by a mutex.

## Key Components

- **`Spinner`** — Core struct managing animation state, TTY detection, and silent mode; zero value is not usable, must be created via `New()` or `NewWithWriter()`.
- **`New()`** — Creates a spinner writing to stdout, animated only on a real TTY; respects `--silent` (writes to `io.Discard`) and `--plain` (disables animation but keeps styled output) modes.
- **`NewWithWriter(w io.Writer)`** — Creates a spinner writing to a custom writer (useful for tests).
- **`Start(text string)`** — Package-level helper combining `New()` and `Start()` in one call.
- **`(*Spinner).Start(text string)`** — Begins animation with given text; idempotent if already running (just updates text).
- **`(*Spinner).UpdateText(text string)`** — Updates the displayed text while running.
- **`(*Spinner).WithTimer()`** — Enables elapsed-time display next to the spinner text.
- **`(*Spinner).Stop()` / `Success()` / `Fail()` / `Warning()` / `Info()`** — Stop the spinner and optionally print a styled final line via pterm printers.
- **`AnyActive() bool`** — Reports whether any spinner is currently running process-wide, allowing other line-rewriting UI (e.g. progress bars) to yield the terminal line.

## Usage Example

```go
package main

import (
	"time"

	"github.com/flamingo-stack/openframe-cli/internal/shared/spinner"
)

func main() {
	s := spinner.Start("Installing dependencies")
	s.WithTimer()

	// Simulate work
	time.Sleep(2 * time.Second)
	s.UpdateText("Finalizing setup")
	time.Sleep(1 * time.Second)

	if err := doWork(); err != nil {
		s.Fail("Installation failed: " + err.Error())
		return
	}
	s.Success("Installation complete")
}

func doWork() error { return nil }
```

Check `spinner.AnyActive()` before writing custom line-rewriting output to avoid cursor conflicts with an active spinner.
