Manages the `--silent` flag for the `ui` package, routing all non-error pterm output to `io.Discard` and signaling other UI components to suppress their own output.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `silent` | `var bool` | Package-level flag tracking whether silent mode is active |
| `SetSilent()` | `func` | Activates silent mode by redirecting non-error pterm printers to `io.Discard` |
| `IsSilent()` | `func bool` | Reports whether `--silent` was applied; consulted by components with their own writers |

## Usage Example

```go
// In the root command's PersistentPreRun hook:
func rootPersistentPreRun(cmd *cobra.Command, args []string) {
    if silentFlag {
        ui.SetSilent()
    }
}

// In a component that manages its own writer (e.g. a spinner):
func (s *Spinner) Done(msg string) {
    if ui.IsSilent() {
        return // suppress output that bypasses pterm's package-level printers
    }
    pterm.Success.WithWriter(s.out).Println(msg)
}
```

## Behavior Notes

- **Call once, early** — mutates pterm's package-level printers and is not reversible within a process
- **Error/Fatal printers are intentionally untouched** — failures are always surfaced regardless of the flag
- **Interactive prompts are intentionally untouched** — discarding their writer would cause a silent hang while still blocking on stdin
- **Components with their own writers must call `IsSilent()`** — `pterm.Success.WithWriter(customWriter)` overrides the `io.Discard` installed by `SetSilent`, so those paths must gate themselves manually
