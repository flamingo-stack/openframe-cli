## silent.go

Implements the CLI's `--silent`/`--verbose`/`--plain` output contract by mutating package-level `pterm` printers. It centralizes how global output flags affect all status output across the CLI, since Cobra only invokes the closest parent's `PersistentPreRunE`.

## Key Components

- **`ApplyGlobalOutputFlags(cmd *cobra.Command)`** — Reads `--silent`, `--plain`, and `--verbose` flags from the given command and applies their effects in order (color contract → silent → plain → verbose timestamps → status prefix theme). Must be called by any command group that defines its own `PersistentPreRunE`, since such hooks shadow the root's and would otherwise leave `--verbose`/`--silent` inert for that subtree.
- **`SetSilent()`** — Implements `--silent` by redirecting non-error `pterm` printers (`Info`, `Success`, `Warning`, `Debug`, and default box/table/header/section/text printers) to `io.Discard`. Error/Fatal printers and interactive prompts are left untouched intentionally.
- **`IsSilent() bool`** — Reports whether `--silent` is active. Components with their own writer (e.g., a spinner using `pterm.Success.WithWriter(s.out)`) must check this explicitly to honor silence.
- **`TimestampsActive() bool`** — Reports whether `--verbose` has enabled per-line timestamps, so long-running loops with their own embedded clock (e.g., an ArgoCD wait heartbeat) can avoid double-timestamping.
- **`silent`, `timestamped`** — Package-level state flags mutated once at startup and read elsewhere in the `ui` package.

## Usage Example

```go
func init() {
    rootCmd.PersistentFlags().Bool("silent", false, "suppress all output except errors")
    rootCmd.PersistentFlags().Bool("verbose", false, "enable debug output with timestamps")
    rootCmd.PersistentFlags().Bool("plain", false, "disable colored output")

    rootCmd.PersistentPreRunE = func(cmd *cobra.Command, args []string) error {
        ui.ApplyGlobalOutputFlags(cmd)
        return nil
    }
}

// Elsewhere, a component with its own writer must check IsSilent explicitly:
func (s *Spinner) Finish(msg string) {
    if ui.IsSilent() {
        return
    }
    pterm.Success.WithWriter(s.out).Println(msg)
}
```

**Note:** `SetSilent()` mutates `pterm`'s package-level printers globally and is meant to be called exactly once, early in the process lifecycle (root command's `PersistentPreRun`). It is not designed to be reversed within a running process.
