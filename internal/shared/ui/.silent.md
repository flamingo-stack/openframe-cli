# silent.go

Implements the CLI's global output-control contract (`--silent`, `--verbose`, `--plain`) by wiring cobra flag values into pterm's package-level printers. It centralizes the logic so any command group in the tree honors the root command's flags consistently, including timestamped log lines and CI-safe output suppression.

## Key Components

- **`ApplyGlobalOutputFlags(cmd *cobra.Command)`** — Entry point called from `PersistentPreRunE`. Reads `--silent`, `--plain`, and `--verbose` flags and applies them in order (color contract → silent → plain → verbose timestamps → status prefix theme). Must be called by every command group that defines its own `PersistentPreRunE`, since cobra only runs the closest parent's hook.
- **`SetSilent()`** — Redirects all non-error pterm printers (`Info`, `Success`, `Warning`, `Debug`, and default components) to `io.Discard`. Leaves `Error`/`Fatal` untouched so failures remain visible, and leaves interactive prompt printers untouched to avoid silent stdin hangs.
- **`IsSilent() bool`** — Reports whether `--silent` was applied. Components writing through their own custom writer (e.g., a spinner) must check this explicitly to respect the suppression contract.
- **`TimestampsActive() bool`** — Reports whether status printers already prepend a wall-clock timestamp (due to `--verbose`), so callers with their own embedded clock (e.g., a wait heartbeat) can avoid double-timestamping a line.
- **`silent`, `timestamped`** — Package-level state flags mutated once during flag application, read elsewhere in the `ui` package (e.g., logo rendering, spinners).

## Usage Example

```go
func init() {
    rootCmd.PersistentFlags().Bool("silent", false, "suppress non-error output")
    rootCmd.PersistentFlags().Bool("verbose", false, "enable debug output with timestamps")
    rootCmd.PersistentFlags().Bool("plain", false, "disable colored output")

    rootCmd.PersistentPreRunE = func(cmd *cobra.Command, args []string) error {
        ui.ApplyGlobalOutputFlags(cmd)
        return nil
    }
}

// Elsewhere, a component with its own writer must respect --silent manually:
func (s *Spinner) finish(msg string) {
    if ui.IsSilent() {
        return
    }
    pterm.Success.WithWriter(s.out).Println(msg)
}
```
