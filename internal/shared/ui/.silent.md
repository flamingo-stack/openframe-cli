This file implements the `--silent` and `--verbose` global output flag contract shared across all CLI commands, controlling which pterm printers emit output and whether status lines carry timestamps.

## Key Components

- **`ApplyGlobalOutputFlags(cmd *cobra.Command)`** — Entry point called from each command group's `PersistentPreRunE`. Reads `--silent`, `--plain`, and `--verbose` flags and applies them in order, with `--silent` taking precedence over `--verbose`. Must be called explicitly by any subtree that defines its own `PersistentPreRunE`, since Cobra only runs the closest parent's hook.
- **`SetSilent()`** — Redirects most package-level pterm printers (`Info`, `Success`, `Warning`, `Debug`, tables, boxes, headers, sections) to `io.Discard`. Leaves `Error`/`Fatal` printers and interactive prompts untouched.
- **`IsSilent() bool`** — Reports whether `--silent` is active. Components writing through their own writer (e.g., a spinner's `pterm.Success.WithWriter(s.out)`) must check this manually to honor silence.
- **`TimestampsActive() bool`** — Reports whether `--verbose` has installed timestamp writers on status printers, so long-running loops with their own embedded clock can avoid double-timestamping a line.
- **`silent`, `timestamped`** — Package-level state flags backing the above accessors.

## Usage Example

```go
func init() {
	rootCmd.PersistentFlags().Bool("silent", false, "suppress non-error output")
	rootCmd.PersistentFlags().Bool("verbose", false, "enable debug output with timestamps")
	rootCmd.PersistentFlags().Bool("plain", false, "disable colored output")

	rootCmd.PersistentPreRunE = func(cmd *cobra.Command, args []string) error {
		ui.ApplyGlobalOutputFlags(cmd)
		return nil
	}
}

// A subcommand group defining its OWN PersistentPreRunE must call this first,
// otherwise --verbose is silently inert for its whole subtree.
var deployCmd = &cobra.Command{
	Use: "deploy",
	PersistentPreRunE: func(cmd *cobra.Command, args []string) error {
		ui.ApplyGlobalOutputFlags(cmd)
		return nil
	},
}

// Components writing via a custom writer must check IsSilent() manually.
func printSpinnerResult(out io.Writer) {
	if ui.IsSilent() {
		return
	}
	pterm.Success.WithWriter(out).Println("done")
}
```
