# plain.go

Implements plain/sequential output mode support for the CLI's UI layer, ensuring output remains readable in non-interactive or logged contexts (e.g., `watch`, `script`, tmux panes, CI logs) by disabling cursor-rewriting animations while preserving color output where appropriate.

## Key Components

- **`SetPlain()`** — Enables plain mode process-wide (invoked from the global `--plain` flag hook).
- **`IsPlain()`** — Reports whether `--plain` mode is active.
- **`Animated()`** — Determines if in-place terminal animation (spinners, live areas) should be used; true only when running in an interactive TTY, not in plain mode, and not silent.
- **`ApplyColorContract()`** — Enforces the standard `NO_COLOR` / `CLICOLOR_FORCE` environment variable contract to control ANSI styling.
- **`NewTimestampWriter(w io.Writer) io.Writer`** — Wraps a writer so each line is prefixed with a `HH:MM:SS.mmm` timestamp, used for `--verbose` debug output correlation.
- **`timestampWriter`** — Internal `io.Writer` implementation backing `NewTimestampWriter`, tracking line-start state to prefix timestamps correctly across multiple `Write` calls.

## Usage Example

```go
import "github.com/flamingo-stack/openframe-cli/internal/ui" // adjust import path as needed

func main() {
    // Called once when parsing the --plain flag
    if plainFlagSet {
        ui.SetPlain()
    }

    // Respect NO_COLOR / CLICOLOR_FORCE env vars
    ui.ApplyColorContract()

    // Decide whether to show a spinner or fall back to sequential logs
    if ui.Animated() {
        // start spinner / live area
    } else {
        // print sequential status lines
    }

    // Wrap stderr for timestamped debug output under --verbose
    debugWriter := ui.NewTimestampWriter(os.Stderr)
    fmt.Fprintln(debugWriter, "cluster event: pod restarted")
}
```
