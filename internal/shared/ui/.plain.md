This file implements `--plain` mode support for the CLI's UI package, controlling whether output uses in-place terminal animation (spinners, live-rewriting progress) or falls back to sequential, log-friendly output while still honoring color settings.

## Key Components

- **`SetPlain()`** — enables plain mode globally for the process; intended to be called once from the `--plain` flag handler.
- **`IsPlain()`** — reports whether plain mode is active.
- **`Animated()`** — determines if in-place animation (spinners/live areas) should be used, requiring an interactive TTY, no `--plain`, and no `--silent`.
- **`ApplyColorContract()`** — implements the standard `NO_COLOR`/`CLICOLOR_FORCE` environment variable contract, disabling pterm styling when appropriate.
- **`NewTimestampWriter(w io.Writer) io.Writer`** — wraps an `io.Writer` to prefix each output line with a `HH:MM:SS.mmm` timestamp, useful for `--verbose` debug logs.
- **`timestampWriter`** — internal `io.Writer` implementation backing `NewTimestampWriter`, tracking line-start state to correctly prefix multi-write streams.

## Usage Example

```go
import "yourmodule/ui"

func main() {
	// Apply NO_COLOR / CLICOLOR_FORCE contract early
	ui.ApplyColorContract()

	// Enable plain mode from a CLI flag
	if plainFlag {
		ui.SetPlain()
	}

	// Decide whether to show a spinner or plain sequential logs
	if ui.Animated() {
		startSpinner()
	} else {
		logStep("Processing...")
	}

	// Wrap verbose debug output with timestamps
	debugWriter := ui.NewTimestampWriter(os.Stderr)
	debugWriter.Write([]byte("cluster event received\n"))
}
```

Plain mode is typically triggered automatically for non-TTY output (e.g., piped or redirected) and explicitly via `--plain` for cases like `watch`, `script`, or logged `tmux` panes where cursor-rewriting animations would corrupt captured output.
