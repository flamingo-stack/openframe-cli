# plain.go

Implements the `--plain` output mode for the CLI, which disables in-place terminal animations (spinners, self-rewriting progress lines) while preserving colored output. It also provides timestamp-prefixing for debug/verbose log streams and honors standard color environment variable contracts (`NO_COLOR`, `CLICOLOR_FORCE`).

## Key Components

- **`SetPlain()`** — Enables plain mode process-wide (invoked from the global `--plain` flag handler).
- **`IsPlain()`** — Reports whether plain mode is active.
- **`Animated()`** — Returns `true` only when the terminal is interactive, plain mode is off, and silent mode is off; used to gate spinners/live areas.
- **`ApplyColorContract()`** — Applies `NO_COLOR`/`CLICOLOR_FORCE` semantics by disabling `pterm` styling when appropriate.
- **`NewTimestampWriter(w io.Writer) io.Writer`** — Wraps a writer so each output line is prefixed with a `HH:MM:SS.mmm` timestamp; used for `--verbose` debug logs.
- **`timestampWriter`** — Internal `io.Writer` implementation tracking line-start state to insert timestamps correctly across multiple `Write` calls.

## Usage Example

```go
import "github.com/flamingo-stack/openframe-cli/internal/ui"

func main() {
	// Called once when parsing the --plain flag
	if plainFlagSet {
		ui.SetPlain()
	}

	// Apply NO_COLOR / CLICOLOR_FORCE environment contract at startup
	ui.ApplyColorContract()

	// Decide whether to show a spinner or fall back to sequential output
	if ui.Animated() {
		startSpinner()
	} else {
		printStepSequentially()
	}

	// Wrap verbose/debug output with timestamps
	debugWriter := ui.NewTimestampWriter(os.Stderr)
	fmt.Fprintln(debugWriter, "waiting for pod to become ready...")
}
```

This design ensures the CLI degrades gracefully in non-interactive environments (CI logs, `tmux`, `watch`, `script`) either automatically (non-TTY) or explicitly via `--plain`, without sacrificing colored output unless `NO_COLOR` is set.
