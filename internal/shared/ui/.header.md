## Overview

Prints a single dimmed informational line displaying the active kube-context before a command executes, acting as a lightweight safety check against running destructive operations against the wrong cluster.

## Key Components

- **`ShowContextHeader()`** — Prints the current kube-context name (prefixed with a bullet glyph) to stdout in a dim/gray color. The output is suppressed in the following cases:
  - Silent mode is enabled (`IsSilent()`)
  - The environment is not an interactive terminal (`isTerminalEnvironment()`)
  - The `TERM` environment variable is `"dumb"`
  - The kubeconfig cannot be loaded or no current context is set

The function relies on `k8s.LoadContexts` to read context information from the default kubeconfig path (`k8s.DefaultKubeconfigPath()`), and on `Glyphs()` for consistent iconography across the UI package.

## Usage Example

```go
package main

import "github.com/flamingo-stack/openframe-cli/internal/ui"

func main() {
	// Call before executing a potentially destructive command
	// (e.g., delete, apply, or cluster teardown operations).
	ui.ShowContextHeader()

	// ... proceed with command logic
}
```

Typical output (when applicable):

```text
● kube-context production-cluster
```

This function is intended to be called at the start of CLI commands that mutate cluster state, giving operators a final visual confirmation of which context is active before changes are applied.
