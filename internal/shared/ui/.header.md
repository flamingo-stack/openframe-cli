## Purpose

Prints a lightweight, dimmed status line showing the current kube-context before a CLI command executes, acting as a safety cue to help users avoid running commands against the wrong Kubernetes cluster.

## Key Components

- **`ShowContextHeader()`** — Displays a single gray-colored line (e.g. `• kube-context my-cluster`) identifying the active kube-context. It silently no-ops when:
  - Silent mode is enabled (`IsSilent()`)
  - The output is not an interactive terminal (`isTerminalEnvironment()`)
  - `TERM` environment variable is `dumb`
  - No kubeconfig contexts can be loaded, or no current context is set

This function relies on `k8s.LoadContexts` and `k8s.DefaultKubeconfigPath()` to resolve the active context, and `Glyphs()` for consistent bullet styling across the UI package.

## Usage Example

```go
package main

import "github.com/flamingo-stack/openframe-cli/internal/ui"

func runClusterCommand() {
    // Show the active kube-context before performing cluster operations
    ui.ShowContextHeader()

    // ... proceed with command logic (e.g., apply, delete, scale)
}
```

Typical output when running in an interactive terminal:

```text
• kube-context production-cluster
```

This function is intended to be called at the start of commands that interact with a Kubernetes cluster, giving users a final visual check of the target context before destructive or state-changing operations proceed.
