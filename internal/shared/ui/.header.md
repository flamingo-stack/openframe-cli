## Overview

`header.go` provides a small safety-oriented UI helper that prints the currently active Kubernetes context before a CLI command executes. It acts as a lightweight visual guard, helping users avoid accidentally running destructive commands against the wrong cluster.

## Key Components

- **`ShowContextHeader()`** — Prints a single dim status line (e.g. `• kube-context my-cluster`) indicating the active kube-context. The output is automatically suppressed when:
  - Silent mode is enabled (`IsSilent()`)
  - The environment is not an interactive terminal (`isTerminalEnvironment()`)
  - `TERM` is set to `dumb`
  - No kubeconfig contexts exist, or loading contexts fails

It relies on `k8s.LoadContexts` and `k8s.DefaultKubeconfigPath()` to resolve the current context, and `Glyphs()` for consistent bullet styling via `pterm`.

## Usage Example

```go
package main

import "github.com/flamingo-stack/openframe-cli/internal/ui"

func main() {
    // Call at the start of a command to remind the user
    // which cluster context they're operating against.
    ui.ShowContextHeader()

    // ... proceed with command logic, e.g. deleting resources
}
```

This is typically invoked at the top of Cobra command `Run`/`RunE` functions in the CLI, right before performing operations that interact with a Kubernetes cluster, so users get a final visual confirmation of the target context.
