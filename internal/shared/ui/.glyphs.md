## Overview

`glyphs.go` defines the terminal symbol vocabulary used across OpenFrame CLI's UI surfaces (step trees, dashboards, plan diffs). It automatically resolves a rich Unicode glyph set or falls back to plain ASCII based on terminal capability detection, and provides helper functions for rendering summary rows and progress bars.

## Key Components

- **`GlyphSet`** — struct holding symbols for status states (`OK`, `Fail`, `Warn`, `Pending`, `Running`) and formatting glyphs (`Bullet`, `Arrow`, `Bar`, `BarEmpty`).
- **`Glyphs()`** — returns the process-wide `GlyphSet`, resolved once via `sync.Once` based on terminal Unicode capability.
- **`glyphsFor(unicode bool) GlyphSet`** — internal factory that builds either the Unicode-rich or ASCII-safe glyph set.
- **`unicodeCapable() bool`** — determines whether Unicode glyphs are safe to use. Defaults to `true`; falls back to `false` only when `OPENFRAME_ASCII=1`, `TERM=dumb`, or a locale (`LC_ALL`/`LC_CTYPE`/`LANG`) explicitly indicates non-UTF-8 encoding.
- **`IsTerminal() bool`** — reports whether stdout is an interactive terminal.
- **`SummaryRow(key, value string)`** — prints an aligned, dim-styled key/value summary line.
- **`ProgressBar(fraction float64, width int) string`** — renders a textual progress bar string using filled/empty glyphs, clamping `fraction` to `[0, 1]`.

## Usage Example

```go
package main

import (
	"fmt"

	"github.com/flamingo-stack/openframe-cli/internal/ui"
)

func main() {
	g := ui.Glyphs()
	fmt.Printf("%s Build complete %s Deploy failed\n", g.OK, g.Fail)

	ui.SummaryRow("stages", "validate 0.1s · cluster 42s · platform 17m20s")

	bar := ui.ProgressBar(0.6, 10)
	fmt.Println(bar) // e.g. "██████░░░░"

	if ui.IsTerminal() {
		fmt.Println("Running in an interactive terminal")
	}
}
```

Environment variables `OPENFRAME_ASCII=1`, `TERM=dumb`, or a non-UTF-8 locale (`LANG`, `LC_ALL`, `LC_CTYPE`) force the ASCII fallback glyph set for compatibility with limited terminals or CI logs.
