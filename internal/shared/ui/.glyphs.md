## Purpose

`glyphs.go` defines the terminal symbol vocabulary (checkmarks, spinners, bullets, progress-bar cells) used across the CLI's richer UI surfaces such as step trees, dashboards, and plan diffs. It automatically selects between rich Unicode glyphs and plain ASCII fallbacks based on terminal capability detection, and provides helpers for rendering summary rows and progress bars.

## Key Components

- **`GlyphSet`** — struct holding the symbol set (`OK`, `Fail`, `Warn`, `Pending`, `Running`, `Bullet`, `Arrow`, `Bar`, `BarEmpty`).
- **`Glyphs()`** — returns the process-wide `GlyphSet`, lazily resolved once via `sync.Once`.
- **`glyphsFor(unicode bool)`** — internal constructor returning either the Unicode or ASCII glyph set.
- **`unicodeCapable()`** — determines Unicode support based on `OPENFRAME_ASCII`, `TERM`, and locale environment variables (`LC_ALL`, `LC_CTYPE`, `LANG`); defaults to `true` (Unicode) unless explicitly disabled.
- **`IsTerminal()`** — reports whether stdout is an interactive terminal.
- **`SummaryRow(key, value string)`** — prints an aligned, dim-colored key/value row for summary panels.
- **`ProgressBar(fraction float64, width int) string`** — renders a text progress bar using filled/empty glyph cells, clamping `fraction` to `[0, 1]`.

## Usage Example

```go
package main

import (
	"fmt"

	"github.com/flamingo-stack/openframe-cli/internal/ui"
)

func main() {
	g := ui.Glyphs()
	fmt.Printf("%s Cluster ready\n", g.OK)
	fmt.Printf("%s Deploying platform...\n", g.Running)

	ui.SummaryRow("stages", "validate 0.1s · cluster 42s · platform 17m20s")

	bar := ui.ProgressBar(0.6, 10)
	fmt.Printf("[%s] 60%%\n", bar)

	if ui.IsTerminal() {
		fmt.Println("Running in an interactive terminal")
	}
}
```

Set `OPENFRAME_ASCII=1` to force plain ASCII glyphs (e.g., for logs or non-UTF-8 terminals) instead of the default Unicode set.
