## glyphs.go

Defines the terminal glyph vocabulary used by OpenFrame CLI's UI surfaces (step trees, dashboards, plan diffs), automatically choosing between rich Unicode symbols and plain ASCII fallbacks based on terminal capability. Also provides small rendering helpers for summary rows and progress bars.

## Key Components

- **`GlyphSet`** — struct holding the symbol vocabulary (`OK`, `Fail`, `Warn`, `Pending`, `Running`, `Bullet`, `Arrow`, `Bar`, `BarEmpty`) used consistently across UI rendering.
- **`Glyphs()`** — returns the process-wide `GlyphSet`, lazily resolved once via `sync.Once` based on terminal Unicode capability.
- **`glyphsFor(unicode bool) GlyphSet`** — internal factory returning either the Unicode or ASCII glyph set.
- **`unicodeCapable() bool`** — determines whether Unicode glyphs are safe to use. Defaults to `true`; falls back to ASCII only when `OPENFRAME_ASCII=1`, `TERM=dumb`, or locale env vars (`LC_ALL`, `LC_CTYPE`, `LANG`) explicitly indicate a non-UTF-8 charset.
- **`IsTerminal() bool`** — reports whether stdout is an interactive terminal.
- **`SummaryRow(key, value string)`** — prints an aligned, dim-styled key/value row for summary panels.
- **`ProgressBar(fraction float64, width int) string`** — renders a textual progress bar (e.g., `"██████░░░░"`), clamping `fraction` to `[0, 1]`.

## Usage Example

```go
package main

import (
	"fmt"

	"github.com/flamingo-stack/openframe-cli/internal/ui"
)

func main() {
	g := ui.Glyphs()
	fmt.Printf("%s Cluster ready\n", g.OK)

	ui.SummaryRow("stages", "validate 0.1s · cluster 42s · platform 17m20s")

	bar := ui.ProgressBar(0.6, 10)
	fmt.Println(bar) // "██████░░░░" or "######...." on ASCII terminals

	if ui.IsTerminal() {
		fmt.Println("Running in an interactive terminal")
	}
}
```

Set `OPENFRAME_ASCII=1` to force plain ASCII output regardless of terminal/locale detection.
