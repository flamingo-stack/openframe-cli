## steps.go

Renders a buildkit-style stage checklist for multi-stage CLI flows (e.g., bootstrap: validate → cluster → platform). Stages are printed as plain sequential lines rather than in-place rewrites, since stages typically run their own spinners/scrolling output that would otherwise conflict with a rewriting tracker. This design is also CI-log friendly. Stage durations are recorded for a final summary line.

## Key Components

- **`Timing`** — Struct capturing a finished stage's title, duration, and failure status.
- **`Tracker`** — Tracks a fixed, ordered sequence of stages. Not safe for concurrent use (stages run sequentially).
- **`NewTracker(titles ...string) *Tracker`** — Creates a tracker for the given ordered stage titles.
- **`(*Tracker) Begin(i int, detail string)`** — Announces the start of stage `i`, printing a "running" glyph, progress indicator (e.g., `[2/3]`), title, and optional dim detail text. Also opens a CI log group.
- **`(*Tracker) Done(i int)`** — Marks stage `i` as successfully completed and prints its duration.
- **`(*Tracker) Fail(i int)`** — Marks stage `i` as failed and prints its duration.
- **`(*Tracker) Timings() []Timing`** — Returns all completed stage timings in order.
- **`(*Tracker) Total() time.Duration`** — Returns total elapsed time since tracker creation.
- **`TimingsLine(timings []Timing) string`** — Formats a summary line like `validate 0.1s · cluster 42s · platform 17m20s`.
- **`FormatDuration(d time.Duration) string`** — Human-friendly duration formatting (`0.8s`, `42s`, `17m20s`, `1h02m`).

## Usage Example

```go
stages := []string{"Validate config", "Create cluster", "Deploy platform"}
tracker := steps.NewTracker(stages...)

tracker.Begin(0, "")
// ... run validation logic ...
tracker.Done(0)

tracker.Begin(1, "k3d-openframe-dev")
// ... run cluster creation, may fail ...
if err != nil {
    tracker.Fail(1)
} else {
    tracker.Done(1)
}

tracker.Begin(2, "")
// ... deploy platform ...
tracker.Done(2)

fmt.Println("Summary:", steps.TimingsLine(tracker.Timings()))
fmt.Println("Total time:", steps.FormatDuration(tracker.Total()))
```

This produces output similar to:

```text
▶ [1/3] Validate config
✔ [1/3] Validate config · 0.1s
▶ [2/3] Create cluster k3d-openframe-dev
✔ [2/3] Create cluster k3d-openframe-dev · 42s
▶ [3/3] Deploy platform
✔ [3/3] Deploy platform · 17m20s
```
