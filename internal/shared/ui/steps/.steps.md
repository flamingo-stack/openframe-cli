# steps.go

Renders a buildkit-style stage checklist for multi-stage CLI flows (e.g., bootstrap: validate → cluster → platform). Stage lines are printed sequentially rather than rewritten in place, since each stage may run its own spinners or scrolling output that would otherwise conflict with an in-place tracker. This approach is also CI-log friendly. Durations for each stage are recorded for a final summary line.

## Key Components

- **`Timing`** — Struct capturing a finished stage's title, duration, and pass/fail status.
- **`Tracker`** — Sequential (not concurrency-safe) tracker over a fixed ordered list of stage titles.
  - **`NewTracker(titles ...string) *Tracker`** — Creates a tracker for the given stage titles.
  - **`(*Tracker) Begin(i int, detail string)`** — Announces the start of stage `i`, printing a running glyph, progress counter (`[i/n]`), title, and optional dim detail. Also opens a CI log group.
  - **`(*Tracker) Done(i int)`** — Marks stage `i` as successfully completed.
  - **`(*Tracker) Fail(i int)`** — Marks stage `i` as failed.
  - **`(*Tracker) Timings() []Timing`** — Returns completed stage timings in order.
  - **`(*Tracker) Total() time.Duration`** — Returns total elapsed time since tracker creation.
- **`TimingsLine(timings []Timing) string`** — Formats a summary line like `validate 0.1s · cluster 42s · platform 17m20s`.
- **`FormatDuration(d time.Duration) string`** — Human-readable duration formatting (`0.8s`, `42s`, `17m20s`, `1h02m`).

## Usage Example

```go
tracker := steps.NewTracker("validate", "cluster", "platform")

tracker.Begin(0, "")
if err := validate(); err != nil {
    tracker.Fail(0)
} else {
    tracker.Done(0)
}

tracker.Begin(1, "k3d-openframe-dev")
if err := createCluster(); err != nil {
    tracker.Fail(1)
} else {
    tracker.Done(1)
}

// After all stages complete:
fmt.Println("Summary:", steps.TimingsLine(tracker.Timings()))
fmt.Println("Total:", steps.FormatDuration(tracker.Total()))
```

This produces console output resembling:

```text
▶ [1/3] validate
✔ [1/3] validate · 0.1s
▶ [2/3] cluster k3d-openframe-dev
✔ [2/3] cluster · 42s
```
