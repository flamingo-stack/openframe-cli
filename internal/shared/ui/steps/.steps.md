# steps.go

Renders a buildkit-style stage checklist for multi-stage CLI flows (e.g., bootstrap: validate → cluster → platform). Each stage prints a starting line, lets its own output (spinners, scrolling logs) render freely, then prints a closing line with its duration — avoiding in-place cursor rewrites that would conflict with nested spinners, while staying CI-log friendly.

## Key Components

- **`Timing`** — struct capturing a finished stage's title, duration, and pass/fail status, used for building a final summary.
- **`Tracker`** — sequential (non-concurrent-safe) tracker over an ordered list of stage titles.
  - **`NewTracker(titles ...string) *Tracker`** — creates a tracker for the given stage sequence.
  - **`(*Tracker) Begin(i int, detail string)`** — announces stage `i` starting, prints a `▶ [i/n] Title` line (optionally with dim detail text), and opens a collapsible log group (e.g., for GitHub Actions).
  - **`(*Tracker) Done(i int)`** — marks stage `i` as successfully completed, printing its duration.
  - **`(*Tracker) Fail(i int)`** — marks stage `i` as failed, printing its duration.
  - **`(*Tracker) Timings() []Timing`** — returns completed stage timings in order.
  - **`(*Tracker) Total() time.Duration`** — wall-clock time since the tracker started.
- **`TimingsLine(timings []Timing) string`** — formats a summary line like `validate 0.1s · cluster 42s · platform 17m20s`.
- **`FormatDuration(d time.Duration) string`** — human-friendly duration formatting (`0.8s`, `42s`, `17m20s`, `1h02m`).

## Usage Example

```go
tracker := steps.NewTracker("validate", "cluster", "platform")

for i, stage := range stages {
    tracker.Begin(i, stage.Detail)
    if err := stage.Run(); err != nil {
        tracker.Fail(i)
        break
    }
    tracker.Done(i)
}

fmt.Println("Summary:", steps.TimingsLine(tracker.Timings()))
fmt.Println("Total:", steps.FormatDuration(tracker.Total()))
```

Typical output:

```text
▶ [1/3] Validate environment
✔ [1/3] Validate environment · 0.3s
▶ [2/3] Create cluster k3d-openframe-dev
✔ [2/3] Create cluster k3d-openframe-dev · 42s
▶ [3/3] Deploy platform
✔ [3/3] Deploy platform · 17m20s
```
