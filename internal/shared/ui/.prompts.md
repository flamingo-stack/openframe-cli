# prompts.go

Provides interactive terminal prompt utilities (confirmations, selection lists, text input) built on `huh` and `pterm`, with safeguards to prevent hanging in non-interactive environments like CI or piped stdin.

## Key Components

- **`IsNonInteractive() bool`** - Detects CI environments or non-terminal stdin to determine if interactive prompts should be avoided.
- **`ErrPromptInterrupted`** - Sentinel error returned when a user cancels a prompt via Ctrl+C.
- **`ConfirmActionInteractive(message string, defaultValue bool) (bool, error)`** - Shows a styled y/N confirmation prompt.
- **`RequireConfirmation(message, flagHint string, defaultValue bool) (bool, error)`** - Confirmation prompt that fails fast (with guidance) instead of blocking when non-interactive.
- **`ConfirmDeletion(resourceType, resourceName string) (bool, error)`** - Deletion confirmation prompt, defaults to No.
- **`SelectFromList(label string, items []string) (int, string, error)`** - Selectable list prompt with fuzzy filtering for long lists; appends "?" to the label.
- **`SelectOption(label string, items []string) (int, string, error)`** - Same as `SelectFromList` but without automatic "?" suffix, for fixed short lists.
- **`PromptInput(label, defaultVal string, validate func(string) error) (string, error)`** - Single-line text input prompt with optional validation.
- **`ValidateNonEmpty(fieldName string) func(string) error`** - Validator ensuring input isn't empty after trimming.
- **`ValidateIntRange(min, max int, fieldName string) func(string) error`** - Validator ensuring input is an integer within a given range.

All interactive functions return an error (`fmt.Errorf`) when called in a non-interactive session instead of blocking indefinitely.

## Usage Example

```go
package main

import (
	"fmt"
	"os"

	"github.com/flamingo-stack/openframe-cli/internal/ui"
)

func main() {
	// Confirm a destructive action, aborting cleanly if non-interactive.
	ok, err := ui.RequireConfirmation("Delete all clusters?", "--force", false)
	if err != nil {
		fmt.Fprintln(os.Stderr, err)
		os.Exit(1)
	}
	if !ok {
		return
	}

	// Select from a list of clusters.
	_, name, err := ui.SelectFromList("Which cluster", []string{"dev", "staging", "prod"})
	if err != nil {
		fmt.Fprintln(os.Stderr, err)
		os.Exit(1)
	}

	// Prompt for a validated text value.
	port, err := ui.PromptInput("Port", "8080", ui.ValidateIntRange(1, 65535, "port"))
	if err != nil {
		fmt.Fprintln(os.Stderr, err)
		os.Exit(1)
	}

	fmt.Printf("Selected %s on port %s\n", name, port)
}
```
