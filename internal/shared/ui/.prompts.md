Provides interactive terminal prompt utilities for the OpenFrame CLI, including confirmation dialogs, list selectors, and input validators with CI/non-interactive environment detection.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `IsNonInteractive()` | func | Detects CI environments or non-TTY stdin to skip blocking prompts |
| `ConfirmActionInteractive()` | func | Styled y/N confirmation prompt with configurable default |
| `RequireConfirmation()` | func | Like `ConfirmActionInteractive` but fails fast in non-interactive sessions |
| `ConfirmDeletion()` | func | Convenience wrapper for delete confirmation, defaults to No |
| `SelectFromList()` | func | Arrow-key list selector returning selected index and value |
| `ValidateNonEmpty()` | func | Returns a validator that rejects blank/whitespace-only input |
| `ValidateIntRange()` | func | Returns a validator that enforces a numeric range |

## Usage Example

```go
// Guard a destructive action — fails gracefully in CI pipelines
confirmed, err := ui.RequireConfirmation("Deploy to production?", "--yes", false)
if err != nil || !confirmed {
    return err
}

// Confirm resource deletion (defaults to No)
ok, err := ui.ConfirmDeletion("namespace", "prod-cluster")

// Present a menu
idx, choice, err := ui.SelectFromList("Choose environment", []string{"dev", "staging", "prod"})

// Validate user text input
validate := ui.ValidateNonEmpty("API key")
if err := validate(""); err != nil {
    fmt.Println(err) // "API key cannot be empty"
}

// Validate numeric input within bounds
validate := ui.ValidateIntRange(1, 65535, "port")
if err := validate("99999"); err != nil {
    fmt.Println(err) // "port must be between 1 and 65535"
}
```

> **CI behavior:** `IsNonInteractive()` returns `true` when `CI`, `GITHUB_ACTIONS`, `GITLAB_CI`, or `CIRCLECI` env vars are set, or when stdin is not a TTY. `RequireConfirmation` will return an error rather than hang.
