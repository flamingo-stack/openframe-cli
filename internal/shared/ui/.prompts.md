## prompts.go

This file implements interactive terminal prompt utilities (confirmations, selection lists, text input) for the CLI, built on `huh` and `pterm`, with built-in safeguards for non-interactive environments like CI pipelines.

## Key Components

- **`IsNonInteractive() bool`** — Detects CI environments (via `CI`, `GITHUB_ACTIONS`, `GITLAB_CI`, `CIRCLECI` env vars) or non-terminal stdin, signaling that prompts must be avoided.
- **`ErrPromptInterrupted`** — Sentinel error returned when a user cancels a prompt with Ctrl+C, normalized from `huh.ErrUserAborted`.
- **`ConfirmActionInteractive(message string, defaultValue bool) (bool, error)`** — Shows a styled y/N confirmation prompt.
- **`RequireConfirmation(message, flagHint string, defaultValue bool) (bool, error)`** — Like `ConfirmActionInteractive`, but errors immediately in non-interactive sessions, suggesting a flag (e.g. `--yes`) to bypass the prompt.
- **`ConfirmDeletion(resourceType, resourceName string) (bool, error)`** — Confirmation prompt specialized for destructive delete actions (defaults to No).
- **`SelectFromList(label string, items []string) (int, string, error)`** — Fuzzy-filterable selection list ("?" appended to label), scrollable for long lists.
- **`SelectOption(label string, items []string) (int, string, error)`** — Same as `SelectFromList` but for short fixed-choice wizard steps.
- **`PromptInput(label, defaultVal string, validate func(string) error) (string, error)`** — Single-line text input with optional validation and default value.
- **`ValidateNonEmpty(fieldName string) func(string) error`** — Validator ensuring a field isn't empty after trimming.
- **`ValidateIntRange(min, max int, fieldName string) func(string) error`** — Validator ensuring input is an integer within a given range.

## Usage Example

```go
if ui.IsNonInteractive() {
    return fmt.Errorf("cannot proceed without a terminal")
}

ok, err := ui.RequireConfirmation("Delete cluster 'prod'?", "--force", false)
if err != nil {
    return err
}
if !ok {
    return nil
}

name, err := ui.PromptInput("Cluster name", "default", ui.ValidateNonEmpty("cluster name"))
if err != nil {
    return err
}

idx, choice, err := ui.SelectFromList("Select environment", []string{"dev", "staging", "prod"})
if err != nil {
    return err
}
fmt.Printf("Selected %s at index %d\n", choice, idx)
```

Callers should always check `IsNonInteractive()` or rely on `RequireConfirmation`/`requireInteractive` guards before invoking prompts to avoid hanging in CI or scripted environments.
