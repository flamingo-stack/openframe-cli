## prompts.go

This file provides interactive CLI prompt helpers (confirmations, selections, and text input) built on `huh` and `pterm`, with built-in safeguards for non-interactive environments like CI or piped stdin.

## Key Components

- **`IsNonInteractive() bool`** — Detects CI environments (via `CI`, `GITHUB_ACTIONS`, `GITLAB_CI`, `CIRCLECI` env vars) or non-terminal stdin, so prompt flows can skip blocking waits.
- **`ErrPromptInterrupted`** — Sentinel error returned when a user cancels a prompt with Ctrl+C; normalized from `huh.ErrUserAborted`.
- **`ConfirmActionInteractive(message string, defaultValue bool) (bool, error)`** — Styled y/N confirmation prompt.
- **`RequireConfirmation(message, flagHint string, defaultValue bool) (bool, error)`** — Like `ConfirmActionInteractive`, but errors immediately in non-interactive sessions, directing the user to a flag (e.g. `--yes`) instead of hanging.
- **`ConfirmDeletion(resourceType, resourceName string) (bool, error)`** — Deletion-specific confirmation defaulting to "No".
- **`SelectFromList(label string, items []string) (int, string, error)`** — List picker with fuzzy filtering (`/`) for long lists; appends `?` to the label.
- **`SelectOption(label string, items []string) (int, string, error)`** — Same as `SelectFromList` but for short, fixed-choice wizard steps (no automatic `?`).
- **`PromptInput(label, defaultVal string, validate func(string) error) (string, error)`** — Single-line text input with optional validation and default pre-fill; result is trimmed.
- **`ValidateNonEmpty(fieldName string) func(string) error`** — Validator ensuring input isn't empty.
- **`ValidateIntRange(min, max int, fieldName string) func(string) error`** — Validator ensuring input is an integer within a range.

All interactive functions guard against non-interactive terminals via `requireInteractive`, returning an error rather than hanging (critical for Windows CI runners where a console is present but unattended).

## Usage Example

```go
// Confirm a destructive action, failing fast in CI
proceed, err := ui.RequireConfirmation("Delete cluster 'prod'?", "--force", false)
if err != nil {
    log.Fatal(err)
}

// Pick from a list with fuzzy filtering
idx, name, err := ui.SelectFromList("Select a cluster", clusterNames)

// Prompt for validated text input
name, err := ui.PromptInput("Cluster name", "default", ui.ValidateNonEmpty("cluster name"))

// Prompt for a bounded integer
countStr, err := ui.PromptInput("Node count", "3", ui.ValidateIntRange(1, 10, "node count"))
```
