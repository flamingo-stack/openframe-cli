## Purpose

This file implements the ASCII/Unicode logo banner displayed by the OpenFrame CLI at startup, with automatic terminal-capability detection to choose between a colorful gradient box (via `pterm`) and a plain-text fallback box.

## Key Components

- **`ShowLogo()`** - Displays the OpenFrame logo unconditionally (unless test/silent mode is active).
- **`ShowLogoConditional(suppress bool)`** - Displays the logo, honoring `TestMode`, an explicit `suppress` flag, and a global `silent` flag; auto-detects whether to render the fancy or plain variant based on terminal capabilities and the `OPENFRAME_FANCY_LOGO` environment variable.
- **`ShowLogoWithContext(ctx context.Context)`** - Displays the logo unless suppressed via a context value (`suppressLogoKey`).
- **`isTerminalEnvironment()`** - Detects whether stdout is attached to an interactive terminal (character device).
- **`showFancyLogo()`** - Renders the logo inside a `pterm` box with a cyan-to-purple gradient and a centered title.
- **`plainLogoLines()`** - Builds the plain-text bordered logo, dynamically sizing the box based on the actual logo art width to avoid border misalignment.
- **`showPlainLogo()`** - Prints the plain-text logo box, line by line.
- **`TestMode`** - Package-level variable that, when `true`, suppresses all logo output (useful in tests).

## Usage Example

```go
package main

import "github.com/flamingo-stack/openframe-cli/internal/ui" // adjust import path as needed

func main() {
    // Display the logo using default auto-detection (fancy vs. plain)
    ui.ShowLogo()

    // Force-suppress the logo (e.g., in quiet/non-interactive mode)
    ui.ShowLogoConditional(true)

    // Suppress logo output during automated tests
    ui.TestMode = true
    ui.ShowLogo() // no-op
}
```

Set the `OPENFRAME_FANCY_LOGO` environment variable to `true` or `false` to explicitly override auto-detection of terminal color support.
