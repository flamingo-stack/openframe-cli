## logo.go

Renders the OpenFrame ASCII art banner displayed at CLI startup, with automatic detection of terminal capabilities to choose between a colorful gradient box (via `pterm`) or a plain-text bordered box for non-interactive or limited terminals.

## Key Components

- **`ShowLogo()`** – Displays the logo unconditionally (respecting test/silent modes).
- **`ShowLogoConditional(suppress bool)`** – Displays the logo unless suppressed, in test mode, or in silent mode; auto-detects fancy vs. plain rendering based on the `OPENFRAME_FANCY_LOGO` env var, terminal type, and color support.
- **`ShowLogoWithContext(ctx context.Context)`** – Displays the logo unless suppression is signaled via a context value (`suppressLogoKey`).
- **`TestMode`** – Package-level flag to globally suppress logo output during tests.
- **`isTerminalEnvironment()`** – Detects whether stdout is attached to an interactive terminal (character device).
- **`showFancyLogo()`** – Renders the logo inside a `pterm` box with a cyan-to-purple RGB gradient applied line-by-line and a centered title.
- **`plainLogoLines()`** – Builds the plain-text bordered logo, dynamically sizing borders/padding based on the actual rune width of the ASCII art (avoids hardcoded width mismatches).
- **`showPlainLogo()`** – Prints the plain-text logo box to stdout.

## Usage Example

```go
package main

import "yourmodule/ui"

func main() {
    // Show logo using auto-detected rendering (fancy or plain)
    ui.ShowLogo()

    // Force-suppress logo (e.g., in quiet/CI mode)
    ui.ShowLogoConditional(true)

    // Suppress logo output entirely during unit tests
    ui.TestMode = true
    ui.ShowLogo() // no-op
}
```

Rendering mode can be controlled via environment variables:

```bash
# Force fancy gradient logo
export OPENFRAME_FANCY_LOGO=true

# Force plain text logo
export OPENFRAME_FANCY_LOGO=false
```
