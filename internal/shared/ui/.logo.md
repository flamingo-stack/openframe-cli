Renders the OpenFrame ASCII art logo to the terminal, supporting both fancy (pterm-enhanced) and plain text display modes based on terminal capabilities and environment configuration.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `TestMode` | `var bool` | Global flag to suppress logo output during tests |
| `ShowLogo()` | func | Displays the logo with default settings |
| `ShowLogoConditional(suppress bool)` | func | Displays the logo with optional programmatic suppression |
| `ShowLogoWithContext(ctx context.Context)` | func | Displays the logo unless suppressed via a context value |
| `isTerminalEnvironment()` | func | Detects whether stdout is an interactive character device |
| `showFancyLogo()` | func (internal) | Renders logo using pterm with cyan/bold styling and a boxed border |
| `showPlainLogo()` | func (internal) | Renders logo using Unicode box-drawing characters, no color |

## Display Mode Selection

The renderer picks between fancy and plain output:

1. `OPENFRAME_FANCY_LOGO=true` → always fancy
2. `OPENFRAME_FANCY_LOGO=false` → always plain
3. Auto-detect → fancy only when stdout is a TTY, `$TERM` is set, `NO_COLOR` is unset, and pterm color is enabled

## Usage Example

```go
// Standard usage — auto-detects terminal capabilities
ui.ShowLogo()

// Suppress during CI or scripted runs
ui.ShowLogoConditional(true)

// Suppress via context (e.g., passed down from a parent command)
ctx := context.WithValue(context.Background(), ui.SuppressLogoKey, true)
ui.ShowLogoWithContext(ctx)

// Suppress all logo output during testing
func TestMain(m *testing.M) {
    ui.TestMode = true
    os.Exit(m.Run())
}
```

## Environment Variables

| Variable | Values | Effect |
|---|---|---|
| `OPENFRAME_FANCY_LOGO` | `true` / `false` | Force fancy or plain mode |
| `NO_COLOR` | any non-empty | Disables fancy mode in auto-detect |
| `TERM` | unset | Disables fancy mode in auto-detect |
