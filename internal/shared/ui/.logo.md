## Purpose

This file implements ASCII/Unicode logo rendering for the OpenFrame CLI, displaying a branded banner at startup. It supports two rendering modes—a colorful "fancy" box using `pterm` for interactive terminals, and a plain-text bordered box for non-interactive or limited environments—with automatic or environment-variable-driven mode selection.

## Key Components

- **`ShowLogo()`** — Displays the logo unconditionally (unless test/silent mode is active).
- **`ShowLogoConditional(suppress bool)`** — Displays the logo with an explicit suppression flag; also respects `TestMode` and a package-level `silent` flag. Chooses fancy vs. plain rendering based on the `OPENFRAME_FANCY_LOGO` env var or terminal auto-detection.
- **`ShowLogoWithContext(ctx context.Context)`** — Displays the logo unless suppressed via a `context.Context` value (`suppressLogoKey`).
- **`TestMode`** — Package-level boolean to suppress all logo output during tests.
- **`isTerminalEnvironment()`** — Detects whether stdout is an actual terminal (character device).
- **`showFancyLogo()`** — Renders the logo inside a `pterm` box with a cyan-to-purple gradient and a styled title.
- **`showPlainLogo()` / `plainLogoLines()`** — Builds and prints a plain-text bordered box logo, computing border widths dynamically from the ASCII art to avoid misalignment.
- **`logoArt`** — The raw ASCII/Unicode art lines spelling "OPENFRAME".

## Usage Example

```go
package main

import (
	"context"
	"myapp/ui"
)

func main() {
	// Simple unconditional display
	ui.ShowLogo()

	// Conditional display, e.g. suppress in quiet mode
	quiet := false
	ui.ShowLogoConditional(quiet)

	// Context-based suppression (e.g., set upstream in a command handler)
	ctx := context.Background()
	ui.ShowLogoWithContext(ctx)

	// Disable logo entirely during tests
	ui.TestMode = true
	ui.ShowLogo() // no-op
}
```

Set `OPENFRAME_FANCY_LOGO=true` or `false` to force a rendering mode, otherwise the CLI auto-detects based on terminal capabilities, `TERM`, and `NO_COLOR`.
