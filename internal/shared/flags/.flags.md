Defines reusable CLI flag management for non-cluster commands, providing a consistent interface for attaching and validating common flags across Cobra commands.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `CommonFlags` | struct | Holds shared flag values: `Verbose`, `DryRun`, and `Force` |
| `FlagManager` | struct | Wraps a `CommonFlags` instance to manage flag registration |
| `NewFlagManager` | func | Constructor for `FlagManager`, accepts a `*CommonFlags` pointer |
| `AddCommonFlags` | method | Registers `--verbose`/`-v`, `--force`/`-f`, and `--dry-run` as persistent flags on a Cobra command; uses placeholder booleans if `common` is `nil` |
| `ValidateCommonFlags` | func | Validation hook for flag combinations (currently a no-op) |

> **Note:** For cluster-specific flags, use `internal/cluster/models.GlobalFlags` instead of `CommonFlags`.

## Usage Example

```go
package main

import (
    "github.com/flamingo-stack/openframe-cli/internal/flags"
    "github.com/spf13/cobra"
)

func main() {
    common := &flags.CommonFlags{}
    fm := flags.NewFlagManager(common)

    rootCmd := &cobra.Command{Use: "openframe"}
    fm.AddCommonFlags(rootCmd)

    // Access parsed flag values after execution
    rootCmd.RunE = func(cmd *cobra.Command, args []string) error {
        if err := flags.ValidateCommonFlags(common); err != nil {
            return err
        }
        if common.Verbose {
            // enable verbose logging
        }
        if common.DryRun {
            // preview actions without executing
        }
        return nil
    }

    rootCmd.Execute()
}
```
