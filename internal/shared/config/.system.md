Provides system-level configuration and initialization for the OpenFrame CLI, handling log directory setup and system-wide settings.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `SystemService` | struct | Manages system-level configuration, holds the log directory path |
| `NewSystemService()` | constructor | Creates a `SystemService` with the default log path set to `<os.TempDir>/openframe-deployment-logs` |
| `Initialize()` | method | Entry point for system setup; runs all initialization tasks |
| `setupLogDirectory()` | method (private) | Creates the log directory with `0750` permissions using `os.MkdirAll` |

## Usage Example

```go
svc := config.NewSystemService()

if err := svc.Initialize(); err != nil {
    log.Fatalf("failed to initialize system: %v", err)
}
// Log directory is now ready at <os.TempDir>/openframe-deployment-logs
```

## Notes

- Log directory defaults to `filepath.Join(os.TempDir(), "openframe-deployment-logs")`, resolving to `/tmp/openframe-deployment-logs` on Linux/macOS or the equivalent temp path on Windows.
- Directory permissions are set to `0750` (owner read/write/execute, group read/execute, no access for others).
- Errors from `Initialize()` wrap underlying OS errors using `%w`, making them compatible with `errors.Is` / `errors.As`.
