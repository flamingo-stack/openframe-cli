Parses a named environment variable and returns `true` only when its value is explicitly truthy (`1`, `true`, `yes`, or `on`, case-insensitive).

## Key Components

- **`EnvBool(name string) bool`** — The sole approved function for reading boolean `OPENFRAME_*` environment flags. Returns `true` for `1`, `true`, `yes`, `on` (case-insensitive, whitespace-trimmed); returns `false` for everything else, including `0` and `false`.

## Usage Example

```go
import "github.com/flamingo-stack/openframe-cli/config"

if config.EnvBool("OPENFRAME_UPDATE_INSECURE_SKIP_VERIFY") {
    // skips release-signature verification only when
    // the variable is explicitly set to a truthy value
}
```

## Why This Exists

The previous `os.Getenv(name) != ""` pattern evaluated `FLAG=0` and `FLAG=false` as `true` — because those strings are non-empty. For security-sensitive flags like `OPENFRAME_UPDATE_INSECURE_SKIP_VERIFY`, this meant a user trying to explicitly disable a feature would silently do the opposite. `EnvBool` enforces an allowlist of truthy values so that only intentional opt-ins take effect.

> **Convention:** All boolean environment variable reads across the CLI **must** use `EnvBool`. Direct `os.Getenv` comparisons for boolean flags are not permitted.
