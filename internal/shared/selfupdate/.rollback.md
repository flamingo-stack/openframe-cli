Manages rollback functionality for the self-update system, allowing restoration of the previously installed binary without requiring a download.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `prevBinaryPath()` | func | Returns the filesystem path (`~/.openframe/state/openframe.prev`) where the previous binary is stored |
| `savePrevious()` | func | Copies a backup binary into the rollback slot after a successful update |
| `PreviousVersion()` | func | Checks if a rollback point exists and returns its version string (best-effort via `--version`) |
| `binaryVersion()` | func | Executes a binary with `--version` and extracts the leading version token; 30s timeout |
| `Updater.Rollback()` | method | Atomically swaps the current binary with the saved previous one and clears the rollback slot |
| `copyFile()` | func | Copies a file atomically using a temp file and `os.Rename`; sets explicit permissions |

## Usage Example

```go
// Check if a previous version is available before offering rollback
if version, ok := selfupdate.PreviousVersion(); ok {
    fmt.Printf("Previous version available: %s\n", version)

    u := selfupdate.Updater{}
    err := u.Rollback(ctx, func(msg string) {
        fmt.Println(msg) // e.g. "Rolled back to the previous version."
    })
    if err != nil {
        log.Fatalf("Rollback failed: %v", err)
    }
}
```

## Notes

- Rollback is a **one-shot operation** — the rollback slot (`openframe.prev`) is removed after use, preventing repeated rollbacks from the same checkpoint
- Windows is explicitly unsupported and returns an error immediately
- `binaryVersion` uses a generous 30-second timeout to avoid test flakiness on loaded machines; a timeout only blanks the displayed version label, it does not prevent rollback from working
- All file writes use atomic temp-file-plus-rename to avoid partial writes leaving the binary in a corrupt state
