Provides the public and internal entry points for downloading and cryptographically verifying a Linux release binary of the OpenFrame CLI, primarily used by the WSL auto-installer.

## Key Components

### `FetchVerifiedLinuxBinary`
Public function that orchestrates the full self-update trust chain for a given `version` and `goarch`. It resolves the GitHub release via tag, then delegates to the internal core function.

### `fetchVerifiedLinuxBinary`
Internal, testable function that performs the actual work against a resolved `Release`:
1. Looks up the archive asset URL by name
2. Fetches and cosign-verifies `checksums.txt` against the pinned GitHub Actions identity
3. Parses the SHA256 checksum for the target archive
4. Downloads and verifies the `.tar.gz` archive before extracting the `openframe` binary

## Usage Example

```go
ctx := context.Background()

binaryData, err := selfupdate.FetchVerifiedLinuxBinary(
    ctx,
    "v1.2.3",   // version tag (with or without "v" prefix)
    "amd64",    // GOARCH
    func(msg string) { fmt.Println(msg) }, // optional progress logger
)
if err != nil {
    log.Fatalf("failed to fetch binary: %v", err)
}

// binaryData contains the verified openframe ELF binary ready for installation
```

## Security Notes

- Signature verification uses cosign against a pinned GitHub Actions OIDC identity
- Checksums are authenticated **before** being used to verify the archive, preventing a compromised release upload from bypassing validation
- Mirrors the exact trust order used by `openframe update` (audit B5/T2), ensuring WSL installations meet the same security bar as native self-updates
