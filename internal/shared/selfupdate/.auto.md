Handles opt-in automatic self-update logic for the OpenFrame CLI, checking for and applying newer same-major releases in a rate-limited, best-effort manner after command execution.

## Key Components

| Symbol | Description |
|---|---|
| `autoUpdateEnv` | Environment variable constant (`OPENFRAME_AUTO_UPDATE`) that gates automatic updates |
| `AutoUpdateEnabled()` | Reports whether the user has opted into auto-update via the env var |
| `MaybeAutoUpdate()` | Core function: rate-limited check + in-place apply for same-major upgrades |
| `sameMajor()` | Helper that compares semver major versions between current and latest release |

## Usage Example

```go
// After a command completes, attempt a background auto-update
msg := selfupdate.MaybeAutoUpdate(
    ctx,
    "v1.3.0",   // current version
    true,        // interactive terminal
    func(status string) {
        fmt.Fprintln(os.Stderr, status)
    },
)
if msg != "" {
    fmt.Fprintln(os.Stderr, msg)
}
```

## Behavior Notes

- **Opt-in only** — auto-update is disabled unless `OPENFRAME_AUTO_UPDATE=true` is set
- **Rate-limited** — shares the daily `checkInterval` marker with the passive update notice
- **Major version safety** — a major bump is never auto-applied; it surfaces a manual-update notice instead
- **Non-blocking** — capped at a 10-minute timeout; never returns an error or alters exit code
- **Rollback** — after a successful update, users can revert with `openframe update rollback`
