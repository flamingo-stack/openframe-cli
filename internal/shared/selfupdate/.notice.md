## notice.go

Implements a passive, rate-limited self-update notice for the OpenFrame CLI. It checks GitHub (at most once every 24 hours, cached on disk) for a newer release and returns a one-line upgrade message when appropriate, without ever blocking or surfacing errors to the caller.

## Key Components

- **`checkInterval`** — constant defining the 24-hour cache window between GitHub queries.
- **`timeNow` / `fetchLatest`** — package-level function variables that seam off time and network dependencies, allowing tests to control the clock and mock the GitHub release fetch.
- **`noticeState`** — struct persisted as JSON (`lastCheck`, `latest`) representing the cached result of the last update check.
- **`stateFile()`** — resolves the on-disk path `~/.openframe/state/update-check.json` for the cache.
- **`loadState()` / `saveState(s noticeState)`** — read and write the cached notice state, failing silently on any error.
- **`noticeSuppressed(current string, interactive bool) bool`** — determines whether the notice must stay silent (opt-out env var, non-interactive session, or unparseable dev version).
- **`MaybeNotify(ctx context.Context, current string, interactive bool) string`** — main entry point; performs the best-effort, rate-limited check and returns an upgrade message or `""`.
- **`notice(current, latest string) string`** — formats the human-readable upgrade message.

## Usage Example

```go
package main

import (
	"context"
	"fmt"
	"os"

	"github.com/flamingo-stack/openframe-cli/internal/selfupdate"
)

func main() {
	ctx := context.Background()
	msg := selfupdate.MaybeNotify(ctx, "v1.2.3", true /* interactive */)
	if msg != "" {
		fmt.Fprintln(os.Stderr, msg)
	}
	// ... continue with normal CLI execution
}
```

Callers should invoke `MaybeNotify` early in CLI startup and print any non-empty result to stderr, keeping stdout clean for machine-readable output. Set the `OPENFRAME_NO_UPDATE_CHECK` environment variable to disable the check entirely.
