## notice.go

Implements a passive, rate-limited "new version available" notice for the OpenFrame CLI's self-update mechanism. It caches the last GitHub release check to disk and avoids network calls more than once every 24 hours, staying silent on any failure so it never disrupts normal CLI usage.

## Key Components

- **`checkInterval`** — 24-hour gate between GitHub API checks; cached results are served in between.
- **`timeNow` / `fetchLatest`** — package-level function variables that seam off the clock and the GitHub release lookup, enabling deterministic tests without waiting or hitting the network.
- **`noticeState`** — struct persisted as JSON, tracking `LastCheck` (unix seconds) and `Latest` (tag name).
- **`stateFile()`** — resolves the cache path at `~/.openframe/state/update-check.json`.
- **`loadState()` / `saveState()`** — read/write the cached state, failing silently on any I/O error.
- **`noticeSuppressed(current, interactive)`** — determines whether the check should be skipped: opt-out via `OPENFRAME_NO_UPDATE_CHECK`, non-interactive sessions (CI, pipes, machine output), or dev builds without a comparable version.
- **`MaybeNotify(ctx, current, interactive)`** — main entry point; performs the best-effort, rate-limited check (2-second timeout) and returns a formatted upgrade message, or an empty string when no notice is warranted.
- **`notice(current, latest)`** — formats the human-readable upgrade message.

## Usage Example

```go
package main

import (
	"context"
	"fmt"
	"os"

	"github.com/flamingo-stack/openframe-cli/internal/selfupdate"
)

func main() {
	ctx := context.Background()
	currentVersion := "v1.2.3"
	interactive := true // e.g., derived from ui.IsNonInteractive()

	if msg := selfupdate.MaybeNotify(ctx, currentVersion, interactive); msg != "" {
		fmt.Fprintln(os.Stderr, msg)
	}
}
```

This is typically invoked once near CLI startup (or after a command completes) so users see the notice on stderr without affecting stdout output used for scripting or machine-readable results.
