Handles passive, rate-limited update notifications by checking GitHub for newer CLI releases and caching results on disk to avoid redundant network calls.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `checkInterval` | Constant | 24-hour cooldown between GitHub version checks |
| `noticeState` | Struct | JSON-serializable cache holding the last check timestamp and latest version string |
| `stateFile()` | Function | Resolves the cache path: `~/.openframe/state/update-check.json` |
| `loadState()` / `saveState()` | Functions | Read/write the `noticeState` cache from disk; failures are silently ignored |
| `noticeSuppressed()` | Function | Returns `true` when the notice must be suppressed (opt-out via `OPENFRAME_NO_UPDATE_CHECK`, non-interactive environment, or dev build) |
| `MaybeNotify()` | Function | Primary entry point — returns a one-line upgrade message or `""` if suppressed, within budget, or on any error |
| `notice()` | Function | Formats the human-readable upgrade string |

## Usage Example

```go
// Typically called once at command startup, result printed to stderr.
msg := selfupdate.MaybeNotify(ctx, "v1.2.0", ui.IsInteractive())
if msg != "" {
    fmt.Fprintln(os.Stderr, msg)
}
// Example output:
// A new OpenFrame CLI release is available: v1.2.0 → v1.3.0. Run `openframe update` to upgrade.
```

## Behavior Notes

- **Cache-first**: If a cached result exists and is younger than 24 hours, no network call is made.
- **Timeout-bounded**: Live GitHub checks are capped at 2 seconds via `context.WithTimeout`.
- **Silent failures**: All errors return `""` — this path must never disrupt machine-parseable output.
- **Suppression conditions**: Set `OPENFRAME_NO_UPDATE_CHECK=true` to opt out, or the check is automatically suppressed in CI/piped environments.
