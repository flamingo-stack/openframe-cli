## notice.go

Implements a passive, rate-limited update notice for the OpenFrame CLI. It checks GitHub for a newer release at most once every 24 hours, caching the result on disk, and returns a one-line upgrade message when a newer version is available — without ever blocking the CLI or surfacing errors.

## Key Components

- **`checkInterval`** — constant (24 hours) controlling how often GitHub is re-queried between cache reads.
- **`timeNow` / `fetchLatest`** — package-level function variables that seam off the clock and the GitHub `Latest` call, enabling deterministic tests.
- **`noticeState`** — struct persisted as JSON, storing `LastCheck` (unix seconds) and `Latest` (tag name).
- **`stateFile()`** — resolves the cache file path at `~/.openframe/state/update-check.json`.
- **`loadState()` / `saveState()`** — read/write the cached `noticeState`, failing silently on any error.
- **`noticeSuppressed(current, interactive)`** — determines whether the check should be skipped due to opt-out env var (`OPENFRAME_NO_UPDATE_CHECK`), non-interactive execution, or an unversioned dev build.
- **`MaybeNotify(ctx, current, interactive)`** — main entry point: performs the rate-limited check (from cache or via a short-timeout network call) and returns an upgrade message or `""`.
- **`notice(current, latest)`** — formats the human-readable upgrade message.

## Usage Example

```go
package main

import (
	"context"
	"fmt"
	"os"

	"github.com/flamingo-stack/openframe-cli/internal/selfupdate"
	"github.com/flamingo-stack/openframe-cli/internal/shared/ui"
)

func main() {
	ctx := context.Background()
	currentVersion := "v1.2.3"

	msg := selfupdate.MaybeNotify(ctx, currentVersion, !ui.IsNonInteractive())
	if msg != "" {
		fmt.Fprintln(os.Stderr, msg)
	}

	// ... rest of CLI command execution
}
```

Calling `MaybeNotify` is safe to invoke unconditionally on CLI startup: it enforces its own timeout, respects the opt-out environment variable, and never returns an error — only an optional string to print to `stderr`.
