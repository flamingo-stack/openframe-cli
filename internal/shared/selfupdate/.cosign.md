Handles Sigstore/cosign signature verification for self-update artifacts, ensuring downloaded binaries were produced by the official GitHub Actions release workflow for this repository.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `signerIssuer` | `const` | OIDC issuer pinned to GitHub Actions token provider |
| `signerSANRegex` | `const` | Regex matching the Fulcio cert SAN for the `release.yml` workflow on `main` or any tag ref |
| `bundleAsset` | `const` | Name of the Sigstore bundle asset published alongside `checksums.txt` |
| `insecureSkipEnv` | `const` | Env var escape hatch (`OPENFRAME_UPDATE_INSECURE_SKIP_VERIFY`) to bypass verification |
| `sigVerifier` | `struct` | Holds trust root and certificate identity; performs artifact verification against the transparency log |
| `verifyChecksumsProd` | `func` | Production entry point — bootstraps TUF trust root and verifies the checksums bundle |
| `fetchTrustRoot` | `func` | Fetches and caches the Sigstore public-good trust root under `~/.openframe/state/tuf` |
| `loadBundle` | `func` | Parses a Sigstore bundle from raw JSON bytes |
| `pinnedIdentity` | `func` | Builds the `CertificateIdentity` policy for the pinned signer |

## Usage Example

```go
// Called internally during self-update; not intended for direct use.
// verifyChecksumsProd wires together trust root + identity + bundle:
err := verifyChecksumsProd(ctx, checksumBytes, bundleJSONBytes)
if err != nil {
    log.Fatalf("signature verification failed: %v", err)
}

// To skip verification in emergencies (not recommended):
// export OPENFRAME_UPDATE_INSECURE_SKIP_VERIFY=1
```

> **Security note:** Both the issuer (`https://token.actions.githubusercontent.com`) and the SAN regex are pinned to [`flamingo-stack/openframe-cli`](https://github.com/flamingo-stack/openframe-cli)'s `release.yml` workflow. Signatures from any other repository, workflow file, or OIDC issuer are rejected.
