Handles the core self-update logic for the OpenFrame CLI, including version comparison, release archive downloading, signature verification, and atomic executable replacement with rollback support.

## Key Components

### Types

- **`Status`** — Struct representing the outcome of a version check, including current/latest versions, update availability, and whether it's a dev build.
- **`Updater`** — Primary struct that orchestrates the update flow. Configurable with custom `GOOS`/`GOARCH`, executable path overrides, a checksum verifier, and a `Warn` callback for persistent messages.
- **`checksumVerifier`** — Function type for verifying cosign signature bundles; defaults to `verifyChecksumsProd` in production.

### Functions

| Function | Description |
|---|---|
| `IsNewer(current, latest string) bool` | Returns `true` if `latest` is a strictly higher semver than `current`; dev builds always return `false` |
| `ChangeVerb(current, target string) string` | Returns a human-readable direction string: `"Update"`, `"Downgrade"`, `"Reinstall"`, or `"Switch"` |
| `(u Updater) Check(...)` | Queries latest or tagged release and returns a `Status` struct |
| `(u Updater) Apply(...)` | Downloads, verifies, and atomically installs a release with smoke-test and rollback |
| `swapExecutable(...)` | Smoke-tests the staged binary, then atomically renames it into place with a `.bak` fallback |
| `(u Updater) verifySignature(...)` | Fetches and verifies the cosign bundle; respects `OPENFRAME_UPDATE_INSECURE_SKIP_VERIFY=1` escape hatch |

## Usage Example

```go
updater := selfupdate.Updater{
    Current: cmd.DefaultVersionInfo.Version,
    Client:  selfupdate.NewGitHubClient("flamingo-stack", "openframe-cli"),
    Warn: func(msg string) { fmt.Fprintln(os.Stderr, msg) },
}

status, rel, err := updater.Check(ctx, "")
if err != nil {
    log.Fatal(err)
}

if status.Available {
    err = updater.Apply(ctx, rel, func(msg string) {
        fmt.Println(msg)
    })
}
```

> **Windows note:** `Apply` returns an error on native Windows; users must re-run the installer from [releases](https://github.com/flamingo-stack/openframe-cli/releases).
