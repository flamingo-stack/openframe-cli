Provides GitHub release metadata fetching and checksum parsing for the OpenFrame CLI self-update mechanism, targeting the `flamingo-stack/openframe-cli` repository.

## Key Components

### Types

- **`Release`** — Subset of a GitHub release payload: tag name, HTML URL, prerelease flag, and attached assets
- **`Asset`** — A single downloadable file (name + browser download URL) attached to a release
- **`Client`** — Configurable HTTP client for the GitHub Releases API; zero value is ready to use

### Functions & Methods

| Symbol | Description |
|---|---|
| `Client.Latest` | Fetches the latest non-prerelease release via `/releases/latest` |
| `Client.ForTag` | Fetches a release by tag; auto-retries with `v`-prefix toggled on 404 |
| `Client.fetchAsset` | Downloads a named asset (bounded to 8 MiB); used for `checksums.txt` and signature bundles |
| `GitHubToken` | Reads `GITHUB_TOKEN` or `GH_TOKEN` from the environment for authenticated API access |
| `parseChecksum` | Extracts a SHA-256 hex digest for a filename from a `sha256sum`-format listing |
| `alternateTag` | Toggles the `v` prefix on a tag string (e.g. `0.4.7` ↔ `v0.4.7`) |

### Sentinel Error

- **`ErrReleaseNotFound`** — Returned when GitHub responds with HTTP 404 for a tag lookup

## Usage Example

```go
ctx := context.Background()

client := selfupdate.Client{
    Token: selfupdate.GitHubToken(), // optional; raises rate limit
}

// Get latest release
rel, err := client.Latest(ctx)
if err != nil {
    log.Fatal(err)
}
fmt.Println("Latest:", rel.TagName, rel.HTMLURL)

// Fetch checksums for artifact verification
data, err := client.fetchAsset(ctx, rel, "checksums.txt")
if err != nil {
    log.Fatal(err)
}

digest, err := selfupdate.parseChecksum(string(data), "openframe-cli_linux_amd64.tar.gz")
// digest is the expected SHA-256 hex string for the artifact
```

> **Security note:** Downloaded artifacts are verified by SHA-256 against `checksums.txt` before touching disk. `checksums.txt` itself is verified via cosign keyless signatures pinned to this repo's GitHub Actions OIDC identity. Set `OPENFRAME_UPDATE_INSECURE_SKIP_VERIFY` to downgrade to integrity-only (with a loud warning).
