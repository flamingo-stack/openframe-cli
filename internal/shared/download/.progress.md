## progress.go

Implements terminal download progress feedback for the `download` package, rendering either a live self-rewriting progress bar or sequential begin/done messages depending on terminal capabilities and current UI state (silent mode, active spinners).

## Key Components

- **`progressEnabled()`** — Determines if the live progress bar can be safely rendered (interactive terminal, not silent, no active spinner).
- **`announceEnabled()`** — Determines if simple begin/done text announcements should be used instead (non-TTY or `--plain` contexts).
- **`progressReader`** — An `io.Reader` wrapper that tracks bytes read and periodically renders a progress line to stderr as data streams through it.
- **`newProgressReader(r io.Reader, label string, total int64) *progressReader`** — Constructs a `progressReader` for a given download stream, label, and expected total size (`-1` if unknown).
- **`(*progressReader).Read(b []byte) (int, error)`** — Reads bytes while triggering throttled progress rendering (every `progressRenderInterval`).
- **`(*progressReader).render()`** — Draws the progress bar/line (percentage, speed, byte count) to stderr.
- **`(*progressReader).done()`** — Clears the progress line once the download completes.
- **`announceStart(label string, total int64)` / `announceDone(label string, took time.Duration)`** — Print sequential start/completion messages via `pterm` for non-live contexts.
- **`humanBytes(n int64) string`** — Formats byte counts as human-readable strings (B, KB, MB, GB).
- **`assetLabel(rawURL string) string`** — Extracts a display label from a download URL's base filename.

## Usage Example

```go
label := assetLabel(downloadURL)

if progressEnabled() {
    pr := newProgressReader(resp.Body, label, resp.ContentLength)
    defer pr.done()
    io.Copy(dest, pr)
} else if announceEnabled() {
    start := time.Now()
    announceStart(label, resp.ContentLength)
    io.Copy(dest, resp.Body)
    announceDone(label, time.Since(start))
} else {
    io.Copy(dest, resp.Body)
}
```

This pattern ensures downloads show appropriate feedback (live bar, text updates, or silence) without interfering with spinners or `--silent`/`--plain` modes.
