## progress.go

Renders download progress feedback for CLI operations, choosing between a live self-rewriting progress bar (for interactive terminals) and sequential begin/done log lines (for non-TTY or `--plain` contexts), while staying silent when appropriate.

## Key Components

- **`progressEnabled()`** — Returns `true` when the live progress bar is safe to render: animated UI mode, not silent, and no spinner currently active.
- **`announceEnabled()`** — Returns `true` when sequential begin/done announcements should be used instead of the live bar (non-TTY or `--plain` mode, unless silent or a spinner owns the line).
- **`progressReader`** — An `io.Reader` wrapper that tracks bytes read and periodically renders a progress line (with percentage/bar if total size is known, or raw byte count otherwise) to stderr.
  - `newProgressReader(r io.Reader, label string, total int64) *progressReader` — constructs a reader; `total < 0` indicates unknown content length.
  - `(*progressReader).Read(b []byte)` — proxies reads and triggers throttled rendering (every `progressRenderInterval`, 120ms).
  - `(*progressReader).render()` — writes the current progress line, including transfer speed.
  - `(*progressReader).done()` — clears the progress line once the download completes.
- **`announceStart(label string, total int64)`** / **`announceDone(label string, took time.Duration)`** — Print simple info-level start/finish messages for non-live-bar contexts.
- **`humanBytes(n int64) string`** — Formats byte counts as human-readable strings (B, KB, MB, GB).
- **`assetLabel(rawURL string) string`** — Derives a display label from a URL's path basename, falling back to `"download"`.

## Usage Example

```go
label := assetLabel(resp.Request.URL.String())
total := resp.ContentLength

if progressEnabled() {
    pr := newProgressReader(resp.Body, label, total)
    defer pr.done()
    io.Copy(dst, pr)
} else if announceEnabled() {
    start := time.Now()
    announceStart(label, total)
    io.Copy(dst, resp.Body)
    announceDone(label, time.Since(start))
} else {
    io.Copy(dst, resp.Body)
}
```

This pattern is used internally by the `download` package to wrap HTTP response bodies, giving users appropriate visual feedback based on terminal capabilities and CLI verbosity flags.
