## progress.go

Implements terminal progress reporting for file downloads in the `download` package. It renders a self-rewriting progress bar on stderr for interactive contexts, or falls back to sequential begin/done announcements when a live bar can't be safely displayed (non-TTY, `--plain` mode, or while a spinner is active).

## Key Components

- **`progressEnabled()`** — Returns true when the live progress bar can safely render (animated terminal, not silent, no spinner active).
- **`announceEnabled()`** — Returns true when sequential begin/done text lines should be used instead of the live bar.
- **`progressReader`** — An `io.Reader` wrapper that tracks bytes read and periodically renders a progress line (bar + percentage + speed, or byte count + speed if total size is unknown).
  - `newProgressReader(r io.Reader, label string, total int64) *progressReader` — Constructor; `total < 0` indicates unknown content length.
  - `Read(b []byte) (int, error)` — Delegates to the wrapped reader, tracking progress and throttling renders to every 120ms.
  - `render()` — Writes the current progress line to stderr, overwriting the previous line.
  - `done()` — Clears the progress line once the download completes.
- **`announceStart(label string, total int64)`** / **`announceDone(label string, took time.Duration)`** — Print simple info lines for non-live-bar contexts.
- **`humanBytes(n int64) string`** — Formats byte counts as human-readable strings (B, KB, MB, GB).
- **`assetLabel(rawURL string) string`** — Extracts a display label from a URL's path base name, defaulting to `"download"`.

## Usage Example

```go
resp, err := http.Get(url)
if err != nil {
    return err
}
defer resp.Body.Close()

label := assetLabel(url)
total := resp.ContentLength

if progressEnabled() {
    pr := newProgressReader(resp.Body, label, total)
    defer pr.done()
    _, err = io.Copy(dstFile, pr)
} else {
    if announceEnabled() {
        announceStart(label, total)
    }
    start := time.Now()
    _, err = io.Copy(dstFile, resp.Body)
    if announceEnabled() {
        announceDone(label, time.Since(start))
    }
}
```

This pattern ensures downloads show appropriate feedback depending on terminal capabilities, avoiding conflicts with active spinners or silent/plain output modes.
