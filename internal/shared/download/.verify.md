# verify.go

Part of the `download` package, this file implements checksum-verified, atomic installation of pinned prerequisite binaries. It replaces unsafe `curl | bash`-style installs by pinning every asset to a version and SHA256 digest, downloading to memory, verifying the checksum, and only then writing the result to disk via a temp-file-plus-rename pattern.

## Key Components

- **`PinnedAsset`** — a single platform's download URL paired with its expected lowercase-hex SHA256.
- **`PinnedTool`** — a tool pinned to a version with per-platform `PinnedAsset` map (keyed `"<GOOS>/<GOARCH>"`), plus `Tarball`/`Zip` flags describing the archive layout. Method `Asset(goos, goarch)` looks up the platform-specific asset.
- **`VerifyChecksum(data, wantHex)`** — computes SHA256 of `data` and compares (case-insensitively) against `wantHex`.
- **`Downloader`** — struct wrapping an `*http.Client` (defaults to a 5-minute-timeout client if unset).
  - `FetchVerified(ctx, asset)` — downloads with a 512 MiB size cap, optional progress/announce reporting, and checksum verification; never returns unverified data.
  - `InstallVerified(ctx, asset, destPath, perm)` — fetches a bare binary and installs it atomically.
  - `InstallVerifiedTarGz` / `InstallVerifiedZipMember` — fetch, extract a named archive member (with a 200 MiB decompression-bomb guard), and install atomically.
  - `FetchVerifiedTarGzMember` — like the tar.gz installer but returns extracted bytes instead of writing to disk (e.g., for streaming into WSL).
- **`extractTarGzMember` / `extractZipMember`** — internal helpers that locate and safely extract a single regular file from a gzip/tar or zip archive.
- **`writeFileAtomic`** — writes bytes to a temp file in the destination directory, `chmod`s it, then renames it into place; cleans up on any failure so no partial file remains.

## Usage Example

```go
tool := download.PinnedTool{
    Name:    "helm",
    Version: "3.14.0",
    Tarball: true,
    Assets: map[string]download.PinnedAsset{
        "linux/amd64": {
            URL:    "https://get.helm.sh/helm-v3.14.0-linux-amd64.tar.gz",
            SHA256: "abc123...",
        },
    },
}

asset, ok := tool.Asset("linux", "amd64")
if !ok {
    log.Fatal("no asset for this platform")
}

d := download.Downloader{}
err := d.InstallVerifiedTarGz(
    context.Background(),
    asset,
    "linux-amd64/helm", // member path inside the archive
    "/usr/local/bin/helm",
    0o755,
)
if err != nil {
    log.Fatalf("install failed: %v", err)
}
```
