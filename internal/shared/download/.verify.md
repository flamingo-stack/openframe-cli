## verify.go

Implements checksum-verified, atomic installation of pinned binary tool downloads for the `download` package. It downloads assets over HTTP, enforces size caps to guard against memory exhaustion and decompression bombs, verifies SHA256 digests before use, and installs binaries (bare, `.tar.gz`, or `.zip`) via a temp-file-plus-rename pattern so failures never leave partial or unverified files in place.

## Key Components

- **`PinnedAsset`** — A single platform's download URL paired with its expected lowercase-hex SHA256.
- **`PinnedTool`** — A tool pinned to a version, with per-platform `Assets` (keyed `"<GOOS>/<GOARCH>"`) and `Tarball`/`Zip` flags describing archive layout. `Asset(goos, goarch)` looks up the platform-specific `PinnedAsset`.
- **`VerifyChecksum(data, wantHex)`** — Computes SHA256 of `data` and compares (case-insensitively) against `wantHex`.
- **`Downloader`** — Fetches and verifies assets; zero value works, uses a 5-minute-timeout default HTTP client, or a custom `Client` for testing.
  - **`FetchVerified(ctx, asset)`** — Downloads, caps at 512 MiB, checksum-verifies, and returns bytes (never returns unverified data).
  - **`InstallVerified(ctx, asset, destPath, perm)`** — Fetches a bare-binary asset and atomically writes it to disk.
  - **`InstallVerifiedTarGz(ctx, asset, member, destPath, perm)`** — Fetches, extracts a named member from a `.tar.gz`, and installs it atomically.
  - **`InstallVerifiedZipMember(ctx, asset, member, destPath, perm)`** — Same as above but for `.zip` archives.
  - **`FetchVerifiedTarGzMember(ctx, asset, member)`** — Fetches and extracts a `.tar.gz` member without installing it (e.g. for streaming into WSL).
- **`extractTarGzMember` / `extractZipMember`** — Internal helpers that locate and read a named archive member, capped at 200 MiB to prevent decompression bombs.
- **`writeFileAtomic(body, destPath, perm)`** — Writes bytes to a temp file in the destination directory, `chmod`s it, then renames it into place; cleans up on any error.

## Usage Example

```go
tool := download.PinnedTool{
    Name:    "helm",
    Version: "3.14.0",
    Tarball: true,
    Assets: map[string]download.PinnedAsset{
        "linux/amd64": {
            URL:    "https://get.helm.sh/helm-v3.14.0-linux-amd64.tar.gz",
            SHA256: "abcd1234...", // pinned digest
        },
    },
}

asset, ok := tool.Asset("linux", "amd64")
if !ok {
    log.Fatal("no asset for this platform")
}

var d download.Downloader // zero value uses default client + 5m timeout
err := d.InstallVerifiedTarGz(
    context.Background(),
    asset,
    "linux-amd64/helm", // member path inside the tar.gz
    "/usr/local/bin/helm",
    0o755,
)
if err != nil {
    log.Fatalf("install failed: %v", err)
}
```
