Secure, verified binary download utilities for prerequisite tool installation. Replaces unverified `curl | bash` patterns by pinning every asset to a version and SHA256 digest, verifying before writing, and using atomic file operations to ensure no partial installs remain on failure.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `PinnedAsset` | A single platform download URL paired with its expected SHA256 hex digest |
| `PinnedTool` | A versioned tool with a platform map (`"<GOOS>/<GOARCH>"`) of `PinnedAsset` entries; `Tarball` flag indicates `.tar.gz` archives |
| `Downloader` | Stateful fetcher with an injectable `*http.Client` (defaults to 5-minute timeout) |

### Functions & Methods

| Symbol | Description |
|--------|-------------|
| `PinnedTool.Asset(goos, goarch)` | Looks up the asset for the given platform key |
| `VerifyChecksum(data, wantHex)` | Returns an error if `sha256(data)` does not match the expected hex digest |
| `Downloader.FetchVerified` | Downloads a URL, enforces a 512 MiB cap, verifies checksum, returns bytes |
| `Downloader.InstallVerified` | Fetches a bare binary and atomically installs it to `destPath` |
| `Downloader.InstallVerifiedTarGz` | Fetches a `.tar.gz`, verifies, extracts a named member, installs atomically |
| `Downloader.FetchVerifiedTarGzMember` | Like `InstallVerifiedTarGz` but returns bytes instead of writing to disk (e.g. for piping into WSL) |
| `extractTarGzMember` (internal) | Extracts a single named member from a gzip-compressed tar, capped at 200 MiB |
| `writeFileAtomic` (internal) | Writes via a temp file and `os.Rename`; cleans up on any failure |

## Usage Example

```go
tool := download.PinnedTool{
    Name:    "helm",
    Version: "v3.14.4",
    Tarball: true,
    Assets: map[string]download.PinnedAsset{
        "linux/amd64": {
            URL:    "https://get.helm.sh/helm-v3.14.4-linux-amd64.tar.gz",
            SHA256: "a5844ef2c38ef6ddf3b5a8f7d91e7e0e9c926b9c0de2aae2b26b4fceb4f5fd61",
        },
    },
}

asset, ok := tool.Asset("linux", "amd64")
if !ok {
    log.Fatal("unsupported platform")
}

d := download.Downloader{}
err := d.InstallVerifiedTarGz(ctx, asset, "linux-amd64/helm", "/usr/local/bin/helm", 0755)
if err != nil {
    log.Fatal(err)
}
```
