## verify.go

Implements verified, integrity-checked binary downloads for prerequisite tools, replacing unsafe "curl | bash" style installs. Every asset is pinned to a specific version and SHA256 digest; downloads are checksum-verified before being atomically moved into place, ensuring failures leave no partial or unverified files behind.

## Key Components

- **`PinnedAsset`** – A single platform's download URL paired with its expected lowercase-hex SHA256 checksum.
- **`PinnedTool`** – Describes a tool pinned to a version, with per-platform `Assets` (keyed `"<GOOS>/<GOARCH>"`) and flags (`Tarball`, `Zip`) indicating archive format.
- **`PinnedTool.Asset(goos, goarch)`** – Looks up the pinned asset for a given platform.
- **`VerifyChecksum(data, wantHex)`** – Validates that `sha256(data)` matches the expected hex digest.
- **`Downloader`** – Fetches and verifies pinned assets using an injectable `*http.Client` (defaults to a 5-minute timeout client).
- **`Downloader.FetchVerified`** – Downloads a `PinnedAsset` (capped at 512 MiB), verifies its checksum, and returns the bytes; never returns unverified data.
- **`Downloader.InstallVerified`** – Downloads, verifies, and atomically installs a bare binary to a destination path.
- **`Downloader.InstallVerifiedTarGz`** / **`InstallVerifiedZipMember`** – Downloads, verifies, extracts a named member from a `.tar.gz` or `.zip` archive, and atomically installs it.
- **`Downloader.FetchVerifiedTarGzMember`** – Downloads, verifies, and extracts an archive member's bytes without installing (e.g., for streaming into WSL).
- **`extractTarGzMember` / `extractZipMember`** – Internal helpers that extract a named regular file from an archive, capped at 200 MiB to guard against decompression bombs.
- **`writeFileAtomic`** – Writes bytes to a destination via temp file + rename, ensuring no partial files remain on failure.

## Usage Example

```go
tool := download.PinnedTool{
    Name:    "helm",
    Version: "v3.14.0",
    Tarball: true,
    Assets: map[string]download.PinnedAsset{
        "linux/amd64": {
            URL:    "https://get.helm.sh/helm-v3.14.0-linux-amd64.tar.gz",
            SHA256: "abc123...",
        },
    },
}

asset, ok := tool.Asset("linux", "amd64")
if !ok {
    log.Fatal("no asset for this platform")
}

d := download.Downloader{}
err := d.InstallVerifiedTarGz(
    context.Background(),
    asset,
    "linux-amd64/helm", // member path inside the archive
    "/usr/local/bin/helm",
    0o755,
)
if err != nil {
    log.Fatalf("install failed: %v", err)
}
```
