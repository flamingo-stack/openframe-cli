Defines pinned, checksum-verified versions of external CLI tools (k3d, mkcert, Helm, Terraform, Infracost) required by the `openframe-cli`, replacing unverified `curl | bash`-style installs with SHA256-validated downloads per platform. Also provides helpers for locating the CLI's managed bin directory, installing pinned tools, and safely updating the process `$PATH`.

## Key Components

- **`K3d`, `Mkcert`, `Helm`, `Terraform`, `Infracost`** — `PinnedTool` variables specifying version, download URL template, archive type (raw binary, tarball, or zip), and per-platform (`GOOS/GOARCH`) SHA256 checksums.
- **`UserBinDir() (string, error)`** — Resolves the CLI-managed bin directory (`~/.openframe/bin`) without creating it.
- **`(Downloader) InstallPinnedTool(ctx, tool PinnedTool, binDir string) (string, error)`** — Installs the pinned tool's platform-appropriate asset into `binDir`, verifying checksum, extracting from tarball/zip if needed, and returns the installed binary path.
- **`isArchiveAsset(url string) bool`** — Internal guard detecting archive extensions (`.tar.gz`, `.tgz`, `.zip`) to prevent accidentally installing compressed bytes as a raw executable.
- **`exeName(name string) string`** — Appends `.exe` on Windows.
- **`PrependToPath(dir string)`** — Prepends a directory to the current process's `$PATH` if not already present (process-scoped only).

## Usage Example

```go
package main

import (
	"context"
	"fmt"
	"log"

	"openframe/internal/download"
)

func main() {
	ctx := context.Background()
	d := download.Downloader{}

	binDir, err := download.UserBinDir()
	if err != nil {
		log.Fatal(err)
	}

	helmPath, err := d.InstallPinnedTool(ctx, download.Helm, binDir)
	if err != nil {
		log.Fatal(err)
	}

	download.PrependToPath(binDir)
	fmt.Println("Installed helm at:", helmPath)
}
```

Adding a new tool requires defining its version, base URL, and per-platform SHA256 checksums (sourced from the upstream release's published checksums), then constructing a `PinnedTool` following the existing patterns above.
