Defines pinned, checksum-verified tool definitions and installation helpers for the three external CLI dependencies (k3d, mkcert, Helm) used by the OpenFrame CLI.

## Key Components

### Pinned Tool Variables

| Variable | Version | Notes |
|---|---|---|
| `K3d` | `v5.9.0` | Kubernetes-in-Docker cluster manager |
| `Mkcert` | `v1.4.4` | Local TLS CA; injects root CA into system trust stores |
| `Helm` | `v4.2.2` | Kubernetes package manager; distributed as `.tar.gz` tarball |

Each `PinnedTool` carries per-platform (`linux/amd64`, `linux/arm64`, `darwin/amd64`, `darwin/arm64`) download URLs and hardcoded SHA256 checksums. Bumping a tool version requires updating both the `Version` constant and all four SHA256 values.

### Functions

- **`UserBinDir() (string, error)`** — Returns `~/.openframe/bin`, the managed directory where verified binaries are installed. Does not create it.
- **`(Downloader) InstallPinnedTool(ctx, tool, binDir) (string, error)`** — Resolves the correct asset for `runtime.GOOS`/`runtime.GOARCH`, creates `binDir` if needed, then delegates to `InstallVerified` (bare binary) or `InstallVerifiedTarGz` (tarball, extracting `<os>-<arch>/<name>`). Returns the installed binary path.
- **`PrependToPath(dir string)`** — Prepends `dir` to the current process `PATH` if not already present. Affects only the running process; never modifies shell configuration.

## Usage Example

```go
dl := download.Downloader{}

binDir, err := download.UserBinDir()
if err != nil {
    log.Fatal(err)
}

helmPath, err := dl.InstallPinnedTool(ctx, download.Helm, binDir)
if err != nil {
    log.Fatal(err)
}

download.PrependToPath(binDir)
// helm is now resolvable via exec.LookPath("helm")
_ = helmPath
```
