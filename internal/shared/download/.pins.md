Defines pinned, checksum-verified versions of external CLI tools (k3d, mkcert, Helm, Terraform, Infracost) required by the OpenFrame CLI, replacing unverified `curl | bash` style installs with secure, reproducible downloads.

## Key Components

- **`K3d`, `Mkcert`, `Helm`, `Terraform`, `Infracost`** — `PinnedTool` values declaring the exact version, download URLs, and SHA256 checksums per `GOOS/GOARCH` platform for each managed tool.
- **`UserBinDir() (string, error)`** — Resolves the CLI-managed binary directory (`~/.openframe/bin`) without creating it.
- **`Downloader.InstallPinnedTool(ctx, tool, binDir) (string, error)`** — Selects the correct asset for the current platform, verifies its checksum, extracts it if needed (tar.gz or zip), and installs it into `binDir`. Returns the installed binary path.
- **`isArchiveAsset(url string) bool`** — Internal guard that detects archive extensions (`.tar.gz`, `.tgz`, `.zip`) to prevent installing compressed bytes as a raw executable when a tool's `Tarball`/`Zip` flags are misconfigured.
- **`exeName(name string) string`** — Appends `.exe` on Windows for binary/archive member naming.
- **`PrependToPath(dir string)`** — Adds a directory to the front of the current process's `PATH` (in-memory only, does not modify shell configuration).

## Usage Example

```go
package main

import (
	"context"
	"fmt"
	"log"

	"openframe/internal/download"
)

func main() {
	ctx := context.Background()
	d := download.Downloader{}

	binDir, err := download.UserBinDir()
	if err != nil {
		log.Fatal(err)
	}

	helmPath, err := d.InstallPinnedTool(ctx, download.Helm, binDir)
	if err != nil {
		log.Fatal(err)
	}

	download.PrependToPath(binDir)
	fmt.Println("helm installed at:", helmPath)
}
```

Bumping a tool's version requires updating both its `Version` constant and every platform's SHA256 checksum, sourced from the upstream release's published checksums.
