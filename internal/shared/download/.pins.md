Defines pinned, checksum-verified third-party CLI tools (k3d, mkcert, helm, terraform, infracost) that replace unverified `curl | bash` style installs, plus helpers to install them into the user's OpenFrame bin directory and manage process `$PATH`.

## Key Components

- **`K3d`, `Mkcert`, `Helm`, `Terraform`, `Infracost`** — `PinnedTool` values declaring a fixed version and per-platform (`GOOS/GOARCH`) download URL with SHA256 checksum. `Helm` and `Terraform` are marked `Tarball`/`Zip` respectively since their assets are archives requiring extraction.
- **`UserBinDir() (string, error)`** — Returns `~/.openframe/bin`, the directory where verified binaries are installed (does not create it).
- **`(Downloader) InstallPinnedTool(ctx, tool, binDir) (string, error)`** — Resolves the asset for the current platform, verifies its checksum, extracts it if it's a tarball/zip (or installs the raw binary otherwise), and returns the installed path. Fails if no asset matches the current platform, or if an archive asset is misconfigured without `Tarball`/`Zip` set.
- **`isArchiveAsset(url) bool`** — Detects `.tar.gz`/`.tgz`/`.zip` URLs to guard against installing compressed bytes as an executable.
- **`exeName(name) string`** — Appends `.exe` on Windows.
- **`PrependToPath(dir)`** — Prepends `dir` to the current process's `$PATH` (in-memory only, no shell profile changes) if not already present.

## Usage Example

```go
package main

import (
	"context"
	"fmt"
	"log"

	"openframe-cli/internal/download" // adjust import path as needed
)

func main() {
	ctx := context.Background()
	d := download.Downloader{}

	binDir, err := download.UserBinDir()
	if err != nil {
		log.Fatal(err)
	}

	path, err := d.InstallPinnedTool(ctx, download.Helm, binDir)
	if err != nil {
		log.Fatal(err)
	}

	download.PrependToPath(binDir)
	fmt.Printf("helm installed at %s\n", path)
}
```

Upgrading a tool requires bumping its `Version` constant and updating every platform's SHA256 with the value published in the upstream release's checksums.
