Wraps errors from interactive confirmation prompts, distinguishing between user interruptions (Ctrl-C) and other prompt failures.

## Key Components

- **`WrapConfirmationError(err error, context string) error`** — Inspects a prompt error and returns it appropriately:
  - `nil` in → `nil` out
  - Interruption signal (Ctrl-C) → returned as-is, allowing `HandleGlobalError` in `main` to print a friendly cancellation message and exit cleanly
  - Any other error → wrapped with the provided `context` prefix using `fmt.Errorf`

## Usage Example

```go
confirmed, err := prompt.AskConfirmation("Delete resource?")
if err := errors.WrapConfirmationError(err, "confirmation prompt failed"); err != nil {
    return err
}
```

## Notes

- Interruption errors are intentionally **not** wrapped — this preserves their identity so upstream handlers (e.g. `HandleGlobalError`) can detect and handle them uniformly with a user-friendly message.
- Never calls `os.Exit` directly; relies on the main error-handling flow for cleanup and exit.
- Depends on `isInterruption(err)` (defined elsewhere in the `errors` package) to detect Ctrl-C signals.
