## errors.go

Centralized error handling for the OpenFrame CLI. Defines domain-specific error types (validation, command execution, branch lookup) and an `ErrorHandler` that renders each into a consistent, actionable terminal panel using `pterm`, distinguishing user interruptions (Ctrl+C) from real failures.

## Key Components

- **`ValidationError`** – field/value/message struct for input validation failures.
- **`AlreadyHandledError`** – wraps an error already displayed to the user, to prevent double-reporting; supports `Unwrap()`.
- **`BranchNotFoundError`** – reports a missing git ref, optionally carrying `Branches`/`Tags` discovered via preflight; `AvailableSummary()` formats them (branches sorted alphabetically, tags version-sorted and capped at `maxTagsShown`).
- **`NewBranchNotFoundError` / `NewBranchNotFoundErrorWithRefs`** – constructors for `BranchNotFoundError`.
- **`ErrorHandler`** – created via `NewErrorHandler(verbose bool)`; its `HandleError(err error)` method dispatches on error type:
  - `ValidationError` → field/value/issue printout
  - `executor.CommandError` → command, exit code, and stderr output, plus a friendly hint
  - `BranchNotFoundError` → missing ref plus available branches/tags
  - anything else → a structured "cause / hint / resume" panel, or a friendly cancellation message for Ctrl+C
- **Helper functions** – `splitCause` (separates headline from root cause across wrapped errors), `firstLine`, `panelRow`, `genericHint`/`friendlyHint`, and `isInterruption`/`isUserInterruption` (detects `context.Canceled`, `ui.ErrPromptInterrupted`, or "interrupted"/"^C" text without over-matching).

## Usage Example

```go
package main

import (
	"github.com/flamingo-stack/openframe-cli/internal/shared/errors"
)

func run() error {
	if invalidInput {
		return &errors.ValidationError{
			Field:   "cluster-name",
			Value:   "My_Cluster",
			Message: "must be lowercase alphanumeric",
		}
	}
	return nil
}

func main() {
	handler := errors.NewErrorHandler(true) // verbose mode

	if err := run(); err != nil {
		handler.HandleError(err)
	}
}
```

When a command fails, wrap it so `ErrorHandler` can extract command context automatically, and use `NewBranchNotFoundErrorWithRefs` when ref discovery data is available, to give users a concrete list of valid branches/tags instead of a generic "check the name" message.
