Centralized error handling package for the OpenFrame CLI, providing structured error types and consistent user-facing error display across all commands.

## Key Components

- **`ValidationError`** — Structured error for field-level validation failures, optionally including the invalid value
- **`AlreadyHandledError`** — Sentinel wrapper indicating an error has already been displayed; prevents double-printing in cobra/main error paths
- **`BranchNotFoundError`** — Specialized error for missing Git refs, with actionable `--ref` hint
- **`ErrorHandler`** — Core handler with typed dispatch (`ValidationError`, `executor.CommandError`, `BranchNotFoundError`, generic) and optional verbose mode
- **`HandleGlobalError`** — Top-level entry point for cobra `RunE` functions; displays the error once and returns `AlreadyHandledError` so deferred cleanup still runs
- **`isInterruption`** — Detects Ctrl+C via `context.Canceled`, `"^C"`, or exact `"interrupted"` match without false-positives on network errors

## Usage Example

```go
// In a cobra RunE function:
func runMyCommand(cmd *cobra.Command, args []string) error {
    verbose, _ := cmd.Flags().GetBool("verbose")

    if err := doWork(); err != nil {
        return errors.HandleGlobalError(err, verbose)
    }
    return nil
}

// In main.go — suppress re-printing errors already shown:
if err := rootCmd.Execute(); err != nil {
    var alreadyHandled *errors.AlreadyHandledError
    if !stderrors.As(err, &alreadyHandled) {
        fmt.Fprintln(os.Stderr, err)
    }
    os.Exit(1)
}

// Constructing typed errors:
return errors.NewBranchNotFoundError("feature/my-branch")

return &errors.ValidationError{
    Field:   "cluster-name",
    Value:   "my cluster!",
    Message: "must be alphanumeric with hyphens only",
}
```
