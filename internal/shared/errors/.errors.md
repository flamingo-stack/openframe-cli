## Purpose

`errors.go` implements the CLI's centralized error handling and presentation layer. It classifies errors by type (validation, command execution, missing branch, generic), renders them as consistent, human-readable panels via `pterm`, and distinguishes real failures from user-initiated interruptions (Ctrl+C).

## Key Components

- **`ValidationError`** — represents field-level validation failures with `Field`, `Value`, and `Message`.
- **`AlreadyHandledError`** — wraps an error that has already been displayed, preventing duplicate output while preserving the chain via `Unwrap`.
- **`BranchNotFoundError`** — represents a missing git ref; carries `Branches`/`Tags` when known, and exposes `AvailableSummary()` to list available refs (tags capped and version-sorted via `maxTagsShown`).
- **`ErrorHandler`** — main entry point, created with `NewErrorHandler(verbose bool)`. Its `HandleError(err)` method dispatches to type-specific handlers using `errors.As`:
  - `handleValidationError` — prints field/value/message.
  - `handleCommandError` — prints failed command, exit code, and captured stderr (matches `executor.CommandError`, the type actually returned by command execution).
  - `handleBranchNotFoundError` — prints the missing branch and available refs.
  - `handleGenericError` — renders a structured panel (`cause`, `chain`, `hint`, `resume`) using `splitCause`, `genericHint`, and an optional `ResumeHint()` interface.
- **Helper functions**: `splitCause` (separates outer message from root cause), `firstLine`, `panelRow` (aligned key/value panel rows), `genericHint`/`friendlyHint` (contextual troubleshooting tips), `isInterruption`/`isUserInterruption` (detects Ctrl+C via `context.Canceled` or `ui.ErrPromptInterrupted`).
- **Constructors**: `NewBranchNotFoundError`, `NewBranchNotFoundErrorWithRefs`.

## Usage Example

```go
package main

import (
	"github.com/flamingo-stack/openframe-cli/internal/shared/errors"
)

func run() error {
	// ... command logic that may fail ...
	return &errors.ValidationError{
		Field:   "cluster-name",
		Value:   "My Cluster",
		Message: "must be lowercase alphanumeric",
	}
}

func main() {
	handler := errors.NewErrorHandler(true) // verbose mode

	if err := run(); err != nil {
		handler.HandleError(err)
	}
}
```

Errors from other packages (e.g., `executor.CommandError`) are automatically detected and rendered with tailored output—no need to manually type-switch at call sites.
