## errors.go

Centralized error types and a formatted error-reporting handler for the OpenFrame CLI. It classifies errors (validation, command execution, missing branch, generic) and renders each as a clear, actionable panel instead of a raw error dump, with special handling for user interruptions (Ctrl+C) and GitHub Actions annotations.

## Key Components

- **`ValidationError`** – Represents field/value validation failures with a descriptive `Error()` message.
- **`AlreadyHandledError`** – Wraps errors already displayed to the user, to avoid duplicate reporting; supports `Unwrap()`.
- **`BranchNotFoundError`** – Represents a missing git ref, optionally carrying available `Branches`/`Tags` for display via `AvailableSummary()`.
- **`ErrorHandler`** – Created with `NewErrorHandler(verbose bool)`; its `HandleError(err error)` method dispatches to type-specific renderers:
  - `handleValidationError` – prints field/value/issue.
  - `handleCommandError` – prints failed command, exit code, and captured stderr output (matches `executor.CommandError`).
  - `handleBranchNotFoundError` – prints the missing branch and available refs.
  - `handleGenericError` – prints a structured panel (`cause`, `chain` if verbose, `hint`, `resume`), with GitHub Actions annotation support via `ui.ErrorAnnotation`.
- **Helper functions** – `splitCause`, `firstLine`, `panelRow`, `genericHint`, `friendlyHint`, `isInterruption`/`isUserInterruption` for formatting and detecting Ctrl+C cancellations.
- **Constructors** – `NewBranchNotFoundError(branch string)`, `NewBranchNotFoundErrorWithRefs(branch string, branches, tags []string)`.

## Usage Example

```go
handler := errors.NewErrorHandler(verbose)

if err := runClusterCreate(); err != nil {
    if stderrors.As(err, new(*errors.ValidationError)) {
        // handled uniformly inside HandleError
    }
    handler.HandleError(err)
    os.Exit(1)
}

// Constructing a branch-not-found error with available refs:
err := errors.NewBranchNotFoundErrorWithRefs("feature-x", []string{"main", "develop"}, tags)
handler.HandleError(err)
```

`HandleError` automatically detects the concrete error type (`ValidationError`, `executor.CommandError`, `BranchNotFoundError`, or generic) and prints the appropriate formatted output, so callers only need to invoke it once per top-level error.
