# friendly.go

Provides plain-language, actionable hints for common low-level failure messages, giving non-technical users a "did you mean" style suggestion alongside raw error output rather than replacing it.

## Key Components

- **`SelfDiagnosed` interface** – marker interface for errors that already carry their own root-cause diagnosis (e.g., embedded pod logs/events). When an error implements this and returns `true`, `friendlyHint` skips pattern matching to avoid misdiagnosing based on embedded diagnostic text.
- **`friendlyHint(err error) string`** – inspects the lowercased error message and returns a friendly hint string for known failure patterns (Helm ownership conflicts, pending Helm releases, connection issues, DNS resolution failures, timeouts, permission errors, missing kube-context, Docker not running), or an empty string if none match or the error is self-diagnosed.
- **`containsAny(s string, subs ...string) bool`** – helper that checks whether a string contains any of the given substrings.

Note the ordering: Helm ownership metadata and pending-release checks are matched *before* the generic timeout/connection cases, since those failures often surface with timeout-like wrapping but require different remediation (rollback, not retry).

## Usage Example

```go
package main

import (
	"errors"
	"fmt"
)

func main() {
	err := errors.New("connection refused: dial tcp 127.0.0.1:6443")

	if hint := friendlyHint(err); hint != "" {
		fmt.Printf("Error: %v\nHint: %s\n", err, hint)
	} else {
		fmt.Printf("Error: %v\n", err)
	}
}
```

```go
// Example of an error opting out of generic hints via SelfDiagnosed.
type stuckAppError struct {
	msg string
}

func (e *stuckAppError) Error() string      { return e.msg }
func (e *stuckAppError) SelfDiagnosed() bool { return true }

// friendlyHint(err) will return "" for this error, since it already
// embeds its own diagnosis (e.g., pod crash logs).
```
