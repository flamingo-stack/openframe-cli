# friendly.go

Provides plain-language, actionable hints for common low-level errors (network, permissions, Helm, Docker) so non-technical users get a "did you mean" suggestion instead of a raw error string. Hints supplement but never replace the underlying error.

## Key Components

- **`SelfDiagnosed`** — Interface for errors that already carry their own root-cause diagnosis (e.g. embedded pod logs/events). Implementing `SelfDiagnosed() bool` opts an error out of generic hint matching, preventing false-positive hints from misfiring on embedded diagnostic text.
- **`friendlyHint(err error) string`** — Inspects an error's message and returns a human-friendly hint string, or `""` if no pattern matches or the error self-diagnoses. Checks (in priority order) for: Helm ownership metadata conflicts, stuck pending Helm releases, connection refused, DNS resolution failures, timeouts, permission/auth errors, missing kube-context, and Docker daemon issues.
- **`containsAny(s string, subs ...string) bool`** — Helper that reports whether `s` contains any of the given substrings.

## Usage Example

```go
err := someClusterOperation()
if err != nil {
    hint := friendlyHint(err)
    if hint != "" {
        fmt.Printf("Error: %v\nHint: %s\n", err, hint)
    } else {
        fmt.Printf("Error: %v\n", err)
    }
}
```

To exempt an error from generic hint matching (because it already embeds its own diagnosis):

```go
type stuckAppError struct {
    msg string
}

func (e *stuckAppError) Error() string { return e.msg }

// SelfDiagnosed marks this error as already explained — friendlyHint will
// skip pattern matching against its embedded pod logs/events.
func (e *stuckAppError) SelfDiagnosed() bool { return true }
```

Note: matching order matters — Helm ownership and pending-release cases are checked before the generic timeout/connection cases, since their symptoms can otherwise be misclassified as simple timeouts.
