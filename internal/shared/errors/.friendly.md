## friendly.go

Provides plain-language, actionable hints for common low-level errors (network, permissions, Docker, Helm state issues), so CLI users get a "did you mean" suggestion instead of just a raw error string. Hints are additive — they never replace the underlying error.

## Key Components

- **`SelfDiagnosed`** — Interface for errors that already carry their own root-cause diagnosis (e.g. an error embedding failing pod logs/events). Errors implementing this are skipped by `friendlyHint` to avoid false-positive pattern matches against embedded diagnostic text.
- **`friendlyHint(err error) string`** — Inspects an error's message (case-insensitive) and returns a human-friendly hint for known failure patterns (Helm ownership conflicts, pending Helm releases, connection refused, DNS resolution failures, timeouts, permission/auth errors, missing kube-context, Docker not running). Returns `""` when no pattern matches or when the error is `SelfDiagnosed`.
- **`containsAny(s string, subs ...string) bool`** — Helper that checks whether a string contains any of the given substrings.

## Usage Example

```go
package errors

import "fmt"

func Example() {
    err := fmt.Errorf("dial tcp 127.0.0.1:6443: connect: connection refused")

    hint := friendlyHint(err)
    if hint != "" {
        fmt.Printf("Error: %v\nHint: %s\n", err, hint)
    }
    // Output:
    // Error: dial tcp 127.0.0.1:6443: connect: connection refused
    // Hint: The cluster isn't reachable — is it running? Try 'openframe cluster status'.
}
```

Errors that implement `SelfDiagnosed` and return `true` bypass hinting entirely:

```go
type diagnosedErr struct{ msg string }

func (e diagnosedErr) Error() string      { return e.msg }
func (e diagnosedErr) SelfDiagnosed() bool { return true }

// friendlyHint(diagnosedErr{"connection refused: <embedded pod logs>"}) returns ""
```

Matching order matters: Helm ownership and pending-release cases are checked **before** generic timeout/connection patterns, since those failures often surface wrapped in timeout-like messages but require different remediation (rollback/uninstall, not retry).
