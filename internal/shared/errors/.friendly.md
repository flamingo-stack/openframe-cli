Translates low-level Go errors into plain-language, actionable hints for non-technical users without replacing the underlying error message.

## Key Components

**`friendlyHint(err error) string`**
Maps common failure patterns (matched via case-insensitive substring checks) to human-readable next steps. Returns `""` when no known pattern matches, preserving default error behavior.

**`containsAny(s string, subs ...string) bool`**
Helper that returns `true` if string `s` contains any of the provided substrings. Used by `friendlyHint` to match multi-variant error messages in a single case branch.

## Matched Error Patterns

| Pattern | Hint Provided |
|---|---|
| Helm ownership metadata conflicts | Recreate cluster or add Helm labels |
| Helm pending-state (interrupted install) | Rollback with `helm rollback` or `helm uninstall` |
| Connection refused / reset | Check cluster is running via `openframe cluster status` |
| DNS / no such host | Check kubeconfig / current context |
| Context deadline / timeout | Wait and retry |
| Permission denied / forbidden | Check credentials / kubeconfig |
| Kube-context not found | Run `kubectl config get-contexts` |
| Docker not running | Start Docker or run `openframe prerequisites check` |

## Usage Example

```go
if hint := friendlyHint(err); hint != "" {
    fmt.Fprintf(os.Stderr, "Hint: %s\n", hint)
}
return fmt.Errorf("install failed: %w", err)
```

## Notes

- Helm ownership and pending-state cases are matched **before** the generic timeout case intentionally — both can surface wrapped inside timeout-looking messages, and their fixes (`helm rollback`, cluster recreate) differ from a simple retry.
- This function is purely additive; it never wraps or modifies the original error.
