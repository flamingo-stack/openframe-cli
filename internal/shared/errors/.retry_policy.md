# retry_policy.go

Implements a configurable retry mechanism for recoverable/transient errors, combining structural Go error classification (network timeouts, syscall errors, Kubernetes API conditions) with substring matching on stderr output from shelled-out tools (helm, kubectl, docker). Provides exponential backoff with jitter and a pluggable executor for running retryable operations.

## Key Components

- **`RetryPolicy`** — interface defining `ShouldRetry`, `GetDelay`, and `GetMaxAttempts` for retry strategies.
- **`RecoverableError`** / **`NonRetryableError`** — interfaces errors can implement to explicitly mark themselves as retryable or never-retryable, overriding heuristic classification.
- **`ExponentialBackoffPolicy`** — default `RetryPolicy` implementation with configurable max attempts, base/max delay, multiplier, jitter, and a table of retryable error substrings.
- **`NewExponentialBackoffPolicy(maxAttempts, baseDelay)`** — constructor with sensible defaults (5 min max delay, 2.0 multiplier, jitter enabled).
- **`classifyTransient(err)`** — structural classifier checking `net.Error` timeouts, `context.Canceled`/`DeadlineExceeded`, syscall errors (`ECONNREFUSED`, `ECONNRESET`, etc.), `io.ErrUnexpectedEOF`, and Kubernetes API error types (conflict, too-many-requests, service unavailable, timeout).
- **`RetryExecutor`** — orchestrates retry attempts using a `RetryPolicy`, supports context cancellation and an optional `onRetry` callback.
- **`InstallationRetryPolicy()`** — preconfigured policy tuned for installation operations (helm/kubectl failure patterns).
- **`contains(str, substr)`** — case-insensitive substring helper.

## Usage Example

```go
policy := errors.InstallationRetryPolicy()
executor := errors.NewRetryExecutor(policy)

err := executor.Execute(ctx, func() error {
    return installHelmChart(ctx, chartName)
})
if err != nil {
    log.Fatalf("installation failed after retries: %v", err)
}
```

Custom policy with retry logging:

```go
policy := errors.NewExponentialBackoffPolicy(5, 2*time.Second)
executor := errors.NewRetryExecutor(policy)
executor.onRetry = func(err error, attempt int, delay time.Duration) {
    log.Printf("retry %d after %v: %v", attempt, delay, err)
}
```
