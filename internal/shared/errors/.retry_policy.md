## retry_policy.go

Implements a configurable retry mechanism for recoverable errors, combining structural error classification (network timeouts, Kubernetes API errors, syscall errors) with substring-based fallback matching for errors surfaced from shelled-out tools (helm, kubectl, docker) whose failure reasons only exist as stderr text.

## Key Components

- **`RetryPolicy`** — interface defining `ShouldRetry`, `GetDelay`, and `GetMaxAttempts` for retry strategies.
- **`RecoverableError`** / **`NonRetryableError`** — interfaces errors can implement to explicitly mark themselves as retryable or never-retryable, overriding automatic classification.
- **`ExponentialBackoffPolicy`** — `RetryPolicy` implementation using exponential backoff with jitter and a configurable map of retryable error substrings.
- **`NewExponentialBackoffPolicy(maxAttempts, baseDelay)`** — constructor with sensible defaults (5-minute max delay, 2x multiplier, jitter enabled).
- **`classifyTransient(err)`** — structural error classifier checking `net.Error` timeouts, context cancellation/deadline, syscall errors (`ECONNREFUSED`, `ECONNRESET`, etc.), and Kubernetes `apierrors` (conflict, timeout, service unavailable, too many requests).
- **`RetryExecutor`** — orchestrates retry execution given a `RetryPolicy`, respecting context cancellation and invoking an optional `onRetry` callback.
- **`InstallationRetryPolicy()`** — preconfigured policy tuned for installation operations (helm/kubectl failures), with 3 attempts and a curated set of retryable substrings.

## Usage Example

```go
policy := errors.InstallationRetryPolicy()
executor := errors.NewRetryExecutor(policy)

err := executor.Execute(ctx, func() error {
    return installHelmChart(ctx, chartConfig)
})
if err != nil {
    log.Fatalf("installation failed after retries: %v", err)
}
```

Custom policy with retry logging:

```go
policy := errors.NewExponentialBackoffPolicy(5, 2*time.Second)
executor := errors.NewRetryExecutor(policy)

err := executor.Execute(ctx, func() error {
    return callFlakyAPI()
})
```

Errors can opt in or out of retry behavior explicitly:

```go
type ChartError struct{ recoverable bool }

func (e *ChartError) IsRecoverable() bool       { return e.recoverable }
func (e *ChartError) GetRetryAfter() time.Duration { return 5 * time.Second }
```
