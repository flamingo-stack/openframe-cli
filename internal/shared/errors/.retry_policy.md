## retry_policy.go

Implements a configurable retry mechanism for handling transient/recoverable errors, primarily used for installation operations (Helm, kubectl, k3d) that may fail due to temporary network or API server issues.

## Key Components

- **`RetryPolicy`** — interface defining retry behavior: `ShouldRetry`, `GetDelay`, `GetMaxAttempts`.
- **`RecoverableError`** / **`NonRetryableError`** — interfaces errors can implement to explicitly opt in or opt out of retries, overriding default classification.
- **`ExponentialBackoffPolicy`** — concrete `RetryPolicy` implementation with exponential backoff, optional jitter, and a table of retryable error substrings for shelled-out tool failures.
- **`NewExponentialBackoffPolicy(maxAttempts, baseDelay)`** — constructor with sensible defaults (5-minute max delay, 2x multiplier, jitter enabled).
- **`classifyTransient(err)`** — structural (type-based) classification of transient errors using `net.Error`, `context` cancellation/timeout, `syscall` errnos, and Kubernetes `apierrors` helpers, checked before falling back to string matching.
- **`RetryExecutor`** — orchestrates retry attempts around an operation, respecting context cancellation and invoking an optional `onRetry` callback.
- **`InstallationRetryPolicy()`** — preconfigured policy (3 attempts, 10s base delay) tailored to installation-related failures.
- **`contains(str, substr)`** — case-insensitive substring helper used for error message matching.

## Usage Example

```go
policy := errors.InstallationRetryPolicy()
executor := errors.NewRetryExecutor(policy)

err := executor.Execute(ctx, func() error {
	return runHelmInstall(releaseName, chart)
})
if err != nil {
	log.Fatalf("installation failed after retries: %v", err)
}
```

Custom policy with a retry callback:

```go
policy := errors.NewExponentialBackoffPolicy(5, 2*time.Second)
executor := &errors.RetryExecutor{}
executor = errors.NewRetryExecutor(policy)

err := executor.Execute(context.Background(), operation)
```

Retry decisions favor structural checks (network timeouts, `context.Canceled`, syscall errnos, Kubernetes API errors) over string matching, with `NonRetryableError` and `RecoverableError` markers taking precedence to avoid re-running unsafe or already-completed operations.
