A thread-safe mock implementation of the `CommandExecutor` interface for use in tests, capturing both flattened command strings (legacy) and structured argv records for security-sensitive assertions.

## Key Components

### Types

| Type | Description |
|------|-------------|
| `RecordedCommand` | Structured command capture with discrete `Args []string`, `Env`, and `Stdin` — enables argv-level security assertions |
| `MockCommandExecutor` | `sync.Mutex`-guarded mock executor with configurable responses, failure simulation, and dual command logs |

### Constructor

- **`NewMockCommandExecutor()`** — returns a mock with empty command logs, an empty response map, and a default success result (`exit 0`, `"mock output"`)

### Configuration Methods

| Method | Purpose |
|--------|---------|
| `SetShouldFail(fail bool, message string)` | Toggles global failure mode; all subsequent executions return exit code 1 |
| `SetResponse(pattern string, result *CommandResult)` | Maps a substring pattern to a specific `CommandResult` |
| `SetDefaultResult(result *CommandResult)` | Overrides the fallback result for unmatched commands |

### Execution Methods

| Method | Purpose |
|--------|---------|
| `Execute(ctx, name, args...)` | Delegates to `ExecuteWithOptions` |
| `ExecuteWithOptions(ctx, options)` | Records command, checks failure mode, pattern-matches response map, falls back to default |

### Inspection Methods

| Method | Returns |
|--------|---------|
| `Commands()` | `[]RecordedCommand` — structured log with discrete argv (preferred for security tests) |
| `GetExecutedCommands()` | `[]string` — flattened command strings (legacy) |
| `GetCommandCount()` | Total number of recorded executions |
| `GetLastCommand()` | Last flattened command string, or `""` |
| `WasCommandExecuted(pattern)` | `bool` — substring match against flattened log |
| `Reset()` | Clears all logs, responses, and failure state |

## Usage Example

```go
exec := executor.NewMockCommandExecutor()

// Simulate a specific command response
exec.SetResponse("helm upgrade", &executor.CommandResult{
    ExitCode: 0,
    Stdout:   "Release deployed",
})

// Run the executor under test
result, err := exec.Execute(ctx, "helm", "upgrade", "my-release", "./chart")

// Inspect structured argv (security assertion: no shell injection via $(...))
for _, cmd := range exec.Commands() {
    for _, arg := range cmd.Args {
        if strings.Contains(arg, "$(") {
            t.Errorf("shell injection in argv: %q", arg)
        }
    }
}

// Simulate failure
exec.SetShouldFail(true, "connection refused")
_, err = exec.Execute(ctx, "kubectl", "apply", "-f", "manifest.yaml")
// err.Error() == "mock command failure: connection refused"

exec.Reset() // clean state for next test
```

> **Security note:** Use `Commands()` (structured `[]RecordedCommand`) rather than `GetExecutedCommands()` (flattened strings) when asserting that no shell metacharacters were injected — a flattened log cannot distinguish a literal `$(x)` argument from a shell-constructed string.
