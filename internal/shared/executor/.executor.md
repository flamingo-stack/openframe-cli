## executor.go

Provides a cross-platform command execution abstraction for the OpenFrame CLI, including a mockable `CommandExecutor` interface, WSL (Windows Subsystem for Linux) availability detection/recovery helpers, and structured error types that capture exit codes and stderr for actionable failure messages.

## Key Components

- **`CommandExecutor` interface** – Abstraction for executing external commands, enabling dependency injection and testing without invoking real processes. Exposes `Execute` and `ExecuteWithOptions`.
- **`RealCommandExecutor`** – Default implementation using `os/exec`, supporting dry-run mode, timeouts, custom working directories, environment variables, and stdin piping.
- **`ExecuteOptions`** – Configuration struct for command execution (command, args, dir, env, timeout, stdin).
- **`CommandResult`** – Captures exit code, stdout, stderr, and duration; `Output()` merges stdout/stderr for convenience.
- **`CommandError`** – Error type carrying exit code and redacted/truncated stderr for accurate automation and diagnostics; unwraps to the underlying `exec` error.
- **`WSLError`** – WSL-specific error with operation name, exit code, stderr, and a remediation suggestion.
- **`IsWSLAvailable` / `IsWSLUbuntuAvailable`** – Cached checks (Windows-only) for WSL and Ubuntu distro availability.
- **`ResetWSLCache`** – Clears cached WSL availability state (useful in tests or after WSL restarts).
- **`TryRecoverWSL`** – Terminates and restarts the Ubuntu WSL distro, then restarts Docker inside it, as a last-resort recovery mechanism.
- **`RestartDockerInWSL`** – Starts/verifies the Docker daemon inside WSL2 Ubuntu.
- **`GetWSLErrorSuggestion`** – Maps WSL exit codes to human-readable troubleshooting suggestions.

## Usage Example

```go
executor := executor.NewRealCommandExecutor(false, true)

result, err := executor.ExecuteWithOptions(context.Background(), executor.ExecuteOptions{
    Command: "helm",
    Args:    []string{"upgrade", "--install", "myapp", "./chart"},
    Timeout: 30 * time.Second,
})

if err != nil {
    var cmdErr *executor.CommandError
    if errors.As(err, &cmdErr) {
        fmt.Printf("command failed with exit code %d: %s\n", cmdErr.ExitCode, cmdErr.Stderr)
    }
    return err
}

fmt.Println(result.Stdout)
```

On Windows, callers can check WSL health before running WSL-dependent commands:

```go
if executor.IsWSLAvailable() && !executor.IsWSLUbuntuAvailable() {
    if err := executor.TryRecoverWSL(); err != nil {
        log.Fatalf("WSL recovery failed: %v", err)
    }
}
```
