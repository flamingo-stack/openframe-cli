## executor.go

Provides a testable abstraction for executing external OS commands, with special handling for WSL (Windows Subsystem for Linux) detection, recovery, and Docker daemon management on Windows hosts. It defines structured error types that preserve exit codes and redacted stderr output for diagnostics.

## Key Components

- **`CommandExecutor`** — interface abstracting command execution (`Execute`, `ExecuteWithOptions`) to enable dependency injection and mocking in tests.
- **`RealCommandExecutor`** — concrete implementation running actual OS processes, supporting dry-run and verbose modes.
- **`ExecuteOptions`** / **`CommandResult`** — structs configuring execution (working dir, env vars, timeout, stdin) and capturing results (exit code, stdout/stderr, duration).
- **`CommandError`** / **`WSLError`** — error types that wrap exit codes and stderr (with noise stripped/truncated via `errorDetail`), preserving automation-friendly exit-code fidelity while surfacing readable failure reasons.
- **`IsWSLAvailable` / `IsWSLUbuntuAvailable`** — cached checks for WSL and Ubuntu distro availability (Windows only).
- **`TryRecoverWSL`** — terminates and restarts the Ubuntu WSL distribution as a last-resort recovery mechanism, then restarts Docker.
- **`RestartDockerInWSL`** — starts/waits for the Docker daemon inside WSL2 Ubuntu.
- **`GetWSLErrorSuggestion`** — maps WSL exit codes to actionable troubleshooting suggestions.
- **`NewRealCommandExecutor(dryRun, verbose bool)`** — constructor for `RealCommandExecutor`.

## Usage Example

```go
ctx := context.Background()
executor := executor.NewRealCommandExecutor(false, true)

result, err := executor.ExecuteWithOptions(ctx, executor.ExecuteOptions{
    Command: "k3d",
    Args:    []string{"cluster", "list"},
    Timeout: 30 * time.Second,
})
if err != nil {
    var cmdErr *executor.CommandError
    if errors.As(err, &cmdErr) {
        fmt.Printf("failed with exit code %d: %s\n", cmdErr.ExitCode, cmdErr.Error())
    }
    return
}
fmt.Println(result.Stdout)

// Windows-specific WSL recovery
if executor.IsWSLAvailable() && !executor.IsWSLUbuntuAvailable() {
    if err := executor.TryRecoverWSL(); err != nil {
        fmt.Println(executor.GetWSLErrorSuggestion(1, "wsl -d Ubuntu"))
    }
}
```
