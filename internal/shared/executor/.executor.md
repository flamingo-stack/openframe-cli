## Executor

Provides an abstraction layer for running external commands, with dedicated support for detecting, diagnosing, and recovering Windows Subsystem for Linux (WSL) environments (used since tools like k3d/helm/Docker may run through WSL on Windows).

## Key Components

- **`CommandExecutor` interface** — abstraction for executing commands, enabling dependency injection and testability (`Execute`, `ExecuteWithOptions`).
- **`RealCommandExecutor`** — concrete implementation that runs actual OS commands, supporting dry-run mode, timeouts, custom working directory, environment variables, and stdin piping.
- **`ExecuteOptions` / `CommandResult`** — structured input/output types for command execution, including exit code, stdout/stderr, and duration.
- **`CommandError` / `WSLError`** — rich error types that carry exit codes and redacted/trimmed stderr output for actionable error messages, stripping noisy logrus progress output while preserving the real failure reason.
- **WSL helper functions**:
  - `IsWSLAvailable()` / `IsWSLUbuntuAvailable()` — cached checks for WSL and Ubuntu distro availability.
  - `ResetWSLCache()` — clears cached WSL state (useful for tests or after WSL restarts).
  - `TryRecoverWSL()` — terminates and restarts the Ubuntu distribution as a last resort, then restarts Docker.
  - `RestartDockerInWSL()` — starts the Docker daemon inside WSL2 Ubuntu.
  - `GetWSLErrorSuggestion(exitCode, command)` — returns actionable troubleshooting text based on WSL exit codes.
- **Constants**: `WSLExitCodeDistroNotFound`, `WSLExitCodeGenericError` — well-known WSL failure exit codes.

## Usage Example

```go
executor := executor.NewRealCommandExecutor(false, true)

result, err := executor.ExecuteWithOptions(context.Background(), executor.ExecuteOptions{
    Command: "k3d",
    Args:    []string{"cluster", "list"},
    Timeout: 30 * time.Second,
})
if err != nil {
    var cmdErr *executor.CommandError
    if errors.As(err, &cmdErr) {
        fmt.Printf("command failed with exit code %d: %s\n", cmdErr.ExitCode, cmdErr.Error())
    }
    return
}

fmt.Println(result.Stdout)

// Windows-specific WSL recovery
if executor.IsWSLAvailable() && !executor.IsWSLUbuntuAvailable() {
    if err := executor.TryRecoverWSL(); err != nil {
        fmt.Println(executor.GetWSLErrorSuggestion(1, "wsl -d Ubuntu"))
    }
}
```
