Provides the core command execution abstraction for the OpenFrame CLI, handling real system command execution, dry-run mode, WSL (Windows Subsystem for Linux) lifecycle management, and structured error types.

## Key Components

### Interfaces & Types

- **`CommandExecutor`** — Interface for executing external commands; supports dependency injection and testing
- **`RealCommandExecutor`** — Concrete implementation using `os/exec`; supports `dryRun` and `verbose` modes
- **`CommandResult`** — Holds `ExitCode`, `Stdout`, `Stderr`, and `Duration` from a completed command
- **`ExecuteOptions`** — Fine-grained execution control: working directory, env vars, timeout, and stdin piping
- **`CommandError`** — Structured error for non-zero exits; captures exit code and redacted stderr
- **`WSLError`** — Structured error for WSL-specific failures with actionable suggestions

### Functions

- **`NewRealCommandExecutor(dryRun, verbose bool)`** — Constructs a `CommandExecutor` instance
- **`IsWSLAvailable()`** — Cached check for WSL presence (Windows only)
- **`IsWSLUbuntuAvailable()`** — Cached check that Ubuntu distro responds in WSL
- **`ResetWSLCache()`** — Clears cached WSL availability (useful after restart or in tests)
- **`TryRecoverWSL()`** — Terminates and restarts the Ubuntu distro, then restores Docker
- **`RestartDockerInWSL()`** — Starts the Docker daemon inside WSL2 Ubuntu
- **`GetWSLErrorSuggestion(exitCode, command)`** — Returns human-readable recovery steps for WSL errors

## Usage Example

```go
exec := executor.NewRealCommandExecutor(false, true)

// Simple execution
result, err := exec.Execute(ctx, "kubectl", "get", "pods")
if err != nil {
    var cmdErr *executor.CommandError
    if errors.As(err, &cmdErr) {
        fmt.Printf("Exit %d: %s\n", cmdErr.ExitCode, cmdErr.Stderr)
    }
}
fmt.Println(result.Stdout)

// Execution with options (timeout, working dir, env, stdin)
result, err = exec.ExecuteWithOptions(ctx, executor.ExecuteOptions{
    Command: "helm",
    Args:    []string{"upgrade", "--install", "my-release", "-f", "-", "./chart"},
    Dir:     "/workspace",
    Env:     map[string]string{"KUBECONFIG": "/home/user/.kube/config"},
    Timeout: 2 * time.Minute,
    Stdin:   valuesYAML,
})
```
