# cleanup.go

Provides backup and restore functionality for files modified by the CLI, ensuring that temporary or generated files can be safely rolled back on error, interruption, or after successful completion.

## Key Components

- **`FileBackup`** - Struct representing a single file backup, tracking the original path, backup location (or in-memory content), and whether the file existed before modification.
- **`FileCleanup`** - Manager that tracks a collection of `FileBackup` entries and coordinates restore/cleanup operations.
- **`NewFileCleanup()`** - Constructor for a `FileCleanup` instance.
- **`RestoreFiles(verbose bool) error`** - Forcefully restores all backed-up files; intended for error and interruption scenarios.
- **`RestoreFilesOnSuccess(verbose bool) error`** - Restores files only after successful completion.
- **`RestoreFilesWithResult(verbose bool, success bool) error`** - Restores files conditionally based on the `success` flag, keeping temp files around when `cleanupOnSuccess` is enabled and the operation failed.
- **`RegisterTempFile(filePath string) error`** - Registers a newly created temporary file for later cleanup (deletion) without needing a backup.
- **`SetCleanupOnSuccessOnly(enabled bool)`** - Configures whether temporary files should only be cleaned up on successful completion.

Internal helpers (`restoreFilesForced`, `restoreFile`, `cleanupBackupFiles`, `copyFile`) handle the low-level restore logic, ensuring backup files are only deleted once their corresponding restore succeeds, preventing data loss.

## Usage Example

```go
cleanup := files.NewFileCleanup()

// Register a temp file created during the operation
if err := cleanup.RegisterTempFile("/tmp/openframe-config.yaml"); err != nil {
    // handle error
}

// Only remove temp files if the overall operation succeeds
cleanup.SetCleanupOnSuccessOnly(true)

success := runOperation() // your business logic

if success {
    if err := cleanup.RestoreFilesOnSuccess(true); err != nil {
        pterm.Error.Printf("cleanup failed: %v\n", err)
    }
} else {
    // On failure or interruption, force restore of original files
    if err := cleanup.RestoreFiles(true); err != nil {
        pterm.Error.Printf("restore failed: %v\n", err)
    }
}
```
