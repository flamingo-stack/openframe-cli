Manages backup and restoration of files modified during CLI operations, enabling safe rollback on errors, interruptions, or successful completion.

## Key Components

### Types

- **`FileBackup`** — Represents a single file backup entry, storing the original path, backup path, optional in-memory content, and whether the file previously existed.
- **`FileCleanup`** — Manages a collection of `FileBackup` entries and controls cleanup behavior (on error vs. on success).

### Functions & Methods

| Symbol | Description |
|---|---|
| `NewFileCleanup()` | Creates a new `FileCleanup` manager with default settings (cleanup on any completion). |
| `RegisterTempFile(filePath)` | Registers a newly created file for deletion on restore (no backup needed). |
| `SetCleanupOnSuccessOnly(enabled)` | Configures whether temporary files are removed only after a successful operation. |
| `RestoreFiles(verbose)` | Restores all backed-up files unconditionally; intended for error/interruption scenarios. |
| `RestoreFilesOnSuccess(verbose)` | Restores files assuming a successful completion. |
| `RestoreFilesWithResult(verbose, success)` | Restores files with explicit success state; respects `cleanupOnSuccess` mode. |
| `restoreFile(backup, verbose)` | Restores a single file from memory or a physical backup file; removes it if it never existed. |
| `cleanupBackupFiles(verbose)` | Deletes physical backup files after restoration is complete. |
| `copyFile(src, dst)` | Copies a file from one path to another, creating destination directories as needed. |

## Usage Example

```go
// Initialize the cleanup manager
cleanup := files.NewFileCleanup()

// Register a temp file created during the operation
cleanup.RegisterTempFile("/tmp/generated-config.yaml")

// On error or interruption, restore everything unconditionally
if err != nil {
    cleanup.RestoreFiles(true)
    return err
}

// On success, clean up temporary files
cleanup.RestoreFilesOnSuccess(true)
```
