# cleanup.go

Implements a backup-and-restore mechanism for files modified or created by the CLI, allowing safe rollback of changes on failure or interruption, and optional retention of temporary files until an operation succeeds.

## Key Components

- **`FileBackup`** – Struct capturing metadata for a single backed-up file: original path, backup path (or in-memory content), whether the file existed originally, and whether content is stored in memory only.
- **`FileCleanup`** – Manager that tracks a list of `FileBackup` entries and coordinates restore/cleanup behavior.
- **`NewFileCleanup()`** – Constructor for a `FileCleanup` instance.
- **`RestoreFiles(verbose bool) error`** – Forcibly restores all tracked files; intended for error/interruption paths.
- **`RestoreFilesOnSuccess(verbose bool) error`** – Restores files only after a successful operation.
- **`RestoreFilesWithResult(verbose bool, success bool) error`** – Core restore logic that respects the `cleanupOnSuccess` flag, skipping temp-file cleanup when the operation failed.
- **`RegisterTempFile(filePath string) error`** – Registers a newly created file (no prior backup needed) for later deletion during restore.
- **`SetCleanupOnSuccessOnly(enabled bool)`** – Configures whether temporary files persist until success.
- **`restoreFile`, `cleanupBackupFiles`, `copyFile`** – Internal helpers for restoring individual files, cleaning physical backup files (while preserving backups for failed restores), and copying file contents.

## Usage Example

```go
cleanup := files.NewFileCleanup()
cleanup.SetCleanupOnSuccessOnly(true)

// Register a file the CLI generates temporarily
if err := cleanup.RegisterTempFile("/tmp/openframe/config.yaml"); err != nil {
    return err
}

// ... perform CLI operation ...

if operationFailed {
    // Force restore/cleanup on error
    if err := cleanup.RestoreFiles(true); err != nil {
        pterm.Warning.Printf("cleanup failed: %v\n", err)
    }
    return err
}

// On success, clean up only now
if err := cleanup.RestoreFilesOnSuccess(true); err != nil {
    return err
}
```

Restore errors are aggregated via `errors.Join` and always returned to the caller, ensuring a silently un-restored file is never hidden from calling code.
