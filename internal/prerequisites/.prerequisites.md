Defines the core domain types for the prerequisites subsystem — the shared contracts that all tool-specific implementations (`Docker`, `kubectl`, `k3d`, `helm`, etc.) are built against.

## Key Components

| Type | Description |
|---|---|
| `Prerequisite` | A single tool/condition the CLI requires, with check, install, and docs fields |
| `Set` | A named group of prerequisites (e.g. `"cluster"` or `"app"`) |
| `MissingItem` | A prerequisite still unsatisfied after a run, with reason and error |
| `Result` | Summary of a `Set` run: satisfied, installed, and still-missing items |
| `Result.OK()` | Returns `true` when all prerequisites are satisfied |

### `Prerequisite` Field Behavior

| Field | Required | Behavior when nil |
|---|---|---|
| `IsSatisfied` | ✅ | — |
| `Install` | ❌ | Falls back to `DocsURL` guidance |
| `Detail` | ❌ | Generic "not installed" wording used |

## Usage Example

```go
docker := prerequisites.Prerequisite{
    Name:        "Docker",
    IsSatisfied: isDockerRunning,
    Install:     installDocker,
    DocsURL:     "https://docs.docker.com/get-docker/",
    Detail: func() string {
        if dockerBinaryExists() {
            return "installed but not running"
        }
        return ""
    },
}

clusterSet := prerequisites.Set{
    Name:  "cluster",
    Items: []prerequisites.Prerequisite{docker},
}
```

## OS Behavior

- **macOS / Linux** — `Install` is called automatically for missing items
- **Windows** — nothing is auto-installed; `DocsURL` is surfaced per missing item

> See the `openframe prerequisites` command for how `Set` instances are wired into the CLI.
