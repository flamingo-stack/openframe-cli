Executes a prerequisite `Set` against the host OS, driving both check-only and install flows while abstracting platform differences.

## Key Components

| Export | Kind | Description |
|--------|------|-------------|
| `Runner` | struct | Holds an optional `OS` override; zero value uses `runtime.GOOS` |
| `NewRunner()` | constructor | Returns a `Runner` targeting the current host OS |
| `Runner.AutoInstalls()` | method | Returns `true` on `darwin`/`linux`, `false` on `windows` and anything else |
| `Runner.Check()` | method | Inspects all prerequisites without installing; populates `Result.Satisfied` / `Result.Missing` |
| `Runner.Run()` | method | Full install pass — auto-installs on supported OSes, falls back to manual guidance elsewhere |
| `satisfied()` | internal helper | nil-safe check; a `Prerequisite` with no `IsSatisfied` func is treated as satisfied |
| `missing()` | internal helper | Builds a `MissingItem`, capturing any `Detail()` reason to avoid misleading "not installed" messages |

## Usage Example

```go
// Dry-run check (no installs)
runner := prerequisites.NewRunner()
result := runner.Check(mySet)
if !result.OK() {
    fmt.Println("Missing:", result.Missing)
}

// Full run with auto-install on macOS/Linux
ctx := context.Background()
result = runner.Run(ctx, mySet)
if !result.OK() {
    for _, m := range result.Missing {
        fmt.Printf("Still missing %s — see %s\n", m.Name, m.DocsURL)
    }
}

// Force Windows behaviour in tests
r := prerequisites.Runner{OS: "windows"}
fmt.Println(r.AutoInstalls()) // false
```

> On Windows, `Run` never calls an installer — it populates `Result.Missing` with the `DocsURL` so the caller can direct users to manual installation steps. See the [Windows release](https://github.com/flamingo-stack/openframe-cli/releases/latest/download/openframe-cli_windows_amd64.zip) for platform-specific guidance.
