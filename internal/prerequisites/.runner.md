## runner.go

Implements OS-aware execution logic for checking and installing prerequisites. It determines whether missing tools can be auto-installed based on the host operating system and orchestrates checking/installing each item in a `Set`.

## Key Components

- **`Runner`** — struct holding an optional `OS` override (defaults to `runtime.GOOS` when empty).
- **`NewRunner()`** — constructs a `Runner` bound to the current host OS.
- **`Runner.AutoInstalls()`** — returns `true` for `darwin`/`linux`, `false` otherwise (e.g. Windows), indicating whether missing prerequisites can be auto-installed.
- **`Runner.Check(set Set) Result`** — read-only check of which prerequisites are satisfied, without installing anything.
- **`Runner.Run(ctx context.Context, set Set) Result`** — checks each prerequisite and, on OSes that support it, installs missing ones. Respects context cancellation by marking remaining items as missing instead of attempting further installs. Never returns an `error` directly — callers must inspect `Result`.
- **`missing(p Prerequisite, err error) MissingItem`** — builds a `MissingItem`, including a human-readable `Reason` from `Prerequisite.Detail` when available.
- **`satisfied(p Prerequisite) bool`** — nil-safe helper; a prerequisite without an `IsSatisfied` check is treated as satisfied.

## Usage Example

```go
runner := prerequisites.NewRunner()

// Check-only mode (e.g. for `prerequisites check` command)
result := runner.Check(mySet)
if !result.OK() {
    fmt.Println("Missing:", result.Missing)
}

// Full run: checks and installs where possible
ctx := context.Background()
result = runner.Run(ctx, mySet)
if result.OK() {
    fmt.Println("All prerequisites satisfied:", result.Satisfied)
} else {
    for _, m := range result.Missing {
        fmt.Printf("Missing %s: %s (%s)\n", m.Name, m.Reason, m.DocsURL)
    }
}

// Testing with a forced OS
testRunner := prerequisites.Runner{OS: "windows"}
fmt.Println(testRunner.AutoInstalls()) // false
```
