## runner.go

Implements OS-aware execution logic for checking and installing CLI prerequisites. It provides the `Runner` type, which drives whether missing dependencies are auto-installed (macOS/Linux) or reported for manual setup (Windows).

## Key Components

- **`Runner`** — struct holding an optional `OS` override; defaults to `runtime.GOOS` when empty.
- **`NewRunner()`** — constructs a `Runner` bound to the host OS.
- **`Runner.AutoInstalls()`** — returns `true` on `darwin`/`linux`, `false` otherwise (e.g. Windows), indicating whether missing prerequisites can be installed automatically.
- **`Runner.Check(set Set) Result`** — evaluates each `Prerequisite` in a `Set` without installing anything, returning which are satisfied vs. missing. Used for a non-mutating `prerequisites check` command.
- **`Runner.Run(ctx context.Context, set Set) Result`** — evaluates and, where supported, installs missing prerequisites. Respects context cancellation by short-circuiting remaining checks and marking them missing. Never returns an error directly; callers must inspect the returned `Result`.
- **`missing(p Prerequisite, err error) MissingItem`** — internal helper building a `MissingItem`, preserving a custom `Reason` via `Prerequisite.Detail` when available.
- **`satisfied(p Prerequisite) bool`** — nil-safe helper; a prerequisite without an `IsSatisfied` check is treated as satisfied.

## Usage Example

```go
runner := prerequisites.NewRunner()

// Non-mutating check
result := runner.Check(mySet)
if !result.OK() {
    fmt.Println("Missing:", result.Missing)
}

// Full run: checks and auto-installs where possible
ctx := context.Background()
result = runner.Run(ctx, mySet)

if result.OK() {
    fmt.Println("All prerequisites satisfied")
} else {
    for _, m := range result.Missing {
        fmt.Printf("Missing %s: %s (docs: %s)\n", m.Name, m.Reason, m.DocsURL)
    }
}
```

For tests, override the detected OS explicitly:

```go
runner := prerequisites.Runner{OS: "windows"}
if runner.AutoInstalls() {
    t.Fatal("expected no auto-install on windows")
}
```
