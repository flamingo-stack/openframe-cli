## runner.go

Implements the `Runner` type, which checks and optionally auto-installs a set of prerequisites (`Set`) with OS-aware behavior. It supports both a dry-run "check only" mode and a full "check and install" mode.

## Key Components

- **`Runner`** – struct holding an optional `OS` override (defaults to `runtime.GOOS` when empty).
- **`NewRunner()`** – constructs a `Runner` for the current host OS.
- **`Runner.AutoInstalls()`** – returns `true` on `darwin`/`linux`, `false` otherwise (e.g., Windows), indicating whether missing prerequisites can be auto-installed.
- **`Runner.Check(set Set) Result`** – evaluates each prerequisite's satisfaction without installing anything; useful for a `prerequisites check` command.
- **`Runner.Run(ctx context.Context, set Set) Result`** – checks each prerequisite and, on supported OSes with an available installer, attempts installation. Respects context cancellation by marking remaining items as missing rather than attempting install. Never returns an error directly—callers should inspect `Result.OK()` / `Result.Missing`.
- **`missing(p Prerequisite, err error) MissingItem`** – internal helper that builds a `MissingItem`, capturing an optional `Detail()`-supplied reason (e.g., "installed but not running").
- **`satisfied(p Prerequisite) bool`** – nil-safe helper; a prerequisite without an `IsSatisfied` check is treated as satisfied.

## Usage Example

```go
package main

import (
	"context"
	"fmt"

	"yourmodule/prerequisites"
)

func main() {
	runner := prerequisites.NewRunner()

	set := prerequisites.Set{
		Items: []prerequisites.Prerequisite{
			// ... define prerequisites with IsSatisfied, Install, DocsURL, etc.
		},
	}

	// Dry-run check only
	checkResult := runner.Check(set)
	fmt.Println("Satisfied:", checkResult.Satisfied)
	fmt.Println("Missing:", checkResult.Missing)

	// Check and auto-install where supported
	ctx := context.Background()
	result := runner.Run(ctx, set)
	if !result.OK() {
		fmt.Println("Some prerequisites are still missing:", result.Missing)
	}
}
```
