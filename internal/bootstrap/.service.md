Orchestrates the full OpenFrame bootstrap sequence: validates Helm values, creates a local Kubernetes cluster, and installs charts in a single command execution.

## Key Components

| Symbol | Description |
|--------|-------------|
| `Service` | Stateless struct that wires cluster creation and chart installation |
| `NewService()` | Constructor returning a ready-to-use `*Service` |
| `Execute()` | Cobra command entry point; resolves flags (`verbose`, `non-interactive`) and delegates to `bootstrap()` |
| `bootstrap()` | Core orchestration: pre-flight validation → cluster create → chart install |
| `createClusterSuppressed()` | Thin wrapper over `cluster.CreateClusterWithPrerequisitesNonInteractive`, returns `*rest.Config` |
| `installChart()` | Builds an `InstallationRequest` and calls `chartServices.InstallChartsWithConfigContext` |
| `defaultClusterName` | Fallback cluster name `"openframe-dev"` when none is supplied |

## Usage Example

```go
// Invoked via the bootstrap cobra command:
//   openframe bootstrap [cluster-name] [--verbose] [--non-interactive]

svc := bootstrap.NewService()

// Directly calling Execute through Cobra wiring:
cmd := &cobra.Command{
    RunE: svc.Execute,
}
cmd.Flags().Bool("verbose", false, "Enable verbose output")
cmd.Flags().Bool("non-interactive", false, "Skip prompts")

// Or call bootstrap internals directly (e.g. in tests):
err := svc.Execute(cmd, []string{"my-cluster"})
if err != nil {
    log.Fatal(err)
}
```

## Notes

- Helm values are validated **before** the cluster is created to avoid wasting time on a full cluster spin-up with a bad config.
- Windows is not handled here — the root command forwards execution into WSL via `wsllauncher` before this code runs, so `bootstrap()` always executes as a Linux process.
- `ClusterAccess` is injected at the composition root to keep the chart subsystem isolated from cluster-creation logic (see `cluster.NewClusterService`).
