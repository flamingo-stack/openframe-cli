# service.go

Implements the `bootstrap` command's orchestration logic, chaining cluster creation and chart installation into a single end-to-end "OpenFrame ready" workflow.

## Key Components

- **`Service`** – Stateless struct exposing the bootstrap workflow.
- **`NewService()`** – Constructor for `Service`.
- **`Execute(cmd *cobra.Command, args []string) error`** – Cobra command entry point; resolves `verbose`/`non-interactive` flags and an optional cluster name argument, then delegates to `bootstrap`, routing errors through `sharedErrors.HandleGlobalError`.
- **`bootstrap(ctx, clusterName, nonInteractive, verbose) error`** – Core workflow: validates helm values, creates the cluster (via `createClusterSuppressed`), installs charts (via `installChart`), and prints a summary. Uses a `steps.Tracker` to time and report each stage (validate → create cluster → install platform).
- **`createClusterSuppressed`** – Wraps `cluster.CreateClusterWithPrerequisitesNonInteractive`, returning a `*rest.Config` for the new cluster.
- **`installChart`** – Calls `chartServices.InstallChartsWithConfigContext` with a request built by `bootstrapInstallRequest`.
- **`bootstrapInstallRequest`** – Builds `utilTypes.InstallationRequest`, explicitly setting `KubeConfig` and `KubeContext` (`"k3d-" + clusterName"`) since bootstrap always creates a k3d cluster — avoids ambiguity from context-name resolution.
- **`printBootstrapSummary` / `bootstrapSummaryMarkdown`** – Render the closing status card to the terminal and as GitHub Actions Step Summary markdown, including per-stage timings.
- **`defaultClusterName`** – Constant (`"openframe-dev"`) used when no cluster name is supplied.

## Usage Example

```go
package cmd

import (
	"github.com/flamingo-stack/openframe-cli/internal/bootstrap"
	"github.com/spf13/cobra"
)

func newBootstrapCommand() *cobra.Command {
	svc := bootstrap.NewService()

	cmd := &cobra.Command{
		Use:   "bootstrap [cluster-name]",
		Short: "Create a cluster and install the OpenFrame platform",
		RunE:  svc.Execute,
	}

	cmd.Flags().Bool("non-interactive", false, "run without prompts")
	return cmd
}
```

Running `openframe bootstrap my-cluster --verbose` validates helm values, creates a k3d cluster named `my-cluster`, installs the platform chart against it, and prints a summary table with per-stage durations.
