## Purpose

`service.go` implements the `bootstrap` command's orchestration logic, chaining cluster creation and OpenFrame chart installation into a single end-to-end workflow. It validates helm values up-front, creates a k3d cluster, installs the ArgoCD app-of-apps stack, and prints a staged progress/summary UI (including a GitHub Actions Step Summary card).

## Key Components

- **`Service`** — stateless struct exposing the bootstrap workflow; created via `NewService()`.
- **`Execute(cmd, args)`** — Cobra command entry point; resolves `verbose`/`non-interactive` flags (checking both local and root persistent flags), extracts the optional cluster name argument, and delegates to `bootstrap`, routing errors through `sharedErrors.HandleGlobalError`.
- **`bootstrap(ctx, clusterName, nonInteractive, verbose)`** — core workflow: defaults the cluster name (`defaultClusterName = "openframe-dev"`), runs a three-stage `steps.Tracker` (validate helm values → create cluster → install platform), and emits a desktop notification on completion.
- **`createClusterSuppressed`** — creates the k3d cluster via `cluster.CreateClusterWithPrerequisitesNonInteractive`, returning a `*rest.Config` for the new cluster.
- **`installChart`** — installs charts against the created cluster using `chartServices.InstallChartsWithConfigContext`.
- **`bootstrapInstallRequest`** — builds the `utilTypes.InstallationRequest`, explicitly setting `KubeContext` to `"k3d-" + clusterName` (not resolved dynamically) since bootstrap always creates a k3d cluster and must not risk matching an unrelated pre-existing context.
- **`printBootstrapSummary` / `bootstrapSummaryMarkdown`** — render the closing status card to the terminal and as markdown for the CI step summary.

## Usage Example

```go
package main

import (
	"github.com/flamingo-stack/openframe-cli/internal/bootstrap"
	"github.com/spf13/cobra"
)

func newBootstrapCmd() *cobra.Command {
	svc := bootstrap.NewService()

	cmd := &cobra.Command{
		Use:  "bootstrap [cluster-name]",
		Args: cobra.MaximumNArgs(1),
		RunE: svc.Execute,
	}
	cmd.Flags().Bool("non-interactive", false, "run without prompts")
	return cmd
}
```

This wires `Service.Execute` as the `RunE` handler for a `bootstrap` Cobra command, which will validate helm values, create a k3d cluster (defaulting to `openframe-dev` if unnamed), and install the OpenFrame platform charts.
