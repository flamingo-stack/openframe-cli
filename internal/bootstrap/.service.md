# service.go

Implements the `bootstrap` command orchestration service, which chains cluster creation and chart installation into a single end-to-end workflow for standing up an OpenFrame environment.

## Key Components

- **`Service`** - Stateless struct providing the bootstrap workflow; instantiated via `NewService()`.
- **`(*Service) Execute(cmd, args)`** - Cobra command entry point. Resolves `verbose` and `non-interactive` flags (falling back to root persistent flags), extracts an optional cluster name from args, and delegates to `bootstrap`, routing errors through `sharedErrors.HandleGlobalError`.
- **`(*Service) bootstrap(ctx, clusterName, nonInteractive, verbose)`** - Core workflow: validates helm values, creates a k3d cluster, then installs charts (ArgoCD + app-of-apps) against that cluster's `rest.Config`. Uses a `steps.Tracker` to report per-stage progress and timing, prints a summary card, and sends a desktop notification on completion.
- **`printBootstrapSummary` / `bootstrapSummaryMarkdown`** - Render the closing status card to the terminal and as markdown appended to the GitHub Actions Step Summary.
- **`(*Service) createClusterSuppressed`** - Wraps `cluster.CreateClusterWithPrerequisitesNonInteractive` to create the cluster and return its `*rest.Config`.
- **`(*Service) installChart`** - Installs charts via `chartServices.InstallChartsWithConfigContext`.
- **`bootstrapInstallRequest`** - Builds the `utilTypes.InstallationRequest` for the newly created cluster, explicitly setting `KubeContext` to `"k3d-" + clusterName` (since bootstrap always creates a k3d cluster) and injecting `ClusterAccess` to keep the app subsystem decoupled from cluster-creation logic.
- **`defaultClusterName`** - Constant (`"openframe-dev"`) used when no cluster name is supplied.

## Usage Example

```go
package main

import (
	"github.com/flamingo-stack/openframe-cli/internal/bootstrap"
	"github.com/spf13/cobra"
)

func newBootstrapCommand() *cobra.Command {
	svc := bootstrap.NewService()

	cmd := &cobra.Command{
		Use:   "bootstrap [cluster-name]",
		Short: "Create a cluster and install OpenFrame in one step",
		RunE: func(cmd *cobra.Command, args []string) error {
			return svc.Execute(cmd, args)
		},
	}

	cmd.Flags().Bool("non-interactive", false, "Run without interactive prompts")
	cmd.Flags().Bool("verbose", false, "Enable verbose output")
	return cmd
}
```

Running `openframe bootstrap my-cluster` creates a k3d cluster named `my-cluster`, installs the OpenFrame chart stack against it, and prints a summary showing the cluster's kube context (`k3d-my-cluster`), stage timings, and next-step commands (`openframe app status`, `openframe app access`).
