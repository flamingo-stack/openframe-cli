Builds a Kubernetes `*rest.Config` from a kubeconfig file and optional context name, bridging context selection to a usable client configuration.

## Key Components

### `RestConfigForContext(kubeconfigPath, contextName string) (*rest.Config, error)`

Loads kubeconfig from the given file path and constructs a `*rest.Config` for the specified context. Passing an empty `contextName` falls back to the kubeconfig's `current-context`.

## Usage Example

```go
// Use the current-context from the kubeconfig
cfg, err := k8s.RestConfigForContext("/home/user/.kube/config", "")
if err != nil {
    log.Fatal(err)
}

// Use a specific named context
cfg, err := k8s.RestConfigForContext("/home/user/.kube/config", "prod-cluster")
if err != nil {
    log.Fatal(err)
}

client, err := kubernetes.NewForConfig(cfg)
```

## Notes

- Wraps `clientcmd.NewNonInteractiveDeferredLoadingClientConfig` for non-interactive (CLI) use — no browser/TTY prompts.
- Errors are wrapped with the context name for clear diagnostics (e.g., `failed to build client config for context "prod-cluster": ...`).
- Intended as the downstream step after `SelectContext` — converts a chosen context into a live client config used by health checks, resource lookups, and the install workflow.
