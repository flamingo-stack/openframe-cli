# restconfig.go

Provides a helper to construct a Kubernetes `*rest.Config` from a kubeconfig file path and an optional context name, enabling per-context client creation for cluster operations.

## Key Components

- **`RestConfigForContext(kubeconfigPath, contextName string) (*rest.Config, error)`** — Builds a `rest.Config` for the given kubeconfig path and context. Supports `$KUBECONFIG`-style multi-file paths (using OS path-list separators) by merging them via `clientcmd`'s `Precedence` loading rule; a single path uses `ExplicitPath` for stricter missing-file errors. An empty `contextName` falls back to the kubeconfig's `current-context`.

## Usage Example

```go
package main

import (
	"fmt"
	"log"

	"k8s.io/client-go/kubernetes"

	"github.com/flamingo-stack/openframe-cli/internal/k8s"
)

func main() {
	// Build a rest.Config for a specific context (or "" for current-context)
	cfg, err := k8s.RestConfigForContext("/home/user/.kube/config", "kind-openframe")
	if err != nil {
		log.Fatalf("failed to build config: %v", err)
	}

	clientset, err := kubernetes.NewForConfig(cfg)
	if err != nil {
		log.Fatalf("failed to create clientset: %v", err)
	}

	nodes, err := clientset.CoreV1().Nodes().List(nil, metav1.ListOptions{})
	if err != nil {
		log.Fatalf("failed to list nodes: %v", err)
	}

	fmt.Printf("Found %d nodes\n", len(nodes.Items))
}
```

This function is typically used after selecting a context (e.g., via a context-selection step) to obtain a working client for health checks, resource inspection, or installation operations against the chosen cluster.
