## restconfig.go

Builds a Kubernetes `*rest.Config` for a specific kubeconfig context, enabling clients to be created against a chosen cluster context rather than always relying on the ambient current-context.

## Key Components

- **`RestConfigForContext(kubeconfigPath, contextName string) (*rest.Config, error)`** - Constructs a REST client configuration from a kubeconfig path and an optional context name. Supports both single-file paths (using `ExplicitPath` for strict missing-file errors) and multi-file paths following the `$KUBECONFIG` list convention (merged via `Precedence`). If `contextName` is empty, the kubeconfig's `current-context` is used.

## Usage Example

```go
package main

import (
	"fmt"
	"log"

	"k8s.io/client-go/kubernetes"

	"github.com/flamingo-stack/openframe-cli/internal/k8s"
)

func main() {
	cfg, err := k8s.RestConfigForContext("/home/user/.kube/config", "kind-openframe")
	if err != nil {
		log.Fatalf("failed to build rest config: %v", err)
	}

	clientset, err := kubernetes.NewForConfig(cfg)
	if err != nil {
		log.Fatalf("failed to create clientset: %v", err)
	}

	fmt.Println("Client created for context:", clientset)
}
```

This is typically used after a context has been chosen (e.g., via a context-selection step) to produce a working client for health checks, resource inspection, or cluster installation operations.
