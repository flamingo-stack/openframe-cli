# restconfig.go

Builds a Kubernetes `rest.Config` for a given kubeconfig context, enabling clients to connect to a specific cluster context selected during CLI operations.

## Key Components

- **`RestConfigForContext(kubeconfigPath, contextName string) (*rest.Config, error)`** — Constructs a `*rest.Config` from a kubeconfig path and an optional context name.
  - If `contextName` is empty, the kubeconfig's `current-context` is used.
  - Supports `$KUBECONFIG`-style multi-file paths (using the OS path list separator) by merging them via `Precedence`; a single file path is treated as `ExplicitPath` to preserve stricter "file not found" error behavior.
  - Wraps errors with context about which kubeconfig context failed to load.

## Usage Example

```go
package main

import (
	"fmt"
	"log"

	"your-module/internal/k8s"
)

func main() {
	kubeconfigPath := "/home/user/.kube/config"
	contextName := "my-cluster-context"

	cfg, err := k8s.RestConfigForContext(kubeconfigPath, contextName)
	if err != nil {
		log.Fatalf("failed to build rest config: %v", err)
	}

	fmt.Printf("Connected to host: %s\n", cfg.Host)
}
```

This function is typically used after a user selects a context (e.g., via `SelectContext`) to produce a working client configuration for health checks, resource inspection, or driving an installation against the chosen cluster.
