Read-only Kubernetes cluster inspector that checks reachability, node health, and allocatable resource capacity without creating or mutating any cluster resources.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `Accessor` | struct | Core type wrapping a `kubernetes.Interface` client |
| `NewAccessorForConfig` | func | Constructs an `Accessor` from a `rest.Config` |
| `Health` | struct | Snapshot of cluster reachability and node readiness |
| `Health.Ready()` | method | Returns `true` if reachable and at least one node is ready |
| `CheckHealth` | method | Lists nodes and reports readiness + server version |
| `Requirements` | struct | Minimum CPU (milli-cores) and memory (bytes) needed |
| `Resources` | struct | Summed allocatable CPU and memory across ready nodes |
| `CheckResources` | method | Compares ready-node capacity against `Requirements` |

## Usage Example

```go
import (
    "context"
    "k8s.io/client-go/tools/clientcmd"
)

config, err := clientcmd.BuildConfigFromFlags("", kubeConfigPath)
if err != nil {
    log.Fatal(err)
}

accessor, err := k8s.NewAccessorForConfig(config)
if err != nil {
    log.Fatal(err)
}

ctx := context.Background()

// Check cluster health
health, err := accessor.CheckHealth(ctx)
if err != nil || !health.Ready() {
    log.Fatalf("cluster not ready: %+v", health)
}
fmt.Printf("Server: %s, Nodes: %d/%d ready\n",
    health.ServerVersion, health.NodesReady, health.NodesTotal)

// Verify minimum capacity (6 cores, 24 GiB RAM)
req := k8s.Requirements{
    CPUMillis: 6000,
    MemBytes:  24 * 1024 * 1024 * 1024,
}
res, sufficient, err := accessor.CheckResources(ctx, req)
if !sufficient {
    log.Fatalf("insufficient capacity: %+v", res)
}
```

> **Note:** `CheckResources` only counts nodes whose `Ready` condition is `True`, ensuring capacity from unschedulable nodes is excluded from the calculation.
