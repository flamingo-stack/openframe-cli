## Overview

`contexts.go` provides read/inspect access to kubeconfig contexts for targeting an *existing* Kubernetes cluster. It is part of the `k8s` package, which is intentionally separate from cluster creation logic (`internal/cluster/...`) — this file is used when the app-install flow needs to work with a cluster the user already has, regardless of how it was created.

## Key Components

- **`ContextInfo`** — struct describing a kubeconfig context (`Name`, `Cluster`, `Current`).
- **`DefaultKubeconfigPath()`** — resolves the kubeconfig path from `$KUBECONFIG`, `~/.kube/config`, or the client-go default.
- **`ResolveContextForCluster(kubeconfigPath, clusterName)`** — returns the best-matching context name for a cluster, preferring an exact match and falling back to the `k3d-<name>` convention.
- **`HasContext(path, name)`** — checks whether a named context exists in the kubeconfig.
- **`SwitchContext(path, name)`** — sets `current-context` in the appropriate file within a `$KUBECONFIG` file list, without altering other entries.
- **`LoadContexts(path)`** — loads and merges kubeconfig file(s), returning sorted `ContextInfo` list and the current context name.
- **`loadMerged` / `currentContextFile`** — internal helpers implementing kubectl-style `$KUBECONFIG` list merging and current-context file resolution.

## Usage Example

```go
package main

import (
	"fmt"
	"log"

	"github.com/flamingo-stack/openframe-cli/internal/k8s"
)

func main() {
	path := k8s.DefaultKubeconfigPath()

	contexts, current, err := k8s.LoadContexts(path)
	if err != nil {
		log.Fatalf("failed to load kubeconfig: %v", err)
	}

	fmt.Println("Current context:", current)
	for _, c := range contexts {
		fmt.Printf("- %s (cluster: %s, current: %v)\n", c.Name, c.Cluster, c.Current)
	}

	// Resolve and switch to the context for a named cluster
	target := k8s.ResolveContextForCluster(path, "my-cluster")
	if k8s.HasContext(path, target) {
		if err := k8s.SwitchContext(path, target); err != nil {
			log.Fatalf("failed to switch context: %v", err)
		}
	}
}
```
