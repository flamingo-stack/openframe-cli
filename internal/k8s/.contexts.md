Provides utilities for reading and resolving kubeconfig contexts, serving as the foundation for interactive cluster selection in the app-install flow.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ContextInfo` | struct | Describes a single kubeconfig context with its name, target cluster, and whether it is the active context |
| `DefaultKubeconfigPath()` | func | Returns the kubeconfig path from `$KUBECONFIG`, `~/.kube/config`, or the client-go recommended fallback |
| `ResolveContextForCluster()` | func | Maps a cluster name to its kubeconfig context, preferring an exact name match then falling back to the k3d convention `k3d-<name>` |
| `LoadContexts()` | func | Parses the kubeconfig at a given path and returns all contexts sorted alphabetically, plus the current-context name |

## Usage Example

```go
// Discover all available contexts
path := k8s.DefaultKubeconfigPath()
contexts, current, err := k8s.LoadContexts(path)
if err != nil {
    log.Fatalf("failed to load kubeconfig: %v", err)
}

for _, ctx := range contexts {
    marker := " "
    if ctx.Current {
        marker = "*"
    }
    fmt.Printf("%s %-30s -> %s\n", marker, ctx.Name, ctx.Cluster)
}

// Resolve the correct context for a named cluster
ctxName := k8s.ResolveContextForCluster(path, "my-cluster")
// Returns "my-cluster" if that context exists, otherwise "k3d-my-cluster"
fmt.Println("Using context:", ctxName)
```

## Notes

- `ResolveContextForCluster` degrades gracefully: if the kubeconfig is unreadable it returns the k3d-prefixed name rather than an error, preserving backward compatibility.
- This package is intentionally scoped to **read/inspect** operations. Cluster creation lives under `internal/cluster/`.
