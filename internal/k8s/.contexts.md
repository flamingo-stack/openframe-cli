# contexts.go

Provides read-only access to Kubernetes kubeconfig contexts — listing, resolving, and switching contexts on an *existing* cluster's kubeconfig file. This is intentionally separate from cluster creation logic, since the app-install flow targets clusters that may already exist regardless of how they were created.

## Key Components

- **`ContextInfo`** — struct describing a single kubeconfig context (`Name`, `Cluster`, `Current`).
- **`DefaultKubeconfigPath()`** — resolves the kubeconfig path from `$KUBECONFIG`, `~/.kube/config`, or the client-go recommended default.
- **`ResolveContextForCluster(kubeconfigPath, clusterName)`** — determines the context name for a cluster, preferring an exact match, falling back to the `k3d-<name>` convention.
- **`HasContext(path, name)`** — checks whether a named context exists in the kubeconfig.
- **`SwitchContext(path, name)`** — sets `current-context` in the kubeconfig, safely writing only to the file that owns `current-context` (per kubectl's `$KUBECONFIG` list convention), without touching other contexts/clusters/users.
- **`LoadContexts(path)`** — loads and merges kubeconfig file(s), returning all contexts (sorted by name) and the current context name. Used to power interactive context-selection menus.
- **`loadMerged` / `currentContextFile`** — internal helpers implementing kubectl-compatible `$KUBECONFIG` list merging and current-context file resolution.

## Usage Example

```go
package main

import (
	"fmt"
	"log"

	"github.com/flamingo-stack/openframe-cli/internal/k8s"
)

func main() {
	path := k8s.DefaultKubeconfigPath()

	contexts, current, err := k8s.LoadContexts(path)
	if err != nil {
		log.Fatalf("failed to load contexts: %v", err)
	}

	fmt.Println("Current context:", current)
	for _, ctx := range contexts {
		fmt.Printf("- %s (cluster: %s, current: %v)\n", ctx.Name, ctx.Cluster, ctx.Current)
	}

	// Resolve a context name for a cluster, preferring exact match over k3d-<name>
	ctxName := k8s.ResolveContextForCluster(path, "my-cluster")

	if k8s.HasContext(path, ctxName) {
		if err := k8s.SwitchContext(path, ctxName); err != nil {
			log.Fatalf("failed to switch context: %v", err)
		}
	}
}
```
