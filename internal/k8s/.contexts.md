## Overview

`contexts.go` provides read/inspect utilities for working with an **existing** Kubernetes cluster's kubeconfig — listing contexts, resolving cluster-to-context mappings, and safely switching the active context. It is intentionally separate from cluster *creation* logic, since it targets clusters that already exist (whether created by `openframe cluster`, manually, or by other tooling).

## Key Components

- **`ContextInfo`** — struct describing a kubeconfig context (`Name`, `Cluster`, `Current`).
- **`DefaultKubeconfigPath()`** — resolves the kubeconfig path from `$KUBECONFIG`, `~/.kube/config`, or client-go's default.
- **`ResolveContextForCluster(kubeconfigPath, clusterName)`** — finds the best-matching context name for a cluster, preferring an exact match then falling back to the `k3d-<name>` convention.
- **`HasContext(path, name)`** — checks whether a named context exists in the kubeconfig.
- **`SwitchContext(path, name)`** — updates `current-context` in the appropriate kubeconfig file, following kubectl's multi-file precedence rules, without altering other contexts/clusters/users.
- **`LoadContexts(path)`** — loads and merges kubeconfig file(s) (supporting `$KUBECONFIG`-style file lists) and returns all contexts sorted by name, plus the current context.
- **`loadMerged`** / **`currentContextFile`** — internal helpers implementing kubectl-compatible merging and current-context file resolution for multi-file `$KUBECONFIG` values.

## Usage Example

```go
import "yourmodule/internal/k8s"

func main() {
	path := k8s.DefaultKubeconfigPath()

	// List all available contexts
	contexts, current, err := k8s.LoadContexts(path)
	if err != nil {
		panic(err)
	}
	for _, c := range contexts {
		fmt.Printf("%s (cluster=%s, current=%v)\n", c.Name, c.Cluster, c.Current)
	}
	fmt.Println("Active context:", current)

	// Resolve the context to use for a given cluster name
	ctxName := k8s.ResolveContextForCluster(path, "my-cluster")

	// Switch to that context
	if err := k8s.SwitchContext(path, ctxName); err != nil {
		panic(err)
	}
}
```
