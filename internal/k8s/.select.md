Implements the interactive Kubernetes context-selection flow, guiding users through choosing a kubeconfig context via a terminal-abstracted prompt interface.

## Key Components

### `Prompter` Interface
An abstraction over terminal interaction, enabling full testability without a real TTY:

| Method | Description |
|---|---|
| `Confirm(message, defaultYes)` | Presents a yes/no question with a default answer |
| `Choose(label, options)` | Presents a labelled list and returns the selected index |

### `SelectContext(contexts, current, p)`
Runs the two-step context-selection flow:
1. If a current context exists, offers it as a one-keystroke default (confirm yes/no)
2. If declined or no current context exists, presents the full context list for selection

Returns the chosen context name, or an error if no contexts are found or selection is invalid.

## Usage Example

```go
type myPrompter struct{}

func (m myPrompter) Confirm(msg string, defaultYes bool) (bool, error) {
    // wire to ui.ConfirmActionInteractive
}
func (m myPrompter) Choose(label string, opts []string) (int, error) {
    // wire to ui.SelectFromList
}

contexts := []k8s.ContextInfo{
    {Name: "prod", Cluster: "prod-cluster"},
    {Name: "staging", Cluster: "staging-cluster"},
}

chosen, err := k8s.SelectContext(contexts, "staging", myPrompter{})
if err != nil {
    log.Fatal(err)
}
fmt.Println("Selected:", chosen)
```

> **Note:** The production `Prompter` implementation is wired at the command layer. For testing, inject a mock that returns predetermined responses without requiring a live terminal.
