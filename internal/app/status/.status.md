# status.go

Aggregates OpenFrame platform status—cluster health, ArgoCD application sync/health state, and admin access credentials—for use by the `openframe app status` and `openframe app access` CLI commands.

## Key Components

- **`Lister`** — Interface for listing ArgoCD applications in the target cluster.
- **`PasswordReader`** — Interface for retrieving the initial ArgoCD admin password.
- **`HealthChecker`** — Interface for checking cluster reachability/readiness.
- **`Report`** — Struct holding the aggregated status: cluster health, application list, sync/healthy counts, and admin password (if available).
  - `Ready() bool` — Returns `true` only if the cluster is reachable and all applications are Synced and Healthy.
  - `Summary() string` — Produces a one-line human-readable status message (handles edge cases like unreachable clusters or missing node health).
- **`Service`** — Orchestrates status aggregation from injected `Lister`, `HealthChecker`, and `PasswordReader` dependencies.
  - `NewService(lister, health, password) *Service` — Constructor; `health` and `password` are optional (may be `nil`), `lister` is required.
  - `Report(ctx, verbose) (Report, error)` — Gathers health, applications, and admin password. Fails only if application listing fails; health/password errors are non-fatal.
- **`summarize(apps)`** — Internal helper that counts total, synced, and healthy applications from an ArgoCD application list.

## Usage Example

```go
lister := argocd.NewClient(/* ... */)
health := k8s.NewHealthChecker(/* ... */)
password := argocd.NewPasswordReader(/* ... */)

svc := status.NewService(lister, health, password)

report, err := svc.Report(context.Background(), false)
if err != nil {
	log.Fatalf("failed to get status: %v", err)
}

fmt.Println(report.Summary())
if report.Ready() {
	fmt.Println("Platform is fully operational")
}
if report.AdminPassword != "" {
	fmt.Printf("Admin password: %s\n", report.AdminPassword)
}
```

## Notes

- `HealthErr` on `Report` captures a non-fatal health check failure without aborting the overall report.
- `Summary()` carefully distinguishes between "cluster unreachable" and "node health unavailable but apps are listable" (common with namespace-scoped RBAC), avoiding contradictory messaging in renderers.
