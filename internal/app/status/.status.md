# status.go

Aggregates OpenFrame platform status by combining cluster health, ArgoCD application sync/health state, and admin credentials into a single report. It backs the `openframe app status` and `openframe app access` commands.

## Key Components

- **`Lister`** — interface for listing ArgoCD applications in the target cluster.
- **`PasswordReader`** — interface for retrieving the initial ArgoCD admin password.
- **`HealthChecker`** — interface for checking cluster reachability/readiness.
- **`Report`** — aggregated status struct containing `Health`, `HealthErr`, `Apps`, `Total`, `Synced`, `Healthy`, and `AdminPassword`.
  - `Ready()` — returns `true` only when the cluster is reachable and all applications are both synced and healthy.
  - `Summary()` — produces a one-line human-readable status string, handling edge cases like unreachable clusters, no applications found, and partial node-health failures without contradicting other output.
- **`Service`** — orchestrates status aggregation from injected `Lister`, `HealthChecker`, and `PasswordReader` sources.
  - `NewService(lister, health, password)` — constructor; `health` and `password` are optional (nil-safe), `lister` is required.
  - `Report(ctx, verbose)` — builds a `Report` by checking health (best-effort), listing applications (hard failure on error), and fetching the admin password (best-effort).
- **`summarize(apps)`** — internal helper that counts total, synced, and healthy applications.

## Usage Example

```go
package main

import (
	"context"
	"fmt"
	"log"

	"github.com/flamingo-stack/openframe-cli/internal/status"
)

func main() {
	ctx := context.Background()

	svc := status.NewService(argoLister, k8sHealthChecker, argoPasswordReader)

	report, err := svc.Report(ctx, false)
	if err != nil {
		log.Fatalf("failed to get status: %v", err)
	}

	fmt.Println(report.Summary())

	if report.Ready() {
		fmt.Println("Platform is fully operational")
	}

	if report.AdminPassword != "" {
		fmt.Printf("Admin password: %s\n", report.AdminPassword)
	}
}
```

Callers typically wire `argocd`-based implementations of `Lister` and `PasswordReader`, plus a `k8s`-based `HealthChecker`, before invoking `Report` to render CLI output.
