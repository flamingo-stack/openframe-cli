Aggregates OpenFrame platform status by combining cluster health, ArgoCD application sync/health state, and admin credentials into a single `Report` for the `openframe app status` and `openframe app access` commands.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `Lister` | Interface | Lists ArgoCD applications in the target cluster |
| `PasswordReader` | Interface | Reads the initial ArgoCD admin password |
| `HealthChecker` | Interface | Reports cluster reachability and readiness |
| `Report` | Struct | Aggregated snapshot: health, apps, sync/healthy counts, admin password |
| `Report.Ready()` | Method | Returns `true` when cluster is reachable and all apps are synced and healthy |
| `Report.Summary()` | Method | Returns a one-line human-readable status string |
| `Service` | Struct | Wires the three sources and produces a `Report` |
| `NewService()` | Constructor | Injects `Lister` (required), `HealthChecker`, and `PasswordReader` (both optional) |
| `Service.Report()` | Method | Runs all checks concurrently; hard-fails only if app listing fails |
| `summarize()` | Internal | Counts total, synced, and healthy apps from a slice |

## Usage Example

```go
svc := status.NewService(
    argocdClient,   // Lister – required
    k8sClient,      // HealthChecker – optional, pass nil to skip
    secretReader,   // PasswordReader – optional, pass nil to skip
)

rep, err := svc.Report(ctx, false)
if err != nil {
    log.Fatalf("failed to gather status: %v", err)
}

fmt.Println(rep.Summary())
// "3/3 synced, 3/3 healthy — READY"

if rep.Ready() {
    fmt.Printf("Admin password: %s\n", rep.AdminPassword)
}
```

## Error Handling

`Service.Report` follows a best-effort pattern: `HealthErr` is populated if the cluster check fails, admin password errors are silently swallowed, but a failure to list ArgoCD applications returns a hard error to the caller.
