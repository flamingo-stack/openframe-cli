# tui.go

Implements the interactive TUI for `app status --interactive`, a k9s-style terminal screen built on Bubble Tea that displays live ArgoCD application status. It reuses the same status service as the non-interactive command for reads and adds a single write action: triggering a sync for the selected application.

## Key Components

- **`Syncer`** - Function type `func(ctx context.Context, names []string) error` used to trigger syncs on selected apps.
- **`Run(ctx, svc, sync, verbose)`** - Entry point that constructs the Bubble Tea model and blocks until the user quits; treats context cancellation (Ctrl+C) as a clean exit.
- **`model`** - The Bubble Tea model holding the current `appstatus.Report`, cursor position, detail/list view toggle, and status notes. Implements `Init`, `Update`, and `View`.
- **Auto-refresh loop** - `refreshEvery` (3s) ticker drives periodic re-fetching of the status report via `tickMsg`/`refreshMsg`.
- **Key bindings** - `up`/`down`/`j`/`k` navigate, `enter` toggles detail view, `s` syncs the selected app, `r` forces a refresh, `q`/`esc`/`ctrl+c` quits.
- **`listView` / `detailView`** - Render the application table and single-app detail panel respectively.
- **`colorByHealth`** - Colorizes text based on ArgoCD health state (Healthy/Degraded/Progressing).

## Usage Example

```go
package main

import (
	"context"

	"github.com/flamingo-stack/openframe-cli/internal/app/status"
	"github.com/flamingo-stack/openframe-cli/internal/tui"
)

func main() {
	ctx := context.Background()
	svc := status.NewService( /* ... */ )

	syncer := func(ctx context.Context, names []string) error {
		// trigger ArgoCD sync for the given app names
		return nil
	}

	if err := tui.Run(ctx, svc, syncer, false); err != nil {
		panic(err)
	}
}
```

Running `tui.Run` launches a full-screen terminal UI that lists OpenFrame applications, auto-refreshes every 3 seconds, and lets the user drill into details or trigger syncs interactively.
