# tui.go

Implements an interactive, k9s-style terminal UI (Bubble Tea) for browsing the status of ArgoCD-managed OpenFrame applications. Invoked via `app status --interactive`, it periodically polls the same status service used by the non-interactive command, renders a navigable list of applications with sync/health state, and supports drilling into per-app details or triggering a sync — all within a single blocking event loop.

## Key Components

- **`Syncer`** — function type `func(ctx, names []string) error` used to trigger an ArgoCD sync for selected apps; injected by the caller so the TUI has no direct ArgoCD write dependency.
- **`Run(ctx, svc, sync, verbose)`** — entry point that builds the Bubble Tea program and blocks until the user quits; treats context cancellation (Ctrl+C) as a clean exit.
- **`model`** — the Bubble Tea model holding the current `appstatus.Report`, cursor position, detail/list view toggle, and status notes.
- **`model.Init/Update/View`** — standard Bubble Tea lifecycle: `Init` kicks off the first refresh and a repeating tick (`refreshEvery` = 3s); `Update` handles refresh results, sync completion, and key events (`up`/`down`/`j`/`k` navigate, `enter` toggles detail, `s` syncs the selected app, `r` refreshes, `q`/`esc`/`ctrl+c` quits); `View` renders the header, list or detail pane, notes, and keybinding hints.
- **`listView` / `detailView`** — render the app table (name, sync, health) and a single app's full detail (revision, conditions, operation state), respectively.
- **`colorByHealth`** — colors text green/red/yellow based on ArgoCD health status.

## Usage Example

```go
import (
	"context"

	"github.com/flamingo-stack/openframe-cli/internal/app/status"
	"github.com/flamingo-stack/openframe-cli/internal/app/status/tui"
)

func runInteractive(ctx context.Context, svc *status.Service) error {
	sync := func(ctx context.Context, names []string) error {
		// call into ArgoCD client to trigger sync for names
		return nil
	}
	return tui.Run(ctx, svc, sync, false /* verbose */)
}
```
