## factory.go

Implements a factory function that constructs the appropriate `Provider` implementation for a given cluster type (k3d, EKS, or GKE), abstracting provider selection away from callers.

## Key Components

- **`New(clusterType models.ClusterType, exec executor.CommandExecutor) (Provider, error)`** — Factory function that returns a `Provider` instance based on `clusterType`:
  - `models.ClusterTypeK3d` or empty string → local k3d cluster manager (default for local development)
  - `models.ClusterTypeEKS` → AWS EKS provider, configured with `pterm.PrintDebugMessages` to enable verbose Terraform output
  - `models.ClusterTypeGKE` → Google GKE provider, similarly wired to the CLI's `--verbose` flag
  - Any other value → returns a `models.NewInvalidConfigError` describing the unknown cluster type

## Usage Example

```go
package main

import (
	"log"

	"github.com/flamingo-stack/openframe-cli/internal/cluster/models"
	"github.com/flamingo-stack/openframe-cli/internal/cluster/providers/provider"
	"github.com/flamingo-stack/openframe-cli/internal/shared/executor"
)

func main() {
	exec := executor.NewCommandExecutor()

	// Defaults to k3d when clusterType is empty
	p, err := provider.New(models.ClusterTypeK3d, exec)
	if err != nil {
		log.Fatalf("failed to create provider: %v", err)
	}

	// Use the provider to manage clusters, e.g. p.Create(...), p.Delete(...)
	_ = p
}
```

## Notes

- Uses `pterm.PrintDebugMessages` as the shared signal for the CLI's global `--verbose` flag, ensuring EKS/GKE Terraform-based providers stream detailed output consistently with the rest of the CLI.
- Errors are returned via `models.NewInvalidConfigError`, keeping configuration validation consistent across the cluster subsystem.
