# factory.go

Implements a factory function that constructs the appropriate `Provider` implementation based on the requested cluster type, abstracting away the concrete provider (k3d, EKS, GKE) construction details from callers.

## Key Components

- **`New(clusterType models.ClusterType, exec executor.CommandExecutor) (Provider, error)`** — Factory function that returns a `Provider` instance based on `clusterType`:
  - `models.ClusterTypeK3d` or empty string → k3d provider (local development default), via `k3d.CreateClusterManagerWithExecutor`
  - `models.ClusterTypeEKS` → AWS EKS provider via `eks.New`, wired with `pterm.PrintDebugMessages` to control terraform output verbosity
  - `models.ClusterTypeGKE` → Google GKE provider via `gke.New`, same verbosity wiring
  - Any other value → returns a `models.NewInvalidConfigError` describing the unknown cluster type

## Usage Example

```go
import (
	"github.com/flamingo-stack/openframe-cli/internal/cluster/models"
	"github.com/flamingo-stack/openframe-cli/internal/cluster/provider"
	"github.com/flamingo-stack/openframe-cli/internal/shared/executor"
)

func createProvider(exec executor.CommandExecutor) (provider.Provider, error) {
	// Defaults to k3d when clusterType is empty
	p, err := provider.New(models.ClusterTypeEKS, exec)
	if err != nil {
		return nil, err
	}

	// Use the provider to manage clusters
	return p, nil
}
```

This factory is typically invoked from higher-level cluster commands (e.g., `create`, `delete`) so the rest of the codebase can work against the generic `Provider` interface without knowing which backend is in use.
