Defines the `Provider` interface — the unified contract for all cluster backends in the OpenFrame CLI. It abstracts cluster lifecycle operations so the rest of the CLI remains backend-agnostic, with `k3d` as the current implementation and GKE/EKS reserved for future use.

## Key Components

**`Provider` interface** — Core abstraction with nine methods:

| Method | Description |
|---|---|
| `CreateCluster` | Provisions a cluster, returns `*rest.Config` |
| `DeleteCluster` | Removes a cluster by name |
| `StartCluster` | Starts a previously stopped cluster |
| `ListClusters` | Lists clusters managed by this provider |
| `ListAllClusters` | Lists all visible clusters |
| `GetClusterStatus` | Returns detailed status for a single cluster |
| `DetectClusterType` | Infers the `ClusterType` from a cluster name |
| `GetRestConfig` | Returns a `*rest.Config` for an existing cluster |
| `GetKubeconfig` | Returns the raw kubeconfig string |

**Compile-time assertion** — `var _ Provider = (*k3d.K3dManager)(nil)` enforces that `k3d.K3dManager` satisfies the interface at build time, catching drift early.

## Usage Example

Depend on the interface, not the concrete type — enabling easy mocking in tests:

```go
// Production wiring: inject the concrete k3d manager
manager := k3d.NewK3dManager(...)
var p provider.Provider = manager

cfg, err := p.CreateCluster(ctx, models.ClusterConfig{
    Name: "openframe-dev",
    Type: models.ClusterTypeK3d,
})

// Test wiring: swap in a mock without changing ClusterService
type mockProvider struct{ provider.Provider }
func (m *mockProvider) CreateCluster(_ context.Context, _ models.ClusterConfig) (*rest.Config, error) {
    return &rest.Config{Host: "https://localhost:6443"}, nil
}
```

> **Design note:** No factory function is intentional. Per the inline audit note (B7), a factory will only be introduced alongside the first real multi-backend caller (GKE or EKS). The interface itself is the extension point.
