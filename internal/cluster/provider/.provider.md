# provider.go

Defines the unified `Provider` abstraction that all Kubernetes cluster backends (k3d, EKS, GKE) implement, allowing the CLI to manage clusters without needing backend-specific logic.

## Key Components

- **`Provider` interface** — the core contract every backend must satisfy, covering cluster lifecycle (`CreateCluster`, `DeleteCluster`, `StartCluster`), discovery (`ListClusters`, `ListAllClusters`, `DetectClusterType`), and connectivity (`GetRestConfig`, `GetKubeconfig`, `GetClusterStatus`).
- **`Planner` interface** — optional capability for cloud providers (EKS, GKE) to preview infrastructure changes via `PlanCluster`, returning a `terraform.PlanSummary`. Not implemented by k3d since local clusters have no meaningful "plan" step.
- **Compile-time assertions** — verify at build time that `k3d.K3dManager`, `eks.Provider`, and `gke.Provider` correctly implement `Provider` (and `Planner` for the cloud providers).

Backend selection happens elsewhere via a `New` factory function (in `factory.go`), keyed on `models.ClusterConfig.Type`, so callers work against the `Provider` interface without knowing the concrete backend.

## Usage Example

```go
package main

import (
	"context"
	"log"

	"github.com/flamingo-stack/openframe-cli/internal/cluster/models"
	"github.com/flamingo-stack/openframe-cli/internal/cluster/providers/provider"
)

func createCluster(ctx context.Context, p provider.Provider, cfg models.ClusterConfig) {
	restConfig, err := p.CreateCluster(ctx, cfg)
	if err != nil {
		log.Fatalf("failed to create cluster: %v", err)
	}
	_ = restConfig // use to build a Kubernetes client
}

func previewCluster(ctx context.Context, p provider.Provider, cfg models.ClusterConfig) {
	// Cloud providers also implement Planner
	if planner, ok := p.(provider.Planner); ok {
		summary, err := planner.PlanCluster(ctx, cfg)
		if err != nil {
			log.Fatalf("plan failed: %v", err)
		}
		log.Printf("plan: %+v", summary)
	}
}
```

See the factory implementation for backend resolution: [factory.go](https://github.com/flamingo-stack/openframe-cli/blob/main/internal/cluster/providers/factory.go).
