# provider.go

Defines the unified `Provider` interface for cluster lifecycle management, abstracting over local (k3d) and cloud (EKS, GKE) Kubernetes cluster backends so the rest of the CLI can operate without knowing which backend is active.

## Key Components

- **`Provider`** — Core interface every cluster backend implements. Covers full lifecycle operations: `CreateCluster`, `DeleteCluster`, `StartCluster`, `ListClusters`, `ListAllClusters`, `GetClusterStatus`, `DetectClusterType`, `GetRestConfig`, and `GetKubeconfig`.
- **`Planner`** — Optional interface for cloud providers (EKS, GKE) that support previewing infrastructure changes via `PlanCluster`, returning a `terraform.PlanSummary` without mutating state. k3d does not implement this, since it has no meaningful "plan" step.
- **Compile-time assertions** — `var` block using blank identifiers to verify `k3d.K3dManager`, `eks.Provider`, and `gke.Provider` satisfy `Provider`, and that `eks.Provider`/`gke.Provider` also satisfy `Planner`. This catches interface drift at build time rather than runtime.

## Usage Example

```go
import (
    "context"

    "github.com/flamingo-stack/openframe-cli/internal/cluster/models"
    "github.com/flamingo-stack/openframe-cli/internal/cluster/provider"
)

func createCluster(ctx context.Context, p provider.Provider, cfg models.ClusterConfig) error {
    restCfg, err := p.CreateCluster(ctx, cfg)
    if err != nil {
        return err
    }
    _ = restCfg // use to build a Kubernetes clientset
    return nil
}

// Optional planning support for cloud providers
func planIfSupported(ctx context.Context, p provider.Provider, cfg models.ClusterConfig) error {
    if planner, ok := p.(provider.Planner); ok {
        summary, err := planner.PlanCluster(ctx, cfg)
        if err != nil {
            return err
        }
        _ = summary // display plan to user
    }
    return nil
}
```

Backend selection happens through a separate factory (`New`, in `factory.go`), which keys off `models.ClusterConfig.Type` to return the correct `Provider` implementation.
