# provider.go

Defines the unified `Provider` interface abstraction that all Kubernetes cluster backends (k3d, EKS, GKE) implement, allowing the rest of the CLI to manage clusters without knowing which backend is in use.

## Key Components

- **`Provider`** — Core interface implemented by every cluster backend. Covers the full cluster lifecycle: `CreateCluster`, `DeleteCluster`, `StartCluster`, `ListClusters`, `ListAllClusters`, `GetClusterStatus`, `DetectClusterType`, `GetRestConfig`, and `GetKubeconfig`.
- **`Planner`** — Optional interface for cloud-only backends (EKS, GKE) that support previewing infrastructure changes via `PlanCluster`, returning a `terraform.PlanSummary` without applying or registering anything. k3d does not implement this, since local clusters have no meaningful "plan" step.
- **Compile-time assertions** — Verify that `k3d.K3dManager`, `eks.Provider`, and `gke.Provider` satisfy `Provider`, and that `eks.Provider`/`gke.Provider` also satisfy `Planner`. These catch interface drift at build time rather than runtime.

Backend selection happens in `New` (factory.go), which resolves the concrete backend based on `ClusterConfig.Type`.

## Usage Example

```go
import (
	"context"

	"github.com/flamingo-stack/openframe-cli/internal/cluster/models"
	"github.com/flamingo-stack/openframe-cli/internal/cluster/providers"
)

func createCluster(ctx context.Context, cfg models.ClusterConfig) error {
	p, err := providers.New(cfg.Type)
	if err != nil {
		return err
	}

	restCfg, err := p.CreateCluster(ctx, cfg)
	if err != nil {
		return err
	}

	// Optional: preview infra changes for cloud providers before creating
	if planner, ok := p.(providers.Planner); ok {
		summary, err := planner.PlanCluster(ctx, cfg)
		if err != nil {
			return err
		}
		_ = summary // inspect planned changes
	}

	_ = restCfg
	return nil
}
```
