Defines the `FlagContainer` type that aggregates all CLI flag structures and dependencies for cluster commands into a single, cohesive container.

## Key Components

| Export | Type | Description |
|---|---|---|
| `FlagContainer` | struct | Holds flag models for all cluster subcommands plus executor/test dependencies |
| `NewFlagContainer()` | constructor | Returns a `FlagContainer` with sensible defaults (`k3d`, 3 nodes, `v1.31.5-k3s1`) |
| `SyncGlobalFlags()` | method | Propagates `GlobalFlags` into each subcommand's flag struct |

## Usage Example

```go
// Initialize with defaults
flags := cluster.NewFlagContainer()

// Bind cobra flags, then sync globals before command execution
flags.Global.Verbose = true
flags.SyncGlobalFlags()

// Inject a mock executor for unit tests
flags.Executor = &mockExecutor{}
flags.TestManager = k3d.NewK3dManager(flags.Executor)
```

## Notes

- `Executor` and `TestManager` are excluded from JSON serialization (`json:"-"`) — they are runtime/test-only dependencies.
- `SyncGlobalFlags()` is a no-op if `Global` is `nil`, making it safe to call unconditionally before dispatch.
- Default `ClusterType` is `"k3d"`; override via `flags.Create.ClusterType` before executing a create command.
