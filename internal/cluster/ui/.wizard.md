Interactive CLI wizard for collecting Kubernetes cluster configuration from users, supporting both quick-default and step-by-step interactive modes.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `ClusterConfig` | struct | Holds wizard-scoped cluster config (name, type, node count, K8s version) |
| `ConfigWizard` | struct | Drives the multi-step interactive prompt flow |
| `NewConfigWizard()` | constructor | Returns a wizard pre-seeded with defaults (`openframe-dev`, k3d, 3 nodes, `latest`) |
| `ConfigWizard.SetDefaults()` | method | Overrides wizard defaults before running |
| `ConfigWizard.Run()` | method | Executes all prompt steps; loops back if user declines confirmation |
| `ConfigurationHandler` | struct | Entry point that lets the user choose between quick and wizard modes |
| `ConfigurationHandler.GetClusterConfig()` | method | Presents mode selector, then delegates to `getQuickConfig` or `getWizardConfig` |

## Usage Example

```go
handler := ui.NewConfigurationHandler()

// Presents "Default configuration" vs "Interactive configuration" prompt.
// If quick mode is chosen, returns defaults immediately.
// If wizard mode is chosen, walks the user through each step.
cfg, err := handler.GetClusterConfig("my-cluster")
if err != nil {
    log.Fatal(err)
}

fmt.Printf("Creating %s cluster with %d nodes\n", cfg.Name, cfg.NodeCount)
```

To invoke the wizard directly with pre-set defaults:

```go
wizard := ui.NewConfigWizard()
wizard.SetDefaults("staging", models.ClusterTypeK3d, 5, "v1.29")

cfg, err := wizard.Run()
if err != nil {
    log.Fatal(err)
}
```

> **Note:** If the user declines the confirmation step, `Run()` restarts recursively, allowing edits without exiting the CLI.
