# wizard.go

Implements an interactive, multi-step configuration wizard for creating Kubernetes clusters (k3d, EKS, GKE), along with a higher-level handler that lets users choose between a quick default setup or the full wizard flow.

## Key Components

- **`ClusterConfig`** – Wizard-local struct holding user answers (name, type, node count, k8s version, and cloud-specific fields like region, project, profile, machine type).
- **`ClusterConfig.ToDomain()`** – Converts wizard answers into the domain `models.ClusterConfig`, attaching a `CloudConfig` block only for EKS/GKE cluster types.
- **`ConfigWizard`** – Orchestrates the step-by-step prompts (name, cluster type, cloud-specific project/region/profile/machine type, node count, k8s version) and a final confirmation step, with support for restarting if the user declines confirmation.
  - `NewConfigWizard()` – Creates a wizard with default values (`openframe-dev`, k3d, 3 nodes, latest version).
  - `SetDefaults(...)` – Overrides initial default values before running.
  - `Run()` – Executes the full interactive flow and returns the final `ClusterConfig`.
- **`ConfigurationHandler`** – Top-level entry point that first asks the user to pick "Default configuration" or "Interactive configuration".
  - `NewConfigurationHandler()` – Constructor.
  - `GetClusterConfig(clusterName string)` – Runs mode selection then delegates to quick or wizard config.
  - `getQuickConfig(...)` – Returns a hardcoded k3d default configuration.
  - `getWizardConfig(...)` – Instantiates and runs `ConfigWizard`, converting the result to the domain model.

## Usage Example

```go
handler := ui.NewConfigurationHandler()

// Prompts user for mode, then walks through quick or wizard flow
config, err := handler.GetClusterConfig("my-cluster")
if err != nil {
    log.Fatal(err)
}

// config is a models.ClusterConfig ready for cluster provisioning
fmt.Printf("Creating cluster: %s (%s)\n", config.Name, config.Type)
```

Cloud-specific fields (`Region`, `Project`, `Profile`, `MachineType`) are only populated—and only appear in the resulting `CloudConfig`—when the selected cluster type is `ClusterTypeEKS` or `ClusterTypeGKE`; for `ClusterTypeK3d`, the wizard instead prompts for a Kubernetes version.
