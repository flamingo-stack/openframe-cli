# wizard.go

Interactive configuration wizard for creating Kubernetes clusters (k3d, EKS, GKE) via terminal prompts, with support for both quick-default and step-by-step interactive setup flows.

## Key Components

- **`ClusterConfig`** - Wizard-local struct holding raw answers (name, type, node count, K8s version, and cloud-specific fields like region, project, profile, machine type).
- **`ClusterConfig.ToDomain()`** - Converts wizard answers into the domain `models.ClusterConfig`, attaching a `CloudConfig` block only for EKS/GKE cluster types.
- **`ConfigWizard`** - Orchestrates the multi-step interactive prompt flow.
  - `NewConfigWizard()` - Creates a wizard with sensible defaults (k3d, 3 nodes, latest version).
  - `SetDefaults(...)` - Overrides default answers before running.
  - `Run()` - Executes the full wizard sequence: cluster name → cluster type → cloud-specific prompts (project/region for GKE, profile/region for EKS, machine type) → node count → K8s version (k3d only) → confirmation. Restarts itself if the user declines confirmation.
- **`ConfigurationHandler`** - Top-level entry point that lets users choose between "quick" (defaults) and "wizard" (interactive) configuration modes.
  - `NewConfigurationHandler()` - Constructor.
  - `GetClusterConfig(clusterName)` - Presents the mode selection and dispatches to the appropriate flow, returning a fully populated `models.ClusterConfig`.
  - `getQuickConfig(clusterName)` - Builds a default k3d configuration (3 nodes, latest version).
  - `getWizardConfig(clusterName)` - Runs `ConfigWizard`, seeding defaults from the provided cluster name.

## Usage Example

```go
handler := ui.NewConfigurationHandler()

// Prompts the user to choose quick defaults or the interactive wizard,
// then returns a fully resolved domain configuration.
clusterConfig, err := handler.GetClusterConfig("my-cluster")
if err != nil {
    return err
}

// clusterConfig is a models.ClusterConfig ready for cluster creation,
// including a Cloud block if Type is EKS or GKE.
fmt.Printf("Creating cluster %q (%s) with %d nodes\n",
    clusterConfig.Name, clusterConfig.Type, clusterConfig.NodeCount)
```

Direct wizard usage (bypassing mode selection):

```go
wizard := ui.NewConfigWizard()
wizard.SetDefaults("prod-cluster", models.ClusterTypeEKS, 5, "latest")

answers, err := wizard.Run()
if err != nil {
    return err
}

domainConfig := answers.ToDomain()
```
