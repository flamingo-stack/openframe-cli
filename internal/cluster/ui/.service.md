Displays cluster information in a formatted table within the CLI, separating presentation logic from cluster business logic for the `ui` package.

## Key Components

- **`ClusterDisplayInfo`** - Struct holding cluster metadata for display: name, type, source (local/openframe/external), context, project, status, node count, creation time, and associated nodes.
- **`NodeDisplayInfo`** - Struct representing a single node's name, role, and status.
- **`DisplayService`** - Struct providing UI rendering methods for cluster data, decoupled from underlying business logic.
- **`NewDisplayService()`** - Constructor that returns a new `DisplayService` instance.
- **`ShowClusterList(clusters []ClusterDisplayInfo, out io.Writer)`** - Renders a table of clusters to the given writer. Dynamically adds SOURCE/CONTEXT/PROJECT columns only when cloud clusters are present, applies status-based coloring via `sharedUI.GetStatusColor`, and falls back to manual formatting if `pterm` table rendering fails.

## Usage Example

```go
package main

import (
	"os"
	"time"

	"github.com/flamingo-stack/openframe-cli/internal/cluster/ui"
)

func main() {
	displaySvc := ui.NewDisplayService()

	clusters := []ui.ClusterDisplayInfo{
		{
			Name:      "local-dev",
			Type:      "k3d",
			Source:    "local",
			Status:    "Running",
			NodeCount: 3,
			CreatedAt: time.Now(),
		},
		{
			Name:      "prod-gcp",
			Type:      "gke",
			Source:    "openframe",
			Context:   "gke_project_us-central1",
			Project:   "my-gcp-project",
			Status:    "Running",
			NodeCount: 5,
			CreatedAt: time.Now(),
		},
	}

	displaySvc.ShowClusterList(clusters, os.Stdout)
}
```

This prints a table to stdout, automatically including cloud-specific columns (SOURCE, CONTEXT, PROJECT) since the list contains a non-local cluster.
