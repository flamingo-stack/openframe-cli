## Overview

This file implements the display/presentation layer for cluster listing output in the `ui` package. It defines data structures for cluster and node information and a `DisplayService` that renders formatted tables to a given writer, decoupling presentation from business logic.

## Key Components

- **`ClusterDisplayInfo`** - Struct holding cluster metadata for display: name, type, source (`local`/`openframe`/`external`), kubeconfig context, GCP project, status, node count, creation time, and associated nodes.
- **`NodeDisplayInfo`** - Struct representing a single node's name, role, and status.
- **`DisplayService`** - Stateless service struct responsible for rendering cluster UI output.
- **`NewDisplayService()`** - Constructor returning a new `DisplayService` instance.
- **`(*DisplayService) ShowClusterList(clusters []ClusterDisplayInfo, out io.Writer)`** - Renders a table of clusters. Dynamically adds `SOURCE`, `CONTEXT`, and `PROJECT` columns only when at least one cluster is non-local (cloud-based), keeping local-only listings compact. Uses `pterm` for colored, formatted tables with a plain-text fallback if rendering fails.

## Usage Example

```go
package main

import (
	"os"
	"time"

	"github.com/flamingo-stack/openframe-cli/internal/cluster/ui"
)

func main() {
	displayService := ui.NewDisplayService()

	clusters := []ui.ClusterDisplayInfo{
		{
			Name:      "local-dev",
			Type:      "k3d",
			Source:    "local",
			Status:    "running",
			NodeCount: 3,
			CreatedAt: time.Now(),
		},
		{
			Name:      "prod-cluster",
			Type:      "gke",
			Source:    "openframe",
			Context:   "gke_project_us-central1_prod",
			Project:   "my-gcp-project",
			Status:    "running",
			NodeCount: 5,
			CreatedAt: time.Now().Add(-48 * time.Hour),
		},
	}

	displayService.ShowClusterList(clusters, os.Stdout)
}
```

This prints a table with cloud-specific columns (`SOURCE`, `CONTEXT`, `PROJECT`) since at least one cluster is non-local; a purely local list would omit these columns.
