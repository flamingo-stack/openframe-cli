Handles cluster and node UI display operations for the CLI, rendering formatted tables of cluster information to a provided writer.

## Key Components

### Types

- **`ClusterDisplayInfo`** — DTO carrying cluster metadata (name, type, status, node count, creation time, and associated nodes) for rendering
- **`NodeDisplayInfo`** — DTO for individual node display data (name, role, status)

### Service

- **`DisplayService`** — Stateless presentation service that separates UI rendering from business logic
- **`NewDisplayService()`** — Constructor returning a new `*DisplayService`

### Methods

- **`ShowClusterList(clusters []ClusterDisplayInfo, out io.Writer)`** — Renders a formatted table of clusters to any `io.Writer`; falls back to manual `fmt.Fprintf` alignment if `pterm` rendering fails; uses `sharedUI.GetStatusColor` to colorize the status column

## Usage Example

```go
svc := ui.NewDisplayService()

clusters := []ui.ClusterDisplayInfo{
    {
        Name:      "prod-cluster",
        Type:      "k3s",
        Status:    "running",
        NodeCount: 3,
        CreatedAt: time.Now(),
    },
}

// Render to stdout
svc.ShowClusterList(clusters, os.Stdout)

// Render to a buffer for testing
var buf bytes.Buffer
svc.ShowClusterList(clusters, &buf)
```

## Notes

- The service is intentionally stateless — no configuration is stored on the struct
- Color codes are stripped via `pterm.RemoveColorFromString` in the fallback path to preserve column alignment
