## Overview

This file implements the presentation layer for cluster listing operations in the OpenFrame CLI. It defines display data structures (`ClusterDisplayInfo`, `NodeDisplayInfo`) and a `DisplayService` responsible for rendering cluster information as formatted tables, keeping UI rendering logic separate from business logic.

## Key Components

- **`ClusterDisplayInfo`** — Struct holding display-ready cluster metadata: name, type, source (local/openframe/external), kubeconfig context, GCP project, status, node count, creation time, and associated nodes.
- **`NodeDisplayInfo`** — Struct representing a single node's name, role, and status for display purposes.
- **`DisplayService`** — Stateless service struct dedicated to rendering cluster UI output.
- **`NewDisplayService()`** — Constructor that returns a new `DisplayService` instance.
- **`(*DisplayService).ShowClusterList(clusters []ClusterDisplayInfo, out io.Writer)`** — Renders a list of clusters as a table. Dynamically adjusts columns (adding SOURCE, CONTEXT, PROJECT) when any cluster originates from a cloud source. Falls back to manual formatted output if `pterm` table rendering fails, and prints a friendly message when the list is empty.

## Usage Example

```go
package main

import (
	"os"
	"time"

	"github.com/flamingo-stack/openframe-cli/internal/cluster/ui"
)

func main() {
	displayService := ui.NewDisplayService()

	clusters := []ui.ClusterDisplayInfo{
		{
			Name:      "dev-cluster",
			Type:      "kind",
			Source:    "local",
			Status:    "Running",
			NodeCount: 3,
			CreatedAt: time.Now(),
		},
		{
			Name:      "prod-cluster",
			Type:      "gke",
			Source:    "openframe",
			Context:   "gke_project_us-central1_prod",
			Project:   "my-gcp-project",
			Status:    "Running",
			NodeCount: 5,
			CreatedAt: time.Now(),
		},
	}

	displayService.ShowClusterList(clusters, os.Stdout)
}
```

This produces a formatted table listing clusters, automatically including cloud-specific columns (SOURCE, CONTEXT, PROJECT) since one of the clusters has a non-local source.
