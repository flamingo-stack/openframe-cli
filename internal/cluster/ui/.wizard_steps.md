## Overview

`wizard_steps.go` implements the individual interactive prompt steps used by the cluster creation wizard. It handles user input collection for cluster name, type, cloud provider details (GCP/AWS), node sizing, Kubernetes version, and a final configuration confirmation summary, with graceful fallback to free-text input when interactive discovery (via `gcloud`/`aws` CLIs) is unavailable or non-interactive mode is active.

## Key Components

- **`WizardSteps`** - Struct grouping all wizard step methods; instantiated via `NewWizardSteps()`.
- **`PromptClusterName(defaultName string)`** - Prompts for and validates a cluster name against domain rules.
- **`PromptClusterType()`** - Presents a selection menu for `k3d`, `gke`, or `eks` cluster types.
- **`PromptProject()`** - Prompts for a GCP project ID, offering an interactive picker (via `discovery.NewGKEDiscoverer`) with manual-entry fallback.
- **`PromptProfile()`** - Prompts for an AWS profile, offering a picker (via `discovery.NewEKSDiscoverer`) with default-credentials and manual-entry options.
- **`PromptAWSRegion(label, defaultRegion, profile string)`** - Prompts for an AWS region, listing account-enabled regions when possible.
- **`PromptRegion(label, defaultRegion, project string)`** - Prompts for a GCP Compute region scoped to a project.
- **`PromptMachineType(defaultType string)`** - Prompts for the node instance type.
- **`PromptNodeCount(defaultCount int)`** - Prompts for worker node count, validated within range 1-10.
- **`PromptK8sVersion()`** - Selects a Kubernetes version from a predefined list.
- **`ConfirmConfiguration(config models.ClusterConfig)`** - Renders a summary table of chosen settings and asks for final confirmation.
- Package-level vars `listSelectableProjects`, `listSelectableProfiles`, `listSelectableAWSRegions`, `listSelectableRegions` - injectable discovery functions used for testing without real cloud CLIs.

## Usage Example

```go
steps := ui.NewWizardSteps()

name, err := steps.PromptClusterName("my-cluster")
if err != nil {
    return err
}

clusterType, err := steps.PromptClusterType()
if err != nil {
    return err
}

nodeCount, err := steps.PromptNodeCount(3)
if err != nil {
    return err
}

confirmed, err := steps.ConfirmConfiguration(config)
if err != nil {
    return err
}
if !confirmed {
    // user chose to go back and modify configuration
}
```
