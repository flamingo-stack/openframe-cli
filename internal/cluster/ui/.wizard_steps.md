Interactive wizard step implementations for the cluster creation TUI, providing prompted input collection for cluster name, type, node count, Kubernetes version, and configuration confirmation.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `WizardSteps` | struct | Handler containing all individual wizard step methods |
| `NewWizardSteps()` | constructor | Instantiates a new `WizardSteps` handler |
| `PromptClusterName()` | method | Prompts for a cluster name with non-empty and domain-rule validation |
| `PromptClusterType()` | method | Select menu for cluster type (`k3d` or `gke`) returning a `models.ClusterType` |
| `PromptNodeCount()` | method | Prompts for worker node count, validated in range 1–10 |
| `PromptK8sVersion()` | method | Select menu for Kubernetes version (`latest`, `v1.31.5-k3s1`, `v1.30.9-k3s1`) |
| `ConfirmConfiguration()` | method | Renders a pterm config summary table and prompts for final confirmation |
| `renderConfigurationTable()` | internal func | Renders a `pterm` table with header; falls back to plain `println` on error |

## Usage Example

```go
steps := ui.NewWizardSteps()

name, err := steps.PromptClusterName("my-cluster")
if err != nil {
    log.Fatal(err)
}

clusterType, err := steps.PromptClusterType()
if err != nil {
    log.Fatal(err)
}

nodeCount, err := steps.PromptNodeCount(3)
if err != nil {
    log.Fatal(err)
}

k8sVersion, err := steps.PromptK8sVersion()
if err != nil {
    log.Fatal(err)
}

config := models.ClusterConfig{
    Name:       name,
    Type:       clusterType,
    NodeCount:  nodeCount,
    K8sVersion: k8sVersion,
}

confirmed, err := steps.ConfirmConfiguration(config)
if err != nil {
    log.Fatal(err)
}

if confirmed {
    // Proceed with cluster creation
}
```

## Notes

- Cluster name validation delegates to both `sharedUI.ValidateNonEmpty` and `models.ValidateClusterName` for combined emptiness and domain-rule checks.
- `ConfirmConfiguration` gracefully falls back to plain output if pterm table rendering fails.
