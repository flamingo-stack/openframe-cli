## wizard_steps.go

Implements the individual interactive prompts used by the cluster creation wizard, including cloud-provider-aware pickers (GCP projects/regions, AWS profiles/regions) with graceful fallback to free-text input when non-interactive or discovery fails.

## Key Components

- **`WizardSteps`** — struct grouping all wizard step methods; created via `NewWizardSteps()`.
- **`PromptClusterName(defaultName string)`** — prompts for and validates a cluster name.
- **`PromptClusterType()`** — selects between k3d, GKE, and EKS cluster types.
- **`PromptProject()`** — picks a GCP project from a discovered list, or falls back to manual entry.
- **`PromptProfile()`** — picks an AWS profile (or default credential chain), or falls back to manual entry.
- **`PromptAWSRegion(label, defaultRegion, profile string)`** — picks an AWS region for the given profile, or falls back to manual entry.
- **`PromptRegion(label, defaultRegion, project string)`** — picks a GCP Compute region for the given project, or falls back to manual entry.
- **`PromptMachineType(defaultType string)`** — prompts for the node instance type.
- **`PromptNodeCount(defaultCount int)`** — prompts for worker node count (1–10).
- **`PromptK8sVersion()`** — selects a Kubernetes version from a fixed list.
- **`ConfirmConfiguration(config models.ClusterConfig)`** — renders a summary table of the chosen configuration and asks for final confirmation.
- **`renderConfigurationTable(data [][]string)`** — helper that renders the summary using `pterm`, with a plain-text fallback.
- Package-level discovery hooks (`listSelectableProjects`, `listSelectableProfiles`, `listSelectableAWSRegions`, `listSelectableRegions`) — overridable vars enabling test injection without invoking real `gcloud`/`aws` CLIs.

## Usage Example

```go
steps := ui.NewWizardSteps()

name, err := steps.PromptClusterName("my-cluster")
if err != nil {
    return err
}

clusterType, err := steps.PromptClusterType()
if err != nil {
    return err
}

if clusterType == models.ClusterTypeGKE {
    project, err := steps.PromptProject()
    if err != nil {
        return err
    }
    region, err := steps.PromptRegion("Region", "us-central1", project)
    if err != nil {
        return err
    }
    _ = region
}

confirmed, err := steps.ConfirmConfiguration(config)
if err != nil {
    return err
}
if !confirmed {
    // return to previous wizard step
}
```
