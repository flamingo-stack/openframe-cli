## wizard_steps.go

Implements the individual interactive prompt steps used by the cluster-creation wizard, including cluster naming, cluster type/provider selection, cloud-specific resource discovery (GCP projects/regions, AWS profiles/regions), sizing options, and a final configuration confirmation screen.

## Key Components

- **`WizardSteps`** — struct grouping all wizard step methods; created via `NewWizardSteps()`.
- **`PromptClusterName(defaultName string)`** — prompts for and validates a cluster name (non-empty + domain rules).
- **`PromptClusterType()`** — lets the user choose between `k3d`, `gke`, and `eks` cluster types.
- **`PromptProject()`** — interactively picks a GCP project (via `discovery.GKEDiscoverer`) with manual-entry fallback, or free-text input when non-interactive/unavailable.
- **`PromptProfile()`** — interactively picks an AWS profile (via `discovery.EKSDiscoverer`), with "default credentials" and manual-entry options.
- **`PromptAWSRegion(label, defaultRegion, profile string)`** — picks an AWS region for a given profile, with manual fallback.
- **`PromptRegion(label, defaultRegion, project string)`** — picks a GCP Compute region for a given project, with manual fallback.
- **`PromptMachineType(defaultType string)`** — prompts for node instance type.
- **`PromptNodeCount(defaultCount int)`** — prompts for worker node count (validated range 1–10).
- **`PromptK8sVersion()`** — selects a Kubernetes version from a preset list.
- **`ConfirmConfiguration(config models.ClusterConfig)`** — renders a summary table of the chosen configuration (with cost/spot hints for cloud clusters) and asks for final confirmation.
- **`renderConfigurationTable(data [][]string)`** — helper that renders the summary table using `pterm`.

Package-level vars (`listSelectableProjects`, `listSelectableProfiles`, `listSelectableAWSRegions`, `listSelectableRegions`) wrap discovery calls and are swappable in tests to avoid invoking real `gcloud`/`aws` CLIs.

## Usage Example

```go
steps := ui.NewWizardSteps()

name, err := steps.PromptClusterName("my-cluster")
if err != nil {
    return err
}

clusterType, err := steps.PromptClusterType()
if err != nil {
    return err
}

if clusterType == models.ClusterTypeGKE {
    project, err := steps.PromptProject()
    if err != nil {
        return err
    }
    region, err := steps.PromptRegion("GCP Region", "us-central1", project)
    if err != nil {
        return err
    }
    _ = region
}

confirmed, err := steps.ConfirmConfiguration(config)
if err != nil {
    return err
}
if !confirmed {
    // return to wizard to edit configuration
}
```
