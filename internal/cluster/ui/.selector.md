Provides cluster selection logic for CLI commands, supporting both argument-based and interactive selection via a reusable `Selector` type.

## Key Components

- **`Selector`** — Struct that encapsulates selection behavior scoped to a named operation (e.g., `"delete"`, `"connect"`).
- **`NewSelector(operation string) *Selector`** — Constructor that binds a human-readable operation label to the selector.
- **`SelectCluster(clusters []models.ClusterInfo, args []string) (string, error)`** — Core method; validates a provided cluster name from `args` against known clusters, or falls back to an interactive list prompt via `sharedUI.SelectFromList`.
- **`showNoClusterMessage()`** — Prints an error when no clusters exist, guiding the user to `openframe cluster create`.
- **`showOperationCancelled()`** — Prints an info message when the user exits the interactive prompt without selecting.
- **`capitalizeFirst(s string) string`** — Utility that upper-cases the first rune of the operation label for display purposes.

## Usage Example

```go
// Argument-based selection (e.g., openframe cluster delete my-cluster)
sel := ui.NewSelector("delete")
name, err := sel.SelectCluster(clusters, []string{"my-cluster"})

// Interactive selection (e.g., openframe cluster delete — no args)
sel := ui.NewSelector("delete")
name, err := sel.SelectCluster(clusters, []string{})
if err != nil {
    log.Fatal(err)
}
if name == "" {
    return // user cancelled or no clusters available
}
// proceed with name
```
