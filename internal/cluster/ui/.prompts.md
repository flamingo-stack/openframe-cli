## prompts.go

Provides interactive CLI prompts and formatting helpers for cluster selection, cost warnings, and destructive-action confirmations in the `ui` package.

## Key Components

- **`ClusterType`, `ClusterInfo`** - Type aliases re-exporting `models.ClusterType` and `models.ClusterInfo` to avoid duplicate definitions.
- **`ClusterTypeK3d`** - Re-exported constant from `models` for UI convenience.
- **`SelectClusterByName(clusters []ClusterInfo, prompt string) (string, error)`** - Presents an interactive picker over a pre-fetched cluster list and returns the selected cluster's name. Business logic (fetching clusters) is kept out of the UI layer.
- **`clusterPickerRows(clusters []ClusterInfo) []string`** - Formats aligned, multi-column rows (name, type, location, status) for the cluster picker.
- **`CostHint(clusterType models.ClusterType) string`** - Returns a cost warning message for cloud cluster types (EKS, GKE), linking to the provider's pricing page instead of hardcoding figures.
- **`NodesLine(config models.ClusterConfig) string`** - Renders the node count, expanding regional (HA) clusters into a "per zone × zones = total" breakdown to avoid underestimating actual node count.
- **`SpotHint(config models.ClusterConfig) string`** - Suggests using `--spot` for cost savings on cloud test clusters; returns an empty string when spot is already enabled or type is non-cloud.
- **`ConfirmTypedClusterName(name string) (bool, error)`** - Forces the user to type the exact cluster name before destroying a cloud cluster, as a stronger safeguard than a yes/no prompt.

## Usage Example

```go
package main

import (
	"fmt"

	"github.com/flamingo-stack/openframe-cli/internal/cluster/models"
	"github.com/flamingo-stack/openframe-cli/internal/cluster/ui"
)

func main() {
	clusters := []ui.ClusterInfo{
		{Name: "dev-cluster", Type: ui.ClusterTypeK3d, Status: "Running"},
	}

	name, err := ui.SelectClusterByName(clusters, "Select a cluster to destroy")
	if err != nil {
		panic(err)
	}

	confirmed, err := ui.ConfirmTypedClusterName(name)
	if err != nil {
		panic(err)
	}
	if !confirmed {
		fmt.Println("Deletion cancelled")
		return
	}

	fmt.Println("Proceeding with deletion of", name)
}
```
