Provides interactive cluster selection UI prompts by wrapping shared UI utilities and domain model types for the cluster package.

## Key Components

| Element | Description |
|---|---|
| `ClusterType` / `ClusterInfo` | Type aliases re-exported from `models` package for UI convenience |
| `ClusterTypeK3d` / `ClusterTypeGKE` | Re-exported cluster type constants |
| `SelectClusterByName` | Interactive prompt to select a cluster by name from a pre-fetched list |
| `selectFromList` | Internal helper delegating to `sharedUI.SelectFromList` |

## Usage Example

```go
// Fetch clusters from business logic layer, then pass to UI
clusters := []models.ClusterInfo{
    {Name: "dev-cluster"},
    {Name: "staging-cluster"},
}

selected, err := ui.SelectClusterByName(clusters, "Select a cluster:")
if err != nil {
    log.Fatal(err)
}

fmt.Printf("You selected: %s\n", selected)
```

## Notes

- UI layer is intentionally decoupled from business logic — clusters are passed in as a plain slice rather than injecting a manager interface
- Returns an empty string (no error) when the cluster list is empty, displaying a `pterm` warning instead
- Delegates list rendering and keyboard navigation to [`sharedUI.SelectFromList`](https://github.com/flamingo-stack/openframe-cli/blob/main/internal/shared/ui)
