## prompts.go

Provides interactive UI prompts and helper text for cluster selection and lifecycle operations (create/destroy) within the `ui` package, bridging domain models to terminal-based user interaction without embedding business logic.

## Key Components

- **`ClusterType` / `ClusterInfo`** — Type aliases re-exporting `models.ClusterType` and `models.ClusterInfo` for UI convenience.
- **`ClusterTypeK3d`** — Re-exported constant from the domain models package.
- **`SelectClusterByName(clusters []ClusterInfo, prompt string) (string, error)`** — Presents an interactive picker for choosing a cluster by name from a pre-fetched list.
- **`clusterPickerRows(clusters []ClusterInfo) []string`** — Formats aligned, multi-column rows (name, type, location, status) for the cluster picker.
- **`selectFromList(prompt string, items []string) (int, string, error)`** — Thin wrapper around the shared UI list selector.
- **`CostHint(clusterType models.ClusterType) string`** — Returns a cost warning message (with a link to provider pricing) for cloud cluster types, without hardcoding prices.
- **`NodesLine(config models.ClusterConfig) string`** — Renders node count, correctly accounting for regional (HA) clusters that provision nodes per zone.
- **`SpotHint(config models.ClusterConfig) string`** — Suggests using `--spot` for eligible cloud cluster types when spot capacity isn't already enabled.
- **`ConfirmTypedClusterName(name string) (bool, error)`** — Forces the user to type the exact cluster name to confirm a destructive cloud cluster deletion.

## Usage Example

```go
package main

import (
	"fmt"

	"github.com/flamingo-stack/openframe-cli/internal/cluster/models"
	"github.com/flamingo-stack/openframe-cli/internal/cluster/ui"
)

func main() {
	clusters := []ui.ClusterInfo{
		{Name: "dev-cluster", Type: ui.ClusterTypeK3d, Status: "running"},
	}

	name, err := ui.SelectClusterByName(clusters, "Select a cluster")
	if err != nil {
		panic(err)
	}
	fmt.Println("Selected:", name)

	config := models.ClusterConfig{Type: models.ClusterTypeGKE, NodeCount: 3}
	fmt.Println(ui.CostHint(config.Type))
	fmt.Println(ui.NodesLine(config))

	confirmed, err := ui.ConfirmTypedClusterName(name)
	if err != nil {
		panic(err)
	}
	fmt.Println("Confirmed:", confirmed)
}
```
