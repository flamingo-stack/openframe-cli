## Overview

`prompts.go` provides interactive UI helpers for cluster selection and confirmation prompts in the `ui` package. It bridges cluster domain models with terminal prompts (via `pterm` and shared UI utilities), keeping presentation logic separate from business logic by accepting pre-fetched data as parameters rather than manager interfaces.

## Key Components

- **`ClusterType` / `ClusterInfo`** – Type aliases re-exporting domain models for UI convenience.
- **`ClusterTypeK3d`** – Re-exported constant from `models`.
- **`SelectClusterByName(clusters []ClusterInfo, prompt string) (string, error)`** – Presents an interactive list of clusters and returns the selected cluster's name.
- **`clusterPickerRows(clusters []ClusterInfo) []string`** – Formats aligned, multi-column rows (name, type, location, status) for the selection list.
- **`selectFromList(prompt string, items []string) (int, string, error)`** – Thin wrapper around the shared selection prompt.
- **`CostHint(clusterType models.ClusterType) string`** – Returns a provider-specific cost warning (with a link to official pricing) for cloud cluster types, avoiding hardcoded prices.
- **`NodesLine(config models.ClusterConfig) string`** – Renders node count text, correctly expanding regional (HA) clusters into "per zone × zones = total" to avoid underestimating actual node counts.
- **`SpotHint(config models.ClusterConfig) string`** – Suggests using `--spot` for EKS/GKE test clusters when spot capacity isn't already enabled.
- **`ConfirmTypedClusterName(name string) (bool, error)`** – Forces the user to type the exact cluster name to confirm a destructive cloud destroy operation.

## Usage Example

```go
clusters := []models.ClusterInfo{
    {Name: "prod-cluster", Type: models.ClusterTypeGKE, Region: "us-central1", Status: "running"},
    {Name: "dev-cluster", Type: models.ClusterTypeK3d, Status: "running"},
}

selectedName, err := ui.SelectClusterByName(clusters, "Select a cluster to manage")
if err != nil {
    log.Fatal(err)
}

// Show cost warning before creating a cloud cluster
fmt.Println(ui.CostHint(models.ClusterTypeGKE))

// Confirm destructive action
confirmed, err := ui.ConfirmTypedClusterName(selectedName)
if err != nil || !confirmed {
    fmt.Println("Aborted")
    return
}
```
