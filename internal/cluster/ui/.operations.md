## operations.go

Provides a user-facing UI layer for cluster lifecycle operations (select, delete, cleanup, status reporting) in the OpenFrame CLI, bridging raw cluster models with interactive prompts, confirmations, and formatted terminal output via `pterm`.

## Key Components

- **`OperationsUI`** — struct exposing operation-related UI methods; instantiated via `NewOperationsUI()`.
- **`SelectClusterForOperation`** — resolves a target cluster from CLI args or interactive selection for a generic operation.
- **`SelectClusterForDelete`** — resolves a cluster to delete, validating existence and prompting for confirmation unless `--force` is set.
- **`SelectClusterForCleanup`** — resolves a cluster for cleanup, with the same confirm/force semantics as delete.
- **`confirmDeletion` / `confirmCleanup`** — internal helpers wrapping `sharedUI` confirmation prompts; fail fast in non-interactive sessions with a `--force` hint.
- **`ShowOperationStart`** — prints a status message when an operation begins.
- **`ShowCleanupSummary`** — reports actual cleanup results (nodes pruned, partial failures) rather than a fixed success message.
- **`ShowOperationSuccess`** — prints a detailed success box, tailoring resource/status wording per `models.ClusterType` (k3d vs. cloud/terraform-managed).
- **`ShowOperationError`** — displays a friendly error with troubleshooting command suggestions.
- **`ShowConfigurationSummary`** — prints cluster config details (name, type, nodes, version, cloud project).

## Usage Example

```go
ui := ui.NewOperationsUI()

// Resolve cluster to delete, honoring --force
clusterName, err := ui.SelectClusterForDelete(clusters, args, force)
if err != nil {
    ui.ShowOperationError("delete", clusterName, err)
    return err
}
if clusterName == "" {
    return nil // cancelled or no clusters available
}

ui.ShowOperationStart("delete", clusterName)
// ... perform deletion ...
ui.ShowOperationSuccess("delete", clusterName, models.ClusterTypeK3d)
```

All output methods respect `--silent` mode by using `pterm.DefaultBasicText` instead of raw `fmt` printing, ensuring consistent CLI output behavior across commands.
