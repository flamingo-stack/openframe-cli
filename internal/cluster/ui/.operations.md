## operations.go

Provides the `OperationsUI` service, a user-facing layer for cluster lifecycle commands (select, delete, cleanup) that handles argument parsing, interactive selection, confirmation prompts, and formatted success/error/summary output for the CLI.

## Key Components

- **`OperationsUI`** — struct exposing UI helpers for cluster operations; created via `NewOperationsUI()`.
- **`SelectClusterForOperation`** — resolves a target cluster from CLI args or interactive prompt for generic operations.
- **`SelectClusterForDelete`** — resolves a cluster for deletion, validates existence (unless `force`), and confirms via `confirmDeletion` unless forced.
- **`SelectClusterForCleanup`** — resolves a cluster for cleanup, validates existence, and confirms via `confirmCleanup` unless forced.
- **`confirmDeletion` / `confirmCleanup`** — private helpers wrapping `sharedUI` confirmation prompts; fail fast with a `--force` hint in non-interactive sessions.
- **`ShowOperationStart`** — prints an operation-in-progress message tailored to `cleanup`, `delete`, or other operations.
- **`ShowCleanupSummary`** — reports actual cleanup results (`models.CleanupResult`), including partial failures and remediation hints, avoiding hardcoded "success" claims.
- **`ShowOperationSuccess`** — prints a detailed success box; tailors the `RESOURCES`/`TYPE` fields to the actual `models.ClusterType` (k3d vs. cloud/terraform-backed).
- **`ShowOperationError`** — prints a formatted error with contextual troubleshooting tips (`openframe cluster list`, `status`, `--verbose`).
- **`ShowConfigurationSummary`** — prints cluster configuration details (name, type, nodes, version, cloud project) using `DefaultBasicText` to respect `--silent` mode.

## Usage Example

```go
ui := ui.NewOperationsUI()

// Resolve cluster to delete from args or interactive prompt
name, err := ui.SelectClusterForDelete(clusters, args, force)
if err != nil {
    ui.ShowOperationError("delete", name, err)
    return err
}
if name == "" {
    return nil // cancelled
}

ui.ShowOperationStart("delete", name)
// ... perform deletion ...
ui.ShowOperationSuccess("delete", name, models.ClusterTypeK3d)
```
