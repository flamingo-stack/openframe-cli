Provides user-friendly terminal UI methods for cluster lifecycle operations (select, delete, cleanup, create) within the OpenFrame CLI, wrapping interactive prompts, confirmation dialogs, and formatted output.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `OperationsUI` | struct | Stateless UI service for cluster operation interactions |
| `NewOperationsUI` | constructor | Instantiates an `OperationsUI` |
| `SelectClusterForOperation` | method | Resolves a cluster name from CLI args or interactive selection for a given operation |
| `SelectClusterForDelete` | method | Resolves cluster name with optional existence validation, confirmation prompt, and `--force` bypass |
| `SelectClusterForCleanup` | method | Same as delete flow but for cleanup; confirmation skipped when `--force` is set |
| `ShowOperationStart` | method | Prints a contextual start message for `cleanup`, `delete`, or generic operations |
| `ShowCleanupSummary` | method | Renders a detailed cleanup result — items removed, partial failures, and remediation hints |
| `ShowOperationSuccess` | method | Renders a rich success box (delete) or generic success line |
| `ShowOperationError` | method | Displays a formatted error with troubleshooting commands |
| `ShowConfigurationSummary` | method | Prints cluster config (name, type, nodes, version) with dry-run/skip-wizard annotations |
| `ShowNoResourcesMessage` | method | Friendly prompt when no clusters exist, pointing to `create` and `list` commands |

## Usage Example

```go
ops := ui.NewOperationsUI()

// Resolve cluster from args or interactive picker
name, err := ops.SelectClusterForDelete(clusters, args, false)
if err != nil || name == "" {
    return err // cancelled or not found
}

ops.ShowOperationStart("delete", name)

if err := doDelete(name); err != nil {
    ops.ShowOperationError("delete", name, err)
    return err
}

ops.ShowOperationSuccess("delete", name)
```

## Notes

- All output uses `pterm` primitives (`pterm.DefaultBasicText`, not `fmt.Println`) so `--silent` mode correctly suppresses non-error output.
- `SelectClusterForDelete` skips existence validation when `force=true` to support fallback cleanup when `k3d list` is unavailable.
- `confirmDeletion` fails fast in non-interactive sessions with a `--force` hint rather than blocking.
