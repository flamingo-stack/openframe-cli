## operations.go

Provides user-facing UI orchestration for cluster lifecycle operations (select, delete, cleanup) in the OpenFrame CLI, wrapping confirmation prompts, progress messages, and result summaries with `pterm`-based console output.

## Key Components

- **`OperationsUI`** — struct exposing cluster-operation UI helpers; instantiated via `NewOperationsUI()`.
- **`SelectClusterForOperation(clusters, args, operation)`** — resolves a cluster name from CLI args or interactive prompt, validating existence.
- **`SelectClusterForDelete(clusters, args, force)`** — resolves cluster for deletion, skipping validation on `force` (for fallback cleanup) and requiring confirmation unless forced.
- **`SelectClusterForCleanup(clusters, args, force)`** — resolves cluster for cleanup with confirmation semantics matching `--force`.
- **`confirmDeletion` / `confirmCleanup`** — internal helpers wrapping `sharedUI.ConfirmDeletion` / `sharedUI.RequireConfirmation`, failing fast in non-interactive sessions with a `--force` hint.
- **`ShowOperationStart(operation, clusterName)`** — prints a status message when an operation begins.
- **`ShowCleanupSummary(clusterName, result)`** — reports actual cleanup results (pruned images, partial failures) rather than a static success message.
- **`ShowOperationSuccess(operation, clusterName, clusterType)`** — prints a detailed success box; tailors the "RESOURCES" claim based on `models.ClusterType` (k3d vs. cloud/terraform).
- **`ShowOperationError(operation, clusterName, err)`** — prints a friendly error with troubleshooting command suggestions.
- **`ShowConfigurationSummary(config, dryRun, skipWizard)`** — prints cluster configuration details (name, type, nodes, version, cloud project) prior to creation.

## Usage Example

```go
ui := ui.NewOperationsUI()

clusterName, err := ui.SelectClusterForDelete(clusters, args, force)
if err != nil {
    ui.ShowOperationError("delete", clusterName, err)
    return err
}
if clusterName == "" {
    return nil // cancelled by user
}

ui.ShowOperationStart("delete", clusterName)
// ... perform deletion ...
ui.ShowOperationSuccess("delete", clusterName, models.ClusterTypeK3d)
```

**Note:** All output uses `pterm.DefaultBasicText` (not raw `fmt`/`pterm.Printf`) so that informational output correctly honors `--silent` mode, which is documented as "errors only."
