## Overview

`service.go` implements `ClusterService`, the business-logic layer for cluster lifecycle operations (create, delete, list, status, cleanup) across supported providers (k3d, EKS, GKE). It coordinates provider selection, UI feedback (spinners, status boxes), and safe reuse/resume semantics for existing clusters.

## Key Components

- **`ClusterService`** — struct wrapping a `provider.Provider` (k3d default), a `CommandExecutor`, and a `suppressUI` flag for automation-friendly output.
- **`NewClusterService` / `NewClusterServiceSuppressed`** — constructors; the latter disables interactive UI (spinners, hints) for scripted/automated use.
- **`bootstrapNodeCount`** — constant (4) documenting the intentional node-count difference between `bootstrap` and `cluster create`.
- **`providerFor(clusterType)`** — resolves the correct provider backend; defaults to the k3d manager, otherwise builds via `provider.New`.
- **`shouldResumeCloudCreate`** — determines if an existing cloud cluster record represents an interrupted create that should be resumed (vs. reused).
- **`CreateCluster`** — creates or reuses/resumes a cluster, returning a `*rest.Config`. Handles existing-cluster detection, UI feedback, and post-creation status verification.
- **`DeleteCluster`** — deletes a cluster with progress feedback, skipping spinners for cloud providers (which stream terraform output).
- **`ListClusters`** — merges local k3d clusters with cloud clusters from the workspace registry; tolerant of provider failures (e.g., Docker not running).
- **`GetClusterStatus` / `GetRestConfig` / `DetectClusterType`** — query cloud providers first, then fall back to k3d.
- **`CleanupCluster`** — reclaims disk space only (does not tear down platform resources like ArgoCD apps or Helm releases); returns a `models.CleanupResult` with partial-failure reporting.
- **`cloudProviders()`** — best-effort constructor for EKS/GKE provider instances, skipping any that fail to initialize.

## Usage Example

```go
exec := executor.NewCommandExecutor()
svc := cluster.NewClusterService(exec)

config := models.ClusterConfig{
    Name: "my-cluster",
    Type: models.ClusterTypeK3d,
}

restConfig, err := svc.CreateCluster(context.Background(), config)
if err != nil {
    log.Fatalf("failed to create cluster: %v", err)
}

// List all clusters (local + cloud)
clusters, err := svc.ListClusters()
if err != nil {
    log.Fatalf("failed to list clusters: %v", err)
}

// Delete a cluster
if err := svc.DeleteCluster(context.Background(), "my-cluster", models.ClusterTypeK3d, false); err != nil {
    log.Fatalf("failed to delete cluster: %v", err)
}
```
