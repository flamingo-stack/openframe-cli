## Overview

`service.go` implements `ClusterService`, the business-logic layer for Kubernetes cluster lifecycle management (create, delete, list, status, cleanup). It coordinates between cluster providers (k3d, EKS, GKE), the executor, and terminal UI (spinners, status boxes), while keeping platform-level operations (like app install/uninstall) explicitly out of scope.

## Key Components

- **`ClusterService`** — struct holding the cluster provider manager, command executor, and a `suppressUI` flag for non-interactive/automation contexts.
- **`NewClusterService` / `NewClusterServiceSuppressed`** — constructors that default to a k3d-backed service, with or without interactive UI output.
- **`providerFor(clusterType)`** — resolves the correct `provider.Provider` backend (k3d vs. cloud) for a given cluster type.
- **`CreateCluster`** — creates a cluster (or reuses/resumes an existing one based on registry status), returning a `*rest.Config` for API access. Displays a spinner (k3d only) and post-creation summary.
- **`DeleteCluster`** — deletes a cluster with progress feedback, respecting the `force` flag.
- **`ListClusters`** — merges local k3d clusters with cloud clusters from the workspace registry; tolerates partial failures (e.g., Docker not running) without hiding other results.
- **`GetClusterStatus` / `GetRestConfig` / `DetectClusterType`** — lookup helpers that check cloud providers first, then fall back to k3d.
- **`CleanupCluster`** — reclaims disk space only (does not tear down platform/app resources — that's `app uninstall`'s responsibility).
- **`shouldResumeCloudCreate`** — determines whether an existing registry entry should be reused or resumed based on cloud cluster status.
- **`bootstrapNodeCount`** — constant (4) documenting the intentional node-count difference between `bootstrap` and `cluster create`.

## Usage Example

```go
import (
	"context"

	"github.com/flamingo-stack/openframe-cli/internal/cluster/models"
	"github.com/flamingo-stack/openframe-cli/internal/shared/executor"
)

func main() {
	exec := executor.NewRealCommandExecutor()
	svc := NewClusterService(exec)

	cfg := models.ClusterConfig{
		Name: "my-cluster",
		Type: models.ClusterTypeK3d,
	}

	restConfig, err := svc.CreateCluster(context.Background(), cfg)
	if err != nil {
		panic(err)
	}

	// Use restConfig to build a Kubernetes clientset
	_ = restConfig

	// List all clusters (local + cloud)
	clusters, _ := svc.ListClusters()
	for _, c := range clusters {
		println(c.Name, string(c.Type), c.Status)
	}
}
```
