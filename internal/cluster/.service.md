## Overview

`service.go` implements `ClusterService`, the business-logic layer for managing OpenFrame Kubernetes clusters. It orchestrates cluster lifecycle operations (create, delete, list, status, cleanup) across local k3d and cloud providers (EKS, GKE), handling UI presentation, spinner feedback, and provider resolution.

## Key Components

- **`ClusterService`** — struct wrapping a `provider.Provider` (k3d manager), a `CommandExecutor`, and a `suppressUI` flag for automation-friendly output.
- **`NewClusterService(exec)`** / **`NewClusterServiceSuppressed(exec)`** — constructors for interactive vs. suppressed (non-interactive/automation) modes.
- **`CreateCluster(ctx, config)`** — creates a cluster, reusing an existing one if healthy, or resuming an interrupted cloud creation via `shouldResumeCloudCreate`. Returns a `*rest.Config` for cluster access.
- **`DeleteCluster(ctx, name, clusterType, force)`** — deletes a cluster with progress feedback (spinner for k3d, streamed logs for cloud).
- **`ListClusters()`** — merges local k3d clusters with cloud clusters from the workspace registry; failures in either are non-fatal.
- **`GetClusterStatus(name)`** / **`GetRestConfig(name)`** / **`DetectClusterType(name)`** — lookups that check cloud providers first, then fall back to k3d.
- **`CleanupCluster(ctx, name, clusterType, verbose)`** — reclaims disk space only (does not tear down platform resources like ArgoCD apps or Helm releases).
- **`providerFor(clusterType)`** — resolves the correct `provider.Provider` backend (k3d vs. cloud factory).
- **`bootstrapNodeCount`** — constant (4) used by `openframe bootstrap`, intentionally higher than the default `cluster create` node count (3).

## Usage Example

```go
exec := executor.NewCommandExecutor()
svc := cluster.NewClusterService(exec)

config := models.ClusterConfig{
    Name: "my-cluster",
    Type: models.ClusterTypeK3d,
}

restCfg, err := svc.CreateCluster(context.Background(), config)
if err != nil {
    log.Fatalf("failed to create cluster: %v", err)
}

clusters, err := svc.ListClusters()
if err != nil {
    log.Fatalf("failed to list clusters: %v", err)
}

err = svc.DeleteCluster(context.Background(), "my-cluster", models.ClusterTypeK3d, false)
if err != nil {
    log.Fatalf("failed to delete cluster: %v", err)
}
```
