Orchestrates the full lifecycle of an OpenFrame cluster, including creation, deletion, status checks, and multi-phase cleanup of Helm releases, ArgoCD Applications, Kubernetes namespaces, and container images.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `ApplicationCleaner` | Interface | Deletes ArgoCD Application CRs and strips stuck finalizers during cleanup |
| `ClusterService` | Struct | Central service holding the cluster provider, executor, UI toggle, and optional app cleaner |
| `NewClusterService` | Constructor | Creates a `ClusterService` with default (interactive) UI |
| `NewClusterServiceSuppressed` | Constructor | Creates a `ClusterService` with UI suppressed for automation/CI |
| `WithApplicationCleaner` | Method | Injects an `ApplicationCleaner` for ArgoCD-aware cleanup; chainable |
| `CreateCluster` | Method | Creates a cluster (or returns config if it already exists), with spinner feedback |
| `DeleteCluster` | Method | Deletes a named cluster with progress feedback |
| `CleanupCluster` | Method | Runs ordered multi-phase cleanup: ArgoCD apps → Helm → finalizers → namespaces → images |
| `ListClusters` | Method | Returns all clusters known to the provider |
| `GetClusterStatus` | Method | Returns status info for a named cluster |
| `GetRestConfig` | Method | Returns a `*rest.Config` for direct Kubernetes API access |

## Usage Example

```go
exec := executor.NewDefaultExecutor()

// Standard interactive service
svc := cluster.NewClusterService(exec)

// Inject ArgoCD cleaner (provided by command layer)
svc.WithApplicationCleaner(myCleaner)

// Create a cluster
cfg := models.ClusterConfig{Name: "openframe-dev", Type: models.ClusterTypeK3d}
restConfig, err := svc.CreateCluster(ctx, cfg)

// Run full cleanup
result, err := svc.CleanupCluster(ctx, "openframe-dev", models.ClusterTypeK3d, true, false)
if len(result.Failures) > 0 {
    // Partial cleanup — inspect result.Failures
}
```

## Notes

- Cleanup is **best-effort**: each phase records failures in `CleanupResult` and continues, so a partially installed cluster is always tearable.
- All Helm calls are pinned to the cluster's explicit `--kube-context` to prevent accidental operations on a different (production) cluster.
- UI suppression (`suppressUI: true`) replaces spinners with plain `pterm.Info` lines for safe use in pipelines.
