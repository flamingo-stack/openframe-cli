## GKE Cluster Discovery

Implements read-only discovery of GKE clusters that exist outside the OpenFrame workspace registry (e.g., created via Terraform or other tools). Discovered clusters are surfaced in `cluster list --all` and `cluster status` but are rejected by all mutating commands since they lack a local workspace. Discovery delegates entirely to the `gcloud` CLI via a mockable `CommandExecutor`, storing no credentials itself.

## Key Components

- **`AuthStatus` (type + constants)** — Represents `gcloud` auth state (`Authenticated`, `NotAuthenticated`, `CLIMissing`) so callers can degrade gracefully instead of erroring.
- **`GKEDiscoverer`** — Main struct wrapping an `executor.CommandExecutor` to run `gcloud` commands.
  - `NewGKEDiscoverer(exec)` — Constructor.
  - `AuthStatus(ctx)` — Probes `gcloud auth list` without failing on missing/unauthenticated CLI.
  - `Projects(ctx)` — Returns unique GCP projects from the user's named gcloud configurations.
  - `AllProjects(ctx)` — Returns all GCP projects accessible to the active identity (for wizards/validation).
  - `Regions(ctx, project)` — Lists Compute Engine regions for a project.
  - `ConfigurationForProject(ctx, project)` — Finds the gcloud configuration name pointing at a given project.
  - `Discover(ctx)` — Lists GKE clusters across all configured projects, best-effort per project, returning a `Result`.
- **`Result`** — Holds discovered `[]models.ClusterInfo` plus per-project `Warnings` (e.g., permission errors) without failing the whole operation.
- **Internal helpers** — `configurations`, `kubeconfigContexts`, `matchContext` (maps clusters to kubeconfig contexts via naming conventions), `titleCase`.

## Usage Example

```go
exec := executor.NewRealCommandExecutor()
discoverer := discovery.NewGKEDiscoverer(exec)

ctx := context.Background()

switch discoverer.AuthStatus(ctx) {
case discovery.CLIMissing:
    fmt.Println("gcloud CLI not installed")
case discovery.NotAuthenticated:
    fmt.Println("run 'gcloud auth login'")
case discovery.Authenticated:
    result, err := discoverer.Discover(ctx)
    if err != nil {
        log.Fatal(err)
    }
    for _, c := range result.Clusters {
        fmt.Printf("%s (%s, %s)\n", c.Name, c.Project, c.Region)
    }
    for _, w := range result.Warnings {
        fmt.Println("warning:", w)
    }
}
```
