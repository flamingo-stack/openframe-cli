## gke.go

Implements GKE cluster discovery for clusters that exist outside the openframe workspace registry. Part of the `discovery` package, it queries the `gcloud` CLI (via the shared `CommandExecutor`) to enumerate projects, regions, and GKE clusters, exposing them as read-only entries for `cluster list --all` and `cluster status`. It never stores credentials, relying entirely on the user's existing `gcloud` authentication.

## Key Components

- **`AuthStatus`** — enum (`Authenticated`, `NotAuthenticated`, `CLIMissing`) representing gcloud CLI usability without treating logout as an error.
- **`GKEDiscoverer`** — struct wrapping a `CommandExecutor`; created via `NewGKEDiscoverer(exec)`.
  - `AuthStatus(ctx)` — probes `gcloud auth list` for an active account.
  - `Projects(ctx)` — unique projects named by the user's gcloud configurations.
  - `AllProjects(ctx)` — all projects accessible to the active identity (`gcloud projects list`), used for the create wizard's project picker.
  - `Regions(ctx, project)` — Compute Engine regions available in a project, used for the create wizard's region picker.
  - `ConfigurationForProject(ctx, project)` — finds the gcloud configuration name pointing at a given project.
  - `Discover(ctx)` — lists GKE clusters across all configured projects, best-effort per project, returning a `Result`.
- **`Result`** — holds discovered `models.ClusterInfo` entries plus per-project `Warnings` (e.g., permission errors) so partial failures don't hide successful results.
- **`matchContext`** — maps a discovered cluster to a kubeconfig context using the three conventional naming patterns (plain name, `gke_<project>_<location>_<name>`, `connectgateway_<project>_<location>_<name>`).
- **`kubeconfigContexts`** — reads context names from the user's kubeconfig (respects `$KUBECONFIG`), tolerant of a missing file.

## Usage Example

```go
exec := executor.NewCommandExecutor()
discoverer := discovery.NewGKEDiscoverer(exec)

ctx := context.Background()

switch discoverer.AuthStatus(ctx) {
case discovery.CLIMissing:
	fmt.Println("gcloud CLI not installed")
case discovery.NotAuthenticated:
	fmt.Println("Run 'gcloud auth login' first")
case discovery.Authenticated:
	result, err := discoverer.Discover(ctx)
	if err != nil {
		log.Fatal(err)
	}
	for _, cluster := range result.Clusters {
		fmt.Printf("%s (%s) - %s nodes: %d\n",
			cluster.Name, cluster.Project, cluster.Status, cluster.NodeCount)
	}
	for _, w := range result.Warnings {
		fmt.Println("warning:", w)
	}
}
```
