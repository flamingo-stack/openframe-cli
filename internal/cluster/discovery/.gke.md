## Overview

`gke.go` implements read-only discovery of Google Kubernetes Engine (GKE) clusters that exist outside the openframe workspace registry. It shells out to the `gcloud` CLI (via the shared `CommandExecutor`) to enumerate projects, regions, and clusters, and attempts to correlate each discovered cluster with a matching kubeconfig context. Discovered clusters are always tagged as external and are never mutable by the CLI.

## Key Components

- **`AuthStatus` / `Authenticated`, `NotAuthenticated`, `CLIMissing`** — enum describing the state of the `gcloud` CLI without treating "not logged in" as a hard error.
- **`GKEDiscoverer`** — main struct wrapping an `executor.CommandExecutor` to run `gcloud` commands.
  - **`NewGKEDiscoverer(exec)`** — constructor.
  - **`AuthStatus(ctx)`** — checks whether `gcloud` is installed and authenticated.
  - **`Projects(ctx)`** — unique projects from the user's named gcloud configurations.
  - **`AllProjects(ctx)`** — all projects visible to the active identity (`gcloud projects list`).
  - **`Regions(ctx, project)`** — available Compute Engine regions for a project.
  - **`ConfigurationForProject(ctx, project)`** — finds the gcloud configuration name pointing at a project.
  - **`Discover(ctx)`** — lists GKE clusters across all configured projects, returning a `Result`.
- **`Result`** — holds discovered `models.ClusterInfo` entries plus per-project warning strings (e.g., permission errors) so partial failures don't hide other results.
- **`kubeconfigContexts()` / `matchContext(...)`** — helpers that map discovered clusters to kubeconfig context names using conventional naming patterns (plain, `gke_*`, `connectgateway_*`).

## Usage Example

```go
exec := executor.NewShellExecutor()
discoverer := discovery.NewGKEDiscoverer(exec)

ctx := context.Background()

switch discoverer.AuthStatus(ctx) {
case discovery.CLIMissing:
    fmt.Println("gcloud CLI not installed")
case discovery.NotAuthenticated:
    fmt.Println("run 'gcloud auth login'")
case discovery.Authenticated:
    result, err := discoverer.Discover(ctx)
    if err != nil {
        log.Fatal(err)
    }
    for _, cluster := range result.Clusters {
        fmt.Printf("%s (%s) in %s\n", cluster.Name, cluster.Status, cluster.Project)
    }
    for _, warn := range result.Warnings {
        fmt.Println("warning:", warn)
    }
}
```
