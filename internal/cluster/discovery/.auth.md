## Overview

`auth.go` implements a unified Google Cloud (`gcloud`) authentication flow used by every GKE-touching command in the CLI. It checks the current auth state, and in interactive sessions offers to run `gcloud auth login` and, when Terraform needs it, `gcloud auth application-default login` — without requiring the user to leave the CLI. Non-interactive (CI) sessions never prompt and instead return an actionable error.

## Key Components

- **`AuthFlow`** — struct encapsulating the login flow, with test seams for interactivity (`interactive`), user confirmation (`confirm`), and login execution (`runLogin`).
- **`NewAuthFlow(exec executor.CommandExecutor) *AuthFlow`** — production constructor wiring real interactive prompts and a `gcloud` subprocess attached to the terminal (for browser-based login flows).
- **`NewAuthFlowWithSeams(...) *AuthFlow`** — test constructor allowing full control over interactivity, confirmation, and login behavior.
- **`(*AuthFlow) Ensure(ctx context.Context, requireADC bool) error`** — main entry point. Verifies `gcloud` is installed, ensures a valid (non-expired) login, and optionally ensures Application Default Credentials (ADC) when `requireADC` is `true`.
- **`(*AuthFlow) hasADC(ctx) bool`** — checks for valid ADC via `gcloud auth application-default print-access-token`.
- **`(*AuthFlow) hasFreshLogin(ctx) bool`** — verifies the primary login can mint a fresh token (catches expired logins that `gcloud auth list` misses).
- **`(*AuthFlow) login(...) error`** — internal helper running a single prompt → execute → re-verify login step.

## Usage Example

```go
package main

import (
	"context"

	"github.com/flamingo-stack/openframe-cli/internal/shared/executor"
)

func main() {
	exec := executor.NewCommandExecutor()
	authFlow := NewAuthFlow(exec)

	ctx := context.Background()

	// For commands only reading cluster info (no Terraform/ADC needed).
	if err := authFlow.Ensure(ctx, false); err != nil {
		panic(err)
	}

	// For `cluster create --type gke`, which requires Terraform + ADC.
	if err := authFlow.Ensure(ctx, true); err != nil {
		panic(err)
	}
}
```

In interactive terminals, `Ensure` prompts the user to log in via browser when needed. In CI or non-interactive environments, it fails fast with a clear message (e.g., `run 'gcloud auth login'`) instead of prompting.
