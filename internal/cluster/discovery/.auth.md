# auth.go

Implements the interactive Google Cloud authentication flow used by every GKE-related command in the CLI. It centralizes the logic for checking `gcloud` auth status, prompting the user to log in when running interactively, and verifying that credentials (including Application Default Credentials for Terraform) are valid before proceeding.

## Key Components

- **`AuthFlow`** — struct encapsulating the auth flow, with injectable seams (`interactive`, `confirm`, `runLogin`) for testability.
- **`NewAuthFlow(exec executor.CommandExecutor) *AuthFlow`** — production constructor wiring real interactivity checks, confirmation prompts, and a terminal-attached `gcloud` login command.
- **`NewAuthFlowWithSeams(...)`** — test constructor allowing full control over interactivity, confirmation, and login behavior.
- **`(*AuthFlow) Ensure(ctx context.Context, requireADC bool) error`** — main entry point; verifies `gcloud` is installed and authenticated, refreshes an expired login if needed, and optionally ensures Application Default Credentials (ADC) exist.
- **`(*AuthFlow) hasADC(ctx) bool`** — checks for valid ADC without prompting.
- **`(*AuthFlow) hasFreshLogin(ctx) bool`** — checks whether the primary login can mint a fresh access token (catches expired-but-"active" accounts).
- **`(*AuthFlow) login(...)`** — internal helper that prompts, runs a `gcloud` login command, and re-verifies success.

## Usage Example

```go
package main

import (
	"context"
	"log"

	"github.com/flamingo-stack/openframe-cli/internal/shared/executor"
)

func main() {
	exec := executor.NewCommandExecutor() // real or mock implementation
	authFlow := discovery.NewAuthFlow(exec)

	ctx := context.Background()

	// For commands that only discover/use a GKE cluster (no ADC needed):
	if err := authFlow.Ensure(ctx, false); err != nil {
		log.Fatalf("authentication failed: %v", err)
	}

	// For `cluster create --type gke`, which runs Terraform and needs ADC:
	if err := authFlow.Ensure(ctx, true); err != nil {
		log.Fatalf("authentication failed: %v", err)
	}
}
```

In non-interactive (CI) environments, `Ensure` never prompts — it returns an actionable error instructing the user to run `gcloud auth login` or `gcloud auth application-default login` manually.
