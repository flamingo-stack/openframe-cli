## Overview

`auth.go` implements the interactive Google Cloud authentication flow used by every GKE-touching CLI command. It centralizes the logic for checking `gcloud` auth state, prompting the user to log in when running interactively, and validating both primary login and Application Default Credentials (ADC) required by Terraform's Google provider.

## Key Components

- **`AuthFlow`** — struct encapsulating the auth flow, with injectable seams (`interactive`, `confirm`, `runLogin`) for testability.
- **`NewAuthFlow(exec)`** — production constructor; wires real interactivity checks, confirmation prompts, and a `gcloud` login command attached to the terminal (stdin/stdout/stderr) so browser-based OAuth flows work correctly.
- **`NewAuthFlowWithSeams(...)`** — test constructor allowing full control over interactivity, confirmation, and login execution.
- **`Ensure(ctx, requireADC)`** — main entry point. Verifies `gcloud` is installed, ensures a fresh (non-expired) login, and optionally ensures ADC is configured. Returns actionable errors in non-interactive (CI) contexts instead of prompting.
- **`hasADC(ctx)`** — checks for valid Application Default Credentials via `gcloud auth application-default print-access-token`.
- **`hasFreshLogin(ctx)`** — verifies the primary login can mint a fresh token (catches expired logins that `gcloud auth list` would misreport as active).
- **`login(ctx, prompt, args, verified, manualHint)`** — shared helper performing prompt → run login command → re-verify, printing success via `pterm`.

## Usage Example

```go
import (
    "context"
    "github.com/flamingo-stack/openframe-cli/internal/shared/executor"
)

func setupGKEAuth(ctx context.Context, exec executor.CommandExecutor) error {
    authFlow := NewAuthFlow(exec)

    // For commands that only need basic gcloud auth (e.g., discovery)
    if err := authFlow.Ensure(ctx, false); err != nil {
        return err
    }

    // For "cluster create --type gke", which also needs Terraform's ADC
    if err := authFlow.Ensure(ctx, true); err != nil {
        return err
    }

    return nil
}
```

In non-interactive (CI) sessions, `Ensure` never prompts — it returns a descriptive error instructing the user to run `gcloud auth login` or `gcloud auth application-default login` manually.
