## eks.go

Implements cluster discovery for AWS EKS by shelling out to the `aws` CLI. It enumerates configured AWS profiles, checks each profile's default region, lists and describes EKS clusters, and maps them into the shared `models.ClusterInfo` format used across the discovery package. Credentials are never handled directly—everything goes through the `aws` CLI via a `CommandExecutor`, making the discoverer fully mockable.

## Key Components

- **`EKSDiscoverer`** - struct wrapping an `executor.CommandExecutor` to run `aws` CLI commands.
- **`NewEKSDiscoverer(exec)`** - constructor for `EKSDiscoverer`.
- **`AuthStatus(ctx)`** - checks whether the `aws` CLI is installed and authenticated (`CLIMissing`, `NotAuthenticated`, `Authenticated`).
- **`Profiles(ctx)`** - returns sorted, deduplicated list of configured AWS profile names.
- **`Regions(ctx, profile)`** - returns sorted list of enabled AWS regions for a given profile (used for wizard region selection).
- **`Discover(ctx)`** - iterates over all profiles, resolves each profile's default region, lists EKS clusters, describes them, deduplicates by ARN, and matches them to kubeconfig contexts. Returns a `Result` containing clusters and non-fatal warnings.
- **`describe(ctx, profile, region, name)`** - fetches cluster details via `aws eks describe-cluster` and maps them to `models.ClusterInfo`.
- **`matchEKSContext(contexts, arn, name)`** - matches a discovered cluster to an existing kubeconfig context by name or ARN.
- Internal helpers: `profileRegion` (resolves a profile's default region), `eksListClusters`/`eksCluster` (JSON response shapes).

## Usage Example

```go
exec := executor.NewShellExecutor()
discoverer := discovery.NewEKSDiscoverer(exec)

ctx := context.Background()

status := discoverer.AuthStatus(ctx)
if status != discovery.Authenticated {
    fmt.Println("AWS CLI not authenticated")
    return
}

result, err := discoverer.Discover(ctx)
if err != nil {
    log.Fatal(err)
}

for _, cluster := range result.Clusters {
    fmt.Printf("EKS cluster: %s (region=%s, context=%s)\n",
        cluster.Name, cluster.Region, cluster.Context)
}
for _, warning := range result.Warnings {
    fmt.Println("warning:", warning)
}
```
