## Purpose

`eks.go` implements discovery of AWS EKS clusters across a user's configured AWS CLI profiles. It shells out to the `aws` CLI via a `CommandExecutor` (never storing credentials directly), enumerating profiles and regions, listing clusters per profile, and mapping results onto the shared `ClusterInfo` model used throughout the `discovery` package.

## Key Components

- **`EKSDiscoverer`** — struct wrapping a `executor.CommandExecutor` to run `aws` CLI commands.
- **`NewEKSDiscoverer(exec)`** — constructor.
- **`AuthStatus(ctx)`** — checks `aws sts get-caller-identity` to report `CLIMissing`, `NotAuthenticated`, or `Authenticated`.
- **`Profiles(ctx)`** — lists sorted, deduplicated AWS profile names via `aws configure list-profiles`.
- **`Regions(ctx, profile)`** — lists sorted, deduplicated enabled AWS regions via `aws ec2 describe-regions`.
- **`Discover(ctx)`** — iterates all profiles (or the default credential chain if none exist), resolves each profile's default region, lists and describes EKS clusters, deduplicates by ARN, and attaches matching kubeconfig contexts. Collects per-profile failures as warnings rather than aborting.
- **`describe(ctx, profile, region, name)`** — internal helper calling `aws eks describe-cluster` and mapping the response to `models.ClusterInfo`.
- **`matchEKSContext(contexts, arn, name)`** — matches a discovered cluster to an existing kubeconfig context by name or ARN convention.

## Usage Example

```go
exec := executor.NewShellExecutor()
discoverer := discovery.NewEKSDiscoverer(exec)

ctx := context.Background()

// Check authentication before discovery
status := discoverer.AuthStatus(ctx)
if status != discovery.Authenticated {
    log.Fatalf("AWS CLI not ready: %v", status)
}

// Discover clusters across all configured profiles
result, err := discoverer.Discover(ctx)
if err != nil {
    log.Fatal(err)
}

for _, cluster := range result.Clusters {
    fmt.Printf("%s (%s) in %s\n", cluster.Name, cluster.Status, cluster.Region)
}
for _, warning := range result.Warnings {
    fmt.Println("warning:", warning)
}
```
