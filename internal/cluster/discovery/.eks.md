## eks.go

Implements cluster discovery for AWS EKS by shelling out to the `aws` CLI. It enumerates clusters across all configured AWS profiles (each queried in its profile's default region), never handling credentials directly, and maps results onto the shared `models.ClusterInfo` type for use alongside other cluster discoverers (e.g., GKE).

## Key Components

- **`EKSDiscoverer`** - struct wrapping a `executor.CommandExecutor` used to run all `aws` CLI commands.
- **`NewEKSDiscoverer(exec)`** - constructor.
- **`AuthStatus(ctx)`** - checks CLI presence and credential validity via `aws sts get-caller-identity`, returning `CLIMissing`, `NotAuthenticated`, or `Authenticated`.
- **`Profiles(ctx)`** - lists configured AWS named profiles (sorted, deduplicated) via `aws configure list-profiles`.
- **`Regions(ctx, profile)`** - lists enabled AWS regions for an account via `aws ec2 describe-regions`, used to populate region pickers.
- **`Discover(ctx)`** - main entry point; iterates all profiles (or default credentials if none), resolves each profile's default region, lists and describes EKS clusters, deduplicates by ARN, and attaches matching kubeconfig contexts. Failures per profile are collected as warnings rather than aborting the whole discovery.
- **`describe(ctx, profile, region, name)`** - fetches cluster details via `aws eks describe-cluster` and converts them to `models.ClusterInfo`.
- **`matchEKSContext(contexts, arn, name)`** - matches a discovered cluster to an existing kubeconfig context by cluster name or ARN.

## Usage Example

```go
exec := executor.NewShellExecutor()
discoverer := discovery.NewEKSDiscoverer(exec)

ctx := context.Background()

switch discoverer.AuthStatus(ctx) {
case discovery.CLIMissing:
    fmt.Println("Install the AWS CLI to discover EKS clusters")
case discovery.NotAuthenticated:
    fmt.Println("Run 'aws configure' or 'aws sso login' first")
case discovery.Authenticated:
    result, err := discoverer.Discover(ctx)
    if err != nil {
        log.Fatal(err)
    }
    for _, cluster := range result.Clusters {
        fmt.Printf("%s (%s) - context: %s\n", cluster.Name, cluster.Region, cluster.Context)
    }
    for _, warning := range result.Warnings {
        fmt.Println("warning:", warning)
    }
}
```
