# main.tf

Root Terraform module generated and owned by the OpenFrame CLI, provisioning a self-contained AWS EKS cluster for OpenFrame workloads. It creates a dedicated VPC (2 availability zones, single NAT gateway) and an EKS cluster with one managed node group, core addons (`vpc-cni`, `kube-proxy`, `coredns`), and the AWS EBS CSI driver addon required for persistent storage. This file is not intended for manual editing — the CLI regenerates `terraform.tfvars.json` alongside it to drive all inputs.

## Key Components

- **`terraform` block** — pins Terraform `>= 1.15.0` and the AWS provider to `>= 6.52, < 7.0`.
- **Input variables** — `cluster_name`, `region`, `profile`, `kubernetes_version` (default `1.33`), `instance_type` (default `m7i-flex.large`, Free-Tier-eligible), `min_nodes`/`max_nodes`/`desired_nodes`, and `spot`.
- **`provider "aws"`** — configures region/profile and applies default tags (`openframe:cluster`, `openframe:managedBy`) to all resources.
- **`module "vpc"`** — `terraform-aws-modules/vpc/aws` v6.6.1, creates a `/16` VPC across 2 AZs with public/private subnets and a single NAT gateway.
- **`module "eks"`** — `terraform-aws-modules/eks/aws` v21.24.1 (exact pin), provisions the cluster, one managed node group with EBS CSI IAM policy and IMDS hop-limit `2`, and explicitly declares required addons since v21 disables auto-bootstrapping.
- **Outputs** — `cluster_name`, `cluster_endpoint`, `cluster_certificate_authority_data`, `region`.

## Usage Example

This file is generated by the OpenFrame CLI, but it can be invoked directly with Terraform for debugging:

```hcl
# terraform.tfvars.json (generated alongside main.tf)
{
  "cluster_name": "openframe-dev",
  "region": "us-east-1",
  "desired_nodes": 3
}
```

```bash
terraform init
terraform plan -var-file=terraform.tfvars.json
terraform apply -var-file=terraform.tfvars.json
```

**Important notes:**
- Module versions are **exact pins**, not ranges — do not loosen them without re-running a full create/delete cycle.
- `instance_type` defaults to `m7i-flex.large` to remain Free-Tier eligible on new AWS accounts.
- The `aws-ebs-csi-driver` addon tags provisioned EBS volumes with `openframe:cluster` so the CLI's teardown logic can locate and clean up orphaned volumes outside Terraform state.
