## provider.go

Implements the `eks` package's `Provider`, which provisions and manages AWS EKS clusters through the shared Terraform engine (`internal/cluster/providers/terraform`). It generates a pinned root Terraform module (using the public `terraform-aws-modules/eks` and `vpc` modules) into a per-cluster workspace and drives `init`/`plan`/`apply`/`destroy` operations against it, with AWS credential and name-collision preflight checks, resumable creates, and kubeconfig integration.

## Key Components

- **`Provider`** — struct holding the Terraform engine, workspace registry, command executor, and an optional interactive apply-confirmation callback.
- **`New(exec, verbose)`** — production constructor using the default `~/.openframe/clusters` registry.
- **`NewWithDeps(engine, registry, exec)`** — test constructor for dependency injection.
- **`PlanCluster(ctx, config)`** — runs a side-effect-free `terraform plan` preview, reusing existing workspace state/backend if present.
- **`CreateCluster(ctx, config)`** — scaffolds or resumes a workspace, regenerates the module from the current template/config, runs `plan` → confirm → `apply`, updates the cluster record, merges kubeconfig, and returns a `*rest.Config`.
- **`DeleteCluster(ctx, config)`** — destroys cloud resources and cleans up the workspace and kubeconfig context (implementation continues beyond shown excerpt).
- **`preflightCredentials`** — validates AWS identity via `aws sts get-caller-identity` before any Terraform run.
- **`preflightNameCollision`** — prevents creating a cluster whose name already exists in AWS but isn't openframe-managed.
- **`backendTF` / `parseBackend`** — render/validate the S3 remote-state backend configuration.

## Usage Example

```go
import (
	"context"

	"github.com/flamingo-stack/openframe-cli/internal/cluster/models"
	"github.com/flamingo-stack/openframe-cli/internal/cluster/providers/eks"
	"github.com/flamingo-stack/openframe-cli/internal/shared/executor"
)

func provisionEKS(ctx context.Context, exec executor.CommandExecutor, cfg models.ClusterConfig) error {
	provider, err := eks.New(exec, true)
	if err != nil {
		return err
	}

	// Preview changes without side effects.
	if _, err := provider.PlanCluster(ctx, cfg); err != nil {
		return err
	}

	// Create (or resume) the cluster and get a kubeconfig-compatible rest.Config.
	restCfg, err := provider.CreateCluster(ctx, cfg)
	if err != nil {
		return err
	}
	_ = restCfg
	return nil
}
```
