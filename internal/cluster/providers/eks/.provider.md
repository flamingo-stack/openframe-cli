## Overview

Implements the `Provider` interface for AWS EKS cluster lifecycle management (create, plan, delete). Provisioning is delegated to a shared Terraform engine: the provider generates a Terraform root module (from pinned `terraform-aws-modules/eks` and `vpc` modules) into a per-cluster workspace directory and drives `init`/`plan`/`apply`/`destroy` there.

## Key Components

- **`Provider`** — struct holding the Terraform engine, workspace registry, command executor, and an optional interactive apply-confirmation callback.
- **`New(exec, verbose)`** — production constructor; uses the default `~/.openframe/clusters` registry and interactive apply confirmation.
- **`NewWithDeps(engine, registry, exec)`** — test constructor for injecting fakes/mocks.
- **`(*Provider).PlanCluster(ctx, config)`** — side-effect-free preview of `CreateCluster`, running `terraform plan` in a throwaway directory (copies existing workspace state/backend if present).
- **`(*Provider).CreateCluster(ctx, config)`** — provisions (or resumes) an EKS cluster, applies a saved plan after optional user confirmation, updates the workspace record, merges kubeconfig, and returns a `*rest.Config`.
- **`(*Provider).DeleteCluster(ctx, ...)`** — destroys cluster resources and cleans up workspace/kubeconfig (implementation continues beyond shown excerpt).
- **`preflightCredentials`** — validates AWS identity via `aws sts get-caller-identity` before running Terraform.
- **`preflightNameCollision`** — prevents creating a cluster whose name already exists in AWS but isn't tracked by openframe.
- **`backendTF` / `parseBackend`** — generate/validate the S3 remote-state backend configuration.

## Usage Example

```go
exec := executor.NewShellExecutor()
provider, err := eks.New(exec, false /* verbose */)
if err != nil {
    log.Fatal(err)
}

config := models.ClusterConfig{
    Name:      "my-eks-cluster",
    NodeCount: 3,
    Cloud: models.CloudConfig{
        Region:  "us-east-1",
        Profile: "default",
    },
}

// Preview changes without side effects
plan, err := provider.PlanCluster(ctx, config)
if err != nil {
    log.Fatal(err)
}
fmt.Println(plan)

// Create (or resume) the cluster
restCfg, err := provider.CreateCluster(ctx, config)
if err != nil {
    log.Fatal(err)
}
```

See the package comment in `internal/cluster/providers/terraform` for details on the workspace layout used by this provider.
