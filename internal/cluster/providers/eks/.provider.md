## Overview

`provider.go` implements the `Provider` type for AWS EKS cluster lifecycle management within the `eks` package. It orchestrates cluster creation, planning, and deletion by generating Terraform root modules (using pinned `terraform-aws-modules/eks` and `vpc` modules) and driving them through the shared `terraform` engine, following the workspace layout defined in `internal/cluster/providers/terraform`.

## Key Components

- **`Provider`** — struct holding the terraform engine, workspace registry, command executor, and an optional `confirmApply` callback for interactive apply confirmation.
- **`New(exec, verbose)`** — production constructor; builds a provider backed by the default `~/.openframe/clusters` registry.
- **`NewWithDeps(engine, registry, exec)`** — test constructor for injecting fakes/mocks.
- **`preflightCredentials`** — validates AWS credentials via `aws sts get-caller-identity` before running Terraform.
- **`preflightNameCollision`** — guards against creating a cluster whose name already exists in AWS but isn't tracked by an openframe workspace.
- **`backendTF` / `parseBackend`** — render and validate the S3 remote-state backend configuration.
- **`PlanCluster(ctx, config)`** — performs a side-effect-free `terraform plan` preview, reusing existing workspace state/backend when present.
- **`CreateCluster(ctx, config)`** — provisions (or resumes) an EKS cluster: scaffolds/refreshes the workspace, runs `init`/plan/apply, updates the cluster record, merges kubeconfig, and returns a `*rest.Config`.
- **`DeleteCluster(ctx, ...)`** — (truncated in source) destroys cluster infrastructure and cleans up workspace/kubeconfig.

## Usage Example

```go
exec := executor.NewShellExecutor()
provider, err := eks.New(exec, true /* verbose */)
if err != nil {
    log.Fatal(err)
}

cfg := models.ClusterConfig{
    Name: "my-eks-cluster",
    Cloud: models.CloudConfig{
        Region: "us-east-1",
    },
    NodeCount: 3,
}

// Preview changes without side effects
plan, err := provider.PlanCluster(context.Background(), cfg)

// Create (or resume) the cluster
restCfg, err := provider.CreateCluster(context.Background(), cfg)
```
