# kubeconfig.go

Generates and manages `kubeconfig` entries for EKS clusters using AWS's `client-go` exec plugin for authentication, eliminating the need for static credentials. Tokens are short-lived and minted on demand via `aws eks get-token`, using the operator's active AWS identity.

## Key Components

- **`execArgs(rec tfengine.Record) []string`** — Builds the `aws eks get-token` command-line arguments for a given cluster record, including optional AWS profile.
- **`execConfig(rec tfengine.Record) *clientcmdapi.ExecConfig`** — Wraps `execArgs` into a client-go `ExecConfig` for exec-based authentication.
- **`caData(rec tfengine.Record) ([]byte, error)`** — Decodes the base64-encoded CA certificate bundle from the cluster record.
- **`kubeconfigFor(rec tfengine.Record) (*clientcmdapi.Config, error)`** — Builds an in-memory kubeconfig with a single cluster/context/auth-info entry named after the cluster.
- **`restConfigFor(rec tfengine.Record) (*rest.Config, error)`** — Builds a `rest.Config` directly from the record, bypassing kubeconfig file generation entirely.
- **`mergeIntoDefaultKubeconfig(rec tfengine.Record) error`** — Merges the cluster's context into the user's default kubeconfig (respecting `$KUBECONFIG`) and sets it as current context. Refuses to overwrite an existing context with the same name pointing at a different server.
- **`removeFromDefaultKubeconfig(rec tfengine.Record) error`** — Removes the cluster's entries from the default kubeconfig after a destroy, but only if the entry still points at the same endpoint. Best-effort — missing entries are not an error.

## Usage Example

```go
rec := tfengine.Record{
    Name:     "my-eks-cluster",
    Region:   "us-east-1",
    Endpoint: "https://EXAMPLE.gr7.us-east-1.eks.amazonaws.com",
    CACert:   "<base64-encoded-ca>",
}

// Get a rest.Config for direct API access (no file I/O)
restCfg, err := restConfigFor(rec)
if err != nil {
    log.Fatal(err)
}

// Or merge the cluster into the user's default kubeconfig
if err := mergeIntoDefaultKubeconfig(rec); err != nil {
    log.Fatal(err)
}

// On cluster teardown, clean up the entry
if err := removeFromDefaultKubeconfig(rec); err != nil {
    log.Fatal(err)
}
```
