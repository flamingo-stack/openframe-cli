Handles kubeconfig generation and management for EKS clusters, using the AWS `aws eks get-token` exec plugin for short-lived, credential-free authentication instead of static tokens.

## Key Components

- **`execArgs(rec tfengine.Record) []string`** — Builds the `aws eks get-token` command-line arguments for a cluster record, including optional AWS profile.
- **`execConfig(rec tfengine.Record) *clientcmdapi.ExecConfig`** — Wraps the exec args into a client-go `ExecConfig` for token-based auth.
- **`caData(rec tfengine.Record) ([]byte, error)`** — Decodes the base64-encoded CA certificate bundle from the cluster record.
- **`kubeconfigFor(rec tfengine.Record) (*clientcmdapi.Config, error)`** — Builds an in-memory kubeconfig with a single cluster/context/auth-info entry named after the cluster.
- **`restConfigFor(rec tfengine.Record) (*rest.Config, error)`** — Builds a `rest.Config` directly from a cluster record, bypassing kubeconfig file I/O.
- **`mergeIntoDefaultKubeconfig(rec tfengine.Record) error`** — Merges the cluster's context into the user's default kubeconfig (honoring `$KUBECONFIG`) and sets it as current context. Refuses to overwrite an existing context with the same name pointing at a different server.
- **`removeFromDefaultKubeconfig(rec tfengine.Record) error`** — Removes the cluster's context from the default kubeconfig after a destroy, but only if the entry still points at the same endpoint. Missing entries are not treated as errors.

## Usage Example

```go
rec := tfengine.Record{
    Name:     "my-eks-cluster",
    Region:   "us-east-1",
    Endpoint: "https://XXXX.eks.amazonaws.com",
    CACert:   base64CAString,
    Profile:  "my-aws-profile",
}

// Build a rest.Config for direct API server access
restCfg, err := restConfigFor(rec)
if err != nil {
    log.Fatal(err)
}

// Or merge the cluster into the user's default kubeconfig
if err := mergeIntoDefaultKubeconfig(rec); err != nil {
    log.Fatal(err)
}

// Later, on cluster destroy
if err := removeFromDefaultKubeconfig(rec); err != nil {
    log.Fatal(err)
}
```

Both `mergeIntoDefaultKubeconfig` and `removeFromDefaultKubeconfig` operate safely alongside other clusters by checking that a same-named context actually points at this cluster's endpoint before modifying or deleting it.
