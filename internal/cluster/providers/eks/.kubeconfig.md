Manages kubeconfig generation and lifecycle for EKS clusters, using the AWS `aws eks get-token` exec plugin for short-lived, credential-free authentication instead of static tokens.

## Key Components

- **`execArgs(rec tfengine.Record) []string`** — Builds the `aws eks get-token` command-line arguments for a given cluster record, including optional AWS profile.
- **`execConfig(rec tfengine.Record) *clientcmdapi.ExecConfig`** — Wraps `execArgs` into a client-go `ExecConfig` for exec-based authentication.
- **`caData(rec tfengine.Record) ([]byte, error)`** — Decodes the base64-encoded CA certificate bundle from the cluster record.
- **`kubeconfigFor(rec tfengine.Record) (*clientcmdapi.Config, error)`** — Builds an in-memory kubeconfig with a single cluster/context/authinfo named after the cluster.
- **`restConfigFor(rec tfengine.Record) (*rest.Config, error)`** — Builds a `rest.Config` directly from a cluster record, bypassing any kubeconfig file.
- **`mergeIntoDefaultKubeconfig(rec tfengine.Record) error`** — Merges the cluster's context into the user's default kubeconfig (honoring `$KUBECONFIG`) and sets it as current context. Refuses to overwrite an existing context with the same name pointing at a different server.
- **`removeFromDefaultKubeconfig(rec tfengine.Record) error`** — Removes the cluster's context from the default kubeconfig after a destroy, but only if it still points at the same endpoint. Best-effort; missing entries are not an error.

## Usage Example

```go
rec := tfengine.Record{
    Name:     "my-eks-cluster",
    Region:   "us-east-1",
    Endpoint: "https://XXXX.eks.amazonaws.com",
    CACert:   base64EncodedCA,
    Profile:  "default",
}

// Merge cluster access into the user's default kubeconfig
if err := mergeIntoDefaultKubeconfig(rec); err != nil {
    log.Fatalf("failed to update kubeconfig: %v", err)
}

// Or build a rest.Config directly for programmatic access
restCfg, err := restConfigFor(rec)
if err != nil {
    log.Fatalf("failed to build rest config: %v", err)
}
```

This design mirrors the GKE provider's kubeconfig handling, ensuring consistent behavior across cloud providers while relying on AWS CLI's exec plugin for dynamic, short-lived credentials.
