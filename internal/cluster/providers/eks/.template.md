This file defines the AWS EKS Terraform template logic for the OpenFrame CLI's cluster provisioning. It embeds a static Terraform root module and converts a validated `ClusterConfig` into the JSON variables (`terraform.tfvars.json`) that drive that module, avoiding HCL templating entirely.

## Key Components

- **`mainTF`** — embedded byte slice containing the static `templates/main.tf` Terraform module; all cluster-specific values are passed via tfvars rather than templating the HCL itself.
- **`tfvars`** — struct mirroring the variables block of `main.tf` (cluster name, region, profile, Kubernetes version, instance type, node scaling bounds, spot flag), tagged for JSON marshaling.
- **`eksVersionRE`** — regex validating Kubernetes version strings against EKS's `<major>.<minor>` format (e.g., `1.33`).
- **`tfvarsFor(config models.ClusterConfig) (tfvars, error)`** — maps a validated `ClusterConfig` to `tfvars`, normalizing the `v` prefix, handling `"latest"` as an omitted (template-default) version, and validating version format.
- **`effectiveMaxNodes(maxNodes, nodeCount int) int`** — resolves the effective max node count, growing an unset max to cover an explicit `--nodes` request rather than letting the template's default (`templateDefaultMaxNodes = 4`) silently reject or truncate it.
- **`validate(config models.ClusterConfig) error`** — enforces EKS-specific invariants (valid name, correct cluster type, required region, non-negative and consistent min/max/desired node counts) before any cloud resources are provisioned.

## Usage Example

```go
config := models.ClusterConfig{
    Name:       "my-cluster",
    Type:       models.ClusterTypeEKS,
    K8sVersion: "v1.33",
    NodeCount:  6,
    Cloud: &models.CloudConfig{
        Region:      "us-east-1",
        MachineType: "t3.medium",
        MaxNodes:    0, // unset, grows to cover NodeCount
    },
}

if err := validate(config); err != nil {
    log.Fatal(err)
}

vars, err := tfvarsFor(config)
if err != nil {
    log.Fatal(err)
}
// vars is marshaled to terraform.tfvars.json alongside the embedded mainTF module
```
