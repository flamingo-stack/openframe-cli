Defines the Terraform template integration for AWS EKS clusters, converting a validated `ClusterConfig` into the JSON `tfvars` consumed by the embedded static root module (`templates/main.tf`), plus the domain validation rules specific to EKS provisioning.

## Key Components

- **`mainTF`** — embedded byte slice containing the static Terraform root module (`templates/main.tf`). No HCL templating is performed; all per-cluster values flow through `terraform.tfvars.json`.
- **`tfvars`** — struct mirroring the variables block of `main.tf` (cluster name, region, profile, Kubernetes version, instance type, node scaling bounds, spot flag), serialized to JSON.
- **`tfvarsFor(config models.ClusterConfig) (tfvars, error)`** — maps a validated `ClusterConfig` to `tfvars`, normalizing the Kubernetes version (stripping `v` prefix, treating `"latest"` as "use template default") and validating it against the EKS `<major>.<minor>` format via `eksVersionRE`.
- **`effectiveMaxNodes(maxNodes, nodeCount int) int`** — resolves the max node count so that an unset `--max-nodes` grows to cover an explicit `--nodes` request, avoiding a node group whose desired size exceeds its default max (`templateDefaultMaxNodes = 4`).
- **`validate(config models.ClusterConfig) error`** — enforces EKS-specific invariants: valid cluster name, correct cluster type, required region, positive node count, non-negative and consistent min/max node bounds, and desired node count within those bounds.

## Usage Example

```go
config := models.ClusterConfig{
    Name:       "my-cluster",
    Type:       models.ClusterTypeEKS,
    K8sVersion: "1.33",
    NodeCount:  3,
    Cloud: &models.CloudConfig{
        Region:      "us-east-1",
        MachineType: "t3.medium",
        MinNodes:    2,
        MaxNodes:    5,
    },
}

if err := validate(config); err != nil {
    // handle invalid configuration
    return err
}

vars, err := tfvarsFor(config)
if err != nil {
    // handle version parsing error
    return err
}

// vars can now be marshaled to terraform.tfvars.json alongside the
// embedded mainTF module before running terraform init/apply.
```
