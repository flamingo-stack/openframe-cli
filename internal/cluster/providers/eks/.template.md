This file defines the Terraform templating and validation logic for provisioning AWS EKS clusters. It embeds a static root Terraform module and converts a validated `ClusterConfig` into the JSON variables (`terraform.tfvars.json`) consumed by that module, avoiding HCL templating entirely.

## Key Components

- **`mainTF`** — embedded byte slice containing the static `templates/main.tf` root module.
- **`tfvars`** — struct mirroring the variables block of `main.tf` (cluster name, region, profile, Kubernetes version, instance type, node scaling bounds, spot flag), serialized to JSON.
- **`eksVersionRE`** — regex validating Kubernetes version strings in `<major>.<minor>` form (e.g., `1.33`).
- **`tfvarsFor(config models.ClusterConfig) (tfvars, error)`** — maps a `ClusterConfig` to `tfvars`, normalizing the version string (stripping `v` prefix, treating `"latest"` as "use template default") and validating its format.
- **`effectiveMaxNodes(maxNodes, nodeCount int) int`** — ensures `--nodes` remains authoritative when `--max-nodes` is unset by growing the effective max to cover the requested node count, avoiding a mid-apply rejection from Terraform.
- **`validate(config models.ClusterConfig) error`** — enforces EKS-specific invariants (valid cluster name, correct cluster type, required region, non-negative and consistent min/max/desired node counts) before any cloud resources are provisioned.

## Usage Example

```go
config := models.ClusterConfig{
    Name:       "my-cluster",
    Type:       models.ClusterTypeEKS,
    K8sVersion: "1.33",
    NodeCount:  3,
    Cloud: &models.CloudConfig{
        Region:      "us-east-1",
        MachineType: "t3.medium",
        MinNodes:    2,
        MaxNodes:    5,
    },
}

if err := validate(config); err != nil {
    log.Fatal(err)
}

vars, err := tfvarsFor(config)
if err != nil {
    log.Fatal(err)
}

data, _ := json.MarshalIndent(vars, "", "  ")
os.WriteFile("terraform.tfvars.json", data, 0644)
```
