Manages the full lifecycle of K3D clusters, including creation, deletion, start, status retrieval, and kubeconfig management, with Docker-based fallback cleanup and WSL/Linux compatibility.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `ClusterManager` | Interface | Contract for detecting cluster types and listing clusters |
| `K3dManager` | Struct | Core manager wrapping a `CommandExecutor` with verbosity and timeout settings |
| `NewK3dManager` | Constructor | Creates a `K3dManager` with default 300s timeout |
| `CreateCluster` | Method | Creates a K3D cluster from config, returns a `*rest.Config` for immediate use |
| `DeleteCluster` | Method | Deletes a cluster; falls back to `forceCleanupDockerContainers` when `force=true` |
| `StartCluster` | Method | Starts a stopped K3D cluster by name |
| `ListClusters` | Method | Returns all K3D clusters as `[]models.ClusterInfo` with a 30s timeout guard |
| `ListAllClusters` | Method | Alias for `ListClusters` for backward compatibility |
| `GetClusterStatus` | Method | Fetches status for a single named cluster |
| `GetRestConfig` | Method | Returns `*rest.Config` for an already-created cluster |
| `forceCleanupDockerContainers` | Method | Removes Docker containers/network by `k3d.cluster` label when `k3d delete` fails |

## Usage Example

```go
exec := executor.NewShellExecutor()
mgr := k3d.NewK3dManager(exec, true)

cfg := models.ClusterConfig{
    Name: "openframe-dev",
    Type: models.ClusterTypeK3d,
}

restConfig, err := mgr.CreateCluster(context.Background(), cfg)
if err != nil {
    log.Fatal(err)
}
// restConfig is ready for use with client-go

clusters, _ := mgr.ListClusters(context.Background())
for _, c := range clusters {
    fmt.Printf("%s: %s (%d nodes)\n", c.Name, c.Status, c.NodeCount)
}

err = mgr.DeleteCluster(context.Background(), "openframe-dev", models.ClusterTypeK3d, true)
```

## Notes

- All operations are Linux/WSL-only; Windows execution is handled upstream by the WSL launcher.
- `CreateCluster` increases inotify limits, prepares kubeconfig directories, and fixes permissions as best-effort steps — none are fatal.
- `forceCleanupDockerContainers` filters by the exact `k3d.cluster=<name>` Docker label (not a regex name filter) to avoid collateral deletion of similarly named clusters.
