## Overview

`manager.go` implements the K3D cluster provider for the OpenFrame CLI, providing lifecycle management (create, delete, start, list, status) for K3D-based Kubernetes clusters. It wraps the `k3d` CLI and Docker commands via a `CommandExecutor` abstraction, handling platform-specific quirks (kubeconfig permissions, inotify limits, stale lock files) and defense-in-depth validation of cluster names before they reach shell/Docker calls.

## Key Components

- **`ClusterManager` interface** — abstraction for detecting cluster type and listing clusters.
- **`K3dManager` struct** — main implementation holding a `CommandExecutor`, verbosity flag, and operation timeout.
- **`NewK3dManager(exec, verbose)`** — constructor with a default 300s timeout.
- **`CreateCluster(ctx, config)`** — validates config, generates a temporary k3d YAML config, tunes host inotify limits, prepares the kubeconfig directory, runs `k3d cluster create`, fixes kubeconfig permissions, and verifies reachability via `client-go`, returning a `*rest.Config`.
- **`GetRestConfig(ctx, clusterName)`** — fetches a `*rest.Config` for an already-existing cluster.
- **`DeleteCluster(ctx, name, clusterType, force)`** — deletes a cluster via `k3d cluster delete`, with a Docker-based force-cleanup fallback (`forceCleanupDockerContainers`) if the k3d command fails and `force` is set.
- **`StartCluster(ctx, name, clusterType)`** — starts a stopped cluster.
- **`ListClusters(ctx)` / `ListAllClusters(ctx)`** — parses `k3d cluster list --output json` into `models.ClusterInfo`.
- **`GetClusterStatus(ctx, name)`** — (truncated) returns detailed status for a single cluster.
- Constants: `defaultK3sImage`, `defaultTimeout`, `timestampSuffixLen`.

## Usage Example

```go
exec := executor.NewShellExecutor()
manager := k3d.NewK3dManager(exec, true) // verbose=true

config := models.ClusterConfig{
    Name: "my-cluster",
    Type: models.ClusterTypeK3d,
}

restConfig, err := manager.CreateCluster(context.Background(), config)
if err != nil {
    log.Fatalf("failed to create cluster: %v", err)
}

clusters, err := manager.ListClusters(context.Background())
if err != nil {
    log.Fatalf("failed to list clusters: %v", err)
}

err = manager.DeleteCluster(context.Background(), "my-cluster", models.ClusterTypeK3d, true)
```

## Notes

- All cluster names are validated with `models.ValidateClusterName` (restricted to `[a-zA-Z0-9-]`) at every entry point where the name is interpolated into shell/Docker/YAML, as defense in depth independent of upstream CLI validation.
- No Windows-specific code path exists; Windows execution is handled by forwarding into WSL (see the `wsllauncher` package), so this manager always runs as Linux.
