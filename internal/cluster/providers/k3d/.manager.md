## Overview

`manager.go` implements `K3dManager`, the K3D cluster provider that creates, deletes, starts, lists, and monitors K3D (lightweight Kubernetes) clusters via the `k3d` and `docker` CLIs. It handles cluster lifecycle operations, kubeconfig management, and platform-specific quirks (WSL, inotify limits, sudo permission fixes).

## Key Components

- **`ClusterManager`** – Interface defining cluster detection and listing operations.
- **`K3dManager`** – Struct wrapping a `executor.CommandExecutor` to run `k3d`/`docker` commands, with `verbose` logging and a configurable `timeout`.
- **`NewK3dManager(exec, verbose)`** – Constructor returning a `K3dManager` with a default 300s timeout.
- **`CreateCluster(ctx, config)`** – Validates the cluster name/config, increases inotify limits, generates a k3d config file, prepares/cleans up kubeconfig state, runs `k3d cluster create`, fixes kubeconfig permissions, and verifies reachability, returning a `*rest.Config`.
- **`GetRestConfig(ctx, clusterName)`** – Retrieves the `rest.Config` for an already-existing cluster.
- **`DeleteCluster(ctx, name, clusterType, force)`** – Runs `k3d cluster delete`, with an optional forced fallback to direct Docker container/network cleanup (`forceCleanupDockerContainers`) if the k3d command fails or hangs.
- **`StartCluster(ctx, name, clusterType)`** – Starts a stopped K3D cluster.
- **`ListClusters` / `ListAllClusters`** – Parses `k3d cluster list --output json` into `[]models.ClusterInfo`, computing creation time from the earliest server node.

All cluster names are validated via `models.ValidateClusterName` at each entry point as defense-in-depth against shell/Docker argument injection, since names are interpolated into generated YAML and CLI arguments.

## Usage Example

```go
package main

import (
	"context"
	"log"

	"github.com/flamingo-stack/openframe-cli/internal/cluster/k3d"
	"github.com/flamingo-stack/openframe-cli/internal/cluster/models"
	"github.com/flamingo-stack/openframe-cli/internal/shared/executor"
)

func main() {
	exec := executor.NewRealCommandExecutor()
	manager := k3d.NewK3dManager(exec, true)

	ctx := context.Background()
	config := models.ClusterConfig{
		Name: "my-cluster",
		Type: models.ClusterTypeK3d,
	}

	restConfig, err := manager.CreateCluster(ctx, config)
	if err != nil {
		log.Fatalf("failed to create cluster: %v", err)
	}

	clusters, err := manager.ListClusters(ctx)
	if err != nil {
		log.Fatalf("failed to list clusters: %v", err)
	}
	log.Printf("Active clusters: %+v", clusters)

	if err := manager.DeleteCluster(ctx, config.Name, models.ClusterTypeK3d, true); err != nil {
		log.Fatalf("failed to delete cluster: %v", err)
	}
	_ = restConfig
}
```
