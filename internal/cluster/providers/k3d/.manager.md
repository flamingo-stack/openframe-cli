## Overview

`manager.go` implements the core K3D cluster lifecycle manager for the OpenFrame CLI. It provides an implementation of the `ClusterManager` interface for creating, deleting, starting, and listing K3D (lightweight Kubernetes) clusters via shell-outs to the `k3d` and `docker` CLIs, with defense-in-depth input validation and platform-aware fallback handling (WSL/Linux only, no native Windows branch).

## Key Components

- **`ClusterManager` interface** – Contract for cluster detection and listing operations (`DetectClusterType`, `ListClusters`, `ListAllClusters`).
- **`K3dManager` struct** – Main implementation wrapping a `executor.CommandExecutor`, verbosity flag, and operation timeout.
- **`NewK3dManager(exec, verbose)`** – Constructor with sensible defaults (300s timeout).
- **`CreateCluster(ctx, config)`** – Validates config, generates a temp k3d YAML config, tunes inotify limits, prepares/fixes kubeconfig permissions, invokes `k3d cluster create`, and verifies reachability, returning a `*rest.Config`.
- **`GetRestConfig(ctx, clusterName)`** – Fetches a `*rest.Config` for an existing cluster.
- **`DeleteCluster(ctx, name, clusterType, force)`** – Deletes a cluster via `k3d cluster delete`, with an optional forced Docker-level cleanup fallback on failure.
- **`forceCleanupDockerContainers(ctx, clusterName)`** – Removes Docker containers/networks labeled for a cluster when `k3d` delete fails.
- **`StartCluster(ctx, name, clusterType)`** – Starts a stopped cluster.
- **`ListClusters` / `ListAllClusters`** – Parses `k3d cluster list --output json` into `models.ClusterInfo`.
- **Constants** – `defaultK3sImage`, `defaultTimeout`, `timestampSuffixLen`.

All cluster names are validated with `models.ValidateClusterName` before being interpolated into generated YAML, shell commands, or Docker filters, guarding against command injection.

## Usage Example

```go
exec := executor.NewShellExecutor()
manager := k3d.NewK3dManager(exec, true)

config := models.ClusterConfig{
	Name: "my-cluster",
	Type: models.ClusterTypeK3d,
}

restConfig, err := manager.CreateCluster(context.Background(), config)
if err != nil {
	log.Fatalf("failed to create cluster: %v", err)
}

clusters, err := manager.ListClusters(context.Background())
if err != nil {
	log.Fatalf("failed to list clusters: %v", err)
}

err = manager.DeleteCluster(context.Background(), "my-cluster", models.ClusterTypeK3d, true)
```
