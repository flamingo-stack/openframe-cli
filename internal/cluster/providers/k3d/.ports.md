Handles automatic port allocation for k3d clusters, selecting available TCP ports for the Kubernetes API, HTTP, and HTTPS endpoints while avoiding conflicts with existing k3d clusters.

## Key Components

- **`PortConfig`** — struct holding allocated `API`, `HTTP`, and `HTTPS` port numbers.
- **`findAvailablePorts(ctx)`** — main entry point; determines ports used by existing k3d clusters, then finds free ports for API (6550/6551), HTTP (80/8080), and HTTPS (443/8443), falling back to a search range if preferred ports are unavailable.
- **`findPort(preferred, searchStart, usedPorts)`** — tries preferred ports first, then scans up to 1000 ports starting at `searchStart` for an available one.
- **`getUsedPortsByExistingClusters(ctx)`** — runs `k3d cluster list --output json` (with a 30-second timeout) and parses cluster node metadata (API port labels and load balancer port mappings) to build a set of ports already in use.
- **`isPortAvailable(port)`** — checks port availability via a TCP dial attempt to `127.0.0.1`, avoiding the need for elevated privileges required by bind-based checks on ports below 1024.

## Usage Example

```go
manager := &K3dManager{
    executor: someExecutor,
}

ctx := context.Background()
ports, err := manager.findAvailablePorts(ctx)
if err != nil {
    log.Fatalf("failed to allocate ports: %v", err)
}

fmt.Printf("API: %d, HTTP: %d, HTTPS: %d\n", ports.API, ports.HTTP, ports.HTTPS)
```

This is typically invoked internally during k3d cluster creation to determine which ports to bind for the API server, HTTP ingress, and HTTPS ingress before invoking the `k3d cluster create` command.
