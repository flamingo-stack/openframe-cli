Port allocation utilities for the `k3d` package, responsible for discovering and reserving available TCP ports when creating k3d clusters.

## Key Components

### `PortConfig`
A struct holding the three allocated port numbers for a cluster:
- `API` — Kubernetes API server port
- `HTTP` — HTTP ingress port
- `HTTPS` — HTTPS ingress port

### `findAvailablePorts() (PortConfig, error)`
Orchestrates port discovery for all three roles. Prefers standard ports (`6550`, `80`, `443`), falls back to high ports (`6551`/`8080`/`8443`), then searches sequentially up to 1000 candidates beyond the fallback.

### `findPort(preferred []int, searchStart int, usedPorts map[int]bool) int`
Generic port selector that first tries a preferred list, then scans sequentially from `searchStart` up to 1000 ports.

### `getUsedPortsByExistingClusters() map[int]bool`
Queries `k3d cluster list --output json` to build a set of ports already claimed by existing clusters, checking both `k3d.server.api.port` runtime labels and load-balancer port mappings.

### `isPortAvailable(port int) bool`
Attempts a TCP dial to `127.0.0.1:<port>` with a 100ms timeout. A refused or timed-out connection indicates the port is free. This avoids privilege issues with bind-based checks for ports below 1024.

## Usage Example

```go
manager := &K3dManager{executor: myExecutor}

ports, err := manager.findAvailablePorts()
if err != nil {
    log.Fatalf("port allocation failed: %v", err)
}

fmt.Printf("API: %d, HTTP: %d, HTTPS: %d\n", ports.API, ports.HTTP, ports.HTTPS)
// e.g. API: 6550, HTTP: 80, HTTPS: 8443
```
