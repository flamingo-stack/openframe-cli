This file implements cluster reachability verification for k3d clusters using the native Kubernetes Go client, replacing reliance on the external `kubectl` binary for context management and health checks.

## Key Components

- **`verifyClusterReachable`** — Method on `K3dManager` that switches the kubeconfig context to the target k3d cluster, builds a `*rest.Config` with TLS verification bypassed (safe for local clusters), waits for the API server's TCP port to open, then polls the Kubernetes API until at least one node reports `Ready`. Returns the usable `*rest.Config` on success.
- **`isTemporaryError`** — Helper that classifies errors (connection refused, timeout, DNS failure, etc.) as retryable versus fatal.
- **`waitForTCPPort`** — Method on `K3dManager` that repeatedly attempts a TCP dial to a host:port until it succeeds or retries are exhausted, guarding against premature API calls before the server socket is listening.
- **`extractHostPort`** — Parses host and port out of a REST config's URL string.
- **`getKubeconfigPath`** — Method on `K3dManager` resolving the kubeconfig file location, honoring the `` `KUBECONFIG` `` environment variable or defaulting to `~/.kube/config`.
- **`firstKubeconfigPath`** — Reduces a colon-separated `` `KUBECONFIG` `` path list to a single usable file path, preferring the first existing entry (mirrors kubectl precedence).
- **`cleanupStaleLockFiles`** — Method on `K3dManager` that removes stale `kubeconfig.lock` files via a shell command (Linux/macOS only, since Windows runs through WSL).

## Usage Example

```go
manager := &K3dManager{verbose: true /* ...other fields */}

ctx := context.Background()
restConfig, err := manager.verifyClusterReachable(ctx, "my-cluster")
if err != nil {
    log.Fatalf("cluster not reachable: %v", err)
}

client, err := kubernetes.NewForConfig(restConfig)
if err != nil {
    log.Fatalf("failed to create client: %v", err)
}
// client is now ready to interact with the k3d cluster
```

This is typically invoked internally after cluster creation (e.g., in a `CreateCluster` flow) to confirm the cluster's API server and nodes are fully operational before proceeding.
