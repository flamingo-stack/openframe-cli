## verify.go

Implements native Kubernetes API–based cluster reachability verification for k3d clusters, replacing reliance on the external `kubectl` binary for context switching and health checks. It handles kubeconfig context management, TLS bypass for local clusters, TCP port readiness checks, and polling for node readiness.

## Key Components

- **`(*K3dManager).verifyClusterReachable(ctx, clusterName) (*rest.Config, error)`** — Core verification routine: loads the kubeconfig, switches to the `k3d-<clusterName>` context, builds a `rest.Config` with TLS verification bypassed (safe for local clusters), waits for the API server's TCP port to open, then polls the Kubernetes API until at least one node reports `Ready`.
- **`isTemporaryError(err) bool`** — Classifies errors (connection refused, timeout, DNS failure, etc.) as retryable versus fatal.
- **`(*K3dManager).waitForTCPPort(ctx, host, port, maxRetries, retryDelay) error`** — Polls a TCP address until it accepts connections, avoiding premature API calls to a not-yet-listening port.
- **`extractHostPort(urlStr) (string, string, error)`** — Parses host and port from a cluster API URL.
- **`(*K3dManager).getKubeconfigPath() string`** — Resolves the kubeconfig file path, respecting `$KUBECONFIG` or defaulting to `~/.kube/config`.
- **`firstKubeconfigPath(kubeconfig string) string`** — Reduces a colon-separated `$KUBECONFIG` list to a single usable file path, mimicking kubectl's precedence (first existing file wins, else first entry).
- **`(*K3dManager).cleanupStaleLockFiles(ctx) error`** — Removes stale `~/.kube/config.lock*` files that can block kubeconfig writes.

## Usage Example

```go
manager := &K3dManager{verbose: true /* ...other fields... */}

ctx := context.Background()
restConfig, err := manager.verifyClusterReachable(ctx, "my-cluster")
if err != nil {
	log.Fatalf("cluster not reachable: %v", err)
}

client, err := kubernetes.NewForConfig(restConfig)
if err != nil {
	log.Fatalf("failed to create client: %v", err)
}

// Cluster is confirmed reachable with at least one Ready node
nodes, _ := client.CoreV1().Nodes().List(ctx, metav1.ListOptions{})
fmt.Printf("Cluster has %d node(s)\n", len(nodes.Items))
```

**Note:** This file targets Linux/macOS execution paths only — on Windows, the CLI forwards commands into WSL, so no Windows-specific branching is required here.
