## engine.go

Implements the `terraform` package's `Engine`, a wrapper around `terraform-exec` that drives `init`, `plan`, `apply`, `destroy`, and `output` for a cluster workspace directory. It abstracts the terraform binary behind a `Runner` interface for testability, adds verbose/quiet output control, best-effort operation logging, and safety checks before destructive operations.

## Key Components

- **`Runner`** – interface subset of `*tfexec.Terraform` used by the engine, enabling mock-based testing without a real terraform binary.
- **`Engine`** – orchestrates terraform commands; constructed via `NewEngine(verbose bool)` (production) or `NewEngineWithRunner(newRunner)` (tests).
- **`FindTerraform()`** – resolves the terraform binary, preferring the CLI-managed pinned install over PATH.
- **`verboseRunner`** – wraps `*tfexec.Terraform` to stream human-readable output only for `Init`/`Plan`, avoiding polluting the terminal with huge JSON blobs during `ApplyJSON`/`DestroyJSON`.
- **`Engine.Init`, `Engine.Apply`, `Engine.Destroy`** – run the corresponding terraform lifecycle steps, with `Apply`/`Destroy` streaming JSON progress and logging to a per-workspace `terraform.log` file (`OpLogName`).
- **`bestEffortTee`** – tees output to a log file without ever failing the actual terraform operation on a log write error.
- **`assertClusterWorkspace`** – guardrail ensuring `Destroy` only runs against a directory containing a generated `main.tf`.
- **`Engine.Plan` / `Engine.PlanForApply`** – run `terraform plan`, returning a `PlanSummary` of resource changes; `PlanForApply` retains the plan file for a subsequent exact apply.
- **`PlanSummary` / `PlanChange`** – structured representation of planned resource additions, changes, and deletions, including raw plan JSON for cost estimation.

## Usage Example

```go
engine := terraform.NewEngine(true) // verbose mode

ctx := context.Background()
dir := "/home/user/.openframe/clusters/mycluster"

if err := engine.Init(ctx, dir); err != nil {
    log.Fatal(err)
}

summary, planFile, err := engine.PlanForApply(ctx, dir)
if err != nil {
    log.Fatal(err)
}
defer os.Remove(planFile)

if summary.HasChanges() {
    fmt.Printf("Add: %d, Change: %d, Destroy: %d\n",
        summary.Add, summary.Change, summary.Destroy)
}

if err := engine.Apply(ctx, dir); err != nil {
    log.Fatal(err)
}
```
