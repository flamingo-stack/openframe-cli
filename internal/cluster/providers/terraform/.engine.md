## Overview

`engine.go` implements the `Engine` type, a thin wrapper around HashiCorp's `terraform-exec` library that drives `init`/`plan`/`apply`/`destroy`/`output` for a workspace's terraform directory. It adds progress streaming, per-workspace operation logging, safety checks against destructive misuse, and a testable seam via the `Runner` interface.

## Key Components

- **`Runner`** — interface subset of `*tfexec.Terraform` used by the engine, enabling tests without a real terraform binary.
- **`Engine`** — orchestrates terraform operations; holds a `newRunner` constructor seam and a `verbose` flag.
- **`FindTerraform()`** — locates the terraform binary, preferring the CLI-managed pinned install over PATH.
- **`NewEngine(verbose bool) *Engine`** — production constructor; in verbose mode wraps the runner in `verboseRunner` to stream human-readable output without leaking machine-readable JSON to the terminal.
- **`NewEngineWithRunner(newRunner)`** — test constructor injecting a custom `Runner` factory.
- **`(*Engine).Init/Apply/Destroy/Plan/PlanForApply`** — core operations; `Apply`/`Destroy` stream JSON progress and tee output into a per-workspace `terraform.log` (`OpLogName`) via `bestEffortTee`, which never fails the operation due to logging errors.
- **`assertClusterWorkspace`** — guards `Destroy` against running outside a CLI-generated workspace (requires a `main.tf`).
- **`PlanSummary` / `PlanChange`** — structured summary of a terraform plan's resource-level create/update/delete actions, including raw plan JSON for cost estimation.

## Usage Example

```go
engine := terraform.NewEngine(true) // verbose output

ctx := context.Background()
workDir := "/home/user/.openframe/clusters/mycluster"

if err := engine.Init(ctx, workDir); err != nil {
    log.Fatal(err)
}

summary, err := engine.Plan(ctx, workDir)
if err != nil {
    log.Fatal(err)
}
if summary.HasChanges() {
    fmt.Printf("plan: %d to add, %d to change, %d to destroy\n",
        summary.Add, summary.Change, summary.Destroy)
}

if err := engine.Apply(ctx, workDir); err != nil {
    log.Fatal(err)
}

// Later, tear down the cluster (requires main.tf present in workDir)
if err := engine.Destroy(ctx, workDir); err != nil {
    log.Fatal(err)
}
```
