## Overview

`engine.go` implements the `Engine` type, a thin wrapper around HashiCorp's `terraform-exec` library that drives `terraform init/plan/apply/destroy/output` for a workspace directory. It abstracts the terraform binary behind a testable `Runner` interface, adds verbose/quiet output control, best-effort operation logging, and safety guardrails before destructive operations.

## Key Components

- **`Runner`** — interface subset of `*tfexec.Terraform` used by the engine, enabling tests without a real terraform binary.
- **`Engine`** — orchestrates terraform commands via an injected `newRunner` factory; holds a `verbose` flag controlling whether terraform's human output streams to the terminal.
- **`FindTerraform()`** — resolves the terraform binary, preferring the CLI-managed pinned install over `PATH`.
- **`NewEngine(verbose bool)`** — production constructor; wraps the runner in `verboseRunner` when verbose mode is enabled.
- **`NewEngineWithRunner(newRunner)`** — test constructor for injecting a mock `Runner`.
- **`verboseRunner`** — decorates `*tfexec.Terraform` to stream `Init`/`Plan` human output to stdout without leaking machine-readable JSON (e.g., `terraform show -json`) into the terminal.
- **`Engine.Init/Apply/Destroy/Plan/PlanForApply`** — core lifecycle operations; `Apply`/`Destroy` stream JSON progress and tee it into a per-workspace `terraform.log` (`OpLogName`) via `bestEffortTee`, which never fails the operation on log-write errors.
- **`assertClusterWorkspace`** — guardrail ensuring `Destroy` only runs in a directory containing a generated `main.tf`, preventing accidental destroys outside CLI-managed workspaces.
- **`PlanSummary` / `PlanChange`** — structured summary of a terraform plan's resource-level actions (create/update/delete), including raw plan JSON for optional cost estimation.

## Usage Example

```go
engine := terraform.NewEngine(true) // verbose mode

ctx := context.Background()
dir := "/home/user/.openframe/clusters/mycluster"

if err := engine.Init(ctx, dir); err != nil {
    log.Fatal(err)
}

summary, err := engine.Plan(ctx, dir)
if err != nil {
    log.Fatal(err)
}
if summary.HasChanges() {
    fmt.Printf("Plan: %d to add, %d to change, %d to destroy\n",
        summary.Add, summary.Change, summary.Destroy)
}

if err := engine.Apply(ctx, dir); err != nil {
    log.Fatal(err) // check terraform.log in dir for full output
}

// Later, tear down the workspace (requires a valid main.tf in dir):
if err := engine.Destroy(ctx, dir); err != nil {
    log.Fatal(err)
}
```
