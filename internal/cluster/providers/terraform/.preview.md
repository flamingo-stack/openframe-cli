## Overview

`preview.go` provides functionality for preparing a temporary directory to run a Terraform preview (plan) against an existing workspace. It selectively copies only the state and backend configuration needed to generate an accurate diff, without carrying over the previously generated module files.

This supports the CLI's "preview before apply" workflow: rather than reusing stale generated Terraform files, the preview regenerates the module from the current template and flags (same as a resume operation), while still diffing against the real existing state.

## Key Components

- **`CopyPlanInputs(srcDir, dstDir string) error`** — Copies `terraform.tfstate` and `backend.tf` from an existing workspace directory (`srcDir`) into a throwaway preview directory (`dstDir`). Missing files are silently skipped (e.g., a workspace that never completed its first apply has no state yet). Any other read/write error is returned immediately.

## Usage Example

```go
package main

import (
	"log"
	"os"
)

func main() {
	// srcDir: existing workspace under ~/.openframe managed by the CLI
	srcDir := "/home/user/.openframe/workspaces/my-cluster"

	// dstDir: a throwaway temp directory for the preview run
	dstDir, err := os.MkdirTemp("", "openframe-preview-")
	if err != nil {
		log.Fatal(err)
	}
	defer os.RemoveAll(dstDir)

	if err := CopyPlanInputs(srcDir, dstDir); err != nil {
		log.Fatalf("failed to prepare preview inputs: %v", err)
	}

	// dstDir now contains terraform.tfstate and backend.tf (if they existed).
	// The caller regenerates the Terraform module in dstDir and runs `terraform plan`.
}
```

## Notes

- File paths are managed internally by the CLI under the user's `~/.openframe` directory, so path-traversal linter warnings (`#nosec G304`, `#nosec G703`) are explicitly suppressed.
- Copied state files are written with restrictive permissions (`0o600`).
