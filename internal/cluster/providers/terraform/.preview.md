Utility for preparing a throwaway Terraform working directory used to preview changes against an existing workspace's real state, without carrying over the generated module.

## Key Components

- **`CopyPlanInputs(srcDir, dstDir string) error`** — Copies only the essential inputs needed to preview a plan for an existing workspace:
  - `terraform.tfstate` — the local state file, used as the diff base
  - `backend.tf` — the backend configuration, required so a remote-state workspace previews against its actual remote state

  The generated Terraform module itself is intentionally **not** copied. Instead, the preview flow regenerates the module from the current template and flags (mirroring how `CreateCluster`/resume works), ensuring the plan accurately reflects what a resume operation would apply.

  Missing source files are tolerated (e.g., a workspace that never completed its first apply has no state yet) and simply skipped rather than causing an error.

## Usage Example

```go
package main

import (
	"log"
	"os"

	"github.com/flamingo-stack/openframe-cli/internal/terraform" // adjust import path as needed
)

func main() {
	srcDir := "/home/user/.openframe/workspaces/my-cluster"
	dstDir, err := os.MkdirTemp("", "preview-*")
	if err != nil {
		log.Fatal(err)
	}
	defer os.RemoveAll(dstDir)

	if err := terraform.CopyPlanInputs(srcDir, dstDir); err != nil {
		log.Fatalf("failed to prepare preview inputs: %v", err)
	}

	// dstDir now contains terraform.tfstate and/or backend.tf (if they existed),
	// ready for module generation and `terraform plan`.
}
```

## Notes

- Files are written with restrictive permissions (`0o600`) since the destination is a private temp directory created via `os.MkdirTemp`.
- `srcDir` is expected to be a CLI-managed path under `~/.openframe`, and `dstDir` is the caller's own temporary directory — both trusted contexts, as noted by the `#nosec` annotations.
