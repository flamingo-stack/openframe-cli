## Overview

This file provides a helper function for staging inputs required to generate a Terraform preview plan for an existing workspace, without copying the workspace's generated module files. It supports a "dry-run" style workflow by isolating only the necessary state and backend configuration into a temporary directory.

## Key Components

- **`CopyPlanInputs(srcDir, dstDir string) error`** — Copies `terraform.tfstate` and `backend.tf` from a source workspace directory (`srcDir`) into a destination throwaway directory (`dstDir`). These two files are the minimum needed for Terraform to compute an accurate diff against real remote state. The Terraform module itself is intentionally excluded, since the preview should regenerate it fresh from the current template and flags—mirroring the behavior of a resume/`CreateCluster` operation. Missing source files (e.g., a workspace that never completed its first apply) are silently skipped rather than treated as errors.

## Usage Example

```go
package main

import (
	"log"
	"os"
)

func main() {
	// srcDir is the existing, CLI-managed workspace directory
	srcDir := os.Getenv("HOME") + "/.openframe/workspaces/my-cluster"

	// dstDir is a throwaway directory created for the preview run
	dstDir, err := os.MkdirTemp("", "openframe-preview-")
	if err != nil {
		log.Fatal(err)
	}
	defer os.RemoveAll(dstDir)

	if err := terraform.CopyPlanInputs(srcDir, dstDir); err != nil {
		log.Fatalf("failed to prepare preview inputs: %v", err)
	}

	// dstDir now contains terraform.tfstate and backend.tf (if they existed)
	// ready for module generation and `terraform plan`
}
```

## Notes

- File permissions on written files are restricted to `0o600` for security.
- `srcDir` is expected to be a CLI-managed path under `~/.openframe`, and `dstDir` should be a fresh directory created via `os.MkdirTemp`, as reflected in the `#nosec` annotations.
