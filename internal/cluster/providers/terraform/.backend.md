## backend.go

Handles opt-in remote Terraform state configuration for OpenFrame CLI clusters. By default, Terraform state remains local to the workspace; this file supports parsing and writing remote backend configuration (S3 for EKS, GCS for GKE) when explicitly requested via a `--backend-config` flag.

## Key Components

- **`BackendConfig`** — Struct holding a parsed backend definition (`Scheme`, `Bucket`, `Prefix`).
- **`backendPartRE`** — Regex restricting bucket/prefix values to safe characters (`A-Za-z0-9._/-`), providing defense-in-depth validation before values are interpolated into generated HCL.
- **`ParseBackendURL(raw string) (BackendConfig, error)`** — Parses a `scheme://bucket[/prefix]` string, validating the scheme (`s3` or `gcs`) and the bucket/prefix format.
- **`(*Workspace) WriteBackend(backendTF []byte) error`** — Writes the generated `backend.tf` file into the workspace's Terraform directory, creating the directory if needed.

## Usage Example

```go
// Parse a user-supplied backend URL
cfg, err := terraform.ParseBackendURL("s3://my-tfstate-bucket/openframe/prod")
if err != nil {
    log.Fatalf("invalid backend config: %v", err)
}

fmt.Println(cfg.Scheme) // "s3"
fmt.Println(cfg.Bucket) // "my-tfstate-bucket"
fmt.Println(cfg.Prefix) // "openframe/prod"

// Render backend.tf HCL for the chosen provider, then write it
backendHCL := renderS3BackendHCL(cfg) // caller-provided rendering logic
if err := workspace.WriteBackend(backendHCL); err != nil {
    log.Fatalf("failed to write backend.tf: %v", err)
}
```

**Notes:**
- Only `s3://` (EKS) and `gcs://` (GKE) schemes are supported.
- Bucket and prefix values are validated against a strict character set before being written into generated HCL files.
- `WriteBackend` creates the workspace's Terraform directory (mode `0o750`) if it doesn't exist and writes `backend.tf` with restrictive permissions (`0o600`).
