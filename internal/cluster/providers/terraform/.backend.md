## backend.go

Handles optional remote Terraform state backend configuration for the `terraform` package. By default, workspaces use local Terraform state; this file enables opt-in remote state via S3 (for EKS) or GCS (for GKE) backends, protecting against state loss if the local machine is unavailable.

## Key Components

- **`BackendConfig`** — struct representing a parsed backend URL, with `Scheme` (`"s3"` or `"gcs"`), `Bucket`, and `Prefix` fields.
- **`backendPartRE`** — regex restricting bucket/prefix values to safe characters (letters, digits, `.`, `_`, `-`, `/`) as defense-in-depth when generating HCL.
- **`ParseBackendURL(raw string) (BackendConfig, error)`** — parses a `scheme://bucket/prefix` string (e.g. `s3://my-bucket/path`) into a `BackendConfig`, validating the scheme and character set.
- **`(*Workspace) WriteBackend(backendTF []byte) error`** — writes the rendered `backend.tf` HCL content into the workspace's Terraform directory, creating the directory if needed.

## Usage Example

```go
package main

import (
	"log"
)

func main() {
	cfg, err := terraform.ParseBackendURL("s3://my-cluster-state/eks/prod")
	if err != nil {
		log.Fatalf("invalid backend config: %v", err)
	}

	// cfg.Scheme == "s3"
	// cfg.Bucket == "my-cluster-state"
	// cfg.Prefix == "eks/prod"

	// Render backend.tf HCL using cfg, then write it to the workspace.
	backendHCL := renderS3BackendHCL(cfg) // application-specific rendering

	ws := terraform.NewWorkspace(/* ... */)
	if err := ws.WriteBackend(backendHCL); err != nil {
		log.Fatalf("failed to write backend.tf: %v", err)
	}
}
```

If `--backend-config` is not provided, the workspace simply omits `WriteBackend`, and Terraform falls back to local state storage.
