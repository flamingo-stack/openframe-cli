## backend.go

Handles optional remote Terraform state configuration for the `terraform` package. Remote state (S3 for EKS, GCS for GKE) is opt-in via a `--backend-config` flag; by default, Terraform state remains local to the workspace. This file parses and validates the backend URL, then writes the generated `backend.tf` file into the workspace's Terraform directory.

## Key Components

- **`BackendConfig`** — Struct representing a parsed backend URL, with `Scheme` (`s3` or `gcs`), `Bucket`, and `Prefix` fields.
- **`backendPartRE`** — Regular expression restricting bucket/prefix values to safe characters (`A-Za-z0-9._/-`) before they are interpolated into generated HCL, providing defense-in-depth validation.
- **`ParseBackendURL(raw string) (BackendConfig, error)`** — Parses a `scheme://bucket[/prefix]` string, validating the scheme (`s3` or `gcs`) and the bucket/prefix character set. Returns a descriptive error on invalid input.
- **`(w *Workspace) WriteBackend(backendTF []byte) error`** — Creates the workspace's Terraform directory (if needed) and writes the provided rendered HCL bytes to `backend.tf`.

## Usage Example

```go
package main

import (
	"fmt"
	"log"
)

func main() {
	cfg, err := terraform.ParseBackendURL("s3://my-cluster-state/prod/eks")
	if err != nil {
		log.Fatalf("invalid backend config: %v", err)
	}
	fmt.Printf("scheme=%s bucket=%s prefix=%s\n", cfg.Scheme, cfg.Bucket, cfg.Prefix)

	// Render backend.tf HCL for the given scheme/bucket/prefix,
	// then persist it into the workspace.
	backendHCL := []byte(fmt.Sprintf(`terraform {
  backend "%s" {
    bucket = "%s"
    prefix = "%s"
  }
}`, cfg.Scheme, cfg.Bucket, cfg.Prefix))

	ws := &terraform.Workspace{ /* ... */ }
	if err := ws.WriteBackend(backendHCL); err != nil {
		log.Fatalf("failed to write backend.tf: %v", err)
	}
}
```

**Note:** Only `s3://` and `gcs://` schemes are supported. Invalid schemes or bucket/prefix values containing disallowed characters return an error before any file is written.
