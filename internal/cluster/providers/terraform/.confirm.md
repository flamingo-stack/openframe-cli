Handles user confirmation and visual rendering of Terraform plan changes before applying infrastructure modifications, ensuring destructive changes are clearly surfaced to the user.

## Key Components

- **`ConfirmApplyInteractive(summary PlanSummary) bool`** — Pre-apply confirmation gate. Auto-approves if there are no changes or the session is non-interactive; otherwise renders the plan diff and prompts the user for explicit confirmation.
- **`RenderPlanDiff(summary PlanSummary)`** — Prints a color-coded, git-style diff of planned Terraform changes, grouped by action type (`+` create, `~` update, `-` destroy, `-/+` replace), followed by a summary count line and a warning if any destructive changes are present.

## Usage Example

```go
package main

import (
	"github.com/flamingo-stack/openframe-cli/internal/terraform"
)

func main() {
	summary := terraform.PlanSummary{
		Add:     3,
		Change:  1,
		Destroy: 1,
		Changes: []terraform.PlanChange{
			{Action: "+", Address: "aws_instance.web"},
			{Action: "-", Address: "aws_instance.old"},
		},
	}

	if terraform.ConfirmApplyInteractive(summary) {
		// proceed with terraform apply
	} else {
		// abort apply
	}
}
```

`ConfirmApplyInteractive` is typically called right before invoking `terraform apply`, giving users a final chance to review and confirm changes—especially important when the plan includes resource destruction.
