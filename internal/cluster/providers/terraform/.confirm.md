Handles the interactive confirmation gate that runs before applying a Terraform plan, rendering a grouped, colored diff and prompting the user to approve destructive or non-trivial changes.

## Key Components

- **`ConfirmApplyInteractive(summary PlanSummary) bool`** — Entry point for the pre-apply confirmation flow. Auto-approves when the plan has no changes or the session is non-interactive; otherwise renders the plan diff and prompts the user with a yes/no confirmation summarizing add/change/destroy counts.
- **`RenderPlanDiff(summary PlanSummary)`** — Prints the plan changes grouped by action (`+` creates, `~` updates, `-` destroys, `-/+` replaces) with color-coded output, followed by a summary counts line. Emits an explicit warning banner when destructive changes (`Destroy > 0`) are present.

## Usage Example

```go
package main

import (
	"fmt"

	"github.com/flamingo-stack/openframe-cli/internal/terraform"
)

func main() {
	summary := terraform.PlanSummary{
		Add:     3,
		Change:  1,
		Destroy: 1,
		Changes: []terraform.PlanChange{
			{Action: "+", Address: "aws_instance.web[0]"},
			{Action: "~", Address: "aws_instance.web[1]"},
			{Action: "-", Address: "aws_security_group.old"},
		},
	}

	if terraform.ConfirmApplyInteractive(summary) {
		fmt.Println("Applying plan...")
	} else {
		fmt.Println("Apply cancelled")
	}
}
```

In non-interactive contexts (e.g., CI pipelines), `ConfirmApplyInteractive` skips the prompt and returns `true` automatically, matching prior scripted `create` behavior while preserving the safer default for interactive terminal sessions.
