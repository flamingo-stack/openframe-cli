## confirm.go

Provides an interactive confirmation gate for applying Terraform plans, rendering a colored, action-grouped diff of planned changes before prompting the user to approve or reject the apply.

## Key Components

- **`ConfirmApplyInteractive(summary PlanSummary) bool`** — The default pre-apply gate for cluster creation. Auto-approves when there are no changes or the session is non-interactive; otherwise renders the plan diff and prompts the user for confirmation.
- **`RenderPlanDiff(summary PlanSummary)`** — Prints a git-style colored diff of the plan, grouped by action (creates, then updates, then destroys/replaces) instead of plan order, followed by a colored summary line and a warning if any resources will be destroyed.

## Usage Example

```go
package main

import "github.com/flamingo-stack/openframe-cli/internal/terraform"

func applyPlan(summary terraform.PlanSummary) error {
	if !terraform.ConfirmApplyInteractive(summary) {
		return fmt.Errorf("apply cancelled by user")
	}

	// proceed with terraform apply
	return runTerraformApply()
}
```

Typical output when destructive changes are present:

```text
  +   aws_instance.web
  ~   aws_security_group.default
  -   aws_s3_bucket.old_logs

Plan: 1 to add, 1 to change, 1 to destroy
This plan DESTROYS resources — review the red lines above before applying
```

`RenderPlanDiff` can also be called independently to display a plan summary without requiring confirmation, useful for dry-run or verbose logging scenarios.
