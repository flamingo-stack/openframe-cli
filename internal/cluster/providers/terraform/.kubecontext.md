## kubecontext.go

This file provides helpers for checking whether a given context (or a context matching a custom predicate) actually exists in the user's kubeconfig, avoiding the pitfall of fabricating a context name from a cluster name when no real kubeconfig entry exists.

Kubeconfig contexts are only merged after a successful `terraform apply`/cluster create. This means a workspace whose provisioning failed at plan time will have no corresponding kubeconfig entry. These functions ensure that cluster listing logic reflects that reality instead of assuming a context exists just because a cluster name is known.

## Key Components

- **`KubeconfigHasContext(name string) bool`** — Reports whether the kubeconfig (loaded via default rules: `$KUBECONFIG` or `~/.kube/config`) contains an exact context match for `name`. Returns `false` on any load error, treating errors as "no context" rather than guessing.
- **`KubeconfigContextMatching(match func(name string) bool) string`** — Loads the kubeconfig, sorts all context names deterministically, and returns the first one for which `match` returns `true`. Returns `""` if the config can't be loaded or no context matches. Useful for recognizing provider-specific naming conventions (e.g., AWS EKS ARN-style contexts, GKE's `gke_<project>_<location>_<name>` format).

## Usage Example

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	// Exact match check
	if KubeconfigHasContext("my-cluster") {
		fmt.Println("Context 'my-cluster' exists in kubeconfig")
	}

	// Custom matching, e.g. find a GKE-style context for a cluster name
	clusterName := "my-cluster"
	found := KubeconfigContextMatching(func(name string) bool {
		return strings.HasSuffix(name, "_"+clusterName)
	})

	if found != "" {
		fmt.Printf("Matched kubeconfig context: %s\n", found)
	} else {
		fmt.Println("No matching context found — cluster may not be provisioned yet")
	}
}
```

Callers should use these functions—rather than assuming a context name from the cluster name—whenever populating a `CONTEXT` column or deciding whether `kubectl`/Terraform can reach a cluster.
