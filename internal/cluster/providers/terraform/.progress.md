# progress.go

Implements a streaming writer that parses Terraform's `-json` machine-readable output and prints concise, human-friendly progress lines using `pterm`. This allows long-running `terraform apply` operations to show live per-resource progress instead of raw JSON.

## Key Components

- **`applyEvent`** — Struct representing the relevant subset of Terraform's JSON-UI event schema (`@level`, `@message`, `type`).
- **`progressLine(line []byte, verbose bool) (string, bool)`** — Parses a single JSON event line and decides whether/how to display it. In non-verbose mode, only meaningful event types (`planned_change`, `apply_start`, `apply_complete`, `apply_errored`, `change_summary`, and error-level `diagnostic`) are surfaced. In verbose mode, every event message is forwarded.
- **`progressWriter`** — An `io.Writer` implementation that buffers partial writes, splits them into complete lines, and feeds each line through `progressLine` for display.
- **`newProgressWriter(verbose bool) io.Writer`** — Constructor returning a ready-to-use `progressWriter`.

## Usage Example

```go
package terraform

import (
	"os/exec"
)

func runApply(verbose bool) error {
	cmd := exec.Command("terraform", "apply", "-json", "-auto-approve")

	w := newProgressWriter(verbose)
	cmd.Stdout = w
	cmd.Stderr = w

	return cmd.Run()
}
```

As Terraform streams JSON lines to stdout, `progressWriter.Write` buffers and splits them, then prints filtered, readable progress messages (e.g., plan details, apply start/complete, and errors) via `pterm.DefaultBasicText`, respecting silent/verbose modes.
