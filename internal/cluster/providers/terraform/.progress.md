# progress.go

Implements a streaming writer that parses Terraform's `-json` machine-readable output (one JSON object per line) and prints concise, human-friendly progress lines during long-running `apply` operations. It filters out noise (refresh/progress ticks) unless verbose mode is enabled, and respects pterm's silent output settings.

## Key Components

- **`applyEvent`** — Struct mapping the relevant subset of Terraform's JSON-UI event schema (`@level`, `@message`, `type`).
- **`progressLine(line []byte, verbose bool) (string, bool)`** — Parses a single JSON event line and decides whether/what to display. In non-verbose mode, only shows `planned_change`, `apply_start`, `apply_complete`, `apply_errored`, `change_summary`, and error-level `diagnostic` events. Verbose mode forwards every event message.
- **`progressWriter`** — An `io.Writer` implementation that buffers partial writes, splits them into complete lines, and prints formatted progress output via `pterm`.
- **`newProgressWriter(verbose bool) io.Writer`** — Constructor that returns a ready-to-use `progressWriter`.

## Usage Example

```go
package main

import (
	"os/exec"
)

func runTerraformApply(verbose bool) error {
	writer := newProgressWriter(verbose)

	cmd := exec.Command("terraform", "apply", "-json", "-auto-approve")
	cmd.Stdout = writer
	cmd.Stderr = writer

	return cmd.Run()
}
```

When Terraform emits JSON-UI lines like:

```json
{"@level":"info","@message":"aws_instance.example: Creating...","type":"apply_start"}
```

`progressWriter` prints:

```text
  aws_instance.example: Creating...
```

Partial writes (e.g., a line split across two `Write` calls) are buffered internally until a full `\n`-terminated line is available, ensuring reliable JSON parsing regardless of how the underlying process streams output.
