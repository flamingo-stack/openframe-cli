# workspace.go

Implements the persistent, on-disk workspace layout for cloud cluster backends (e.g. EKS) under `~/.openframe/clusters/<name>/`. It manages the registry record (`cluster.json`), the generated Terraform root module, and safe read/write/scaffold operations that treat the Terraform state file as the authoritative record of billed cloud resources.

## Key Components

- **`Status`** — lifecycle enum (`StatusCreating`, `StatusReady`, `StatusFailed`) with a `Title()` method for display formatting, tolerant of empty/unknown values.
- **`Record`** — JSON-serializable registry entry for a cluster (name, type, status, region, provider-specific fields, node count, HA flag, endpoint, CA cert, timestamps).
- **`Workspace`** — represents one cluster's directory; provides `Scaffold`, `ReadRecord`, `WriteRecord`, `SetStatus`, `Remove`, `Exists`, `Dir`, `TerraformDir`.
- **`Registry`** — enumerates all cluster workspaces under a base directory; provides `List`, `Get`, `Workspace`.
- **`WriteModule`** — writes `main.tf` and `terraform.tfvars.json` into a target directory (used both for real workspaces and throwaway plan-preview dirs).
- **`DefaultBaseDir` / `DefaultRegistry`** — resolve the base directory (respecting `OPENFRAME_CLUSTERS_DIR` override) and open the default registry.
- **`OpenWorkspace`** — addresses a workspace path without creating it.

## Usage Example

```go
registry, err := terraform.DefaultRegistry()
if err != nil {
    log.Fatal(err)
}

ws := registry.Workspace("my-cluster")

record := terraform.Record{
    Name:      "my-cluster",
    Type:      models.ClusterTypeEKS,
    Status:    terraform.StatusCreating,
    Region:    "us-east-1",
    NodeCount: 3,
    CreatedAt: time.Now(),
}

// Write generated Terraform files + initial record.
if err := ws.Scaffold(record, mainTFBytes, tfvarsStruct); err != nil {
    log.Fatal(err)
}

// After a successful apply, update status.
if err := ws.SetStatus(terraform.StatusReady); err != nil {
    log.Fatal(err)
}

// List all known clusters.
records, err := registry.List()
```

Note: `Workspace.Remove` and re-`Scaffold` must only occur after a successful `terraform destroy`, since the `terraform.tfstate` file is the sole pointer to live, billed cloud resources.
