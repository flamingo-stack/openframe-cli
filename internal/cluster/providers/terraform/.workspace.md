## Overview

`workspace.go` implements the persistent, file-based registry for cloud cluster (e.g., EKS) workspaces used by the `terraform` package. It manages the on-disk layout under `~/.openframe/clusters/<name>/` — containing the generated Terraform root module, tfvars, state file, and a JSON registry record (`cluster.json`) tracking cluster metadata and lifecycle status. The design intentionally never deletes a workspace on failed operations, since the Terraform state file is the sole reliable reference to potentially billed cloud resources.

## Key Components

- **`Status`** — Type representing cluster lifecycle state (`StatusCreating`, `StatusReady`, `StatusFailed`), with a `Title()` method for display formatting.
- **`Record`** — Struct persisted as `cluster.json`, holding cluster metadata (name, type, status, region, provider-specific fields, node count, HA flag, endpoint, CA cert).
- **`Workspace`** — Represents a single cluster's directory. Key methods:
  - `Scaffold` — creates directories and writes the initial module/tfvars/record, refusing to overwrite existing state.
  - `ReadRecord` / `WriteRecord` — load/persist `cluster.json` (atomic write via temp file + rename).
  - `SetStatus` — updates only the status field.
  - `Remove` — deletes the workspace (only safe after successful destroy).
  - `Exists`, `Dir`, `TerraformDir` — path/state helpers.
- **`WriteModule`** — Writes `main.tf` and `terraform.tfvars.json` to any directory (used by both real workspaces and plan previews).
- **`Registry`** — Lists and retrieves cluster workspaces under a base directory (`List`, `Get`, `Workspace`).
- **`DefaultBaseDir` / `DefaultRegistry`** — Resolve the default registry location (`~/.openframe/clusters`, overridable via `$OPENFRAME_CLUSTERS_DIR`).

## Usage Example

```go
registry, err := terraform.DefaultRegistry()
if err != nil {
    log.Fatal(err)
}

ws := registry.Workspace("my-cluster")

record := terraform.Record{
    Name:      "my-cluster",
    Status:    terraform.StatusCreating,
    Region:    "us-east-1",
    NodeCount: 3,
    CreatedAt: time.Now(),
}

if err := ws.Scaffold(record, mainTFBytes, tfvarsStruct); err != nil {
    log.Fatal(err)
}

// After a successful apply:
if err := ws.SetStatus(terraform.StatusReady); err != nil {
    log.Fatal(err)
}

// List all registered clusters:
records, err := registry.List()
```
