# workspace.go

Implements the on-disk workspace layout and registry for provider-neutral cloud cluster state, persisted under `~/.openframe/clusters/<name>/`. Each workspace holds a `cluster.json` registry record plus a generated Terraform root module and its local state file, which is treated as the authoritative pointer to any billed cloud resources.

## Key Components

- **`Status`** — Lifecycle enum (`StatusCreating`, `StatusReady`, `StatusFailed`) with a `Title()` method for display-friendly capitalization, tolerant of missing/unknown values.
- **`Record`** — Persisted registry entry (`cluster.json`) capturing cluster type, status, region, provider-specific fields (profile/project), node count, HA flag, and Terraform outputs (endpoint, CA cert).
- **`Workspace`** — Represents one cluster's directory. Key methods:
  - `Dir()` / `TerraformDir()` — path accessors.
  - `Exists()` — checks for a registry record.
  - `Scaffold(record, mainTF, tfvars)` — creates the workspace and writes the initial module/record, refusing to overwrite existing Terraform state.
  - `ReadRecord()` / `WriteRecord(r)` — load/persist `cluster.json`, with atomic temp-file + rename writes to avoid truncation.
  - `SetStatus(s)` — updates only the lifecycle status.
  - `Remove()` — deletes the workspace (only safe after a successful destroy).
- **`WriteModule(dir, mainTF, tfvars)`** — Standalone helper to write `main.tf` and `terraform.tfvars.json` into any directory (used by both real workspaces and throwaway plan previews).
- **`Registry`** — Enumerates workspaces under a base directory:
  - `NewRegistry(base)` / `DefaultRegistry()` — construct against `~/.openframe/clusters` or `$OPENFRAME_CLUSTERS_DIR`.
  - `Workspace(name)` — open a specific workspace.
  - `List()` — returns all readable cluster records, skipping unreadable/non-workspace directories.
  - `Get(name)` — returns a record or `models.ErrClusterNotFound`.
- **`DefaultBaseDir()`** — Resolves the registry base path, honoring the `OPENFRAME_CLUSTERS_DIR` environment override.

## Usage Example

```go
registry, err := terraform.DefaultRegistry()
if err != nil {
    log.Fatal(err)
}

ws := registry.Workspace("my-eks-cluster")

if !ws.Exists() {
    record := terraform.Record{
        Name:   "my-eks-cluster",
        Type:   models.ClusterTypeEKS,
        Status: terraform.StatusCreating,
        Region: "us-east-1",
    }
    if err := ws.Scaffold(record, mainTF, tfvars); err != nil {
        log.Fatal(err)
    }
}

// After a successful terraform apply:
if err := ws.SetStatus(terraform.StatusReady); err != nil {
    log.Fatal(err)
}

// List all registered clusters:
records, err := registry.List()
if err != nil {
    log.Fatal(err)
}
for _, r := range records {
    fmt.Println(r.Name, r.Status.Title())
}
```
