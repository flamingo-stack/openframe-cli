## cost.go

Provides optional cost estimation for Terraform plans by integrating with the [infracost](https://www.infracost.io) CLI. Cost figures are only ever sourced from infracost's live output — no pricing values are hardcoded, and if infracost is unavailable or fails, callers must fall back to a generic pricing pointer rather than fabricated numbers.

## Key Components

- **`InfracostAvailable() bool`** — Checks whether the `infracost` binary is reachable, preferring the CLI-managed install directory (`~/.openframe/bin`) over a bare `PATH` lookup, since each CLI invocation is a fresh process.
- **`infracostBreakdown`** — Internal struct mapping the relevant fields (`totalMonthlyCost`, `currency`) from `infracost breakdown --format json` output.
- **`EstimateMonthlyCost(ctx, execer, planJSON) (string, error)`** — Writes the given Terraform plan JSON to a temporary file, runs `infracost breakdown` against it (bounded by a 60-second timeout independent of the parent context), parses the resulting JSON, and returns a human-readable estimate like `"142.53 USD"`. Returns an error on any failure (missing plan, missing API key, network issues, unparseable output).

## Usage Example

```go
if terraform.InfracostAvailable() {
    estimate, err := terraform.EstimateMonthlyCost(ctx, execer, planJSON)
    if err != nil {
        // Fall back to a generic pricing hint — never guess a number.
        fmt.Println("Cost estimate unavailable:", err)
    } else {
        fmt.Println("Estimated monthly cost:", estimate)
    }
} else {
    fmt.Println("Install infracost to see a monthly cost estimate.")
}
```

Typical flow: check `InfracostAvailable()` before attempting estimation during a `terraform plan` dry-run preview, then call `EstimateMonthlyCost` with the plan JSON output and a `sharedexec.CommandExecutor` to execute the `infracost` command.
