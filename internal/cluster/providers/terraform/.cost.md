## Overview

Provides optional cost estimation for Terraform plans by integrating with the [infracost](https://www.infracost.io) CLI. This is a strictly opt-in feature: if infracost isn't installed or configured, no cost figures are shown or fabricated—only a pointer to the cloud provider's pricing page is offered elsewhere in the CLI.

## Key Components

- **`InfracostAvailable() bool`** — Checks whether the `infracost` binary is reachable on `$PATH`, first prepending the CLI-managed bin directory (`~/.openframe/bin`) so installs made by this CLI are detected even in a fresh process.
- **`infracostBreakdown`** — Internal struct mapping the relevant fields (`totalMonthlyCost`, `currency`) from `infracost breakdown --format json` output.
- **`EstimateMonthlyCost(ctx, execer, planJSON) (string, error)`** — Writes the given Terraform plan JSON to a temp file, runs `infracost breakdown` against it with a 60-second timeout, and returns a formatted string like `"142.53 USD"`. Any failure (missing API key, network issue, unparseable output) returns an error rather than a guessed value.

## Usage Example

```go
if terraform.InfracostAvailable() {
    estimate, err := terraform.EstimateMonthlyCost(ctx, executor, planJSON)
    if err != nil {
        // Fall back to a generic pricing-page hint; never fabricate a cost.
        fmt.Println("Cost estimate unavailable:", err)
    } else {
        fmt.Println("Estimated monthly cost:", estimate)
    }
} else {
    fmt.Println("Install infracost for cost estimates: https://www.infracost.io")
}
```

## Notes

- Cost estimation always runs with its own bounded timeout (60s) since the network call to infracost's pricing API must never stall the parent operation (e.g., a `terraform plan` dry-run preview).
- The temporary plan file is written with `0o600` permissions and cleaned up automatically via `defer`.
- If `Currency` is missing from infracost's output, it defaults to `"USD"`.
