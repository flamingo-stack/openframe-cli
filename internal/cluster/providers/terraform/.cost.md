## cost.go

Provides optional cost estimation for Terraform plans by integrating with the [infracost](https://www.infracost.io) CLI. Cost figures are never hardcoded or guessed — if `infracost` is unavailable or fails, callers must fall back to a generic pricing hint instead of fabricated numbers.

## Key Components

- **`InfracostAvailable() bool`** — Checks whether the `infracost` binary is reachable, prioritizing the CLI-managed install directory (`~/.openframe/bin`) before falling back to `PATH` lookup. This ensures the binary is found even within a fresh process per CLI invocation.
- **`infracostBreakdown`** — Internal struct mapping the relevant fields (`totalMonthlyCost`, `currency`) from `infracost breakdown --format json` output.
- **`EstimateMonthlyCost(ctx context.Context, execer sharedexec.CommandExecutor, planJSON []byte) (string, error)`** — Writes the given Terraform plan JSON to a temporary file, runs `infracost breakdown` against it with a 60-second timeout, and parses the result into a human-readable string like `"142.53 USD"`. Returns an error on any failure (missing plan, execution failure, unparseable output, or missing cost data).

## Usage Example

```go
if terraform.InfracostAvailable() {
    estimate, err := terraform.EstimateMonthlyCost(ctx, execer, planJSON)
    if err != nil {
        // Fall back to a generic pricing hint — never fabricate a cost.
        fmt.Println("Cost estimate unavailable:", err)
    } else {
        fmt.Println("Estimated monthly cost:", estimate)
    }
} else {
    fmt.Println("Install infracost for cost estimates: https://www.infracost.io")
}
```

## Notes

- The temporary plan file is written with restrictive permissions (`0o600`) and cleaned up automatically via `defer`.
- A dedicated 60-second timeout is applied independently of the parent context, since `infracost` makes a network call to its pricing API and must not stall the overall dry-run flow.
- Currency defaults to `"USD"` if the `infracost` output omits it.
