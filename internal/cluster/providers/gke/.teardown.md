# teardown.go

Implements GKE cluster teardown safety logic that prevents orphaned, billable Persistent Disks from surviving cluster destruction. It handles two complementary phases: releasing PVC-backed disks *before* terraform destroy, and sweeping for any orphaned disks that survive *after* destroy.

## Key Components

- **`releaseWorkloadDisks(ctx, rec)`** — Best-effort pre-destroy step. Deletes all application namespaces (via Kubernetes API) so the GKE CSI driver releases PVC-provisioned Persistent Disks before terraform destroys the node pool, since those disks live outside terraform state.
- **`appNamespacesToDelete(all)`** — Filters out system namespaces and orders `argocd` first, so its controller stops reconciling before managed workloads are deleted.
- **`isSystemNamespace(ns)`** — Identifies cluster/control-plane namespaces (`default`, `kube-system`, `kube-*`, `gke-*`, `gmp-*`) that must never be deleted.
- **`countDeletablePVs(pvs)`** — Counts PersistentVolumes with `Delete` reclaim policy, used to detect when disk drain is complete.
- **`(*Provider) sweepOrphanedDisks(ctx, project, name, location, force)`** — Post-destroy cleanup. Lists disks labeled for the destroyed cluster, scopes them to the correct location, and deletes them with operator consent (`--force` or interactive prompt), otherwise prints a manual cleanup hint.
- **`disksInLocation(disks, location)`** — Scopes candidate disks to the cluster's region/zone, since GKE cluster names are unique per location, not per project.
- **`parseDisks(out)`** — Parses tab-separated `gcloud compute disks list` output into `disk` structs, correctly preserving empty columns for regional disks.
- **`disk`** — Represents a labeled Persistent Disk with `name`, `zone`, and `region`; `location()` resolves the effective location.
- **`printOrphanList` / `printOrphanCleanupHint`** — User-facing output for reporting surviving disks and manual cleanup commands.

## Usage Example

```go
// Before terraform destroy: attempt to release PVC-backed disks
releaseWorkloadDisks(ctx, tfRecord)

// ... terraform destroy runs here ...

// After destroy: sweep for any orphaned disks left behind
provider.sweepOrphanedDisks(ctx, "my-gcp-project", "my-cluster", "us-central1", force)
```

Both functions are designed to be **best-effort and non-blocking**: failures (unreachable cluster, RBAC errors, timeouts) are logged via `pterm.Debug`/`pterm.Warning` but never halt the teardown flow. `diskDrainTimeout` (5 min) bounds the wait for disk release, and `kubeCallTimeout` (20s) bounds individual API calls.
