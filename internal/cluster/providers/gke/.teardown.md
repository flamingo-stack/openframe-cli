# teardown.go

Implements safe teardown logic for GKE clusters, ensuring that PVC-backed Persistent Disks (which live outside terraform state) are released before `terraform destroy` runs, and sweeps up any orphaned disks that survive the destroy.

## Key Components

- **`isSystemNamespace(ns string) bool`** — Determines if a namespace is a system/control-plane namespace that must never be deleted (e.g. `kube-system`, `default`, and `kube-`/`gke-`/`gmp-` prefixed namespaces).
- **`appNamespacesToDelete(all []string) []string`** — Returns application namespaces to delete, ordered with `argocd` first so its controller stops re-syncing before dependent workloads are removed.
- **`countDeletablePVs(pvs []corev1.PersistentVolume) int`** — Counts PersistentVolumes with a `Delete` reclaim policy, used to detect when disk release has completed.
- **`releaseWorkloadDisks(ctx context.Context, rec tfengine.Record)`** — Deletes application namespaces and polls (bounded by `diskDrainTimeout`) until backing disks are released by the CSI driver, before terraform destroys the node pool. Fully best-effort; never blocks the destroy.
- **`disk` struct** — Represents a labeled Persistent Disk found during the post-destroy sweep, with `zone`/`region` and a `location()` helper.
- **`disksInLocation(disks []disk, location string) []disk`** — Filters disks to only those belonging to the deleted cluster's specific location, since GKE cluster names are unique per location, not per project.
- **`(*Provider) sweepOrphanedDisks(ctx, project, name, location string, force bool)`** — Lists disks labeled for the destroyed cluster and deletes them with operator consent (`--force` flag or interactive confirmation), or prints a manual cleanup hint.
- **`printOrphanList` / `printOrphanCleanupHint`** — Helper output functions for reporting surviving disks and cleanup instructions.
- **`parseDisks(out string) []disk`** — Parses tab-separated `gcloud compute disks list` output into `disk` values, preserving empty columns for regional disks.

## Usage Example

```go
// Before destroying the cluster infrastructure, release workload disks
// so the CSI driver deletes their backing Persistent Disks first.
releaseWorkloadDisks(ctx, record)

// ... terraform destroy runs here ...

// After destroy, sweep for any orphaned disks still labeled for this cluster.
provider.sweepOrphanedDisks(ctx, "my-gcp-project", "my-cluster", "us-central1", force)
```

This logic is invoked internally as part of the GKE provider's cluster deletion workflow, ensuring no billable orphaned disks are left behind after teardown.
