Defines a structured error wrapper for the `gke` package that attaches a "resume hint" to an error, ensuring the hint survives generic interruption handling (e.g., Ctrl+C) which normally discards the error's message text.

## Key Components

- **`resumeHintError`** - A struct implementing the `error` interface that wraps an underlying error along with a `hint` string, exposing the hint via a `ResumeHint()` method rather than embedding it in the error message.
- **`resumeHintError.Error()`** - Returns the underlying error's message, preserving standard error text.
- **`resumeHintError.Unwrap()`** - Supports Go's `errors.Unwrap`/`errors.Is`/`errors.As` chain by exposing the wrapped error.
- **`resumeHintError.ResumeHint()`** - Returns the attached hint string, intended to be picked up by `internal/shared/errors` even when an operation is interrupted.
- **`withResumeHint(err error, hint string) error`** - Constructor function that wraps an error with a resume hint.

## Usage Example

```go
func setupCluster() error {
	if err := runGKECommand(); err != nil {
		return withResumeHint(err, "Run 'openframe gke resume' to continue setup")
	}
	return nil
}
```

This pattern ensures that even if the operation is interrupted (e.g., via Ctrl+C) and the generic handler only prints "Operation cancelled by user.", downstream error handling in `internal/shared/errors` can still retrieve and display the resume hint by calling `ResumeHint()` on the error, guiding the user on how to continue.
