Defines a structured error wrapper that preserves a resumable-command hint even when an operation is interrupted (e.g., via Ctrl+C), ensuring guidance isn't silently discarded by the generic interruption handler in the GKE package.

## Key Components

- **`resumeHintError`** — a struct implementing the `error` interface that wraps an underlying error alongside a `hint` string. It provides:
  - `Error() string` — returns the wrapped error's message
  - `Unwrap() error` — supports Go's `errors.Unwrap`/`errors.Is`/`errors.As` chains
  - `ResumeHint() string` — exposes the hint separately from the error message, so callers (like `internal/shared/errors`) can retrieve it even when `Error()` text is discarded
- **`withResumeHint(err error, hint string) error`** — helper function that wraps a given error with a resume hint, returning it as a `*resumeHintError`.

## Usage Example

```go
package gke

func doClusterOperation() error {
	if err := someLongRunningStep(); err != nil {
		return withResumeHint(err, "run `openframe gke resume` to continue from where it left off")
	}
	return nil
}

// Elsewhere, a generic interruption handler catches Ctrl+C and prints
// "Operation cancelled by user." but can still surface the resume hint:
func handleInterrupt(err error) {
	type resumeHinter interface {
		ResumeHint() string
	}
	if rh, ok := err.(resumeHinter); ok {
		fmt.Println("Operation cancelled by user.")
		fmt.Println("Hint:", rh.ResumeHint())
	}
}
```

This pattern ensures that even when an operation is cancelled mid-flight, users are still told how to resume it, instead of losing that context because only `err.Error()` was inspected.
