Defines a structured error wrapper that attaches a resumable-command hint to an error, ensuring the hint survives generic interruption handling (e.g., Ctrl+C) that otherwise discards the error message text.

## Key Components

- **`resumeHintError`** — A struct implementing the `error` interface that wraps an underlying error along with a `hint` string suggesting how to resume the operation.
- **`Error() string`** — Returns the wrapped error's message, satisfying the standard `error` interface.
- **`Unwrap() error`** — Returns the underlying wrapped error, enabling compatibility with `errors.Is`/`errors.As`.
- **`ResumeHint() string`** — Returns the attached hint string. This method is used by `internal/shared/errors` to extract and display the hint even when the operation was interrupted (e.g., via Ctrl+C), since the generic interruption handler discards `err.Error()`.
- **`withResumeHint(err error, hint string) error`** — Helper function that wraps an error with a resume hint, attaching it structurally rather than embedding it in the error message text.

## Usage Example

```go
func provisionCluster() error {
	if err := runProvisioningStep(); err != nil {
		return withResumeHint(err, "openframe gke create --resume my-cluster")
	}
	return nil
}
```

When this error propagates up through the CLI's interruption handler, the handler can check for a `ResumeHint() string` method via a type assertion and display the hint to the user, even though it only prints "Operation cancelled by user." and ignores `err.Error()` in the Ctrl+C path.
