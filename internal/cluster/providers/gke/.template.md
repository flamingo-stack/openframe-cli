## template.go

This file defines the GKE-specific Terraform template logic for the OpenFrame CLI, translating a validated `ClusterConfig` into `terraform.tfvars.json` values consumed by the embedded static `main.tf` module, and enforcing GKE-specific configuration invariants.

## Key Components

- **`mainTF`** — embedded byte slice of `templates/main.tf`, the static root Terraform module for GKE clusters. All cluster-specific values are passed via tfvars rather than HCL templating.
- **`tfvars`** — struct mirroring the variable block of `main.tf` (cluster name, project, region, node pool sizing, machine type, spot instances, etc.), serialized to JSON.
- **`tfvarsFor(config models.ClusterConfig) (tfvars, error)`** — maps a `ClusterConfig` to `tfvars`, normalizing the Kubernetes version (stripping `v` prefix, mapping `"latest"` to GKE's default) and validating it against the `<major>.<minor>` format via `gkeVersionRE`.
- **`effectiveMaxNodes(maxNodes, nodeCount int) int`** — computes the effective autoscaler max when `--max-nodes` is omitted, ensuring the desired node count doesn't exceed the template default (`templateDefaultMaxNodes = 4`) and fail mid-apply.
- **`validate(config models.ClusterConfig) error`** — enforces GKE domain rules: valid cluster name, correct cluster type, required `region`/`project`, non-negative and consistent min/max node bounds, and that `NodeCount` falls within those bounds.

## Usage Example

```go
config := models.ClusterConfig{
    Name:       "my-cluster",
    Type:       models.ClusterTypeGKE,
    K8sVersion: "v1.33",
    NodeCount:  6,
    Cloud: &models.CloudConfig{
        Project:     "my-gcp-project",
        Region:      "us-central1",
        MachineType: "e2-standard-4",
        MaxNodes:    0, // unset, will grow to cover NodeCount
    },
}

if err := validate(config); err != nil {
    log.Fatal(err)
}

vars, err := tfvarsFor(config)
if err != nil {
    log.Fatal(err)
}
// vars can now be marshaled to JSON and written as terraform.tfvars.json
```
