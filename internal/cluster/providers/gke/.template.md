## template.go

Defines the Terraform templating layer for GKE cluster provisioning within the `gke` package. It embeds the static root Terraform module and translates a validated `models.ClusterConfig` into the JSON-encoded `terraform.tfvars.json` values consumed by that module, along with domain-level validation of GKE-specific config constraints.

## Key Components

- **`mainTF`** — embedded byte slice containing the static `templates/main.tf` root module. No HCL templating is performed; all per-cluster customization flows through tfvars.
- **`tfvars`** — struct mirroring the variables block of `main.tf` (cluster name, project, region, zone, Kubernetes version, instance type, node bounds, spot flag), tagged for JSON serialization.
- **`tfvarsFor(config models.ClusterConfig) (tfvars, error)`** — maps a `ClusterConfig` to `tfvars`, normalizing the Kubernetes version (stripping `v` prefix, mapping `"latest"` to empty) and validating it matches GKE's `<major>.<minor>` format.
- **`effectiveMaxNodes(maxNodes, nodeCount int) int`** — computes the max node bound to write into tfvars. If `--max-nodes` is unset and the requested node count exceeds the template default (`templateDefaultMaxNodes = 4`), it raises the max to accommodate the requested count, avoiding a mid-apply autoscaler rejection.
- **`validate(config models.ClusterConfig) error`** — enforces GKE-specific invariants: valid cluster name, correct cluster type, required region/project, non-negative and consistent min/max node bounds, and that `NodeCount` falls within `[MinNodes, MaxNodes]`.
- **`gkeVersionRE`** — regex validating Kubernetes version strings against GKE's `<major>.<minor>` format.

## Usage Example

```go
config := models.ClusterConfig{
    Name:       "my-cluster",
    Type:       models.ClusterTypeGKE,
    K8sVersion: "v1.33",
    NodeCount:  6,
    Cloud: &models.CloudConfig{
        Project:     "my-gcp-project",
        Region:      "us-central1",
        MachineType: "e2-standard-4",
        MaxNodes:    0, // unset, will grow to cover NodeCount
    },
}

if err := validate(config); err != nil {
    // handle invalid configuration
}

vars, err := tfvarsFor(config)
if err != nil {
    // handle version parsing error
}
// vars can now be marshaled to terraform.tfvars.json alongside mainTF
```
