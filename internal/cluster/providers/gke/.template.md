## Overview

`template.go` implements the GKE-specific Terraform template binding for the OpenFrame CLI's cluster provisioning system. It embeds a static root Terraform module (`templates/main.tf`) and translates a validated `models.ClusterConfig` into a `tfvars` struct that is serialized to `terraform.tfvars.json`, avoiding any HCL templating.

## Key Components

- **`mainTF`** — Embedded byte slice containing the static `templates/main.tf` Terraform module.
- **`tfvars`** — Struct mirroring the variables block of the Terraform template (cluster name, project, region, node pool sizing, etc.).
- **`tfvarsFor(config models.ClusterConfig) (tfvars, error)`** — Maps a `ClusterConfig` into `tfvars`, normalizing the Kubernetes version (stripping `v` prefix, mapping `"latest"` to empty) and validating it against the `<major>.<minor>` format GKE expects.
- **`effectiveMaxNodes(maxNodes, nodeCount int) int`** — Ensures `--nodes` remains authoritative when `--max-nodes` is unset by growing the autoscaler max to cover the requested node count instead of failing mid-apply.
- **`validate(config models.ClusterConfig) error`** — Enforces GKE-specific invariants (valid cluster name, correct cluster type, required region/project, non-negative and consistent node bounds, desired node count within min/max) before any infrastructure is provisioned.

## Usage Example

```go
config := models.ClusterConfig{
    Name:       "my-cluster",
    Type:       models.ClusterTypeGKE,
    K8sVersion: "v1.33",
    NodeCount:  6,
    Cloud: &models.CloudConfig{
        Project:     "my-gcp-project",
        Region:      "us-central1",
        MachineType: "e2-standard-4",
        MaxNodes:    0, // unset, will grow to cover NodeCount
    },
}

if err := validate(config); err != nil {
    log.Fatalf("invalid cluster config: %v", err)
}

vars, err := tfvarsFor(config)
if err != nil {
    log.Fatalf("failed to build tfvars: %v", err)
}

data, _ := json.MarshalIndent(vars, "", "  ")
os.WriteFile("terraform.tfvars.json", data, 0644)
```

This validates the config, builds the corresponding `tfvars`, and writes it alongside the embedded `main.tf` for `terraform apply`.
