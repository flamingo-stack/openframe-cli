Manages kubeconfig generation and lifecycle for GKE clusters, integrating client-go's exec-based authentication (via `gke-gcloud-auth-plugin`) instead of static credentials, and safely merging/removing cluster contexts in the user's default kubeconfig (honoring `$KUBECONFIG`).

## Key Components

- **`execConfig()`** — Builds the `ExecConfig` pointing to `gke-gcloud-auth-plugin`, used for all GKE auth entries so tokens are minted fresh from the operator's gcloud identity.
- **`caData(rec tfengine.Record)`** — Decodes the base64-encoded CA certificate from a Terraform-produced cluster record.
- **`kubeconfigFor(rec tfengine.Record)`** — Builds a standalone in-memory `clientcmdapi.Config` with a single cluster/context/auth-info, all named after the cluster.
- **`restConfigFor(rec tfengine.Record)`** — Builds a `rest.Config` directly from a cluster record for programmatic Kubernetes API access (bypassing kubeconfig files).
- **`mergeIntoDefaultKubeconfig(rec tfengine.Record)`** — Writes the cluster's context into the user's default kubeconfig and sets it as current context. Refuses to overwrite an existing same-named context that points at a different server, preventing accidental clobbering of unrelated clusters.
- **`removeFromDefaultKubeconfig(rec tfengine.Record)`** — Removes the cluster's context from the default kubeconfig after a destroy, but only if the entry still points at the same endpoint (mirrors the merge guard).

## Usage Example

```go
rec := tfengine.Record{
    Name:     "my-gke-cluster",
    Endpoint: "https://34.123.45.67",
    CACert:   "LS0tLS1CRUdJTi...", // base64-encoded CA cert
}

// Merge cluster context into the user's default kubeconfig
if err := mergeIntoDefaultKubeconfig(rec); err != nil {
    log.Fatalf("failed to update kubeconfig: %v", err)
}

// Or build a rest.Config for direct API access
restCfg, err := restConfigFor(rec)
if err != nil {
    log.Fatalf("failed to build rest config: %v", err)
}

// On teardown, remove the context if it still belongs to this cluster
if err := removeFromDefaultKubeconfig(rec); err != nil {
    log.Printf("warning: failed to clean up kubeconfig: %v", err)
}
```
