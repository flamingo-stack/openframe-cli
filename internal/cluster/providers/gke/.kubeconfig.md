# kubeconfig.go

Manages kubeconfig generation and lifecycle for GKE clusters, using the `gke-gcloud-auth-plugin` exec plugin for short-lived, credential-free authentication instead of static tokens.

## Key Components

- **`execConfig()`** — Builds an `ExecConfig` pointing to `gke-gcloud-auth-plugin`, which mints tokens on-demand from the operator's `gcloud` identity.
- **`caData(rec tfengine.Record)`** — Decodes the base64-encoded CA certificate bundle produced by the GKE Terraform module.
- **`kubeconfigFor(rec tfengine.Record)`** — Constructs an in-memory `clientcmdapi.Config` with a single cluster/context/auth-info set, all keyed by the cluster's plain name for exact-match resolution.
- **`restConfigFor(rec tfengine.Record)`** — Builds a `rest.Config` directly from a `tfengine.Record`, useful for programmatic Kubernetes API access without writing a file.
- **`mergeIntoDefaultKubeconfig(rec tfengine.Record)`** — Merges the generated context into the user's default kubeconfig (respecting `$KUBECONFIG`) and sets it as current context. Refuses to overwrite an existing same-named context pointing at a different server, to avoid clobbering unrelated access.
- **`removeFromDefaultKubeconfig(rec tfengine.Record)`** — Removes the cluster's context from the default kubeconfig after a destroy operation, but only if the entry still points at the same endpoint — mirroring the no-clobber safeguard from the merge function.

## Usage Example

```go
rec := tfengine.Record{
    Name:     "my-gke-cluster",
    Endpoint: "https://34.123.45.67",
    CACert:   base64EncodedCA,
}

// Merge cluster credentials into the user's default kubeconfig
if err := mergeIntoDefaultKubeconfig(rec); err != nil {
    log.Fatalf("failed to update kubeconfig: %v", err)
}

// Or build a rest.Config for direct API access
restCfg, err := restConfigFor(rec)
if err != nil {
    log.Fatalf("failed to build rest config: %v", err)
}

// On teardown
if err := removeFromDefaultKubeconfig(rec); err != nil {
    log.Fatalf("failed to clean up kubeconfig: %v", err)
}
```
