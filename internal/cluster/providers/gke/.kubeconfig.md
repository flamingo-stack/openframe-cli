# kubeconfig.go

Manages kubeconfig generation and lifecycle for GKE clusters, wiring in the `gke-gcloud-auth-plugin` exec-based authentication (no static credentials are stored) and safely merging/removing cluster contexts in the user's default kubeconfig.

## Key Components

- **`execConfig() *clientcmdapi.ExecConfig`** — Builds the exec plugin configuration that delegates authentication to `gke-gcloud-auth-plugin`, ensuring short-lived tokens are minted from the operator's gcloud identity.
- **`caData(rec tfengine.Record) ([]byte, error)`** — Decodes the base64-encoded CA certificate bundle from a Terraform-produced cluster record.
- **`kubeconfigFor(rec tfengine.Record) (*clientcmdapi.Config, error)`** — Renders an in-memory `clientcmdapi.Config` with a single cluster/context/auth-info entry named after the cluster.
- **`restConfigFor(rec tfengine.Record) (*rest.Config, error)`** — Builds a `rest.Config` directly from a cluster record, useful for programmatic Kubernetes API access without writing a kubeconfig file.
- **`mergeIntoDefaultKubeconfig(rec tfengine.Record) error`** — Writes the cluster's context into the user's default kubeconfig (respecting `$KUBECONFIG`) and sets it as current. Refuses to overwrite a same-named context pointing at a different server.
- **`removeFromDefaultKubeconfig(rec tfengine.Record) error`** — Removes the cluster's context from the default kubeconfig after a destroy, but only if the entry still points at the same endpoint (mirrors the merge guard).

## Usage Example

```go
import tfengine "github.com/flamingo-stack/openframe-cli/internal/cluster/providers/terraform"

rec := tfengine.Record{
    Name:     "my-gke-cluster",
    Endpoint: "https://34.123.45.67",
    CACert:   base64EncodedCA,
}

// Merge the cluster into the user's default kubeconfig
if err := mergeIntoDefaultKubeconfig(rec); err != nil {
    log.Fatalf("failed to update kubeconfig: %v", err)
}

// Or build a rest.Config for direct API usage
restCfg, err := restConfigFor(rec)
if err != nil {
    log.Fatalf("failed to build rest config: %v", err)
}

// On teardown
if err := removeFromDefaultKubeconfig(rec); err != nil {
    log.Fatalf("failed to clean up kubeconfig: %v", err)
}
```

This file is used internally by the GKE provider during cluster create/destroy flows to keep the user's `kubectl` context in sync with provisioned infrastructure, without ever persisting long-lived credentials to disk.
