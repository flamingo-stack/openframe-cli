## Overview

Implements the `Provider` for creating and managing Google Kubernetes Engine (GKE) clusters via a shared Terraform engine. It builds and drives a Terraform root module (pinned `terraform-google-modules/kubernetes-engine` + network modules) inside a per-cluster workspace, handling preflight checks, orphan-resource detection, and plan/apply/destroy flows.

## Key Components

- **`Provider`** — main struct wrapping the Terraform engine, cluster registry, command executor, and an optional interactive apply confirmation callback.
- **`New(exec, verbose)`** — production constructor; wires up the default `~/.openframe/clusters` registry and interactive apply confirmation.
- **`NewWithDeps(engine, registry, exec)`** — test constructor for dependency injection.
- **`PlanCluster(ctx, config)`** — runs a side-effect-free `terraform plan` preview (throwaway workspace, using current template/flags; copies real state/backend for existing workspaces).
- **`preflightCredentials`** — verifies gcloud auth and project access before running Terraform.
- **`ensureProjectServices`** — idempotently enables required GCP APIs (`compute.googleapis.com`, `container.googleapis.com`) outside of Terraform state.
- **`preflightNameCollision`** — blocks creation if a cluster name already exists in GCP but isn't openframe-managed.
- **`ensureZone` / `firstZoneInRegion`** — deterministically resolves a zone for non-HA (zonal) clusters.
- **`orphanFromInterruptedCreate(err, terraformDir)`** — detects GCP 409/`alreadyExists` errors caused by interrupted creates and returns actionable remediation (delete or `terraform import`).
- **`backendTF` / `parseBackend`** — generate and validate the GCS remote-state backend configuration.

## Usage Example

```go
exec := executor.NewShellExecutor()
provider, err := gke.New(exec, true /* verbose */)
if err != nil {
    log.Fatal(err)
}

config := models.ClusterConfig{
    Name: "my-cluster",
    Cloud: &models.CloudConfig{
        Project: "my-gcp-project",
        Region:  "us-central1",
    },
}

// Preview changes without side effects
summary, err := provider.PlanCluster(context.Background(), config)
if err != nil {
    log.Fatal(err)
}
fmt.Println(summary)
```

Related workspace layout and Terraform engine details are documented in `internal/cluster/providers/terraform`.
