## Overview

Implements the `Provider` type for creating and managing Google Kubernetes Engine (GKE) clusters through the shared terraform engine. It generates a terraform root module per cluster workspace, runs preflight checks against GCP (credentials, project APIs, name collisions), and drives terraform init/plan/apply/destroy for the cluster lifecycle.

## Key Components

- **`Provider`** — struct that provisions and manages GKE clusters, wrapping a terraform `Engine`, a workspace `Registry`, a `CommandExecutor`, and an optional `confirmApply` hook for interactive apply confirmation.
- **`New(exec, verbose)`** — production constructor; builds a `Provider` with the default `~/.openframe/clusters` registry.
- **`NewWithDeps(engine, registry, exec)`** — test constructor for injecting fakes/mocks.
- **`PlanCluster(ctx, config)`** — runs a dry-run terraform plan in a throwaway directory (copying existing state/backend when resuming a workspace), without mutating the real workspace.
- **`preflightCredentials`** — verifies gcloud authentication and project access before any terraform runs.
- **`ensureProjectServices`** — idempotently enables required GCP APIs (`compute.googleapis.com`, `container.googleapis.com`).
- **`preflightNameCollision`** — refuses to create a cluster whose name already exists in GCP but isn't tracked by openframe.
- **`ensureZone` / `firstZoneInRegion`** — resolves a deterministic zone for zonal (non-HA) clusters.
- **`orphanFromInterruptedCreate(err, terraformDir)`** — detects GCP "already exists" (409) errors caused by an interrupted create, returning actionable remediation (delete or `terraform import`).
- **`backendTF` / `parseBackend`** — render and validate the GCS remote-state backend configuration.

## Usage Example

```go
exec := executor.NewShellExecutor()
provider, err := gke.New(exec, true /* verbose */)
if err != nil {
    log.Fatal(err)
}

config := models.ClusterConfig{
    Name: "my-cluster",
    Cloud: &models.CloudConfig{
        Project: "my-gcp-project",
        Region:  "us-central1",
    },
}

// Preview changes without side effects
summary, err := provider.PlanCluster(context.Background(), config)
if err != nil {
    log.Fatal(err)
}
fmt.Println(summary)
```
