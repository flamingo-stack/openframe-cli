## Overview

Implements the `cluster.Provider` interface for Google Kubernetes Engine, driving cluster provisioning through the shared terraform engine (`internal/cluster/providers/terraform`). It generates a versioned root terraform module into the cluster's workspace, runs preflight checks against GCP (credentials, required APIs, name collisions), and manages the full create/plan/destroy lifecycle.

## Key Components

- **`Provider`** — struct holding the terraform engine, workspace registry, command executor, and an optional interactive apply-confirmation hook.
- **`New(exec, verbose)`** — production constructor using the default `~/.openframe/clusters` registry.
- **`NewWithDeps(engine, registry, exec)`** — test constructor for dependency injection.
- **`PlanCluster(ctx, config)`** — runs a side-effect-free `terraform plan` preview, rebuilding the module/tfvars from current config and copying in existing state/backend if the workspace already exists.
- **`orphanFromInterruptedCreate(err, terraformDir)`** — detects GCP `409 alreadyExists` errors caused by an interrupted create, returning actionable remediation (import or manual delete) instead of a generic retry hint.
- **`preflightCredentials(ctx, project)`** — validates gcloud auth and project access before any terraform run.
- **`ensureProjectServices(ctx, project)`** — idempotently enables required GCP APIs (`compute.googleapis.com`, `container.googleapis.com`), tolerating permission failures if APIs are already on.
- **`preflightNameCollision(ctx, config)`** — blocks creation if a cluster name already exists in GCP but isn't openframe-managed.
- **`firstZoneInRegion` / `ensureZone`** — deterministically resolve a zone for non-HA (zonal) clusters.
- **`backendTF` / `parseBackend`** — build and validate the GCS terraform backend configuration.

## Usage Example

```go
exec := executor.NewCommandExecutor()
provider, err := gke.New(exec, true)
if err != nil {
    log.Fatal(err)
}

config := models.ClusterConfig{
    Name: "my-cluster",
    Cloud: &models.CloudConfig{
        Project: "my-gcp-project",
        Region:  "us-central1",
    },
}

// Preview changes before applying
summary, err := provider.PlanCluster(context.Background(), config)
if err != nil {
    log.Fatal(err)
}
fmt.Println(summary)
```

Note: `CreateCluster` (referenced but truncated in this file) completes the lifecycle by applying the plan, registering the workspace, and configuring `kubectl` access via `k8s.io/client-go`.
