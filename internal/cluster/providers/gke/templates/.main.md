# main.tf

Root Terraform module generated and managed by the OpenFrame CLI to provision a self-contained GKE cluster on Google Cloud. It creates a dedicated VPC with pod/service secondary ranges, Cloud NAT for private-node egress, and a regional or zonal GKE cluster with a single autoscaling node pool. This file is CLI-owned and should not be edited by hand — all inputs are supplied via `terraform.tfvars.json`.

## Key Components

- **`terraform` block** — Pins Terraform `>= 1.15.0` and the `hashicorp/google` provider (`>= 7.17.0, < 8`).
- **Input variables** — `cluster_name`, `project`, `region`, `regional`, `zone`, `kubernetes_version`, `instance_type`, `min_nodes`, `max_nodes`, `desired_nodes`, `spot`.
- **`provider "google"`** — Configures project/region and applies default resource labels for CLI tracking.
- **`module.network`** — Uses `terraform-google-modules/network/google` to create a VPC with a primary subnet plus `pods` and `services` secondary IP ranges.
- **`google_compute_router.nat` / `google_compute_router_nat.nat`** — Cloud NAT setup enabling egress for private (no external IP) GKE nodes.
- **`module.gke`** — Uses the `terraform-google-modules/kubernetes-engine/google//modules/private-cluster` submodule to provision a private-node GKE cluster (public API endpoint) with one autoscaling node pool. Deletion protection is disabled to support `openframe cluster delete`.
- **Outputs** — `cluster_name`, `cluster_endpoint` (sensitive), `cluster_certificate_authority_data` (sensitive), `region`.

## Usage Example

This module is not intended to be invoked manually, but the CLI effectively runs:

```hcl
# terraform.tfvars.json (generated by the CLI)
{
  "cluster_name": "my-openframe-cluster",
  "project": "my-gcp-project",
  "region": "us-central1",
  "regional": false,
  "zone": "us-central1-a",
  "kubernetes_version": "1.33",
  "instance_type": "e2-standard-4",
  "min_nodes": 1,
  "max_nodes": 4,
  "desired_nodes": 3,
  "spot": false
}
```

```bash
terraform init
terraform apply -var-file="terraform.tfvars.json"
```

Retrieve cluster connection details from outputs:

```bash
terraform output cluster_name
terraform output -raw cluster_endpoint
terraform output -raw cluster_certificate_authority_data
```

**Note:** Project APIs (compute, container) must be enabled by the CLI beforehand — this module deliberately does not manage them to avoid ownership conflicts across shared-project clusters.
