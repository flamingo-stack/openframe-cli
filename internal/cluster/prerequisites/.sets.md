## sets.go

Defines the prerequisite sets required for each supported cluster type (local k3d, EKS, and GKE), wiring individual tool installers into the shared prerequisites framework used to validate and auto-install dependencies before cluster operations.

## Key Components

- **`ClusterSet()`** — Returns the prerequisite set for local k3d clusters: Docker (must be running, not just installed), k3d, and helm. Includes custom detail messaging when Docker is installed but not running.
- **`EKSSet()`** — Returns the prerequisite set for AWS EKS clusters: terraform and the AWS CLI. No local runtime tools required.
- **`GKESet()`** — Returns the prerequisite set for GCP GKE clusters: terraform, gcloud CLI, and gke-gcloud-auth-plugin.
- **`SetForClusterType(clusterType models.ClusterType) (fw.Set, error)`** — Dispatches to the correct prerequisite set based on cluster type (empty string defaults to k3d). Returns an error for unrecognized types.
- **`toolPrerequisite(...)`** — Internal helper that adapts a tool installer's `IsInstalled`/`Install`/`GetInstallHelp` methods into a `fw.Prerequisite`.
- **`asCtxInstall(...)`** — Internal helper adapting a no-argument `Install() error` function to the framework's `context.Context`-aware install signature.

## Usage Example

```go
import (
	"github.com/flamingo-stack/openframe-cli/internal/cluster/models"
	"github.com/flamingo-stack/openframe-cli/internal/cluster/prerequisites"
)

func ensureReady(clusterType models.ClusterType) error {
	set, err := prerequisites.SetForClusterType(clusterType)
	if err != nil {
		return err
	}

	// Validate/install prerequisites using the shared framework
	return set.Ensure(context.Background())
}
```

This is typically invoked before creating or managing a cluster, ensuring Docker/k3d/helm (local) or terraform plus the relevant cloud CLI (EKS/GKE) are available and properly configured, with platform-specific behavior: automatic installation on macOS/Linux, and manual setup guidance on Windows.
