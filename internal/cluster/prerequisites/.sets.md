## sets.go

Defines the prerequisite sets required for each supported cluster type (local k3d, AWS EKS, and Google GKE), wiring individual tool installers into the shared prerequisites framework (`fw.Set`).

## Key Components

- **`ClusterSet()`** — Builds the prerequisite set for local k3d clusters: Docker (must be running, not just installed), k3d, and helm. Includes custom `Detail` logic to distinguish "not installed" from "installed but not running" for Docker.
- **`EKSSet()`** — Builds the prerequisite set for AWS EKS clusters: terraform and the AWS CLI. No local runtime (Docker/k3d) is required.
- **`GKESet()`** — Builds the prerequisite set for Google GKE clusters: terraform, gcloud CLI, and gke-gcloud-auth-plugin.
- **`SetForClusterType(clusterType models.ClusterType) (fw.Set, error)`** — Dispatches to the correct set based on `models.ClusterType`, treating an empty type as the local k3d default. Returns an error for unrecognized types.
- **`toolPrerequisite(...)`** — Internal helper that adapts a tool installer's `IsInstalled`/`Install`/`GetInstallHelp` methods into a `fw.Prerequisite`.
- **`asCtxInstall(...)`** — Internal helper that wraps a no-arg `Install() error` function into the `context.Context`-aware signature expected by the framework.

## Usage Example

```go
import (
    "context"

    "github.com/flamingo-stack/openframe-cli/internal/cluster/models"
    "github.com/flamingo-stack/openframe-cli/internal/cluster/prerequisites"
)

func checkPrerequisites(ctx context.Context, clusterType models.ClusterType) error {
    set, err := prerequisites.SetForClusterType(clusterType)
    if err != nil {
        return err
    }

    // Pass `set` to the shared prerequisites framework runner to verify
    // or auto-install missing tools before creating the cluster.
    return runFrameworkChecks(ctx, set)
}
```

Each returned `fw.Set` contains the ordered list of `fw.Prerequisite` items relevant to that cluster type, ready to be validated or auto-installed by the shared `internal/prerequisites` framework.
