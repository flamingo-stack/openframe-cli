Defines the prerequisite set required for local cluster operations, bundling Docker (running), k3d, and Helm into a single `fw.Set` using the shared prerequisites framework.

## Key Components

| Symbol | Description |
|---|---|
| `ClusterSet()` | Returns an `fw.Set` named `"cluster"` containing prerequisites for Docker, k3d, and Helm |
| `toolPrerequisite()` | Adapter that maps the standard tool-installer interface (`IsInstalled`/`Install`/`GetInstallHelp`) to `fw.Prerequisite` |
| `asCtxInstall()` | Wraps a plain `func() error` install function to match the framework's `func(context.Context) error` signature |

## Usage Example

```go
// Verify (and optionally auto-install) all cluster prerequisites
// before provisioning a k3d cluster.
set := prerequisites.ClusterSet()

if err := set.Ensure(ctx); err != nil {
    log.Fatalf("cluster prerequisites not met: %v", err)
}
```

## Notes

- **Docker** receives special handling: when the binary is present but the daemon is stopped, the `Detail` function returns a targeted message directing the user to start Docker Desktop or the daemon, rather than the generic "not installed" fallback.
- **kubectl is intentionally excluded** — the CLI communicates with Kubernetes via `client-go` directly and does not require the `kubectl` binary.
- On **macOS/Linux**, the framework auto-installs missing tools; on **Windows**, it surfaces each missing dependency with manual setup guidance from `DocsURL`.
