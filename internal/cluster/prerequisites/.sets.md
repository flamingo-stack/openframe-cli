## sets.go

Defines the prerequisite sets required for each cluster type (local k3d, AWS EKS, GCP GKE), wiring individual tool installers into the shared `prerequisites` framework so the CLI can check, report, and (where possible) auto-install missing dependencies before cluster operations.

## Key Components

- **`ClusterSet() fw.Set`** — Prerequisites for local k3d clusters: Docker (must be *running*, not just installed), k3d, and helm. Includes custom `Detail` logic to distinguish "not installed" from "installed but daemon not running".
- **`EKSSet() fw.Set`** — Prerequisites for EKS clusters: terraform and the AWS CLI. No local runtime tools required.
- **`GKESet() fw.Set`** — Prerequisites for GKE clusters: terraform, gcloud CLI, and gke-gcloud-auth-plugin.
- **`SetForClusterType(clusterType models.ClusterType) (fw.Set, error)`** — Dispatches to the correct set based on cluster type; treats empty string as the k3d default; returns an error for unrecognized types.
- **`toolPrerequisite(name, isInstalled, install, help) fw.Prerequisite`** — Internal helper adapting the common tool-installer interface (`IsInstalled`/`Install`/`GetInstallHelp`) into a framework `Prerequisite`.
- **`asCtxInstall(install func() error) func(context.Context) error`** — Internal adapter wrapping a no-arg install function into the context-aware signature expected by the framework.

## Usage Example

```go
import (
    "github.com/flamingo-stack/openframe-cli/internal/cluster/models"
    "github.com/flamingo-stack/openframe-cli/internal/cluster/prerequisites"
)

func checkPrereqs(clusterType models.ClusterType) error {
    set, err := prerequisites.SetForClusterType(clusterType)
    if err != nil {
        return err
    }

    // Pass `set` to the shared prerequisites framework to verify
    // or install missing tools before proceeding with cluster creation.
    return runPrerequisiteFramework(set)
}
```

Each returned `fw.Set` bundles a name (e.g., `"cluster"`, `"eks"`, `"gke"`) with a list of `fw.Prerequisite` entries, each exposing a satisfaction check, an install action, and documentation link for manual setup on platforms where auto-install isn't supported.
