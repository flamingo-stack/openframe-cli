Provides installers for the Google Cloud CLI tooling required by the GKE provider: the `gcloud` CLI itself and the `gke-gcloud-auth-plugin` kubeconfig exec plugin used for GKE cluster authentication.

## Key Components

- **`GcloudInstaller`** - Checks for and installs the `gcloud` CLI.
  - `NewGcloudInstaller() *GcloudInstaller` - Constructor.
  - `IsInstalled() bool` - Verifies `gcloud` is on `$PATH` and runs successfully (`gcloud --version`, with a 10s timeout).
  - `GetInstallHelp() string` - Returns platform-specific install guidance via `platform.InstallHint`.
  - `Install() error` - On macOS, installs via Homebrew (`brew install --cask google-cloud-sdk`), requiring `brew` to be present first. On other OSes, returns an error directing the user to manual installation docs, since Linux setup is distribution-specific.

- **`AuthPluginInstaller`** - Checks for and installs `gke-gcloud-auth-plugin`.
  - `NewAuthPluginInstaller() *AuthPluginInstaller` - Constructor.
  - `IsInstalled() bool` - Checks if `gke-gcloud-auth-plugin` exists on `$PATH`.
  - `GetInstallHelp() string` - Returns platform-specific install guidance.
  - `Install() error` - Installs the plugin via `gcloud components install gke-gcloud-auth-plugin --quiet`. Requires `gcloud` to already be installed; fails with guidance if `gcloud` is missing or if the component install fails (e.g., when `gcloud` was installed via an OS package manager rather than the official installer).

- Internal test seams `lookPath` and `runQuiet` are package-level vars allowing tests to stub out binary lookup and command execution without invoking real `brew`/`gcloud` commands.

## Usage Example

```go
package main

import (
	"fmt"

	"github.com/flamingo-stack/openframe-cli/internal/provider/gke/gcloud"
)

func main() {
	installer := gcloud.NewGcloudInstaller()
	if !installer.IsInstalled() {
		if err := installer.Install(); err != nil {
			fmt.Println("Install failed:", installer.GetInstallHelp())
			return
		}
	}

	authPlugin := gcloud.NewAuthPluginInstaller()
	if !authPlugin.IsInstalled() {
		if err := authPlugin.Install(); err != nil {
			fmt.Println("Auth plugin install failed:", err)
		}
	}
}
```
