## gcloud.go

Provides installers for the Google Cloud CLI (`gcloud`) and the `gke-gcloud-auth-plugin` kubeconfig exec plugin, both required by the GKE provider for authenticating and interacting with Google Kubernetes Engine clusters.

## Key Components

- **`GcloudInstaller`** — Manages the `gcloud` CLI.
  - `NewGcloudInstaller() *GcloudInstaller` — constructor.
  - `IsInstalled() bool` — checks that `gcloud` exists on `$PATH` and responds to `gcloud --version` within a 10-second timeout.
  - `GetInstallHelp() string` — returns platform-specific install hints via `platform.InstallHint`.
  - `Install() error` — installs via Homebrew cask (`google-cloud-sdk`) on macOS; on other OSes returns an error directing the user to manual install docs, since Linux setup requires distro-specific repos.

- **`AuthPluginInstaller`** — Manages `gke-gcloud-auth-plugin`.
  - `NewAuthPluginInstaller() *AuthPluginInstaller` — constructor.
  - `IsInstalled() bool` — checks the plugin binary exists on `$PATH`.
  - `GetInstallHelp() string` — returns platform-specific install hints.
  - `Install() error` — installs via `gcloud components install gke-gcloud-auth-plugin --quiet`; fails fast if `gcloud` itself is missing.

- **Test seams** — Package-level vars `lookPath` (wraps `exec.LookPath`) and `runQuiet` (wraps command execution) allow install logic to be unit-tested without invoking real `brew`/`gcloud` binaries.

- **`commandExists(cmd string) bool`** — helper checking binary availability via `lookPath`.

## Usage Example

```go
package main

import (
	"fmt"

	"github.com/flamingo-stack/openframe-cli/internal/platform/gcloud"
)

func main() {
	installer := gcloud.NewGcloudInstaller()
	if !installer.IsInstalled() {
		if err := installer.Install(); err != nil {
			fmt.Println("gcloud install failed:", err)
			fmt.Println(installer.GetInstallHelp())
			return
		}
	}

	authPlugin := gcloud.NewAuthPluginInstaller()
	if !authPlugin.IsInstalled() {
		if err := authPlugin.Install(); err != nil {
			fmt.Println("auth plugin install failed:", err)
		}
	}
}
```

**Note:** Automatic installation is only supported on macOS (via Homebrew). On Linux and other platforms, `Install()` returns an error pointing to manual setup instructions from `GetInstallHelp()`.
