# gcloud.go

Provides installer implementations for the Google Cloud CLI (`gcloud`) and the `gke-gcloud-auth-plugin`, both required by the GKE cluster provider for authentication and cluster management.

## Key Components

- **`GcloudInstaller`** - Manages the `gcloud` CLI itself.
  - `NewGcloudInstaller() *GcloudInstaller` - Constructor.
  - `IsInstalled() bool` - Checks that `gcloud` exists on `$PATH` and `gcloud --version` succeeds within a 10-second timeout.
  - `GetInstallHelp() string` - Returns platform-specific install guidance via `platform.InstallHint`.
  - `Install() error` - On macOS, installs via Homebrew (`brew install --cask google-cloud-sdk`), requiring `brew` to be present first. On other platforms, automatic installation is unsupported and the user is directed to manual install docs (Linux requires distro-specific repo setup).

- **`AuthPluginInstaller`** - Manages `gke-gcloud-auth-plugin`, the kubeconfig exec plugin used to authenticate to GKE clusters.
  - `NewAuthPluginInstaller() *AuthPluginInstaller` - Constructor.
  - `IsInstalled() bool` - Checks whether the binary exists on `$PATH`.
  - `GetInstallHelp() string` - Returns platform-specific install guidance.
  - `Install() error` - Installs the plugin via `gcloud components install gke-gcloud-auth-plugin --quiet`, requiring `gcloud` to already be installed.

- **Test seams** - Package-level vars `lookPath` (wraps `exec.LookPath`) and `runQuiet` (wraps `exec.Command(...).Run()`) allow installer logic to be unit tested without invoking real `brew`/`gcloud` binaries.

## Usage Example

```go
installer := gcloud.NewGcloudInstaller()

if !installer.IsInstalled() {
    if err := installer.Install(); err != nil {
        fmt.Println(installer.GetInstallHelp())
        log.Fatal(err)
    }
}

authPlugin := gcloud.NewAuthPluginInstaller()
if !authPlugin.IsInstalled() {
    if err := authPlugin.Install(); err != nil {
        log.Fatal(err)
    }
}
```

Both installers are typically invoked as part of the GKE provider's dependency-resolution flow, ensuring prerequisites are satisfied before cluster operations proceed.
