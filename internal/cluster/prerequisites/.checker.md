Orchestrates prerequisite validation for the OpenFrame cluster setup by checking that Docker, k3d, and Helm are installed and available before cluster operations proceed.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `PrerequisiteChecker` | struct | Holds a list of `Requirement` entries to validate |
| `Requirement` | struct | Describes a single tool with name, command, install check, and help text |
| `NewPrerequisiteChecker()` | constructor | Returns a checker pre-loaded with Docker, k3d, and Helm requirements |
| `CheckAll()` | method | Iterates all requirements, returns `(allPresent bool, missing []string)` |
| `CheckPrerequisites()` | func | Top-level entry point; delegates to the non-interactive installer flow |

## Usage Example

```go
// Programmatic check — useful in tests or internal tooling
checker := prerequisites.NewPrerequisiteChecker()
ok, missing := checker.CheckAll()
if !ok {
    fmt.Printf("Missing prerequisites: %v\n", missing)
}

// Standard CLI entry point (respects CI / non-TTY environments)
if err := prerequisites.CheckPrerequisites(); err != nil {
    log.Fatal(err)
}
```

## Notes

- **Docker special-casing**: distinguishes between Docker not being installed vs. installed but not running, providing a targeted help message for each scenario.
- **Non-interactive safety**: `CheckPrerequisites` calls `ui.IsNonInteractive()` so CI pipelines or piped invocations never block on an interactive prompt.
- **Extensible**: add new tools by appending a `Requirement` entry to the slice in `NewPrerequisiteChecker`.
