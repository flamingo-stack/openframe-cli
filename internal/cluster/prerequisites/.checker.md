## checker.go

Defines the prerequisite requirement sets for each supported cluster type (local k3d, AWS EKS, GCP GKE) and provides functions to check and gate cluster operations on required CLI tools being installed.

## Key Components

- **`PrerequisiteChecker`** — holds a list of `Requirement` entries to validate.
- **`Requirement`** — struct describing a tool's name, command, and callbacks for checking installation status, retrieving install help text, and performing installation.
- **`NewPrerequisiteChecker()`** — builds the requirement set for local k3d clusters: Docker, k3d, and Helm.
- **`NewEKSPrerequisiteChecker()`** — builds the requirement set for EKS clusters: Terraform and AWS CLI.
- **`NewGKEPrerequisiteChecker()`** — builds the requirement set for GKE clusters: Terraform, gcloud CLI, and gke-gcloud-auth-plugin.
- **`(*PrerequisiteChecker) CheckAll()`** — checks all requirements, returning whether all are present and a list of missing tool names.
- **`CheckPrerequisites()`** — runs the default (k3d) prerequisite check/install flow, respecting non-interactive environments.
- **`checkerForClusterType(clusterType models.ClusterType)`** — pure dispatch mapping a `ClusterType` to its corresponding `PrerequisiteChecker` (nil for unknown types).
- **`CheckForClusterType(clusterType models.ClusterType)`** — runs the prerequisite gate for a given cluster type, auto-installing missing tools when non-interactive.

## Usage Example

```go
package main

import (
	"log"

	"github.com/flamingo-stack/openframe-cli/internal/cluster/models"
	"github.com/flamingo-stack/openframe-cli/internal/cluster/prerequisites"
)

func main() {
	// Check prerequisites for a specific cluster type before provisioning.
	if err := prerequisites.CheckForClusterType(models.ClusterTypeEKS); err != nil {
		log.Fatalf("prerequisite check failed: %v", err)
	}

	// Or check the default local k3d requirement set directly.
	checker := prerequisites.NewPrerequisiteChecker()
	ok, missing := checker.CheckAll()
	if !ok {
		log.Printf("missing tools: %v", missing)
	}
}
```

Unknown cluster types return `nil` from `checkerForClusterType`, meaning `CheckForClusterType` passes silently and defers failure to the provider factory.
