# checker.go

Defines and dispatches prerequisite requirement sets for the different cluster types supported by the CLI (local k3d, AWS EKS, and Google GKE). It provides a data-driven `PrerequisiteChecker` structure that describes each required tool (name, command, install-check, help text, and installer) and exposes high-level functions to validate and install missing tools based on the target cluster type.

## Key Components

- **`PrerequisiteChecker`** – holds a list of `Requirement` entries to validate.
- **`Requirement`** – describes a single dependency: display name, CLI command, an `IsInstalled` check, `InstallHelp` message generator, and an `Install` function.
- **`NewPrerequisiteChecker()`** – builds the requirement set for local k3d clusters: Docker, k3d, and Helm.
- **`NewEKSPrerequisiteChecker()`** – builds the requirement set for AWS EKS: Terraform and AWS CLI (no local runtime needed).
- **`NewGKEPrerequisiteChecker()`** – builds the requirement set for GKE: Terraform, gcloud CLI, and the `gke-gcloud-auth-plugin`.
- **`(*PrerequisiteChecker) CheckAll()`** – returns whether all requirements are satisfied and a list of missing tool names.
- **`checkerForClusterType(clusterType)`** – pure dispatch mapping a `models.ClusterType` to the appropriate checker (nil for unknown types).
- **`CheckPrerequisites()`** – runs the default (k3d) prerequisite gate, auto-installing in non-interactive environments (e.g., CI).
- **`CheckForClusterType(clusterType)`** – runs the prerequisite gate for a specific cluster type, installing missing tools as needed.

## Usage Example

```go
import (
    "github.com/flamingo-stack/openframe-cli/internal/cluster/models"
    "github.com/flamingo-stack/openframe-cli/internal/cluster/prerequisites"
)

// Check and install prerequisites for the default (k3d) cluster setup.
if err := prerequisites.CheckPrerequisites(); err != nil {
    log.Fatalf("prerequisite check failed: %v", err)
}

// Check prerequisites for a specific cluster type (e.g., EKS).
if err := prerequisites.CheckForClusterType(models.ClusterTypeEKS); err != nil {
    log.Fatalf("EKS prerequisites not satisfied: %v", err)
}

// Manually inspect missing requirements without installing.
checker := prerequisites.NewGKEPrerequisiteChecker()
allPresent, missing := checker.CheckAll()
if !allPresent {
    fmt.Println("Missing tools:", missing)
}
```
