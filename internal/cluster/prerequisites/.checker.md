# checker.go

Defines cluster-type-specific prerequisite requirement sets and dispatch logic for verifying required CLI tools before cluster operations. Each cluster type (local k3d, AWS EKS, GCP GKE) has its own `PrerequisiteChecker` composed of `Requirement` entries that know how to detect, explain, and install their tool.

## Key Components

- **`Requirement`** — struct describing a single dependency: its display `Name`, `Command`, and functions to check installation status (`IsInstalled`), provide help text (`InstallHelp`), and perform installation (`Install`).
- **`PrerequisiteChecker`** — holds a list of `Requirement`s and exposes `CheckAll()` to verify them, returning whether all are present and a list of missing tool names.
- **`NewPrerequisiteChecker()`** — builds the requirement set for local k3d clusters: Docker, k3d, and Helm.
- **`NewEKSPrerequisiteChecker()`** — builds the requirement set for AWS EKS clusters: Terraform and AWS CLI (no local container runtime needed).
- **`NewGKEPrerequisiteChecker()`** — builds the requirement set for GCP GKE clusters: Terraform, gcloud CLI, and the `gke-gcloud-auth-plugin`.
- **`checkerForClusterType(clusterType models.ClusterType) *PrerequisiteChecker`** — pure dispatch function mapping a `ClusterType` to its checker; returns `nil` for unknown types, deferring failure to the provider factory.
- **`CheckForClusterType(clusterType models.ClusterType) error`** — public entry point that resolves the checker for a cluster type and runs installation, auto-approving in non-interactive/CI environments.
- **`CheckPrerequisites() error`** — legacy/default entry point using the base `NewInstaller()` for non-interactive checking.

## Usage Example

```go
import (
	"github.com/flamingo-stack/openframe-cli/internal/cluster/models"
	"github.com/flamingo-stack/openframe-cli/internal/cluster/prerequisites"
)

func setupCluster(clusterType models.ClusterType) error {
	// Runs the appropriate prerequisite gate (Docker/k3d/Helm or
	// terraform + cloud CLI), installing missing tools automatically
	// in CI or non-interactive shells.
	if err := prerequisites.CheckForClusterType(clusterType); err != nil {
		return err
	}
	return nil
}
```

For a manual check without installation:

```go
checker := prerequisites.NewPrerequisiteChecker()
ok, missing := checker.CheckAll()
if !ok {
	// missing contains names like "Docker", "k3d", "helm"
}
```
