# installer.go

Implements the `Installer` type responsible for detecting missing cluster prerequisites, installing them (interactively or non-interactively), and ensuring Docker is running before continuing. It orchestrates the check → install → verify flow driven by a `PrerequisiteChecker`'s requirement list, and provides platform-specific manual instructions when automated installation is declined or fails.

## Key Components

- **`Installer`** - struct wrapping a `*PrerequisiteChecker` that supplies the data-driven list of requirements (differs between k3d local and EKS cloud setups).
- **`NewInstaller()`** - constructs an `Installer` with the default `PrerequisiteChecker`.
- **`NewInstallerWithChecker(checker *PrerequisiteChecker)`** - constructs an `Installer` around a custom requirement set.
- **`CheckAndInstallNonInteractive(nonInteractive bool)`** - main entry point; runs a three-phase flow: (1) determine missing tools vs. Docker-not-running, (2) install missing tools (auto-confirmed in non-interactive mode, prompted otherwise), (3) start and wait for Docker if needed. Fails fast on any error rather than continuing with a broken environment.
- **`installSpecificTools(tools []string)`** - installs each tool with a spinner UI and verifies post-install that binaries are actually usable.
- **`installTool(tool string)`** - looks up and invokes a single requirement's `Install` function.
- **`requirement(name string)`** - case-insensitive lookup of a `Requirement` by name.
- **`containsTool(tools []string, name string)`** - case-insensitive membership check helper.
- **`showManualInstructions()`** - renders a table of manual install instructions for all requirements.
- **`showDockerStartInstructions()`** - prints OS-specific (`darwin`, `linux`, `windows`) guidance for starting Docker manually.

## Usage Example

```go
package main

import (
	"log"

	"github.com/flamingo-stack/openframe-cli/internal/cluster/prerequisites"
)

func main() {
	installer := prerequisites.NewInstaller()

	// Run in non-interactive mode (e.g., CI pipeline)
	if err := installer.CheckAndInstallNonInteractive(true); err != nil {
		log.Fatalf("prerequisite check failed: %v", err)
	}

	// Proceed with cluster creation, Docker is guaranteed installed and running
}
```

To use a custom requirement set (e.g., for cloud clusters):

```go
checker := prerequisites.NewPrerequisiteChecker() // or a cloud-specific variant
installer := prerequisites.NewInstallerWithChecker(checker)
err := installer.CheckAndInstallNonInteractive(false) // interactive prompts
```
