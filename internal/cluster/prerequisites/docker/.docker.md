Provides cross-platform Docker installation and daemon management for the OpenFrame CLI, supporting macOS (via Homebrew) and multiple Linux distributions (Alpine, Ubuntu/Debian, CentOS/RHEL, Fedora, Arch).

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `DockerInstaller` | struct | Implements installation lifecycle: `IsInstalled()`, `GetInstallHelp()`, `Install()` |
| `IsDockerRunning()` | func | Checks if the Docker daemon is responsive (5-second timeout via `docker ps`) |
| `StartDocker()` | func | Starts the Docker daemon on macOS (Docker Desktop) or Linux (systemd / OpenRC / service) |
| `NewDockerInstaller()` | func | Constructor returning a `*DockerInstaller` |
| `installLinux()` | method | Dispatches to the correct distro installer by probing available package managers |

## Usage Example

```go
installer := docker.NewDockerInstaller()

if !installer.IsInstalled() {
    fmt.Println(installer.GetInstallHelp())
    if err := installer.Install(); err != nil {
        log.Fatalf("Docker install failed: %v", err)
    }
}

if !docker.IsDockerRunning() {
    if err := docker.StartDocker(); err != nil {
        log.Fatalf("Could not start Docker: %v", err)
    }
}
```

## Platform Notes

- **macOS**: installs Docker Desktop via `brew install --cask docker`, then opens the app
- **Linux**: auto-detects package manager (`apk` → `apt` → `yum` → `dnf` → `pacman`) and configures the Docker service + user group
- **Windows**: not handled here by design — the CLI forwards execution into WSL, where it runs as a Linux process; native Windows paths are explicitly unsupported
