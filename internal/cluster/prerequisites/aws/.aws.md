# aws.go

Implements the `AwsInstaller`, responsible for detecting and installing the AWS CLI, a required dependency for the EKS provider (used for `aws eks get-token` kubeconfig authentication). Credential validation is deliberately out of scope here—that responsibility belongs to the EKS provider's preflight checks via `aws sts get-caller-identity`.

## Key Components

- **`AwsInstaller`** — struct implementing the installer interface for the AWS CLI.
- **`NewAwsInstaller()`** — constructor returning a new `AwsInstaller`.
- **`IsInstalled()`** — checks if the `aws` binary exists on `PATH` and responds successfully to `aws --version`.
- **`GetInstallHelp()`** — returns a platform-specific install hint string.
- **`Install()`** — dispatches to `installMacOS()` or `installLinux()` based on `runtime.GOOS`; Windows is intentionally unsupported since the CLI forwards to WSL for Windows execution.
- **`installMacOS()`** — installs via Homebrew (`brew install awscli`), failing if `brew` is not present.
- **`installLinux()`** — tries `apt`, `dnf`, `yum`, and `pacman` in order, using `sudo -n` for non-interactive privilege escalation, and verifies the installed version is AWS CLI v2 (since v1 is incompatible with EKS token auth).
- **`installedIsV2()` / `isV2Output()`** — internal helpers that parse `aws --version` output to distinguish CLI v1 from v2, scanning all output tokens to tolerate stderr noise.
- **Test seams** — `lookPath`, `runCommand`, and `awsVersionOutput` are package-level vars enabling mocking in unit tests without invoking real package managers or binaries.

## Usage Example

```go
installer := aws.NewAwsInstaller()

if !installer.IsInstalled() {
    if err := installer.Install(); err != nil {
        fmt.Println("AWS CLI install failed:", err)
        fmt.Println(installer.GetInstallHelp())
        return
    }
}

fmt.Println("AWS CLI is ready for EKS authentication")
```

**Note:** On Linux, if the distro's package manager only provides AWS CLI v1 (e.g., Ubuntu 22.04), `Install()` returns an error instructing the user to install v2 manually, since v1's EKS token format is no longer accepted by `kubectl`.
