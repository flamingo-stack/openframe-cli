## Overview

Implements `AwsInstaller`, a platform-specific installer responsible for ensuring the AWS CLI (v2) is available on the system, since the EKS provider relies on `aws eks get-token` for kubeconfig authentication. It does not validate AWS credentials — that responsibility belongs to the EKS provider, which runs `aws sts get-caller-identity` separately.

## Key Components

- **`AwsInstaller`** - struct implementing installer behavior for the AWS CLI.
- **`NewAwsInstaller()`** - constructor returning a new `AwsInstaller`.
- **`IsInstalled()`** - checks whether the `aws` binary exists and responds correctly to `aws --version`.
- **`GetInstallHelp()`** - returns a platform-specific install hint via the `platform` package.
- **`Install()`** - dispatches installation logic based on `runtime.GOOS` (macOS via Homebrew, Linux via package managers). Windows is intentionally unsupported since the CLI runs through WSL as Linux.
- **`installMacOS()`** - installs via `brew install awscli`.
- **`installLinux()`** - tries `apt`, `dnf`, `yum`, and `pacman` in order, installing the correct v2 package name per distro, then verifies the installed version is v2.
- **`installedIsV2()` / `isV2Output()`** - determine whether the installed `aws` binary is CLI v2, since v1's `get-token` output is incompatible with modern kubectl auth.
- Package-level test seams: `lookPath`, `runCommand`, `awsVersionOutput` — allow unit testing without invoking real package managers or binaries.

## Usage Example

```go
installer := aws.NewAwsInstaller()

if !installer.IsInstalled() {
    if err := installer.Install(); err != nil {
        fmt.Println("AWS CLI installation failed:", err)
        fmt.Println(installer.GetInstallHelp())
        return
    }
}

fmt.Println("AWS CLI is ready for EKS authentication")
```

**Note:** On Linux, installs require passwordless `sudo` access (`sudo -n`), since this flow assumes prior user confirmation in the CLI's prerequisite check step. If the distro's default package resolves to AWS CLI v1, `Install()` returns an explicit error directing the user to manual installation instructions.
