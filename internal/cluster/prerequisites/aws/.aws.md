## AWS CLI Installer

This file implements the `AwsInstaller` component, responsible for detecting and installing the AWS CLI (v2), which is required by the EKS provider for `kubeconfig` authentication via `aws eks get-token`. Note that AWS credential validation is intentionally out of scope here—that is handled separately by the EKS provider using `aws sts get-caller-identity`.

## Key Components

- **`AwsInstaller`** — struct implementing the installer interface for the AWS CLI.
- **`NewAwsInstaller()`** — constructor for `AwsInstaller`.
- **`IsInstalled()`** — checks whether the `aws` binary exists and runs successfully.
- **`GetInstallHelp()`** — returns platform-specific manual install instructions.
- **`Install()`** — dispatches to macOS or Linux install logic based on `runtime.GOOS`; Windows is unsupported since the CLI runs under WSL as Linux.
- **`installMacOS()`** — installs via Homebrew (`brew install awscli`).
- **`installLinux()`** — tries `apt`, `dnf`, `yum`, or `pacman` (in that order) with `sudo -n`, then verifies the installed version is v2, since some distro repos still ship legacy v1.
- **`installedIsV2()` / `isV2Output()`** — parse `aws --version` output (checking both stdout and stderr) to confirm the CLI is v2, since v1's auth output format is incompatible with `kubectl`.
- Package-level test seams: `lookPath`, `runCommand`, `awsVersionOutput` — allow mocking binary lookup and command execution in unit tests without invoking real package managers.

## Usage Example

```go
installer := aws.NewAwsInstaller()

if !installer.IsInstalled() {
    if err := installer.Install(); err != nil {
        fmt.Println("Install failed:", err)
        fmt.Println(installer.GetInstallHelp())
        return
    }
}

fmt.Println("AWS CLI is ready for EKS authentication")
```

**Note:** There is no verified-download fallback—AWS does not publish stable, pinnable checksums for its frequently rotated v2 installer bundles, so installation always goes through the platform's native package manager.
