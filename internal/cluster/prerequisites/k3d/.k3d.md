Manages k3d (Kubernetes-in-Docker) installation detection and cross-platform installation for the OpenFrame CLI, with platform-aware install strategies and verified binary downloads.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `K3dInstaller` | struct | Main installer implementing the shared installer interface |
| `NewK3dInstaller()` | constructor | Returns a new `*K3dInstaller` instance |
| `IsInstalled()` | method | Detects k3d presence; uses WSL2 on Windows, binary check + version probe elsewhere |
| `GetInstallHelp()` | method | Returns platform-specific install hint string |
| `Install()` | method | Dispatches to macOS (Homebrew) or Linux install path; Windows is intentionally unsupported (CLI runs inside WSL) |
| `installVerified()` | method | Downloads a pinned k3d binary with SHA256 verification into `~/.openframe/bin` without requiring `sudo` |
| `isK3dInstalled()` | func | Runs `k3d version` with a 5-second timeout to avoid hangs |

## Platform Matrix

| OS | Strategy |
|----|----------|
| macOS | Homebrew (`brew install k3d`) |
| Ubuntu / Debian | Verified binary download (no official apt repo) |
| RHEL / Fedora | Verified binary download (no official yum/dnf repo) |
| Arch Linux | AUR via `yay`/`paru`, falls back to verified download |
| Windows | Detection via WSL2; installation deferred to Linux path inside WSL |

## Usage Example

```go
installer := k3d.NewK3dInstaller()

if !installer.IsInstalled() {
    fmt.Println(installer.GetInstallHelp())

    if err := installer.Install(); err != nil {
        log.Fatalf("k3d install failed: %v", err)
    }
}
```

## Notes

- `installVerified()` replaces the previous `curl | bash` approach, pinning a specific version and checking SHA256 (security audit I5/M1).
- The installed binary lands in `~/.openframe/bin`; `download.PrependToPath` makes it available in the current process without a shell restart.
- `runCommand` suppresses stdout/stderr during package manager installs to keep CLI output clean.
