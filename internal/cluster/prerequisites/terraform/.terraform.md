## Overview

`terraform.go` implements the `TerraformInstaller`, a component responsible for detecting and installing the Terraform CLI required by OpenFrame's cloud cluster provisioning. Because Terraform is no longer reliably available via package managers (the Homebrew formula was disabled after the BUSL license change), this installer always downloads and verifies a pinned binary into `~/.openframe/bin` rather than treating that as a fallback path.

## Key Components

- **`TerraformInstaller` struct** — Installer implementation with no internal state.
- **`NewTerraformInstaller() *TerraformInstaller`** — Constructor.
- **`IsInstalled() bool`** — Checks whether an accessible `terraform` binary satisfies the minimum version constraint (`>= 1.15.0`), prepending the CLI's managed bin directory to `$PATH` first so previously pinned installs are detected.
- **`GetInstallHelp() string`** — Returns a platform-specific install hint via `platform.InstallHint`.
- **`Install() error`** — Downloads, verifies (SHA256), and installs the pinned Terraform release for `darwin`, `linux`, and `windows`; returns an error on unsupported platforms.
- **`versionSatisfies(version string, major, minor int) bool`** — Internal helper comparing a semantic version string against a minimum major/minor; treats unparseable versions as too old (safe default).
- **`commandExists(cmd string) bool`** — Internal helper checking `$PATH` for a given executable.
- **`minMajor`, `minMinor`** — Constants defining the minimum supported Terraform version (1.15).

## Usage Example

```go
package main

import (
	"log"

	"github.com/flamingo-stack/openframe-cli/internal/terraform"
)

func main() {
	installer := terraform.NewTerraformInstaller()

	if !installer.IsInstalled() {
		log.Println("Terraform not found or version too old, installing pinned build...")
		if err := installer.Install(); err != nil {
			log.Fatalf("failed to install terraform: %v", err)
		}
	}

	log.Println("Terraform is ready for provisioning.")
}
```

If installation fails on an unsupported OS, `GetInstallHelp()` can be surfaced to guide the user toward manual installation steps.
