## terraform.go

Implements installation and version verification for the Terraform CLI, a dependency required by OpenFrame's cloud cluster provisioning engine. Unlike other tool installers (docker, k3d, helm), this always installs a pinned, checksum-verified binary into `~/.openframe/bin` rather than relying on system package managers, since current Terraform releases are no longer distributed via Homebrew core.

## Key Components

- **`TerraformInstaller`** — struct implementing the tool-installer interface for Terraform.
- **`NewTerraformInstaller()`** — constructor returning a new `*TerraformInstaller`.
- **`IsInstalled() bool`** — checks whether a `terraform` binary satisfying the minimum required version (`>= 1.15`) is reachable on `PATH`, prepending the CLI's managed bin directory first.
- **`GetInstallHelp() string`** — returns platform-specific install guidance via `platform.InstallHint`.
- **`Install() error`** — installs the verified Terraform binary; supported on `darwin`, `linux`, and `windows`.
- **`versionSatisfies(version string, major, minor int) bool`** — helper comparing a semantic version string against a minimum major/minor constraint; treats unparseable versions as too old.
- **`commandExists(cmd string) bool`** — helper checking if a command is available on `PATH`.
- **`minMajor`, `minMinor`** — constants defining the minimum supported Terraform version (1.15), matching the `required_version` constraint in generated Terraform root modules.

## Usage Example

```go
installer := terraform.NewTerraformInstaller()

if !installer.IsInstalled() {
    fmt.Println(installer.GetInstallHelp())
    if err := installer.Install(); err != nil {
        log.Fatalf("failed to install terraform: %v", err)
    }
}

// After installation, terraform is available on PATH
// via ~/.openframe/bin for use by the provisioning engine.
```

Internally, `Install()` downloads a pinned release using `download.Downloader.InstallPinnedTool`, verifies its SHA256 checksum, places it in the user's `~/.openframe/bin` directory (no `sudo` required), and prepends that directory to `$PATH` for the current process.
