## Overview

`terraform.go` implements the installer responsible for provisioning the Terraform CLI required by OpenFrame's cloud cluster providers. Unlike other tools (docker/k3d/helm), it does not rely on system package managers as a primary path — it always installs a pinned, SHA256-verified Terraform binary into `~/.openframe/bin`, since current Terraform releases are no longer reliably available via package managers (e.g., the homebrew-core formula is disabled due to the BUSL licensing change).

## Key Components

- **`TerraformInstaller`** — struct implementing the installer interface for Terraform.
- **`NewTerraformInstaller()`** — constructor returning a new `TerraformInstaller`.
- **`IsInstalled() bool`** — checks if a `terraform` binary is on `PATH` (prepending the CLI-managed bin dir first) and whether its version satisfies the minimum required version (`>= 1.15.0`), as parsed from `terraform version -json`.
- **`versionSatisfies(version string, major, minor int) bool`** — compares a semantic version string against a minimum major/minor; treats unparseable versions as too old (fails safe).
- **`GetInstallHelp() string`** — returns platform-specific installation guidance via `platform.InstallHint`.
- **`Install() error`** — installs Terraform on darwin, linux, or windows by delegating to `installVerified`; returns an error on unsupported platforms.
- **`installVerified() error`** — downloads the pinned Terraform release, verifies its checksum, installs it into the user's bin directory, and updates `PATH` for the current process.
- **`commandExists(cmd string) bool`** — helper checking if a command is resolvable via `exec.LookPath`.
- **`minMajor`, `minMinor`** — constants defining the minimum supported Terraform version (1.15).

## Usage Example

```go
package main

import (
	"log"

	"github.com/flamingo-stack/openframe-cli/internal/platform/terraform"
)

func main() {
	installer := terraform.NewTerraformInstaller()

	if !installer.IsInstalled() {
		if err := installer.Install(); err != nil {
			log.Fatalf("failed to install terraform: %v", err)
		}
	}

	// Terraform binary is now available on PATH for provisioning commands
}
```

This installer is typically invoked during cluster provisioning setup, ensuring a compatible Terraform version is available before running any Terraform-based cloud provider workflows.
