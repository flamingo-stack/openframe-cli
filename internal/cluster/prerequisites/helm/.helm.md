Manages Helm installation across macOS and Linux platforms, providing detection, install hints, and verified binary downloads for use within the OpenFrame CLI toolchain.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `HelmInstaller` | struct | Main installer type implementing the shared installer interface |
| `NewHelmInstaller()` | constructor | Returns a new `*HelmInstaller` instance |
| `IsInstalled()` | method | Detects Helm presence; on Windows delegates to WSL2 via `wsllauncher` |
| `GetInstallHelp()` | method | Returns platform-appropriate install hint string |
| `Install()` | method | Dispatches to macOS (Homebrew) or Linux (verified download) install path |
| `installVerified()` | method | Downloads pinned Helm tarball, verifies SHA256, and installs to `~/.openframe/bin` without requiring `sudo` |

## Usage Example

```go
installer := helm.NewHelmInstaller()

if !installer.IsInstalled() {
    fmt.Println(installer.GetInstallHelp())

    if err := installer.Install(); err != nil {
        log.Fatalf("helm install failed: %v", err)
    }
}
```

## Notes

- **Windows** is intentionally unsupported in `Install()` — the CLI forwards execution into WSL2, where the Linux path runs instead.
- `isHelmInstalled()` applies a **5-second timeout** when running `helm version` to prevent hangs on broken installs.
- `installVerified()` replaces the legacy `curl get-helm-3 | bash` pattern with a pinned, SHA256-verified download into `~/.openframe/bin`, scoped to audit requirement `T0.3`.
