# infracost.go

Provides installer logic for the optional [infracost](https://www.infracost.io/) CLI, which powers monthly cost estimates in the cloud dry-run preview feature. Installation is never mandatory—the CLI only offers to install it, and generating estimates additionally requires the user to run `infracost auth login` once for a free API key (no cloud credentials involved).

## Key Components

- **`Installer`** — struct implementing the optional-tool installer pattern.
- **`NewInstaller()`** — constructs a new `Installer`.
- **`(*Installer) IsInstalled() bool`** — checks whether a working `infracost` binary is reachable, preferring the CLI-managed bin directory, and verifies it responds to `--version` within a 5-second timeout.
- **`(*Installer) GetInstallHelp() string`** — returns a platform-specific install hint via `platform.InstallHint`.
- **`(*Installer) Install() error`** — downloads the pinned, checksum-verified infracost release archive and installs the binary into `~/.openframe/bin`, then prepends that directory to `$PATH`.
- **`archiveMemberAndDest(goos, goarch, binDir string) (member, dest string)`** — resolves the archive member name and destination path, accounting for irregular archive layouts (unix embeds os/arch in the binary name; Windows ships a bare `infracost.exe`).

## Usage Example

```go
installer := infracost.NewInstaller()

if !installer.IsInstalled() {
    fmt.Println(installer.GetInstallHelp())
    if err := installer.Install(); err != nil {
        log.Fatalf("failed to install infracost: %v", err)
    }
}

// After installation, prompt the user to authenticate once:
fmt.Println("Run `infracost auth login` to enable cost estimates.")
```

Supported platforms are `darwin`, `linux`, and `windows`; any other `GOOS` returns an error from `Install()`. Assets are resolved and checksum-verified via `download.Infracost.Asset(goos, goarch)` before installation.
