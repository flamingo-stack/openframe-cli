# infracost.go

Installs and manages the optional [infracost](https://www.infracost.io/) CLI, which powers the monthly cost estimate shown in the cloud dry-run preview. Installation of this tool is always opt-in — the CLI only offers to install it — and generating estimates additionally requires the user to run `infracost auth login` once to obtain a free API key (no cloud credentials are involved).

## Key Components

- **`Installer`** — struct implementing the install workflow for the `infracost` binary.
- **`NewInstaller() *Installer`** — constructor for `Installer`.
- **`(*Installer) IsInstalled() bool`** — checks whether a working `infracost` binary is reachable, preferring the CLI-managed bin directory, and validates it by running `infracost --version` with a 5-second timeout.
- **`(*Installer) GetInstallHelp() string`** — returns a platform-specific manual install hint via `platform.InstallHint`.
- **`(*Installer) Install() error`** — downloads the pinned, SHA256-verified `infracost` release for the current OS/arch and installs it into `~/.openframe/bin`.
- **`archiveMemberAndDest(goos, goarch, binDir string) (member, dest string)`** — resolves the archive member name and install destination path, accounting for irregular archive layouts (unix binaries are named `infracost-<os>-<arch>`, Windows ships a bare `infracost.exe`).

## Usage Example

```go
package main

import (
	"fmt"

	"github.com/flamingo-stack/openframe-cli/internal/shared/infracost"
)

func main() {
	installer := infracost.NewInstaller()

	if installer.IsInstalled() {
		fmt.Println("infracost is already installed")
		return
	}

	if err := installer.Install(); err != nil {
		fmt.Println("Automatic install failed:", err)
		fmt.Println(installer.GetInstallHelp())
		return
	}

	fmt.Println("infracost installed. Run `infracost auth login` to enable cost estimates.")
}
```

Supported platforms for automatic installation are `darwin`, `linux`, and `windows`; any other `GOOS` returns an error advising manual installation.
