## Overview

Implements optional installation of the `infracost` CLI, used to power monthly cost estimates in the cloud dry-run preview feature. Installation is never mandatory — this package only offers to install the tool, and actual cost estimates additionally require the user to authenticate separately via `infracost auth login`.

## Key Components

- **`Installer`** — Struct implementing the installer interface for the infracost CLI.
- **`NewInstaller() *Installer`** — Constructs a new `Installer` instance.
- **`(*Installer) IsInstalled() bool`** — Checks whether a working `infracost` binary is reachable, prepending the CLI-managed bin directory to `$PATH` and validating with `infracost --version`.
- **`(*Installer) GetInstallHelp() string`** — Returns platform-specific installation guidance via `platform.InstallHint`.
- **`(*Installer) Install() error`** — Downloads the pinned, checksum-verified infracost release for the current OS/architecture and installs it into the user's `~/.openframe/bin` directory.
- **`archiveMemberAndDest(goos, goarch, binDir string) (member, dest string)`** — Internal helper resolving the archive member name and install destination path, accounting for irregular archive layouts (Unix archives embed OS/arch in the member name; Windows ships a bare `infracost.exe`).
- **`commandExists(cmd string) bool`** — Internal helper checking `$PATH` for a given executable using `exec.LookPath`.

## Usage Example

```go
package main

import (
	"fmt"

	"github.com/flamingo-stack/openframe-cli/internal/deps/infracost"
)

func main() {
	installer := infracost.NewInstaller()

	if installer.IsInstalled() {
		fmt.Println("infracost is already installed")
		return
	}

	fmt.Println(installer.GetInstallHelp())

	if err := installer.Install(); err != nil {
		fmt.Printf("failed to install infracost: %v\n", err)
		return
	}

	fmt.Println("infracost installed successfully. Run 'infracost auth login' to enable estimates.")
}
```

**Note:** Supported platforms are `darwin`, `linux`, and `windows`. Any other `runtime.GOOS` returns an error during `Install()`. Binaries are downloaded from a pinned, SHA256-verified release (`download.Infracost`) and extracted using `download.Downloader.InstallVerifiedTarGz`.
