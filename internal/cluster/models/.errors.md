Domain-level error types for cluster operations, providing structured, inspectable errors for the `models` package.

## Key Components

| Type / Function | Description |
|---|---|
| `ErrClusterNotFound` | Error when a named cluster cannot be located |
| `ErrProviderNotFound` | Error when no provider exists for a given `ClusterType` |
| `ErrInvalidClusterConfig` | Error for invalid configuration, carrying the field, value, and reason |
| `ErrClusterOperation` | Wrappable error for general operation failures; implements `Unwrap()` for `errors.As`/`errors.Is` |
| `NewClusterNotFoundError` | Constructor for `ErrClusterNotFound` |
| `NewProviderNotFoundError` | Constructor for `ErrProviderNotFound` |
| `NewInvalidConfigError` | Constructor for `ErrInvalidClusterConfig` |
| `NewClusterOperationError` | Constructor for `ErrClusterOperation` |

## Usage Example

```go
// Creating errors via constructors
err := models.NewClusterNotFoundError("prod-k8s")
fmt.Println(err) // cluster 'prod-k8s' not found

// Wrapping a cause in an operation error
cause := errors.New("timeout")
opErr := models.NewClusterOperationError("delete", "prod-k8s", cause)
fmt.Println(opErr) // cluster delete operation failed for 'prod-k8s': timeout

// Unwrapping for type inspection
var notFound models.ErrClusterNotFound
if errors.As(err, &notFound) {
    fmt.Println("Missing cluster:", notFound.Name)
}

// Checking wrapped cause
var clusterOp models.ErrClusterOperation
if errors.As(opErr, &clusterOp) {
    fmt.Println("Root cause:", errors.Unwrap(clusterOp))
}
```

> All four error types are concrete structs, making them safe to inspect with `errors.As` without relying on string matching.
