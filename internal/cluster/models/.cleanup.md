Defines the `CleanupResult` model used to track the outcome of a best-effort cleanup run, recording what was actually removed and which phases failed, so summaries reflect real results instead of assuming full success.

## Key Components

- **`CleanupResult`** — struct holding `NodesPruned` (count of removed objects) and `Failures` (list of human-readable per-phase failure messages).
- **`AddFailure(phase string, err error)`** — appends a formatted failure entry (`"<phase>: <err>"`) to `Failures`.
- **`Removed() int`** — returns the total number of objects successfully removed (`NodesPruned`).
- **`Partial() bool`** — returns `true` if any phase recorded a failure, indicating the cleanup completed but is incomplete.

## Usage Example

```go
result := &models.CleanupResult{}

// Phase 1: prune nodes
if err := pruneNodes(); err != nil {
    result.AddFailure("prune nodes", err)
} else {
    result.NodesPruned++
}

// Phase 2: remove unused images
if err := removeUnusedImages(); err != nil {
    result.AddFailure("remove unused images", err)
}

// Report accurate outcome
if result.Partial() {
    fmt.Printf("Cleanup completed with issues. Removed %d objects.\n", result.Removed())
    for _, f := range result.Failures {
        fmt.Println(" -", f)
    }
} else {
    fmt.Printf("Cleanup succeeded. Removed %d objects.\n", result.Removed())
}
```

This pattern ensures cleanup commands never falsely claim full success when some phases fail, keeping the best-effort contract transparent to users.
