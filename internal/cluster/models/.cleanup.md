Defines the `CleanupResult` model used to track what a best-effort cluster cleanup run actually accomplished, enabling honest reporting of partial outcomes rather than unconditional success messages.

## Key Components

### `CleanupResult` struct
Tracks per-phase removal counts and accumulated failures across a cleanup run:

| Field | Description |
|---|---|
| `ApplicationsDeleted` | ArgoCD/Helm applications removed |
| `FinalizersCleared` | Kubernetes finalizers unblocked |
| `ReleasesRemoved` | Helm releases purged |
| `NamespacesDeleted` | Namespaces torn down |
| `NodesPruned` | Nodes drained and removed |
| `Failures` | Human-readable lines for each failed phase |

### Methods

| Method | Returns | Description |
|---|---|---|
| `AddFailure(phase, err)` | — | Appends a formatted `"phase: error"` line to `Failures` |
| `Removed()` | `int` | Sum of all per-phase deletion counters |
| `Partial()` | `bool` | `true` when at least one phase failed |

## Usage Example

```go
result := &models.CleanupResult{}

if err := deleteApplications(ctx); err != nil {
    result.AddFailure("applications", err)
} else {
    result.ApplicationsDeleted = count
}

if err := pruneNodes(ctx); err != nil {
    result.AddFailure("nodes", err)
} else {
    result.NodesPruned = pruned
}

fmt.Printf("Removed %d object(s)\n", result.Removed())

if result.Partial() {
    fmt.Println("Partial cleanup — phases that failed:")
    for _, f := range result.Failures {
        fmt.Println(" •", f)
    }
}
```

A non-empty `Failures` slice with no returned error is the expected partial-cleanup outcome: the command exits successfully while surfacing exactly what was left behind.
