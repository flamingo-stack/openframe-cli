Defines the core interfaces for the CLI command system, establishing contracts for flag management, execution context, and cluster command lifecycle.

## Key Components

| Interface | Description |
|---|---|
| `CommandFlags` | Minimum contract for command flags; exposes `GetGlobal()` to retrieve shared `GlobalFlags` |
| `CommandExecutor` | Wraps the underlying `executor.CommandExecutor` for use within command handlers |
| `ClusterCommand` | Full lifecycle contract all cluster commands must satisfy |

### `ClusterCommand` Methods

| Method | Responsibility |
|---|---|
| `GetCommand(flags)` | Returns the `cobra.Command` definition |
| `Execute(cmd, args, flags, executor)` | Runs the command business logic |
| `ValidateFlags(flags)` | Validates command-specific flag values |
| `SetupFlags(cmd, flags)` | Registers flags onto the cobra command |

## Usage Example

```go
// Implement ClusterCommand for a custom command
type MyCommand struct{}

func (c *MyCommand) GetCommand(flags models.CommandFlags) *cobra.Command {
    return &cobra.Command{
        Use:   "my-command",
        Short: "Does something useful",
    }
}

func (c *MyCommand) Execute(
    cmd *cobra.Command,
    args []string,
    flags models.CommandFlags,
    exec models.CommandExecutor,
) error {
    runner := exec.GetExecutor()
    return runner.Run("kubectl", "get", "pods")
}

func (c *MyCommand) ValidateFlags(flags models.CommandFlags) error {
    if flags.GetGlobal().KubeconfigPath == "" {
        return errors.New("kubeconfig path is required")
    }
    return nil
}

func (c *MyCommand) SetupFlags(cmd *cobra.Command, flags models.CommandFlags) {
    cmd.Flags().StringVar(&myFlag, "my-flag", "", "Custom flag")
}
```

## Notes

- All cluster commands must implement the full `ClusterCommand` interface to integrate with the CLI dispatch layer.
