Defines flag structures and validation logic for all OpenFrame CLI cluster subcommands, mapping Cobra flag bindings to typed structs and enforcing naming/value constraints.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `GlobalFlags` | Type alias | Re-exports `flags.CommonFlags` as the single source of truth for shared flags |
| `CreateFlags` | Struct | Embeds `GlobalFlags`; adds `ClusterType`, `NodeCount`, `K8sVersion`, `SkipWizard` |
| `ListFlags` | Struct | Embeds `GlobalFlags`; adds `Quiet` |
| `StatusFlags` | Struct | Embeds `GlobalFlags`; adds `Detailed`, `NoApps` |
| `DeleteFlags` | Struct | Embeds `GlobalFlags`; adds `Force` |
| `CleanupFlags` | Struct | Embeds `GlobalFlags`; adds `Force` (aggressive cleanup semantics) |
| `AddGlobalFlags` | Func | Registers shared flags on a `*cobra.Command` via `FlagManager` |
| `AddCreateFlags` | Func | Registers `--type`, `--nodes`, `--version`, `--skip-wizard` |
| `ValidateClusterName` | Func | Enforces DNS-1123-compatible naming: alphanumeric + hyphens, max 63 chars |
| `ValidateCreateFlags` | Func | Validates global flags and asserts `NodeCount >= 1` |

## Usage Example

```go
import (
    "github.com/flamingo-stack/openframe-cli/internal/models"
    "github.com/spf13/cobra"
)

func NewCreateCmd() *cobra.Command {
    f := &models.CreateFlags{}

    cmd := &cobra.Command{
        Use:   "create [name]",
        Short: "Create a cluster",
        PreRunE: func(cmd *cobra.Command, args []string) error {
            if len(args) > 0 {
                if err := models.ValidateClusterName(args[0]); err != nil {
                    return err
                }
            }
            return models.ValidateCreateFlags(f)
        },
        RunE: func(cmd *cobra.Command, args []string) error {
            // f.ClusterType, f.NodeCount, etc. are populated
            return nil
        },
    }

    models.AddGlobalFlags(cmd, &f.GlobalFlags)
    models.AddCreateFlags(cmd, f)
    return cmd
}
```

**Valid cluster names:** `my-cluster`, `prod`, `a`, `openframe-dev-1`

**Invalid cluster names:** `-starts-with-hyphen`, `toolongname...` (>63 chars), `has spaces`
