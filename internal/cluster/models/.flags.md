# flags.go

Defines Cobra CLI flag structs and validation logic for the `cluster` command family (create, list, status, delete, cleanup). It centralizes flag registration and cross-flag validation, including cloud-provider-specific rules for EKS and GKE clusters.

## Key Components

- **`GlobalFlags`** - Type alias for `flags.CommonFlags`, the shared base for all cluster subcommand flags.
- **`CreateFlags`** - Flags for cluster creation, including local (`ClusterType`, `NodeCount`, `K8sVersion`) and cloud-only options (`Region`, `Profile`, `Project`, `MachineType`, `MinNodes`, `MaxNodes`, `Spot`, `HA`, `BackendConfig`).
- **`ListFlags`**, **`StatusFlags`**, **`DeleteFlags`**, **`CleanupFlags`** - Command-specific flag structs embedding `GlobalFlags`.
- **`AddGlobalFlags`, `AddCreateFlags`, `AddListFlags`, `AddStatusFlags`, `AddDeleteFlags`, `AddCleanupFlags`** - Register the respective flags on a `cobra.Command`.
- **`ValidateClusterName`** - Enforces DNS-1123-style naming rules (max 63 chars, alphanumeric/hyphen, must start/end alphanumeric).
- **`ValidateGlobalFlags`, `ValidateCreateFlags`, `ValidateListFlags`, `ValidateStatusFlags`, `ValidateDeleteFlags`, `ValidateCleanupFlags`** - Validate flag combinations, including EKS/GKE-specific requirements (e.g., `--region` required with `--skip-wizard`) and cross-cloud conflict detection (e.g., `--project` rejected for EKS).

## Usage Example

```go
import (
    "github.com/spf13/cobra"
    "github.com/flamingo-stack/openframe-cli/internal/cluster/models"
)

func newCreateCommand() *cobra.Command {
    var createFlags models.CreateFlags

    cmd := &cobra.Command{
        Use: "create [NAME]",
        RunE: func(cmd *cobra.Command, args []string) error {
            if err := models.ValidateClusterName(args[0]); err != nil {
                return err
            }
            if err := models.ValidateCreateFlags(&createFlags); err != nil {
                return err
            }
            // proceed with cluster creation...
            return nil
        },
    }

    models.AddGlobalFlags(cmd, &createFlags.GlobalFlags)
    models.AddCreateFlags(cmd, &createFlags)
    return cmd
}
```

Validation ensures cloud-only flags (e.g., `--region`, `--project`) aren't misused with local cluster types, and that provider-specific flags (`--profile` for AWS, `--project` for GCP) aren't mixed across providers.
