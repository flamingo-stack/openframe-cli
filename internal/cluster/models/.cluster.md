## cluster.go

Defines the core domain models for representing and configuring Kubernetes clusters across multiple backends (k3d, GKE, EKS) in the OpenFrame CLI.

## Key Components

- **`ClusterType`** – String enum identifying the cluster backend (`k3d`, `gke`, `eks`).
- **`ParseClusterType(s string) (ClusterType, error)`** – Normalizes user input into a `ClusterType`, case-insensitively accepting provider aliases (`aws` → `eks`, `gcp` → `gke`). Returns an empty type for empty input and an error for unrecognized values.
- **`ClusterConfig`** – Configuration used to create/manage a cluster: name, type, node count, Kubernetes version, and optional `Cloud` settings (nil for local k3d clusters).
- **`GKERegionalZones`** – Constant (`3`) representing the default zone spread for GKE regional (HA) clusters; used to correctly compute total node counts (per-zone × zones).
- **`CloudConfig`** – Provider-agnostic cloud settings: region, GCP project, AWS profile, machine type, autoscaling bounds, spot instances, HA flag, zone, and remote backend state location.
- **`ClusterSource`** – Enum distinguishing cluster ownership: `SourceOpenframe` (full lifecycle) vs. `SourceExternal` (read-only, discovered cluster).
- **`ClusterInfo`** – Runtime/status snapshot of a cluster including source, context, project/profile/region, server readiness counts, node count, Kubernetes version, creation time, and node list.
- **`NodeInfo`** – Basic per-node status: name, status, and role.

## Usage Example

```go
package main

import (
	"fmt"
	"log"

	"models"
)

func main() {
	clusterType, err := models.ParseClusterType("aws")
	if err != nil {
		log.Fatal(err)
	}

	cfg := models.ClusterConfig{
		Name:       "prod-cluster",
		Type:       clusterType,
		NodeCount:  3,
		K8sVersion: "1.29",
		Cloud: &models.CloudConfig{
			Region:  "us-east-1",
			Profile: "default",
			HA:      true,
		},
	}

	fmt.Printf("Creating %s cluster: %s\n", cfg.Type, cfg.Name)
}
```

**Note:** When `Cloud.HA` is `true` on GKE, the actual node count is `NodeCount × GKERegionalZones`, since GKE provisions node pools per zone.
