Defines the core data models for Kubernetes cluster management across multiple provider types (k3d, GKE, EKS).

## Key Components

| Type | Kind | Description |
|---|---|---|
| `ClusterType` | `string` alias | Enum-style constants for supported cluster providers |
| `ClusterConfig` | struct | Input configuration for creating/managing a cluster |
| `ClusterInfo` | struct | Runtime state of a cluster, including node readiness |
| `NodeInfo` | struct | Per-node status, role, and name within a cluster |
| `ProviderOptions` | struct | Provider-specific option bag passed at runtime |
| `K3dOptions` | struct | k3d port mapping configuration |
| `GKEOptions` | struct | GKE zone and project targeting |

**Supported cluster types:**

```go
ClusterTypeK3d ClusterType = "k3d"
ClusterTypeGKE ClusterType = "gke"
ClusterTypeEKS ClusterType = "eks"
```

## Usage Example

```go
cfg := models.ClusterConfig{
    Name:       "dev-cluster",
    Type:       models.ClusterTypeK3d,
    NodeCount:  3,
    K8sVersion: "1.29",
}

opts := models.ProviderOptions{
    K3d: &models.K3dOptions{
        PortMappings: []string{"8080:80", "8443:443"},
    },
    Verbose: true,
}

// Inspect cluster readiness - prefer ReadyServers/TotalServers
// over the human-readable Status string in machine consumers
info := models.ClusterInfo{
    Name:         cfg.Name,
    Type:         cfg.Type,
    ReadyServers: 3,
    TotalServers: 3,
    Status:       "3/3",
}
```

> **Note:** `ClusterInfo.Status` is a human-readable fraction (e.g. `"1/1"`) intended for display only. Programmatic consumers should use `ReadyServers` and `TotalServers` directly to avoid string parsing.
