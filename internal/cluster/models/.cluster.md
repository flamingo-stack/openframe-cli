## cluster.go

Defines the core domain models for representing Kubernetes clusters (k3d, GKE, EKS) across the OpenFrame CLI, including type parsing, configuration, and runtime cluster/node information.

## Key Components

- **`ClusterType`** — string enum for supported cluster backends: `ClusterTypeK3d`, `ClusterTypeGKE`, `ClusterTypeEKS`.
- **`ParseClusterType(s string) (ClusterType, error)`** — normalizes user input (case-insensitive), accepting provider aliases (`aws` → EKS, `gcp` → GKE). Empty string returns `""` (caller applies default); unrecognized values return an error.
- **`ClusterConfig`** — desired-state configuration for creating a cluster (name, type, node count, Kubernetes version, optional `Cloud` settings).
- **`GKERegionalZones`** — constant (`3`) documenting that GKE regional clusters provision nodes *per zone*, used to compute total node counts for HA clusters.
- **`CloudConfig`** — provider-agnostic cloud settings (region, GCP project, AWS profile, machine type, min/max nodes, spot instances, `HA` flag, `Zone`, and `BackendConfig` for remote Terraform state).
- **`ClusterSource`** — enum distinguishing CLI-managed clusters (`SourceOpenframe`) from externally discovered, read-only clusters (`SourceExternal`).
- **`ClusterInfo`** — runtime snapshot of a cluster's state (type, source, kubeconfig context, project/profile/region, server readiness, node count, version, creation time, and node list).
- **`NodeInfo`** — basic node metadata (name, status, role).

## Usage Example

```go
package main

import (
	"fmt"
	"log"

	"github.com/flamingo-stack/openframe-cli/internal/models"
)

func main() {
	ctype, err := models.ParseClusterType("aws")
	if err != nil {
		log.Fatal(err)
	}

	cfg := models.ClusterConfig{
		Name:      "my-cluster",
		Type:      ctype, // resolves to ClusterTypeEKS
		NodeCount: 3,
		Cloud: &models.CloudConfig{
			Region:  "us-east-1",
			Profile: "default",
			HA:      true,
		},
	}

	fmt.Printf("Creating %s cluster %q with %d nodes\n", cfg.Type, cfg.Name, cfg.NodeCount)
}
```

For a regional GKE cluster, multiply the configured `NodeCount` by `models.GKERegionalZones` when displaying the total provisioned node count to avoid surprising users.
