## cluster.go

Defines the core domain types for representing and configuring Kubernetes clusters across supported backends (k3d, GKE, EKS), including cloud-specific settings and cluster ownership semantics.

## Key Components

- **`ClusterType`** – enum-like string type identifying the cluster backend (`k3d`, `gke`, `eks`).
- **`ParseClusterType(s string) (ClusterType, error)`** – normalizes user input into a `ClusterType`, accepting provider aliases (`aws` → `eks`, `gcp` → `gke`), case-insensitive; empty string passes through unchanged, unknown values return an error.
- **`ClusterConfig`** – describes desired cluster state (name, type, node count, Kubernetes version, optional `CloudConfig` for managed clusters).
- **`GKERegionalZones`** – constant (3) representing GKE's default zone spread for regional/HA clusters; used to compute actual node totals (per-zone × zones).
- **`CloudConfig`** – provider-agnostic cloud settings: region, project/profile, machine type, autoscaling bounds, spot instances, HA flag, zone, and optional remote backend state location.
- **`ClusterSource`** – identifies cluster ownership: `SourceOpenframe` (CLI-managed, full lifecycle) vs `SourceExternal` (discovered, read-only).
- **`ClusterInfo`** – runtime/discovered cluster state including source, context, region/project/profile, server readiness counts, node count, version, and node list.
- **`NodeInfo`** – per-node status details (name, status, role).

## Usage Example

```go
clusterType, err := models.ParseClusterType("aws")
if err != nil {
    log.Fatal(err)
}

cfg := models.ClusterConfig{
    Name:      "my-cluster",
    Type:      clusterType, // resolves to ClusterTypeEKS
    NodeCount: 3,
    Cloud: &models.CloudConfig{
        Region:  "us-east-1",
        Profile: "default",
        HA:      true,
    },
}

if cfg.Cloud.HA {
    totalNodes := cfg.NodeCount * models.GKERegionalZones
    fmt.Printf("Provisioning %d nodes across %d zones\n", totalNodes, models.GKERegionalZones)
}
```

Note: `GKERegionalZones` applies specifically to GKE regional clusters; treat EKS/HA node math separately per provider semantics.
