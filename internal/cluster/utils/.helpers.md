Provides a deprecated data transfer type for cluster selection results within the utils package.

## Key Components

- **`ClusterSelectionResult`** — Struct holding the outcome of a cluster selection operation, with `Name` (string) and `Type` (`models.ClusterType`) fields. Marked deprecated in favor of UI types.

## Usage Example

```go
result := utils.ClusterSelectionResult{
    Name: "my-cluster",
    Type: models.ClusterTypeKind,
}

fmt.Println(result.Name, result.Type)
```

> **Note:** This type is deprecated. Use the corresponding UI types instead.
