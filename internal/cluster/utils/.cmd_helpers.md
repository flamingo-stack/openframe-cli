Provides shared helper utilities for CLI command setup, including global flag management, command service creation, and standardized error handling wrapping for Cobra commands.

## Key Components

- **`InitGlobalFlags()`** — Thread-safe lazy initialization of the global `cluster.FlagContainer` used across all cluster commands.
- **`GetCommandService()`** — Builds a `cluster.ClusterService`, using an injected test executor if present, otherwise a real executor configured from the global `--dry-run`/`--verbose` flags.
- **`CommandExecutor()`** — Returns the `executor.CommandExecutor` commands should use: the injected test executor when available, or a real one honoring global flags.
- **`WrapCommandWithCommonSetup(runFunc)`** — Wraps a Cobra `RunE` function to standardize error handling: already-handled errors (`errors.AlreadyHandledError`) pass through untouched, while new errors are displayed once via `errors.NewErrorHandler` and converted to `AlreadyHandledError` so `main.go` exits non-zero without duplicate output.
- **`SyncGlobalFlags()`** / **`ValidateGlobalFlags()`** — Propagate and validate global flag state against `models.ValidateGlobalFlags`.
- **`GetGlobalFlags()`** — Returns (and initializes if needed) the global `FlagContainer`.
- **`SetTestExecutor(exec)`** / **`ResetGlobalFlags()`** — Test-only helpers to inject a mock executor and reset global state between test cases.

## Usage Example

```go
func NewStartCommand() *cobra.Command {
	cmd := &cobra.Command{
		Use: "start",
		RunE: utils.WrapCommandWithCommonSetup(func(cmd *cobra.Command, args []string) error {
			service := utils.GetCommandService()
			return service.StartCluster(args[0])
		}),
	}
	return cmd
}

// In a cmd-layer test:
func TestStartCommand(t *testing.T) {
	utils.SetTestExecutor(mockExecutor)
	defer utils.ResetGlobalFlags()

	// run command, assert on mockExecutor calls
}
```

**Note:** This package must never import test packages (`tests/...`); test-only helpers like `SetTestExecutor` and `ResetGlobalFlags` are provided here specifically so production binaries don't need to link in test dependencies like `testify`.
