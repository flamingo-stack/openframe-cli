# cmd_helpers.go

Provides shared helper utilities for CLI command implementations, including global flag management, command service instantiation, and consistent error handling wrapping for Cobra commands.

## Key Components

- **`InitGlobalFlags()`** - Thread-safe initialization of the global `FlagContainer` used across all cluster commands.
- **`GetCommandService()`** - Constructs a `cluster.ClusterService`, using an injected test executor if available, otherwise a real executor honoring `--dry-run`/`--verbose` flags.
- **`CommandExecutor()`** - Returns the appropriate `executor.CommandExecutor` (test-injected or real) for commands to shell out through.
- **`WrapCommandWithCommonSetup(runFunc)`** - Wraps a Cobra `RunE` function to standardize error handling, ensuring errors are displayed once and marked as `AlreadyHandledError` so `main.go` exits non-zero without double-printing.
- **`SyncGlobalFlags()`** - Propagates global flag values to individual command flag sets.
- **`ValidateGlobalFlags()`** - Validates the current global flags via `models.ValidateGlobalFlags`.
- **`GetGlobalFlags()`** - Returns (and lazily initializes) the global `FlagContainer`.
- **`SetTestExecutor(exec)`** - Test-only helper to inject a mock executor into global flags.
- **`ResetGlobalFlags()`** - Test-only helper to reset global flags to `nil`.

**Note:** This package must never import `tests/...` packages, to avoid pulling test dependencies (e.g., testify) into the shipped binary.

## Usage Example

```go
func NewClusterCreateCommand() *cobra.Command {
	cmd := &cobra.Command{
		Use: "create",
		RunE: utils.WrapCommandWithCommonSetup(func(cmd *cobra.Command, args []string) error {
			utils.SyncGlobalFlags()
			if err := utils.ValidateGlobalFlags(); err != nil {
				return err
			}

			service := utils.GetCommandService()
			return service.CreateCluster(args)
		}),
	}
	return cmd
}

// In tests, inject a mock executor:
func TestClusterCreate(t *testing.T) {
	mockExec := &mocks.FakeExecutor{}
	utils.SetTestExecutor(mockExec)
	defer utils.ResetGlobalFlags()

	// run command logic using the mock executor
}
```
