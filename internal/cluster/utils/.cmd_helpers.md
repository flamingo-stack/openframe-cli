## cmd_helpers.go

Provides shared utilities for CLI command setup, including global flag management, command service creation, and standardized error handling for cluster-related cobra commands.

## Key Components

- **`InitGlobalFlags()`** — Thread-safe lazy initialization of the global `cluster.FlagContainer`.
- **`GetCommandService()`** — Constructs a `cluster.ClusterService`, using an injected test executor if present, otherwise a real executor configured from global `--dry-run`/`--verbose` flags.
- **`CommandExecutor()`** — Returns the appropriate `executor.CommandExecutor` (test-injected or real) for commands to shell through.
- **`WrapCommandWithCommonSetup()`** — Wraps a cobra command's `RunE` function to ensure consistent error handling: errors are displayed once and converted to `errors.AlreadyHandledError` so `main.go` exits non-zero without duplicate error printing.
- **`SyncGlobalFlags()`** — Propagates global flags to all command-level flags.
- **`ValidateGlobalFlags()`** — Validates the current global flags.
- **`GetGlobalFlags()`** — Initializes (if needed) and returns the global `FlagContainer`.
- **`SetTestExecutor(exec)`** — Test-only helper to inject a mock `CommandExecutor`.
- **`ResetGlobalFlags()`** — Test-only helper to reset global state between test runs.

## Usage Example

```go
func newClusterCreateCommand() *cobra.Command {
	cmd := &cobra.Command{
		Use: "create",
		RunE: utils.WrapCommandWithCommonSetup(func(cmd *cobra.Command, args []string) error {
			service := utils.GetCommandService()
			return service.CreateCluster(args[0])
		}),
	}
	return cmd
}

// In tests:
func TestClusterCreate(t *testing.T) {
	mockExec := &mockCommandExecutor{}
	utils.SetTestExecutor(mockExec)
	defer utils.ResetGlobalFlags()

	// run command using injected mock executor
}
```

**Note:** This package must never import `tests/...` packages, since doing so would pull test-only dependencies (e.g., `testify`) into the shipped production binary.
