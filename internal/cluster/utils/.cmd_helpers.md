Shared CLI command helpers providing global flag management, command service initialization, and consistent error handling for all cluster commands.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `InitGlobalFlags` | `func` | Lazily initializes the global `FlagContainer` (thread-safe via mutex) |
| `GetGlobalFlags` | `func` | Returns the global `FlagContainer`, initializing it if needed |
| `GetCommandService` | `func` | Builds a `ClusterService` using an injected executor or a real one from current flags |
| `WrapCommandWithCommonSetup` | `func` | Middleware that wraps a Cobra `RunE` function with centralized error display and `AlreadyHandledError` sentinel propagation |
| `SyncGlobalFlags` | `func` | Propagates global flag values to all command-level flags |
| `ValidateGlobalFlags` | `func` | Runs validation rules against the current global flags |
| `SetTestExecutor` | `func` | Injects a mock `CommandExecutor` for cmd-layer tests only |
| `ResetGlobalFlags` | `func` | Clears the global flag container; used for test cleanup |

## Usage Example

```go
// Register and wrap a cobra command
func NewMyCmd() *cobra.Command {
    cmd := &cobra.Command{
        Use:   "my-command",
        Short: "Does something useful",
        RunE: utils.WrapCommandWithCommonSetup(func(cmd *cobra.Command, args []string) error {
            utils.SyncGlobalFlags()
            if err := utils.ValidateGlobalFlags(); err != nil {
                return err
            }
            svc := utils.GetCommandService()
            return svc.DoSomething()
        }),
    }
    return cmd
}

// In tests — inject a mock executor and clean up afterwards
func TestMyCmd(t *testing.T) {
    utils.SetTestExecutor(myMockExecutor)
    t.Cleanup(utils.ResetGlobalFlags)
    // ...
}
```

## Notes

- `WrapCommandWithCommonSetup` prevents duplicate error output by checking for `AlreadyHandledError` before printing; the root command must have `SilenceErrors` enabled.
- This package must **never** import `tests/...` to avoid pulling test dependencies into the shipped binary.
- `SetTestExecutor` / `ResetGlobalFlags` are test-only entry points; production code does not call them.
