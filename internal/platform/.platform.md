Centralizes host OS detection and per-tool prerequisite installation guidance, mapping tool names to OS-specific install hints to support non-technical users when a required CLI dependency is missing.

## Key Components

| Symbol | Kind | Description |
|--------|------|-------------|
| `OS` | Type | String alias representing the host operating system (`darwin`, `linux`, `windows`) |
| `Current()` | Function | Returns the host `OS` via `runtime.GOOS` |
| `IsWindows()` | Function | Convenience boolean check for Windows hosts |
| `InstallDocs` | Struct | Per-OS installation hint strings with a `Default` fallback |
| `InstallDocs.Hint()` | Method | Returns the appropriate hint for the current OS, falling back to `Default` |
| `toolDocs` | Variable | Internal map of tool name → `InstallDocs`; single source of truth for prerequisite hints |
| `InstallHint(tool)` | Function | Public entry point — returns the OS-appropriate install hint for a named tool |

**Registered tools:** `docker`, `k3d`, `helm`, `certificates`

## Usage Example

```go
package main

import (
    "fmt"
    "github.com/flamingo-stack/openframe-cli/internal/platform"
)

func main() {
    // Detect current OS
    fmt.Println("Running on:", platform.Current())

    // Check if a required tool is available; surface a hint if not
    if !dockerInstalled() {
        fmt.Println(platform.InstallHint("docker"))
        // macOS output:
        // "Docker: Install Docker Desktop from https://docker.com/products/docker-desktop
        //  or run 'brew install --cask docker'"
    }

    // Skip Windows-specific logic
    if platform.IsWindows() {
        fmt.Println(platform.InstallHint("certificates"))
        // "Certificates: Please install mkcert manually from
        //  https://github.com/FiloSottile/mkcert and run 'mkcert localhost 127.0.0.1'"
    }
}
```

## Fallback Behaviour

`InstallHint` never panics on an unregistered tool name — unknown tools receive a generic `"please install <tool> and ensure it is on your PATH"` message. Within `InstallDocs`, any OS without a specific entry falls back to `Default`, ensuring Windows and unrecognised platforms always receive a documentation link rather than a hard failure.
