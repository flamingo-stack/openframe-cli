## Overview

The `platform` package centralizes host operating system detection and provides per-OS installation guidance for CLI prerequisites (Docker, k3d, Helm, Terraform, gcloud, etc.). It ensures users on macOS, Linux, and Windows receive tailored, actionable instructions when a required tool is missing, rather than a generic error.

## Key Components

- **`OS`** — Type alias for representing the host operating system (`Darwin`, `Linux`, `Windows` constants).
- **`Current()`** — Returns the current host OS as reported by the Go runtime.
- **`IsWindows()`** — Convenience check for whether the host is Windows.
- **`InstallDocs`** — Struct holding per-OS installation guidance strings (`Darwin`, `Linux`, `Windows`, `Default`).
- **`InstallDocs.Hint()`** — Returns the guidance string for the current OS, falling back to `Default`.
- **`toolDocs`** — Map of tool name → `InstallDocs`, acting as the single source of truth for install hints (covers `docker`, `k3d`, `helm`, `certificates`, `terraform`, `gcloud`, `gke-gcloud-auth-plugin`, `infracost`, `aws`).
- **`InstallHint(tool string)`** — Public entry point that looks up a tool's OS-specific install message, or returns a generic fallback for unknown tools.

## Usage Example

```go
package main

import (
	"fmt"

	"github.com/flamingo-stack/openframe-cli/platform"
)

func main() {
	if platform.IsWindows() {
		fmt.Println("Running on Windows")
	}

	// Get install guidance for a missing prerequisite
	fmt.Println(platform.InstallHint("docker"))
	fmt.Println(platform.InstallHint("k3d"))

	// Unknown tools get a safe generic fallback
	fmt.Println(platform.InstallHint("some-custom-tool"))
}
```

This is typically used in prerequisite-checking logic, where a tool is detected as missing and `platform.InstallHint(toolName)` is surfaced to the user in an error or warning message.
