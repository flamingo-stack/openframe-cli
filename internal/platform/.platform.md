## Overview

The `platform` package centralizes host operating system detection and per-tool installation guidance for CLI prerequisites. It provides OS-aware, actionable install hints (e.g., macOS `brew` commands vs. Linux package manager instructions) instead of generic error messages, so users missing a required tool are pointed toward a concrete fix.

## Key Components

- **`OS`** — string type identifying the host OS, with constants `Darwin`, `Linux`, `Windows`.
- **`Current()`** — returns the host OS as reported by the Go runtime (`runtime.GOOS`).
- **`IsWindows()`** — convenience check for whether the host is Windows.
- **`InstallDocs`** — struct holding per-OS installation guidance strings (`Darwin`, `Linux`, `Windows`, `Default`).
  - **`Hint()`** — returns guidance for the current OS, falling back to `Default`.
  - **`hintFor(os OS)`** — internal helper resolving guidance for a specific OS.
- **`toolDocs`** — package-level map of tool name to `InstallDocs`, the single source of truth for prerequisites like `docker`, `k3d`, `helm`, `certificates`, `terraform`, `gcloud`, `gke-gcloud-auth-plugin`, `infracost`, and `aws`.
- **`InstallHint(tool string)`** — public entry point returning the OS-appropriate install message for a named tool; unknown tools get a generic fallback message rather than an error.

## Usage Example

```go
package main

import (
	"fmt"

	"github.com/flamingo-stack/openframe-cli/pkg/platform"
)

func main() {
	if platform.IsWindows() {
		fmt.Println("Running on Windows")
	}

	// Get install guidance for a missing prerequisite
	fmt.Println(platform.InstallHint("docker"))
	fmt.Println(platform.InstallHint("k3d"))

	// Unknown tools still get a safe fallback
	fmt.Println(platform.InstallHint("some-custom-tool"))
}
```

This is typically used in prerequisite-checking code paths: when a required binary (Docker, Helm, k3d, etc.) isn't found on `$PATH`, the CLI calls `platform.InstallHint(toolName)` to display a helpful, OS-specific remediation message instead of failing silently.
