## platform.go

Provides host-OS detection and centralized, per-tool installation guidance for missing prerequisites. It ensures users on macOS, Linux, and Windows receive OS-appropriate install instructions instead of generic errors, supporting a friendlier CLI experience for non-technical users.

## Key Components

- **`OS`** — string type identifying the host operating system (`Darwin`, `Linux`, `Windows` constants).
- **`Current()`** — returns the host OS as reported by the Go runtime.
- **`IsWindows()`** — convenience check for whether the current host is Windows.
- **`InstallDocs`** — struct holding per-OS installation guidance (`Darwin`, `Linux`, `Windows`, `Default` fields).
- **`InstallDocs.Hint()`** — returns guidance for the current OS, falling back to `Default`.
- **`toolDocs`** — package-level map from tool name (e.g. `docker`, `k3d`, `helm`, `terraform`, `gcloud`, `aws`) to its `InstallDocs`, acting as the single source of truth for prerequisite install hints.
- **`InstallHint(tool string)`** — public entry point returning the install message for a named tool on the current OS, with a generic fallback for unrecognized tools.

## Usage Example

```go
package main

import (
	"fmt"

	"github.com/flamingo-stack/openframe-cli/internal/platform"
)

func main() {
	if platform.IsWindows() {
		fmt.Println("Running on Windows")
	}

	// Show install guidance for a missing prerequisite
	fmt.Println(platform.InstallHint("docker"))
	fmt.Println(platform.InstallHint("helm"))

	// Unknown tools still return a safe fallback message
	fmt.Println(platform.InstallHint("some-custom-tool"))
}
```

This is typically invoked by prerequisite-checking logic when a required binary (Docker, k3d, Helm, Terraform, etc.) is not found on the `$PATH`, giving users a clear, OS-specific next step.
