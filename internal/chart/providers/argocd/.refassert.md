Provides ref-pinning validation for ArgoCD child applications, detecting the V3 silent-failure case where a legacy chart ignores the `repository.branch` pin and deploys from `main` instead of the requested ref.

## Key Components

| Symbol | Kind | Description |
|--------|------|-------------|
| `refMismatch` | struct | Captures a single child app whose `targetRevision` diverges from the requested ref |
| `defaultRefs` | var | Set of branch names (`""`, `main`, `master`, `head`) treated as unpinned — mismatches against these are silently ignored |
| `verifyRefPinning` | func | Iterates child apps, filters to matching repo URLs, and returns all `targetRevision` mismatches |
| `normalizeRef` | func | Strips `refs/heads/` / `refs/tags/` prefixes for short-name comparison |
| `normalizeRepoURL` | func | Canonicalizes a git remote URL (lowercased, scheme-stripped, credential-stripped, `.git`-stripped) |
| `refMismatchError` | func | Builds an actionable `error` message listing every divergent app |

## Usage Example

```go
// After app install completes and ArgoCD reports Healthy+Synced:
mismatches := verifyRefPinning(childApps, "https://github.com/org/repo.git", "feature/my-branch")
if len(mismatches) > 0 {
    return refMismatchError("feature/my-branch", mismatches)
}
// e.g. error output:
// requested ref "feature/my-branch" was NOT deployed: this branch's chart
// predates ref pinning ...
//   - app-worker is on "main", not "feature/my-branch"
```

## Notes

- **Repo scope**: only apps whose `RepoURL` normalizes to the same canonical URL as `repoURL` are evaluated; third-party chart sources are skipped.
- **Empty `targetRevision`**: silently skipped — ArgoCD inherits the repo default and there is nothing concrete to compare.
- **`v`-prefix tags**: `v1.2.3` and `1.2.3` are intentionally treated as **distinct** refs and will produce a mismatch if they differ.
