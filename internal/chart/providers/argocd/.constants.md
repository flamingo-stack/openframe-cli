Defines all compile-time constants for the ArgoCD package, serving as the single source of truth for chart identity, installation naming, and application status strings.

## Key Components

### Install Identity Constants
| Constant | Value |
|---|---|
| `ArgoCDNamespace` | `"argocd"` |
| `ArgoCDReleaseName` | `"argo-cd"` |
| `ArgoCDChartRef` | `"argo/argo-cd"` |
| `ArgoCDChartVersion` | `"10.1.4"` |
| `ArgoHelmRepoURL` | `"https://argoproj.github.io/argo-helm"` |

> **Note:** `ArgoCDNamespace` is coupled with `fullnameOverride: argocd` in `argocd-values.yaml` — keep both in sync when changing.

### Health Status Constants
- `ArgoCDHealthHealthy`, `ArgoCDHealthProgressing`, `ArgoCDHealthDegraded`, `ArgoCDHealthMissing`

### Sync Status Constants
- `ArgoCDSyncSynced`, `ArgoCDSyncOutOfSync`, `ArgoCDStatusUnknown`

> **Warning:** These status strings are compared by equality to determine install completion. Always use the constants — never raw strings — to avoid silent breakage.

## Usage Example

```go
// Check if an ArgoCD application is fully ready
func isReady(health, sync string) bool {
    return health == argocd.ArgoCDHealthHealthy &&
           sync == argocd.ArgoCDSyncSynced
}

// Install using the pinned chart identity
installer.Install(
    argocd.ArgoCDReleaseName,
    argocd.ArgoCDChartRef,
    argocd.ArgoCDChartVersion,
    argocd.ArgoCDNamespace,
    argocd.ArgoHelmRepoURL,
)
```
