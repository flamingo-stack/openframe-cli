Provides the `WaitForApplications` function and supporting logic for polling ArgoCD application health and sync status during platform installation, handling timeouts, cancellations, and failure recovery.

## Key Components

- **`WaitForApplications(ctx, config)`** — Main entry point. Waits for all ArgoCD applications to reach `Healthy + Synced` state. Handles dry-run bypass, deadline validation, bootstrap phase, and the main polling loop.
- **Bootstrap phase** — A 30-second warm-up period with 5-second cluster health checks before entering the main monitoring loop.
- **Main polling loop** — Checks application status every 2 seconds with configurable timeout (default: 60 minutes). Tracks:
  - `everReadyApps` — apps that have been healthy at least once
  - `stallTracker` — detects stalled/stuck applications (see `stall.go`)
  - `fatalManifestTracker` — fast-fails on deterministic manifest errors (see `fatalmanifest.go`)
  - Repo-server health with up to 3 auto-recovery attempts
- **Spinner management** — Thread-safe `stopSpinner()` using `sync.Mutex`; falls back to plain `pterm` output in silent mode.
- **WSL/Windows recovery** — On `runtime.GOOS == "windows"`, attempts `executor.TryRecoverWSL()` before counting consecutive cluster failures.
- **`timeoutError`** — Returns a structured error naming the specific apps that never became ready, including their last health state and a `kubectl` command hint.

## Usage Example

```go
mgr := argocd.NewManager(client)
cfg := config.ChartInstallConfig{
    ClusterName: "openframe",
    Verbose:     true,
    DryRun:      false,
}

ctx, cancel := context.WithTimeout(context.Background(), 90*time.Minute)
defer cancel()

if err := mgr.WaitForApplications(ctx, cfg); err != nil {
    log.Fatalf("ArgoCD apps not ready: %v", err)
}
```
