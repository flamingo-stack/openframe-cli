## Overview

`wait.go` implements the core wait-loop logic for the ArgoCD `Manager`, polling ArgoCD Applications until they all reach `Healthy` + `Synced` status (or a timeout/fatal error occurs) after a chart install. It coordinates progress display (dashboard/spinner/plain output), cluster health monitoring, repo-server issue detection/recovery, and several stall/degraded/fatal-manifest trackers to fail fast on unrecoverable states instead of always waiting for the full timeout.

## Key Components

- **`WaitForApplications(ctx, config)`** — Main entry point. Skips work in dry-run mode, validates remaining context deadline, waits for ArgoCD readiness and repo-server health, then runs a bootstrap phase followed by the main monitoring loop until all applications are ready or an error/timeout occurs.
- **Display coordination** — Chooses between `appDashboard` (interactive live view), `uispinner.Spinner` (one-line status), or plain `pterm` output based on `config.Silent`/`config.Verbose`.
- **`waitNote` helper** — Routes ad-hoc status messages either to the dashboard's note area or through the standard printer (preserving CI `::warning::` annotation behavior).
- **Bootstrap phase** — A fixed 30-second window with periodic cluster connectivity checks and failure-count tolerance before entering the main loop.
- **Main monitoring loop** — Polls applications on an interval, tracks readiness counts, stabilization checks, and per-application state via helper trackers: `stallTracker`, `fatalManifestTracker`, `degradedTracker`, and repo-server recovery counters.
- **Timeout/error diagnostics** — Retains `lastNotReadyApps`, `lastNotReadyNames`, `lastNotReadyDetails`, and `lastAppsSeen` so timeout/cancellation errors report exactly which applications were stuck and why.

## Usage Example

```go
mgr := argocd.NewManager(clusterName, executor)

cfg := config.ChartInstallConfig{
    ClusterName: "my-cluster",
    Verbose:     true,
    Silent:      false,
    DryRun:      false,
}

ctx, cancel := context.WithTimeout(context.Background(), 60*time.Minute)
defer cancel()

if err := mgr.WaitForApplications(ctx, cfg); err != nil {
    log.Fatalf("ArgoCD applications did not become ready: %v", err)
}
```

This is typically invoked automatically as part of the chart installation flow after the app-of-apps bootstrap, ensuring the CLI blocks until the platform is fully synced before proceeding.
