## Overview

`wait.go` implements the ArgoCD application readiness watcher used during platform installation. `Manager.WaitForApplications` blocks until all applications deployed by the app-of-apps pattern reach `Healthy` + `Synced` status, while orchestrating cluster health checks, repo-server recovery, stall/degraded-app detection, and rich user-facing progress reporting.

## Key Components

- **`WaitForApplications(ctx, config)`** — main entry point. Skips work in dry-run mode, validates there is enough time before the context deadline, then runs a bootstrap wait (30s) followed by a main polling loop until all apps are ready or a timeout/cancellation occurs.
- **Display modes** — chooses between a live `appDashboard` (interactive, non-verbose), a `uispinner.Spinner` (default), or plain `pterm.Info` logging (`--silent`), with `waitNote` routing one-off messages appropriately.
- **Health checks** — `checkRepoServerHealth`, `checkClusterConnectivity`, `repoServerAge`, and `triggerRepoServerRecovery` guard against known ArgoCD repo-server failure modes (OOMKill, CrashLoopBackOff) with cold-start grace handling.
- **Tracking state** — `stallTracker`, `fatalManifestTracker`, and `degradedTracker` detect stuck syncs, invalid chart manifests, and terminally degraded apps to fail fast instead of waiting out the full timeout.
- **Timeout/cancellation handling** — `capToDeadline` bounds the wait to the caller's context deadline; cancellation paths print a last-known-state summary (ready count, pending app names) before returning an error.

## Usage Example

```go
mgr := argocd.NewManager(executor, platformClient)

cfg := config.ChartInstallConfig{
    ClusterName: "openframe-cluster",
    Verbose:     false,
    Silent:      false,
    DryRun:      false,
}

ctx, cancel := context.WithTimeout(context.Background(), 60*time.Minute)
defer cancel()

if err := mgr.WaitForApplications(ctx, cfg); err != nil {
    log.Fatalf("ArgoCD applications did not become ready: %v", err)
}
```

This is typically invoked as the final step of a chart install workflow, after ArgoCD itself and the app-of-apps root application have been deployed to the cluster.
