Diagnostic helper for ArgoCD applications whose workloads are unhealthy despite a successful sync. It inspects pods belonging to a "Degraded" application, identifies failing containers (crash loops, image pull errors, config errors), and pulls crash logs plus recent warning events to explain *why* a pod is stuck — turning a silent timeout into an actionable root cause.

## Key Components

- **`failingContainers(pod)`** — Pure function that scans a pod's container statuses and returns `containerIssue` entries for any container that is waiting on an error reason, terminated non-zero, or crash-looping between restarts. Marks issues `terminal` when they won't self-recover.
- **`containerIssue`** — Struct describing a single failing container: pod, container name, image, reason, restart count, and whether it's terminal.
- **`terminalWaitingReasons`** — Map of Kubernetes waiting reasons (e.g. `CrashLoopBackOff`, `ImagePullBackOff`) considered unrecoverable without intervention.
- **`isImagePullReason(reason)`** — Detects image-pull-related failure reasons to surface a registry-credentials hint.
- **`(m *Manager) appPods(ctx, ns, appName)`** — Lists pods for an app by ArgoCD tracking labels, falling back to the whole namespace; returns whether the pods are confidently attributable (`owned`) to that app.
- **`(m *Manager) diagnoseFailingApps(ctx, apps)`** — Main entry point: builds a human-readable diagnostic report per app (failing pods, reasons, logs, warning events) and returns the subset of apps that are genuinely stuck (terminal + owned), safe to use for fail-fast decisions.
- **`(m *Manager) lastPodLogs(ctx, ns, pod, container, previous)`** — Fetches the last N log lines from a container, optionally from its previous (crashed) instance.
- **`(m *Manager) recentWarningEvents(ctx, ns)`** — Returns the most recent Kubernetes Warning events in a namespace, newest first.
- **`indentLines(s, prefix)`** — Utility to indent multi-line strings for report formatting.

## Usage Example

```go
diag, stuckApps := manager.diagnoseFailingApps(ctx, degradedApps)

if len(stuckApps) > 0 {
    fmt.Println("Fail-fast: these apps will not recover on their own:")
    for _, app := range stuckApps {
        fmt.Println(" -", app.Name)
    }
}

if diag != "" {
    fmt.Println("Diagnostic details:")
    fmt.Println(diag)
}
```

This is typically invoked while waiting for ArgoCD applications to become healthy, allowing the caller to abort early with a meaningful root cause instead of waiting out a full timeout.
