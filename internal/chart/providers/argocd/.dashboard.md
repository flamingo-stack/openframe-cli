## dashboard.go

Implements `appDashboard`, an in-place, live-updating terminal view used during ArgoCD application installs to show overall readiness progress along with the specific applications that are still not healthy/synced. It replaces a plain spinner during long-running waits (up to an hour) so a stuck install is visually distinguishable from a working one.

## Key Components

- **`appDashboard`** — struct holding the live dashboard state (area printer, start time, per-app ready timestamps, pinned notes). All methods are nil-safe, so a `nil` dashboard silently becomes a no-op (used when not in an interactive/animated terminal).
- **`newAppDashboard()`** — constructs and starts the dashboard; returns `nil` if the terminal isn't animated (`ui.Animated()` is false) or the area printer fails to start.
- **`(*appDashboard) Update(ready, total int, apps []Application)`** — redraws the dashboard each poll cycle: spinner frame, elapsed time, progress bar, and a list of not-ready applications.
- **`notReadyLines(apps []Application) string`** — renders the not-ready apps (sorted, capped at `dashboardMaxApps`), colored by health (red = Degraded, yellow = Progressing, gray = other).
- **`pendingSummary(apps []Application, limit int) string`** — compact one-line summary of pending apps (e.g. `tenant(Progressing), gateway(Degraded), +3 more`) for non-interactive log output.
- **`(*appDashboard) Note(styled string)`** — pins a one-off event line (e.g. stall hint) below the dashboard, keeping only the last 5.
- **`(*appDashboard) Fail(text string)` / `Stop()` / `FinishSuccess(text string)`** — tear down the dashboard, optionally printing a final success/failure line. `FinishSuccess` appends the slowest-to-become-ready applications.
- **`(*appDashboard) slowestLine(n int) string`** — formats the top `n` slowest applications by time-to-ready, e.g. `(slowest: tenant 9m12s · datasources 4m01s)`.
- **`dashboardMaxApps`** — constant capping how many not-ready apps are displayed at once.

## Usage Example

```go
dashboard := newAppDashboard() // nil if not an interactive terminal

for {
    apps, ready, total := pollArgoCDApplications()
    dashboard.Update(ready, total, apps)

    if stalled {
        dashboard.Note(pterm.FgYellow.Sprint("no progress in 2m — check ArgoCD UI"))
    }

    if ready == total {
        dashboard.FinishSuccess("OpenFrame applications installed")
        break
    }
    if failed {
        dashboard.Fail("installation failed: " + pendingSummary(apps, 3))
        break
    }
    time.Sleep(5 * time.Second)
}
```
