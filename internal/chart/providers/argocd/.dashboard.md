# dashboard.go

Implements `appDashboard`, a live, in-place terminal view used while waiting for ArgoCD applications to become healthy. It replaces a single spinner line with a redrawing block that shows elapsed time, a progress bar, and which applications are still not ready (with their health/sync status), making a working install visually distinguishable from a stalled one. All methods are nil-safe, so a nil dashboard silently becomes a no-op ("not active") mode.

## Key Components

- **`appDashboard`** - struct holding the `pterm.AreaPrinter`, start time, per-app ready timestamps, and pinned notes; guarded by a mutex for concurrent updates.
- **`newAppDashboard()`** - constructor; returns `nil` when the terminal isn't interactive/animated (e.g., `--silent` or `--verbose` mode), disabling the dashboard entirely.
- **`(*appDashboard).Update(ready, total int, apps []Application)`** - redraws the dashboard frame: spinner, elapsed time, progress bar, and list of not-ready apps.
- **`(*appDashboard).Note(styled string)`** - pins a one-off event line (e.g., stall/recovery notice) below the dashboard, capped to the last 5 entries.
- **`(*appDashboard).Fail(text string)` / `Stop()` / `FinishSuccess(text string)`** - terminate the dashboard, optionally printing a success/failure message; `FinishSuccess` appends the slowest-to-ready applications.
- **`notReadyLines(apps []Application) string`** - formats a color-coded, capped (`dashboardMaxApps`) list of pending applications for the live view.
- **`pendingSummary(apps []Application, limit int) string`** - one-line, comma-separated summary of pending apps for scrollback/log output (non-interactive fallback).
- **`dashboardMaxApps`** - constant capping how many pending apps are listed before summarizing as "+N more".

## Usage Example

```go
dash := newAppDashboard() // nil if terminal isn't interactive

for {
    apps, ready, total := pollArgoCDApplications()
    dash.Update(ready, total, apps)

    if stalled {
        dash.Note(pterm.FgYellow.Sprint("no progress in 2m, still waiting..."))
    }

    if allReady {
        dash.FinishSuccess("OpenFrame applications installed")
        break
    }
    if failed {
        dash.Fail("installation failed: see application errors above")
        break
    }
    time.Sleep(pollInterval)
}
```
