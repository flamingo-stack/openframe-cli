# dashboard.go

Implements a live, in-place terminal dashboard for tracking ArgoCD application readiness during OpenFrame installation. Instead of a static spinner, it renders a self-updating block showing elapsed time, a progress bar, and per-application health/sync status for any apps that aren't yet ready — making it easy to distinguish a healthy install from a stalled one at a glance.

## Key Components

- **`appDashboard`** — Core struct managing the live dashboard state (progress, timing, notes). All methods are nil-safe, so a nil dashboard silently no-ops (used when the terminal isn't interactive or when `--silent`/`--verbose` is active).
- **`newAppDashboard()`** — Constructor; returns `nil` if the terminal isn't animated (non-interactive), otherwise starts a `pterm.AreaPrinter`.
- **`Update(ready, total int, apps []Application)`** — Redraws the dashboard on each poll cycle, showing the progress bar and a list of not-ready applications.
- **`Note(styled string)`** — Pins a one-off event line (e.g., stall hints) below the dashboard, capped to the last 5 notes.
- **`Fail(text)` / `Stop()` / `FinishSuccess(text)`** — Terminate the live dashboard and print a final status line; `FinishSuccess` appends a "slowest apps" summary.
- **`notReadyLines(apps)`** — Helper that formats not-ready apps (alphabetical, capped at `dashboardMaxApps`), color-coded by health state.
- **`pendingSummary(apps, limit)`** — Produces a compact, single-line summary of pending apps for non-interactive/log output (e.g., `"tenant(Progressing), gateway(Degraded), +3 more"`).
- **`slowestLine(n)`** — Renders the top-N slowest-to-become-ready applications for the final success message.

## Usage Example

```go
// Start the dashboard (returns nil if not in an interactive terminal)
dash := newAppDashboard()

for !allReady {
    apps, ready, total := pollArgoCDApps()
    dash.Update(ready, total, apps)

    if stalled {
        dash.Note(pterm.FgYellow.Sprint("no progress in 2m — check ArgoCD"))
    }
    time.Sleep(pollInterval)
}

if success {
    dash.FinishSuccess("OpenFrame applications installed")
} else {
    dash.Fail("installation failed: timeout waiting for applications")
}
```

This pattern is typically used inside a polling loop that repeatedly queries ArgoCD `Application` resources and updates the dashboard until all applications report `Healthy`/`Synced` status.
