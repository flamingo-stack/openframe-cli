Detects and surfaces permanent manifest-generation failures in ArgoCD applications, short-circuiting long waits when a requested chart path or revision simply does not exist.

## Key Components

### Variables

| Variable | Purpose |
|---|---|
| `manifestErrorContexts` | Strings that confirm a condition is a manifest-generation error (gate before deterministic check) |
| `deterministicManifestPatterns` | Fragments that mark a failure as permanent (e.g., `"no such file or directory"`) |
| `fatalManifestAfter` | Duration (2 min) a deterministic error must persist before triggering a fail-fast |
| `fatalManifestMinChecks` | Minimum consecutive observations (5) required to avoid false positives from connectivity gaps |

### Functions & Types

| Symbol | Description |
|---|---|
| `isDeterministicManifestError(condition)` | Returns `true` when a condition string indicates a permanent, non-retryable manifest failure |
| `fatalManifestTracker` | Per-application tracker recording how long a deterministic error has persisted; resets on change |
| `fatalManifestTracker.observe(apps, now)` | Advances counters for affected apps; returns those breaching both thresholds |
| `fatalManifestError(requestedRef, apps)` | Renders a human-readable error message with per-app details and remediation hints |

## Usage Example

```go
tracker := newFatalManifestTracker()

// Called once per polling tick
fatal := tracker.observe(liveApps, time.Now())
if len(fatal) > 0 {
    return fatalManifestError(requestedRef, fatal)
}
```

## Thresholds

Both conditions must be satisfied before a fail-fast fires:

```text
elapsed >= fatalManifestAfter  (2 minutes)
   AND
checks  >= fatalManifestMinChecks (5 consecutive observations)
```

This guards against transient errors (EOF, connection resets) triggering a premature failure while still avoiding the 20+ minute wait previously observed for genuinely unresolvable errors.
