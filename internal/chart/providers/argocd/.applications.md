## Purpose

This file implements the `Manager` type for interacting with ArgoCD Application custom resources in a Kubernetes cluster, part of the `argocd` package used by `openframe-cli`. It provides Kubernetes client initialization (both kubeconfig-based and pre-configured `rest.Config`), TLS bypass handling for local k3d clusters, and data structures for representing ArgoCD Application status (health, sync state, resource conditions) parsed either via `kubectl` JSON output or the Kubernetes dynamic client.

## Key Components

- **`Manager`** — Core struct holding executor, cluster name, native Kubernetes clients (`kubeClient`, `apiextClient`, `dynamicClient`), and various tunable timeouts/retry counts (e.g., `waitTimeout`, `syncWait`, `podWaitTimeout`) used to control polling behavior during install/sync operations.
- **`NewManager`, `NewManagerWithCluster`, `NewManagerWithConfig`** — Constructors for creating a `Manager`, with or without an explicit cluster context or pre-built `rest.Config`.
- **`(*Manager) initKubernetesClients`** — Lazily builds Kubernetes clients from a kubeconfig file, applying insecure TLS settings and Windows host normalization for local clusters.
- **`(*Manager) WithWaitTimeout` / `SetClusterName`** — Fluent configuration setters.
- **`Application`** — Represents parsed ArgoCD application status (health, sync, conditions, operation phase, source repo info, unhealthy child resources).
- **`ResourceIssue`** — Represents a single unhealthy child resource within a Degraded application.
- **`argoApp`** — Internal struct mirroring the raw JSON shape of an ArgoCD `Application` resource, used for unmarshaling.
- **`argoAppFromObject`** — Converts a dynamic-client unstructured object into an `argoApp` via JSON round-trip.
- **`applicationGVR`** — `GroupVersionResource` for `argoproj.io/v1alpha1` Applications, used with the dynamic client instead of importing the ArgoCD Go module directly.
- **`getKubeconfigPath`** — Resolves the kubeconfig path from `$KUBECONFIG` or the default `~/.kube/config`.

## Usage Example

```go
executor := executor.NewCommandExecutor()

// Option 1: build from kubeconfig + cluster name
mgr := argocd.NewManagerWithCluster(executor, "k3d-openframe")

// Option 2: build from an existing rest.Config (e.g., right after cluster creation)
mgr, err := argocd.NewManagerWithConfig(executor, restConfig)
if err != nil {
    log.Fatalf("failed to create ArgoCD manager: %v", err)
}

// Customize wait behavior for a force-sync scenario
mgr = mgr.WithWaitTimeout(10 * time.Minute)
```
