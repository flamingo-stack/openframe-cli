## Overview

Defines the `Manager` type for `argocd`, which drives ArgoCD-specific operations (application status inspection, sync, and readiness waiting) against a Kubernetes cluster. It exposes both a native Kubernetes/dynamic-client path and a `kubectl`-fallback path for reading ArgoCD `Application` custom resources, avoiding a hard dependency on the ArgoCD Go module.

## Key Components

- **`Manager`** — Core struct holding a `CommandExecutor`, optional cluster name, native Kubernetes clients (`kubeClient`, `apiextClient`, `dynamicClient`), and tunable timing fields (`StabilizationChecks`, `syncWait`, `waitTimeout`, `groupWait`, `crdWaitRetries`, `podWaitTimeout`, `podWaitInterval`, `podReadyTimeout`) used to control sync/wait behavior and support fast test overrides.
- **`NewManager` / `NewManagerWithCluster` / `NewManagerWithConfig`** — Constructors for `Manager`; `NewManagerWithConfig` pre-initializes native clients from a `*rest.Config` (applying insecure TLS handling for local k3d clusters).
- **`initKubernetesClients`** — Lazily builds kubeconfig-based clients (core, apiextensions, dynamic), resolving cluster context and normalizing the host for Windows/Docker Desktop setups.
- **`WithWaitTimeout`** — Fluent setter for overriding the default 60-minute `WaitForApplications` timeout.
- **`SetClusterName`** — Sets the explicit kubeconfig context to target.
- **`Application`** — Represents parsed ArgoCD application status (health, sync, conditions, operation state, source repo info, and `UnhealthyResources`).
- **`ResourceIssue`** — Describes a single unhealthy child resource within a `Degraded` application.
- **`argoApp`** / **`argoAppFromObject`** — Internal JSON-shaped struct and converter used to parse Application data uniformly from both `kubectl` JSON output and dynamic-client unstructured objects.
- **`applicationGVR`** — `GroupVersionResource` (`argoproj.io/v1alpha1/applications`) used by the dynamic client.

## Usage Example

```go
import (
	"github.com/flamingo-stack/openframe-cli/internal/chart/argocd"
	"github.com/flamingo-stack/openframe-cli/internal/shared/executor"
)

// Using kubectl-backed executor with explicit cluster context
exec := executor.NewCommandExecutor()
mgr := argocd.NewManagerWithCluster(exec, "k3d-openframe")
mgr = mgr.WithWaitTimeout(10 * time.Minute)

// Or, with a pre-built *rest.Config (e.g., right after cluster creation)
mgr, err := argocd.NewManagerWithConfig(exec, restConfig)
if err != nil {
	log.Fatalf("failed to create argocd manager: %v", err)
}
```

## Notes

Applications are read via the dynamic client rather than the official ArgoCD Go module, since that module is not designed for external import (its `go.mod` uses a local `replace` directive). This design also decouples the CLI from any specific deployed ArgoCD version.
