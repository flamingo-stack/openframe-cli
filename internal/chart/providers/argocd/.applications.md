Provides ArgoCD application lifecycle management for the OpenFrame CLI, including Kubernetes client initialization, application status modeling, and dynamic CRD access via the Kubernetes API.

## Key Components

### Types

- **`Manager`** — Core struct handling ArgoCD operations; holds Kubernetes clients (`kubeClient`, `dynamicClient`, `apiextClient`), cluster context, and configurable timeouts for sync/wait behavior.
- **`Application`** — Public representation of an ArgoCD application's runtime state (health, sync status, conditions, source info).
- **`argoApp`** — Internal JSON-mapped struct used for parsing raw ArgoCD CRD objects from both `kubectl` and the dynamic client.

### Constructors

- **`NewManager`** — Basic manager from a `CommandExecutor`.
- **`NewManagerWithCluster`** — Manager with an explicit kubecontext cluster name.
- **`NewManagerWithConfig`** — Preferred constructor when a `*rest.Config` is already available (e.g., post k3d cluster creation); initializes all three Kubernetes clients eagerly.

### Key Functions

- **`initKubernetesClients()`** — Lazily initializes `kubeClient`, `apiextClient`, and `dynamicClient` from kubeconfig; handles Windows `host.docker.internal` normalization and TLS bypass for local k3d clusters.
- **`argoAppFromObject()`** — Converts a dynamic-client unstructured map to `argoApp` via JSON round-trip.
- **`applicationFromArgoApp()`** — Maps `argoApp` to the public `Application` type with safe defaults.
- **`getTotalExpectedApplications()`** — Best-effort upfront application count using the dynamic client.

### Constants

- **`applicationGVR`** — `GroupVersionResource` for `argoproj.io/v1alpha1/applications`, used with the dynamic client to avoid importing the argo-cd module directly.

## Usage Example

```go
// Preferred: use an existing rest.Config
mgr, err := argocd.NewManagerWithConfig(exec, restConfig)
if err != nil {
    log.Fatal(err)
}
mgr.WithWaitTimeout(15 * time.Minute)

// Or: resolve context by cluster name
mgr := argocd.NewManagerWithCluster(exec, "k3d-openframe")
```
