## diagnostics.go

Provides diagnostic and self-healing utilities for ArgoCD deployments, including cluster connectivity checks, repo-server health monitoring, and automated recovery via pod restarts and hard refreshes. All checks are best-effort and rely on the native Kubernetes client rather than shelling out to `kubectl`.

## Key Components

- **`RepoServerIssue`** - Struct describing a detected repo-server problem (`Type`, `Message`, `Recoverable`).
- **`(m *Manager) printArgoCDPodDiagnostics(ctx)`** - Prints a summary of ArgoCD deployments/pods (readiness, restarts, waiting reasons) when pods fail to become ready.
- **`(m *Manager) checkClusterConnectivity(ctx, verbose)`** - Verifies the Kubernetes API server is reachable via a lightweight namespace GET; used to detect cluster loss mid-install.
- **`(m *Manager) printClusterDiagnostics(ctx)`** - Prints node count and readiness when the cluster becomes unreachable.
- **`(m *Manager) checkRepoServerHealth(ctx, verbose)`** - Inspects repo-server pods for OOM kills, restarts, `CrashLoopBackOff`, or non-`Running` phase; returns the first `RepoServerIssue` found.
- **`(m *Manager) hardRefreshApplications(ctx, names)`** - Patches Applications with `argocd.argoproj.io/refresh: hard` to force manifest re-fetch from git, bypassing the repo-server cache.
- **`(m *Manager) triggerRepoServerRecovery(ctx, appName)`** - Deletes repo-server pods to force a restart, waits up to ~60s for recovery, then hard-refreshes the triggering application.
- **`(m *Manager) repoServerAge(ctx)`** - Returns the age of the youngest repo-server pod; used to avoid restarting a repo-server still in cold-start (`repoServerColdStartGrace` = 3 minutes).
- **Helpers:** `oomKilled`, `containerReadiness`, `totalRestarts`, `nodeReady` - small utilities for inspecting pod/container/node status.

## Usage Example

```go
// Check if the repo-server has an unhealthy state
if issue := manager.checkRepoServerHealth(ctx, true); issue != nil {
    if issue.Recoverable {
        if ok := manager.triggerRepoServerRecovery(ctx, "my-application"); ok {
            fmt.Println("repo-server recovered and app refreshed")
        }
    } else {
        fmt.Println("unrecoverable issue:", issue.Message)
    }
}

// Verify cluster is reachable before proceeding
if err := manager.checkClusterConnectivity(ctx, false); err != nil {
    manager.printClusterDiagnostics(ctx)
}
```
