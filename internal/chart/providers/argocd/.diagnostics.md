## diagnostics.go

Provides diagnostic and self-healing utilities for ArgoCD deployments, including pod/cluster health checks, repo-server issue detection, and automated recovery via pod restarts and hard refreshes.

## Key Components

- **`RepoServerIssue`** – Struct describing a detected ArgoCD repo-server problem (`Type`, `Message`, `Recoverable`).
- **`repoServerColdStartGrace`** – Constant grace period (3 minutes) preventing premature restarts of a newly-started repo-server.
- **`(m *Manager) repoServerAge(ctx)`** – Returns the age of the youngest repo-server pod, used to avoid disrupting cold starts.
- **`(m *Manager) printArgoCDPodDiagnostics(ctx)`** – Prints a summary of ArgoCD deployments and pods when readiness fails.
- **`(m *Manager) checkClusterConnectivity(ctx, verbose)`** – Verifies the Kubernetes API is reachable via a lightweight namespace lookup; used by wait loops to detect cluster loss mid-install.
- **`(m *Manager) printClusterDiagnostics(ctx)`** – Prints node readiness summary when the cluster becomes unreachable.
- **`(m *Manager) checkRepoServerHealth(ctx, verbose)`** – Inspects repo-server pods for OOM kills, restarts, `CrashLoopBackOff`, or non-`Running` phase; returns the first `*RepoServerIssue` found.
- **`oomKilled(cs)`** – Helper checking current/previous container termination for an OOM-killed reason.
- **`(m *Manager) hardRefreshApplications(ctx, names)`** – Patches Applications with a hard-refresh annotation to force manifest re-fetch from git, bypassing the repo-server cache.
- **`(m *Manager) triggerRepoServerRecovery(ctx, appName)`** – Deletes repo-server pods to force recreation, waits (~60s) for health recovery, then hard-refreshes the triggering application.
- **`containerReadiness`, `totalRestarts`, `nodeReady`** – Small helpers for summarizing pod/node status.

## Usage Example

```go
mgr := &Manager{ /* kubeClient, dynamicClient initialized */ }

ctx := context.Background()

// Check cluster reachability before proceeding with install steps
if err := mgr.checkClusterConnectivity(ctx, true); err != nil {
    mgr.printClusterDiagnostics(ctx)
    return err
}

// Detect and recover from a stuck repo-server
if issue := mgr.checkRepoServerHealth(ctx, true); issue != nil && issue.Recoverable {
    if mgr.triggerRepoServerRecovery(ctx, "my-application") {
        pterm.Success.Println("repo-server recovered")
    }
}
```

This file is internal to the `argocd` package and is typically invoked from higher-level install/wait orchestration logic rather than used directly by CLI commands.
