Provides diagnostic and recovery utilities for ArgoCD workloads running in Kubernetes, including pod health checks, cluster connectivity verification, repo-server restart logic, and application hard-refresh triggering.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `RepoServerIssue` | struct | Describes a detected repo-server problem with a type (`communication`, `resource`, `git`, `timeout`), message, and recoverability flag |
| `repoServerAge` | method | Returns the age of the youngest repo-server pod; used to enforce a cold-start grace period before restart |
| `printArgoCDPodDiagnostics` | method | Prints deployment readiness and per-pod container status/restart counts when pods fail to become ready |
| `checkClusterConnectivity` | method | Lightweight API-server reachability check via a namespace GET; used by the install wait loop |
| `printClusterDiagnostics` | method | Prints node readiness summary when the cluster becomes unreachable |
| `checkRepoServerHealth` | method | Inspects repo-server pods for restarts, `CrashLoopBackOff`, OOM, or non-Running phase |
| `hardRefreshApplications` | method | Patches ArgoCD Applications with a hard-refresh annotation to bypass stale manifest cache |
| `triggerRepoServerRecovery` | method | Deletes repo-server pods and waits for recreation, then hard-refreshes the triggering application |
| `containerReadiness` | func | Returns ready/total container counts for a pod |
| `totalRestarts` | func | Sums all container restart counts for a pod |
| `nodeReady` | func | Returns human-readable node readiness string |

## Usage Example

```go
mgr, _ := argocd.NewManager(cfg)

// Check cluster is reachable before proceeding
if err := mgr.checkClusterConnectivity(ctx, true); err != nil {
    log.Fatalf("cluster unreachable: %v", err)
}

// Inspect repo-server health
if issue := mgr.checkRepoServerHealth(ctx, false); issue != nil {
    fmt.Printf("repo-server issue [%s]: %s (recoverable=%v)\n",
        issue.Type, issue.Message, issue.Recoverable)

    // Attempt recovery only if the pod is old enough to not be cold-starting
    if age, ok := mgr.repoServerAge(ctx); ok && age > 3*time.Minute {
        if recovered := mgr.triggerRepoServerRecovery(ctx, "my-app"); !recovered {
            mgr.printArgoCDPodDiagnostics(ctx)
        }
    }
}
```

## Notes

- All methods are **best-effort** — a nil `kubeClient` causes graceful no-ops rather than panics.
- `repoServerColdStartGrace` (3 min) prevents the restart loop from triggering during initial manifest rendering on slow clusters (e.g., k3d).
- Hard refresh (`hardRefreshApplications`) is preferred over normal refresh post-restart because a normal refresh only compares against the now-empty manifest cache, leaving apps stuck in `Unknown`.
