## diagnostics.go

Provides diagnostic and self-healing utilities for ArgoCD deployments within the `argocd` package. It inspects pod/node health via the native Kubernetes client, detects repo-server failure modes (crash loops, OOM kills, restarts), and triggers recovery (pod restart + hard refresh) when the repo-server is stuck.

## Key Components

- **`RepoServerIssue`** — struct describing a detected repo-server problem (`Type`, `Message`, `Recoverable`).
- **`repoServerColdStartGrace`** — constant guarding against restarting a repo-server that is still warming up.
- **`(m *Manager) repoServerAge(ctx)`** — returns the age of the youngest repo-server pod.
- **`(m *Manager) printArgoCDPodDiagnostics(ctx)`** — prints a summary of ArgoCD deployments and pods (status, readiness, restart counts, waiting reasons).
- **`(m *Manager) checkClusterConnectivity(ctx, verbose)`** — lightweight reachability check via a namespace GET call; initializes clients and handles WSL-specific hints.
- **`(m *Manager) printClusterDiagnostics(ctx)`** — prints node count and readiness summary.
- **`(m *Manager) checkRepoServerHealth(ctx, verbose)`** — inspects repo-server pods and returns the first `*RepoServerIssue` found (OOMKilled, restarts, CrashLoopBackOff, non-Running phase), or `nil` if healthy.
- **`oomKilled(cs)`** — checks whether a container's current or previous state was terminated by OOM killer.
- **`(m *Manager) hardRefreshApplications(ctx, names)`** — patches Applications with a hard-refresh annotation to force manifest re-fetch from git, bypassing the repo-server cache.
- **`(m *Manager) triggerRepoServerRecovery(ctx, appName)`** — deletes repo-server pods to force recreation, waits (~60s) for health recovery, then hard-refreshes the triggering application.
- **`containerReadiness(p)`**, **`totalRestarts(p)`**, **`nodeReady(n)`** — small helpers for summarizing pod/node status.

## Usage Example

```go
// Check if the cluster is reachable before proceeding
if err := manager.checkClusterConnectivity(ctx, true); err != nil {
    manager.printClusterDiagnostics(ctx)
    return err
}

// Detect and recover from a stuck repo-server
if issue := manager.checkRepoServerHealth(ctx, false); issue != nil && issue.Recoverable {
    if manager.triggerRepoServerRecovery(ctx, "my-application") {
        pterm.Success.Println("repo-server recovered")
    }
}
```
