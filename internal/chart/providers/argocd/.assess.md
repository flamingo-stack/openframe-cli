Classifies and assesses ArgoCD application health and sync states during a polling cycle, providing utilities to determine deployment completeness and categorize application issues.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `appAssessment` | struct | Snapshot of one polling tick — tracks ready count, healthy names, and not-ready labels |
| `appNames` | func | Extracts ordered application names from a slice of `Application` |
| `assessApplications` | func | Classifies apps by health/sync state; updates the session-wide `everReady` map |
| `isDeploymentComplete` | func | Returns `true` when all currently-visible apps are ready and the count meets the high-water mark |
| `repoServerErrorPatterns` | var | String fragments used to detect repo-server manifest failures in condition messages |
| `classifyAppIssues` | func | Splits apps into `unknown` and `conditionErrors` slices; updates per-app error counts in place |

## Usage Example

```go
// Build the session-wide "ever ready" tracker
everReady := make(map[string]bool)
issueCounts := make(map[string]int)
maxSeen := 0

apps := fetchApplications() // returns []Application

// Update high-water mark
if len(apps) > maxSeen {
    maxSeen = len(apps)
}

// Assess current tick
assessment := assessApplications(apps, everReady)

if isDeploymentComplete(len(apps), assessment.ready, maxSeen) {
    fmt.Println("All applications healthy and synced.")
}

// Detect repo-server errors vs. unknown states
unknown, conditionErrors := classifyAppIssues(apps, issueCounts)
if len(unknown) > 0 {
    fmt.Printf("Unknown apps: %v\n", appNames(unknown))
}
if len(conditionErrors) > 0 {
    fmt.Printf("Repo-server errors: %v\n", appNames(conditionErrors))
}
```

> **Note:** `assessApplications` permanently marks apps in `everReady` once they reach `Healthy+Synced`. Deterministic manifest errors (see `fatalmanifest.go`) are intentionally excluded from `conditionErrors` to prevent futile repo-server restart loops.
