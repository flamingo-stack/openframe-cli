## assess.go

This file implements the assessment logic used to evaluate the health, sync status, and readiness of ArgoCD `Application` resources during polling loops, supporting deployment-completion detection and repo-server error diagnostics.

## Key Components

- **`appAssessment`** - Struct summarizing a single polling tick: count of ready apps, healthy app names, and display/name lists of not-yet-ready apps.
- **`appNames(apps []Application) []string`** - Extracts application names, preserving order.
- **`assessApplications(apps []Application, everReady map[string]bool) appAssessment`** - Classifies applications by health/sync state for one tick, updating the session-wide `everReady` set for apps that have ever reached Healthy+Synced.
- **`isDeploymentComplete(totalApps, currentlyReady, maxSeenTotal, expectedTotal int) bool`** - Determines whether deployment is fully complete, guarding against false positives when the API returns a partial list of apps (e.g., during multi-wave app-of-apps rollouts).
- **`repoServerErrorPatterns`** - List of condition-message substrings indicating ArgoCD repo-server failures (e.g., `"EOF"`, `"Unavailable"`).
- **`classifyAppIssues(apps []Application, issueCounts map[string]int) (unknown, conditionErrors []Application)`** - Separates apps with `Unknown` health/sync from those exhibiting repo-server errors, updating a persistent issue-count map while excluding deterministic manifest errors.

## Usage Example

```go
everReady := make(map[string]bool)
issueCounts := make(map[string]int)

assessment := assessApplications(apps, everReady)
fmt.Printf("Ready: %d, Not Ready: %v\n", assessment.ready, assessment.notReady)

complete := isDeploymentComplete(
    len(apps),
    assessment.ready,
    maxSeenTotal,
    expectedTotal,
)

unknown, repoErrors := classifyAppIssues(apps, issueCounts)
if len(repoErrors) > 0 {
    fmt.Println("Repo-server issues detected:", appNames(repoErrors))
}
```

This logic is typically invoked inside a polling loop that periodically fetches `Application` status from the ArgoCD API and reports progress or triggers recovery actions (e.g., repo-server restarts) based on the classification results.
