## assess.go

Provides assessment logic for polling ArgoCD application status during deployment, classifying applications by health/sync state and determining overall deployment completion.

## Key Components

- **`appAssessment`** — struct summarizing one polling tick: count of ready apps, names of healthy apps, and display/bare-name lists of not-yet-ready apps.
- **`appNames(apps []Application) []string`** — extracts application names, preserving order.
- **`assessApplications(apps []Application, everReady map[string]bool) appAssessment`** — classifies applications as ready (Healthy+Synced) or not-ready, tracking a session-wide "ever ready" set so apps stay counted even if they later fall out of sync.
- **`isDeploymentComplete(totalApps, currentlyReady, maxSeenTotal, expectedTotal int) bool`** — determines whether deployment is complete, guarding against false positives caused by the API momentarily returning a partial application list (important for app-of-apps patterns that create apps in waves).
- **`repoServerErrorPatterns`** — list of condition-message substrings (e.g. `"EOF"`, `"Unavailable"`) indicating ArgoCD repo-server failures.
- **`classifyAppIssues(apps []Application, issueCounts map[string]int) (unknown, conditionErrors []Application)`** — separates apps stuck in `Unknown` health/sync from those with repo-server condition errors, updating `issueCounts` in place (excludes deterministic manifest errors, which repo-server restarts can't fix).

## Usage Example

```go
everReady := make(map[string]bool)
issueCounts := make(map[string]int)

// Each polling tick:
assessment := assessApplications(apps, everReady)
fmt.Printf("Ready: %d, Not ready: %v\n", assessment.ready, assessment.notReady)

unknown, condErrors := classifyAppIssues(apps, issueCounts)
if len(condErrors) > 0 {
    fmt.Println("Possible repo-server issues:", appNames(condErrors))
}

if isDeploymentComplete(len(apps), assessment.ready, maxSeenTotal, expectedTotal) {
    fmt.Println("Deployment complete!")
}
```

This logic is typically invoked inside a polling loop that repeatedly queries ArgoCD's application list and reports progress until `isDeploymentComplete` returns `true`.
