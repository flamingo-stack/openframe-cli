## assess.go

Implements the health-assessment logic used to poll ArgoCD `Application` resources during deployment monitoring. It classifies applications by readiness, detects stalled/unknown states, and determines whether a full deployment (an "app-of-apps" rollout) has completed.

## Key Components

- **`appAssessment`** — struct summarizing one polling tick: count of ready apps, healthy app names, and labeled/bare names of apps not yet ready.
- **`appNames(apps []Application) []string`** — extracts application names, preserving order.
- **`assessApplications(apps []Application, everReady map[string]bool) appAssessment`** — classifies apps as ready (Healthy + Synced) or not, builds human-readable status labels, and records apps that have ever reached readiness in `everReady`.
- **`isDeploymentComplete(totalApps, currentlyReady, maxSeenTotal, expectedTotal int) bool`** — determines overall completion using a high-water-mark guard, preventing premature success when ArgoCD momentarily reports fewer apps than previously seen (e.g., due to multi-wave app-of-apps creation).
- **`repoServerErrorPatterns []string`** — known condition-message substrings indicating repo-server failures.
- **`classifyAppIssues(apps []Application, issueCounts map[string]int) (unknown, conditionErrors []Application)`** — separates apps stuck in `Unknown` health/sync from those with repo-server errors (excluding deterministic manifest errors), updating a per-app issue counter used for recovery-restart decisions.

## Usage Example

```go
everReady := make(map[string]bool)
issueCounts := make(map[string]int)

assessment := assessApplications(apps, everReady)
unknown, condErrs := classifyAppIssues(apps, issueCounts)

complete := isDeploymentComplete(
    len(apps),
    assessment.ready,
    maxSeenTotal,
    expectedTotal,
)

if complete {
    fmt.Println("Deployment complete: all applications healthy and synced")
} else {
    fmt.Printf("Not ready: %v\n", assessment.notReady)
}
```

This logic underpins the CLI's deployment-progress polling, providing accurate readiness signals and surfacing repo-server or manifest issues during ArgoCD-based installs.
