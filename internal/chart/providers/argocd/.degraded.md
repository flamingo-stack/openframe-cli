## degraded.go

Implements fail-fast detection for ArgoCD applications stuck in a `Degraded+Synced` state, preventing CI jobs from silently hanging until a timeout when a workload has already passed its progress deadline and will not self-heal.

## Key Components

- **`degradedFailAfter()`** — Returns the duration an app must remain continuously `Degraded+Synced` before becoming a fail-fast candidate. Defaults to 8 minutes; configurable via the `OPENFRAME_DEGRADED_FAIL_AFTER` environment variable (Go duration format).
- **`degradedMinChecks`** — Minimum number of poll observations required before crossing the wall-clock threshold counts, guarding against false positives from sparse polling.
- **`degradedRecheckInterval`** — Throttles re-reporting of a persistent candidate (1 minute) to avoid re-running expensive pod diagnostics on every poll cycle.
- **`degradedTracker`** / **`degradedEntry`** — Per-application state tracker recording how long an app has been continuously degraded; resets when the app recovers or disappears.
- **`newDegradedTracker()`** — Constructs a tracker initialized with the configured fail-after duration.
- **`(*degradedTracker).observe(apps, now)`** — Scans applications, updates tracked state, and returns the sorted list of apps that qualify as fail-fast candidates (candidacy alone doesn't trigger failure — callers must confirm a genuinely stuck pod).
- **`degradedAppError(apps, diag)`** — Builds a descriptive, self-diagnosed error message embedding pod diagnostic output (crash logs/events) and `kubectl` inspection hints.

## Usage Example

```go
tracker := argocd.newDegradedTracker()

for {
    apps := fetchApplications() // poll ArgoCD
    candidates := tracker.observe(apps, time.Now())

    for _, app := range candidates {
        if terminal, diag := diagnoseFailingApps(app); terminal {
            return degradedAppError([]Application{app}, diag)
        }
    }

    time.Sleep(2 * time.Second)
}
```

This is used internally by the ArgoCD wait loop to abort early with actionable diagnostics instead of waiting out the full CI timeout on unrecoverable deployments.
