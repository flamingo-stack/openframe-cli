## degraded.go

Implements fail-fast detection for ArgoCD applications stuck in a terminal `Degraded`+`Synced` state, avoiding the previous behavior of silently waiting out the full timeout on workloads that will never recover on their own.

## Key Components

- **`degradedFailAfter() time.Duration`** — Returns the duration an app must remain continuously `Degraded`+`Synced` before being considered a fail-fast candidate. Defaults to 8 minutes, overridable via the `OPENFRAME_DEGRADED_FAIL_AFTER` environment variable (Go duration format, e.g. `"5m"`).
- **`degradedMinChecks`** — Minimum poll count required before the wall-clock threshold counts, preventing two isolated sightings across a long gap from falsely triggering.
- **`degradedRecheckInterval`** — Throttles (to 1 minute) how often a persistent candidate is re-reported, since each report triggers an expensive pod diagnosis (pod list, log streams, events).
- **`degradedTracker`** / **`degradedEntry`** — Per-application state tracker recording how long an app has stayed `Degraded`+`Synced`, resetting on recovery/state change and forgetting apps that disappear.
- **`newDegradedTracker() *degradedTracker`** — Constructor initializing the tracker with the configured fail-after duration.
- **`(*degradedTracker) observe(apps []Application, now time.Time) []Application`** — Scans applications, updates tracking state, and returns those that have crossed both the check-count and duration thresholds (sorted by name). Being a candidate is necessary but not sufficient — callers must independently confirm a genuinely stuck pod.
- **`degradedAppError(apps []Application, diag string) error`** — Builds a descriptive, self-diagnosed error message listing affected apps, embedding pod diagnostic details, and suggesting `kubectl` inspection commands.

## Usage Example

```go
tracker := newDegradedTracker()

for {
    apps := fetchArgoCDApplications()
    candidates := tracker.observe(apps, time.Now())

    if len(candidates) > 0 {
        if diag := diagnoseFailingApps(candidates); diag != "" {
            return degradedAppError(candidates, diag)
        }
    }

    time.Sleep(2 * time.Second)
}
```

This is typically used inside an ArgoCD sync-wait loop: each poll cycle calls `observe` to detect apps stuck in `Degraded`+`Synced`, and only aborts the wait once a genuinely stuck pod (e.g., `CrashLoopBackOff`, `ImagePullBackOff`) is confirmed, surfacing a clear diagnostic instead of hanging until the CI timeout.
