Implements stall detection for the `WaitForApplications` loop, tracking per-application health/sync state to identify ArgoCD applications that have been stuck in an `OutOfSync` state without progressing.

## Key Components

### Constants

- **`stallAfter`** (`90 * time.Second`) — How long an application's state must remain unchanged before it is considered stalled. Tuned to outlast slow-but-live rollouts while leaving room to act within the overall wait budget.

### Types

- **`stallTracker`** — Maintains a per-application map of observed states and the time each state was first entered.
- **`stallEntry`** — Holds a `"health|sync"` fingerprint string and the timestamp when the application first entered that state.

### Functions

| Function | Description |
|---|---|
| `newStallTracker()` | Allocates and returns an initialized `stallTracker`. |
| `(s *stallTracker) observe(apps, now)` | Updates state records for all currently visible applications; resets an app's timer on any state change and purges apps no longer in the set. |
| `(s *stallTracker) stalledStragglers(apps, now)` | Returns a sorted list of application names that are `Healthy+OutOfSync` and have held that exact state for at least `stallAfter`. |

## Usage Example

```go
tracker := newStallTracker()

// Inside the wait loop, called once per tick:
now := time.Now()
tracker.observe(pendingApps, now)

stalled := tracker.stalledStragglers(pendingApps, now)
if len(stalled) > 0 {
    // Either trigger a sync on stalled apps or print an actionable hint.
    fmt.Printf("stalled OutOfSync apps: %v\n", stalled)
}
```

> **Design note:** Per-app tracking prevents a "noisy neighbour" — an app oscillating between states — from continuously resetting a shared global timer and masking a genuinely stuck application elsewhere in the set.
