Defines a marker error type used within the `argocd` package to signal that an error message already contains a complete root-cause diagnosis, preventing the generic error handler from appending misleading "friendly hints" derived from pattern-matching the embedded diagnostic text.

## Key Components

- **`diagnosedError`** - Unexported struct wrapping a diagnostic message string.
- **`(*diagnosedError) Error() string`** - Implements the standard `error` interface, returning the embedded message.
- **`(*diagnosedError) SelfDiagnosed() bool`** - Marker method (structurally matched by `internal/shared/errors`) that always returns `true`, telling the generic error handler to skip its heuristic hint logic.
- **`selfDiagnosedError(msg string) error`** - Constructor that wraps a fully-built diagnostic message into a `diagnosedError`.

## Usage Example

```go
// When you've already gathered detailed diagnostics (e.g., pod crash logs,
// warning events, per-app health status), wrap the final message so the
// generic error handler doesn't misinterpret embedded text as a new problem.
func checkAppHealth(appName string, podLogs string) error {
    diagnosis := fmt.Sprintf(
        "application %q is unhealthy:\n%s",
        appName, podLogs,
    )
    return selfDiagnosedError(diagnosis)
}

// Elsewhere, the generic handler detects SelfDiagnosed() == true
// and prints the message as-is, without appending a misleading
// "cluster unreachable" style hint based on pattern matching.
```

## Notes

This type exists specifically to fix a bug where a pod log line such as `connect: connection refused` embedded in diagnostic output caused the generic handler to falsely report that the cluster itself was unreachable. By implementing `SelfDiagnosed() bool`, this error opts out of that pattern-matching behavior.
