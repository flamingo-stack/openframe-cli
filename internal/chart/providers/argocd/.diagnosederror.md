Defines a lightweight error type used within the `argocd` package to mark errors whose messages already contain complete root-cause diagnostics, preventing the generic error handler from appending misleading "friendly hints" based on pattern matching.

## Key Components

- **`diagnosedError`** — a struct wrapping a diagnostic message string (`msg`). Implements the `error` interface via `Error()`.
- **`SelfDiagnosed() bool`** — marker method returning `true`, structurally matched by `internal/shared/errors` to identify errors that should bypass generic hint decoration.
- **`selfDiagnosedError(msg string) error`** — constructor function that wraps a fully-formed diagnostic message string into a `*diagnosedError`.

## Usage Example

```go
// When building a diagnostic message from pod crash logs, warning events,
// or per-app health checks, wrap it so the generic error handler doesn't
// try to reinterpret the embedded diagnostics as a new failure signal.
func diagnoseAppFailure(appName string, podLogs string) error {
    diagnosis := fmt.Sprintf(
        "application %q failed:\n%s",
        appName, podLogs,
    )
    return selfDiagnosedError(diagnosis)
}

// Elsewhere, the generic error handler checks for SelfDiagnosed()
// before attempting to append a pattern-matched hint:
if sd, ok := err.(interface{ SelfDiagnosed() bool }); ok && sd.SelfDiagnosed() {
    // print err.Error() as-is, no additional hint appended
}
```

This prevents scenarios where embedded log text (e.g., `"connect: connection refused"`) is misinterpreted by the generic handler as evidence of a cluster connectivity issue, when it is actually just part of the diagnostic output already being displayed.
