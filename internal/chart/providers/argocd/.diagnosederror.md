Defines a marker error type used by the ArgoCD package to indicate that an error message already contains a complete root-cause diagnosis, preventing the generic error handler from appending misleading auto-generated hints.

## Key Components

- **`diagnosedError`** — internal struct implementing the `error` interface, holding a pre-built diagnostic message.
- **`(*diagnosedError) Error() string`** — returns the embedded diagnostic message.
- **`(*diagnosedError) SelfDiagnosed() bool`** — returns `true`, a structural marker recognized by the generic error handler (in `internal/shared/errors`) to suppress its pattern-matched "friendly hint" logic.
- **`selfDiagnosedError(msg string) error`** — constructor that wraps a fully-formed diagnostic message into a `diagnosedError`.

## Usage Example

```go
// When you've already gathered detailed diagnostics (e.g., pod crash logs,
// warning events, per-app health status), wrap the final message so the
// generic error handler doesn't try to re-diagnose it:

diagnosis := fmt.Sprintf(
    "application %q is degraded: pod %s crashed with log: %s",
    appName, podName, crashLog,
)

return selfDiagnosedError(diagnosis)
```

This prevents scenarios where embedded diagnostic text (such as a pod log line containing `"connect: connection refused"`) is mistakenly pattern-matched by the generic error handler, which might otherwise incorrectly claim the cluster itself is unreachable even though the diagnostics were successfully retrieved and printed.
