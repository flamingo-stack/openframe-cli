Manages ArgoCD Helm values by embedding a baseline YAML at build time and providing utilities to deep-merge user overrides, validate values files, and expose the merged result for Helm installs.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `argoCDValues` | `var` (embedded) | Baseline ArgoCD Helm values, embedded from `argocd-values.yaml` at build time |
| `UserArgoCDKey` | `const` | Top-level key (`"argocd"`) scoping user overrides in `openframe-helm-values.yaml` |
| `GetArgoCDValues()` | `func` | Returns the raw embedded baseline YAML string |
| `MergedArgoCDValues()` | `func` | Deep-merges the `argocd:` subtree from user values over the baseline; returns merged YAML and sorted override keys |
| `ValidateUserValuesFile()` | `func` | Pre-flight check: reads, parses, and validates the user values file before any cluster work begins |
| `deepMerge()` | `func` (internal) | Recursively merges maps in place; scalars and lists replace (matches Helm's merge semantics) |

## Usage Example

```go
// Pre-flight validation before cluster operations
if err := argocd.ValidateUserValuesFile("/path/to/openframe-helm-values.yaml"); err != nil {
    log.Fatalf("invalid values file: %v", err)
}

// Load and merge user overrides
data, _ := os.ReadFile("/path/to/openframe-helm-values.yaml")
var userValues map[string]interface{}
yaml.Unmarshal(data, &userValues)

mergedYAML, overriddenKeys, err := argocd.MergedArgoCDValues(userValues)
if err != nil {
    log.Fatalf("merge failed: %v", err)
}
if len(overriddenKeys) > 0 {
    log.Printf("warning: user is overriding ArgoCD keys: %v", overriddenKeys)
}

// mergedYAML is ready to pass to helm install/upgrade
```

## Merge Behavior

- **No `argocd:` key** → baseline returned unchanged, zero allocations
- **`argocd: null` or `argocd: {}`** → treated as no-op, baseline returned unchanged
- **Non-mapping value** → hard error (prevents silent drops of intended overrides)
- **Nested maps** → merged recursively; scalars and lists replace the baseline value
