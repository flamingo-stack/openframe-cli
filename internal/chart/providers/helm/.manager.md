Manages Helm operations for the OpenFrame CLI, providing installation, verification, and lifecycle management of Helm releases (primarily ArgoCD) against Kubernetes clusters.

## Key Components

### `HelmManager` struct
Core manager holding a `CommandExecutor`, Kubernetes REST config, dynamic client, typed client, and verbose flag.

### `NewHelmManager`
Constructor that accepts a `rest.Config` and builds both `kubernetes.Interface` and `dynamic.Interface` clients. Gracefully degrades if clients cannot be initialized. Applies insecure TLS config for local k3d clusters.

### Key Methods

| Method | Description |
|--------|-------------|
| `IsHelmInstalled` | Checks if the `helm` binary is available via `helm version --short` |
| `IsChartInstalled` | Queries `helm list` to determine if a named release exists in a namespace |
| `UninstallRelease` | Runs `helm uninstall` with `--ignore-not-found`; no `--wait` to avoid finalizer deadlocks |
| `InstallArgoCDWithProgress` | Installs ArgoCD with spinner UI, feeding chart values via stdin |
| `installArgoCDHelm` | Pure install helper building and executing the `helm upgrade --install` command |
| `getHelmEnv` | Returns writable Helm env vars (`HELM_CACHE_HOME`, etc.) for CI compatibility |

### Helper Functions

- `argoCDInstallArgs` — Builds the `helm upgrade --install` argument slice; pure/testable
- `helmKubeContext` — Resolves the kube context from config or cluster name
- `userValues` — Reads and parses `openframe-helm-values.yaml`, returning the `argocd:` subtree for override merging

## Usage Example

```go
exec := executor.NewDefaultExecutor()
restConfig, _ := k8s.GetRestConfig(kubeContext)

mgr, err := helm.NewHelmManager(exec, restConfig, verbose)
if err != nil {
    log.Fatal(err)
}

// Check helm availability
if err := mgr.IsHelmInstalled(ctx); err != nil {
    log.Fatal("helm not found")
}

// Install ArgoCD with progress UI
err = mgr.InstallArgoCDWithProgress(ctx, config.ChartInstallConfig{
    ClusterName: "my-cluster",
    Verbose:     true,
})
```
