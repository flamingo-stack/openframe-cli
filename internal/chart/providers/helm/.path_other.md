Provides a no-op implementation of `expandShortPath` for non-Windows platforms, ensuring cross-platform compatibility for Windows-specific 8.3 short filename expansion logic.

## Key Components

- **`expandShortPath(path string) (string, error)`** — Returns the input path unchanged; Windows short filename (8.3 format) expansion is not applicable on non-Windows systems.

## Usage Example

```go
// On Linux/macOS, the path is returned as-is with no transformation
result, err := expandShortPath("/usr/local/bin/helm")
// result == "/usr/local/bin/helm", err == nil
```

## Notes

- Compiled only on non-Windows platforms via the `//go:build !windows` constraint
- Pairs with a Windows-specific counterpart that performs actual short path resolution
- Part of the `helm` package's cross-platform path handling strategy
