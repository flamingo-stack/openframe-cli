This file implements ArgoCD readiness checks and diagnostics for the Helm installation workflow, ensuring workloads, namespaces, and the Kubernetes API are actually available before proceeding—working around race conditions common in k3d/CI/Windows-WSL2 environments.

## Key Components

- **`waitForArgoCDDeployments(ctx, verbose)`** — Polls the Kubernetes API (native `client-go`) to confirm the `argocd-server`/`argocd-repo-server` Deployments and `argocd-application-controller` StatefulSet exist, working around Helm's `--wait` returning before objects are actually created.
- **`ensureArgoCDNamespace(ctx, clusterName, verbose)`** — Creates the `argocd` namespace if missing and polls until it reaches `Active` phase, compensating for Helm's `--create-namespace` not blocking until completion.
- **`apiDialAddress(host)`** — Normalizes a `rest.Config` host URL into a dialable `host:port`, defaulting to port 443 when the endpoint (e.g. managed GKE/EKS control planes) omits one.
- **`waitForAPIPort(ctx, timeout)`** — TCP-dials the Kubernetes API port before issuing API calls, preventing repeated failed requests against a not-yet-open port on Windows/WSL2.
- **`verifyHelmRelease(ctx, releaseName, namespace, clusterName, verbose)`** — Runs `helm list` and `helm status` to confirm a release truly exists and is healthy, since Helm can report success without creating resources.
- **`showArgoCDDiagnostics(ctx, _)`** — Prints a compact summary of ArgoCD Deployments and Pods (readiness, restarts, waiting reasons) when installation fails.

## Usage Example

```go
func (h *HelmManager) installArgoCD(ctx context.Context, clusterName string, verbose bool) error {
    if err := h.ensureArgoCDNamespace(ctx, clusterName, verbose); err != nil {
        return err
    }

    // ... run `helm install argocd ...` via executor ...

    if err := h.waitForArgoCDDeployments(ctx, verbose); err != nil {
        h.showArgoCDDiagnostics(ctx, clusterName)
        return fmt.Errorf("argocd workloads not ready: %w", err)
    }

    return h.verifyHelmRelease(ctx, "argocd", argocd.ArgoCDNamespace, clusterName, verbose)
}
```

These methods are intended to run as part of `HelmManager`'s ArgoCD install pipeline, using its embedded `kubeClient` (client-go), `kubeConfig`, and command `executor` to validate cluster state at each step and surface actionable diagnostics on failure.
