Handles ArgoCD installation readiness checks for the Helm-based chart provider, including waiting for workloads to appear, ensuring the `argocd` namespace exists, verifying the Helm release, and printing diagnostics when installation fails. It exists to work around race conditions where Helm or `k3d` report success before Kubernetes objects or the API server are actually ready.

## Key Components

- `waitForArgoCDDeployments(ctx, verbose)` - Polls the native Kubernetes API to confirm the `argocd-server`, `argocd-repo-server` Deployments and `argocd-application-controller` StatefulSet exist, first waiting for the API port to open.
- `ensureArgoCDNamespace(ctx, clusterName, verbose)` - Creates the `argocd` namespace if missing and polls until its phase becomes `Active`. Includes a WSL cluster hint check for Windows environments.
- `apiDialAddress(host)` - Normalizes a `rest.Config` host string into a dialable `host:port`, defaulting to port 443 when none is specified (needed for managed control planes like GKE/EKS).
- `waitForAPIPort(ctx, timeout)` - TCP-dials the Kubernetes API address in a poll loop to avoid hitting a not-yet-open port on Windows/WSL2.
- `verifyHelmRelease(ctx, releaseName, namespace, clusterName, verbose)` - Confirms a Helm release actually exists via `helm list` and `helm status`, since Helm can report success without creating resources.
- `showArgoCDDiagnostics(ctx, _)` - Prints a compact summary of ArgoCD Deployments and Pods (readiness, restarts, waiting reasons) for troubleshooting failed installs.

## Usage Example

```go
// After installing the ArgoCD Helm chart, verify workloads and release health.
func (h *HelmManager) installArgoCD(ctx context.Context, clusterName string, verbose bool) error {
    if err := h.ensureArgoCDNamespace(ctx, clusterName, verbose); err != nil {
        return err
    }

    // ... helm install invocation happens here ...

    if err := h.waitForArgoCDDeployments(ctx, verbose); err != nil {
        h.showArgoCDDiagnostics(ctx, clusterName)
        return err
    }

    return h.verifyHelmRelease(ctx, "argocd", argocd.ArgoCDNamespace, clusterName, verbose)
}
```

These helpers are internal methods on `HelmManager` and are typically called sequentially during chart installation flows in the `helm` package, guarding against race conditions common in k3d and CI/Windows-WSL2 environments.
