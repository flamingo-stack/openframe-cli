Provides ArgoCD-specific Kubernetes readiness checks for the Helm installation flow, handling race conditions between Helm completion and actual workload creation in k3d/CI environments.

## Key Components

| Function | Description |
|---|---|
| `waitForArgoCDDeployments` | Polls the Kubernetes API until all expected ArgoCD Deployments and StatefulSets exist in the `argocd` namespace (90s timeout, 1s interval) |
| `ensureArgoCDNamespace` | Creates the `argocd` namespace if missing and waits for it to reach `Active` phase (30s timeout) |
| `waitForAPIPort` | TCP-dials the Kubernetes API server until the port is open, preventing request floods on Windows/WSL2 (configurable timeout) |
| `verifyHelmRelease` | Runs `helm list` and `helm status` to confirm a release was actually created after Helm exits |
| `showArgoCDDiagnostics` | Prints a compact summary of ArgoCD Deployments and Pod statuses via the native client when installation fails |
| `verifyClusterConnectivity` | Retries (up to 5x) a namespace GET to confirm the cluster is reachable before app-of-apps installation |

## Usage Example

```go
mgr := &HelmManager{
    kubeClient: client,
    kubeConfig: restConfig,
    executor:   exec,
}

ctx := context.Background()

// Ensure namespace exists before Helm install
if err := mgr.ensureArgoCDNamespace(ctx, "k3d-openframe", true); err != nil {
    log.Fatal(err)
}

// Wait for workloads after Helm returns
if err := mgr.waitForArgoCDDeployments(ctx, true); err != nil {
    mgr.showArgoCDDiagnostics(ctx, "k3d-openframe")
    log.Fatal(err)
}

// Confirm the Helm release exists
if err := mgr.verifyHelmRelease(ctx, "argo-cd", "argocd", "k3d-openframe", true); err != nil {
    log.Fatal(err)
}
```

> **Note:** ArgoCD v3.x (Helm chart 10.x) deploys `argocd-application-controller` as a **StatefulSet**; `argocd-server` and `argocd-repo-server` remain as Deployments. All polling uses `wait.PollUntilContextTimeout` from `k8s.io/apimachinery`.
