This file implements post-Helm-install verification and readiness checks for ArgoCD deployment on Kubernetes clusters, addressing race conditions between Helm's `--wait` completion and actual Kubernetes resource creation (particularly relevant for k3d/CI/Windows-WSL2 environments).

## Key Components

- **`waitForArgoCDDeployments`** — Polls the Kubernetes API (via native client-go) to confirm expected ArgoCD Deployments (`argocd-server`, `argocd-repo-server`) and StatefulSets (`argocd-application-controller`) exist, with a 90-second timeout and 1-second polling interval.
- **`ensureArgoCDNamespace`** — Creates the `argocd` namespace if missing and polls until it reaches `Active` phase, compensating for Helm's `--create-namespace` not blocking until completion.
- **`apiDialAddress`** — Normalizes a `rest.Config` Host URL into a dialable `host:port` string, defaulting to port 443 for managed control planes (GKE/EKS) that expose bare hostnames.
- **`waitForAPIPort`** — Performs a TCP dial check against the Kubernetes API port before issuing API calls, preventing request floods against a not-yet-ready port on Windows/WSL2.
- **`verifyHelmRelease`** — Runs `helm list` and `helm status` via the executor to confirm a release was actually created, catching silent Helm failures.
- **`showArgoCDDiagnostics`** — Prints a compact summary of ArgoCD Deployment and Pod status (readiness, restarts, waiting reasons) for troubleshooting failed installs.

## Usage Example

```go
func (h *HelmManager) installArgoCD(ctx context.Context, clusterName string, verbose bool) error {
    if err := h.ensureArgoCDNamespace(ctx, clusterName, verbose); err != nil {
        return err
    }

    // ... run helm install ...

    if err := h.verifyHelmRelease(ctx, "argo-cd", argocd.ArgoCDNamespace, clusterName, verbose); err != nil {
        return err
    }

    if err := h.waitForArgoCDDeployments(ctx, verbose); err != nil {
        h.showArgoCDDiagnostics(ctx, clusterName)
        return fmt.Errorf("ArgoCD did not become ready: %w", err)
    }

    return nil
}
```

These functions are internal methods on `HelmManager` (in the `helm` package) and rely on an initialized `kubeClient` (client-go) and `kubeConfig`, used internally by the chart installation workflow rather than called directly by consumers of the package.
