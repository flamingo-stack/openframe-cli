Windows-only utility that expands Windows 8.3 short filenames (e.g., `RUNNER~1`) to their full long path equivalents using the Win32 `GetLongPathNameW` API. Required for WSL compatibility, which cannot resolve short-form Windows paths.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `kernel32` | `*syscall.LazyDLL` | Lazy-loaded handle to `kernel32.dll` |
| `procGetLongPathNameW` | `*syscall.LazyProc` | Bound reference to the `GetLongPathNameW` Win32 function |
| `expandShortPath` | `func` | Converts a short 8.3 path to its full long path; returns original on failure |

## Usage Example

```go
// Expand a short Windows path before passing to WSL
longPath, err := expandShortPath(`C:\Users\RUNNER~1\AppData`)
if err != nil {
    log.Fatal(err)
}
// longPath => "C:\Users\runneradmin\AppData"
```

## Behavior Notes

- **Empty input**: returned unchanged with no error
- **API failure (first call)**: if `GetLongPathNameW` returns `0` (e.g., path does not exist), the original path is returned as a safe fallback — no error is propagated
- **API failure (second call)**: same silent fallback to the original path
- **Build constraint**: `//go:build windows` ensures this file is compiled only on Windows; a platform-neutral stub or alternative implementation should exist for other OSes
