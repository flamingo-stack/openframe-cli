Defines shared data types for the `git` package, providing structures used across git operations.

## Key Components

### `CloneResult`

A struct that holds the output of a git clone operation:

| Field | Type | Description |
|-------|------|-------------|
| `TempDir` | `string` | Path to the temporary directory created during cloning |
| `ChartPath` | `string` | Path to the chart directory within the cloned repository |

## Usage Example

```go
package main

import "github.com/flamingo-stack/openframe-cli/internal/git"

func handleClone(result git.CloneResult) {
    defer os.RemoveAll(result.TempDir) // Cleanup temp directory when done

    // Access the chart at the resolved path
    fmt.Println("Chart located at:", result.ChartPath)
}
```

## Notes

- `TempDir` should be cleaned up by the caller after use (e.g., via `defer os.RemoveAll`)
- `ChartPath` is typically a subdirectory within `TempDir` pointing to a Helm chart or similar artifact
