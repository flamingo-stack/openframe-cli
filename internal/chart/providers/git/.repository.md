# repository.go

Implements git repository operations for chart repositories using the `go-git` library — no dependency on an external `git` binary. Handles shallow cloning by branch or tag, and pre-flight ref validation, while ensuring credentials for private repositories are never leaked into URLs, process arguments, or on-disk credential files.

## Key Components

- **`Repository`** — struct providing git operations; instantiated via `NewRepository()`.
- **`NewRepository() *Repository`** — constructor for a `Repository` handler.
- **`(*Repository) CloneChartRepository(ctx, config) (*CloneResult, error)`** — performs a shallow, single-ref clone of `config.GitHubRepo` into a temporary directory. Tries `config.GitHubBranch` first as a branch, then as a tag, so both branch names and release tags work. Credentials are extracted from the URL and passed via an in-memory auth method rather than embedded in the URL.
- **`(*Repository) ValidateRef(ctx, config) error`** — performs a lightweight `ls-remote` to confirm the configured ref exists before any cluster-mutating operations occur. Returns a `*sharedErrors.BranchNotFoundError` listing available branches/tags when the ref is missing.
- **`(*Repository) Cleanup(tempDir string)`** — removes a temporary clone directory, logging (via `pterm.Warning`) rather than failing if removal fails.
- **`isBranchNotFound(err error) bool`** — detects go-git's "ref not found" error conditions to distinguish retryable ref-lookup failures from real auth/network errors.
- **`chartResult(tempDir, chartSubPath) (*CloneResult, error)`** (internal) — verifies the expected chart subpath exists in the cloned repo, cleaning up on failure.

## Usage Example

```go
repo := git.NewRepository()

config := &models.AppOfAppsConfig{
	GitHubRepo:   "https://github.com/flamingo-stack/openframe-cli.git",
	GitHubBranch: "main",
	ChartPath:    "charts/app-of-apps",
}

// Validate ref exists before mutating the cluster.
if err := repo.ValidateRef(ctx, config); err != nil {
	log.Fatalf("ref validation failed: %v", err)
}

// Clone and use the chart.
result, err := repo.CloneChartRepository(ctx, config)
if err != nil {
	log.Fatalf("clone failed: %v", err)
}
defer repo.Cleanup(result.TempDir)

fmt.Println("Chart available at:", result.ChartPath)
```

Note: `config.GitHubRepo` may embed a token (e.g. `https://<token>@github.com/...`); the token is stripped from the URL and applied only via in-memory auth, and is masked in any error output.
