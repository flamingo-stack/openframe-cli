Handles shallow git clone operations for Helm chart repositories using `go-git` — no external `git` binary required. Tokens are kept in-memory only and never written to disk, URLs, or process arguments.

## Key Components

| Export | Description |
|--------|-------------|
| `Repository` | Struct that encapsulates all git operations |
| `NewRepository()` | Constructor returning a `*Repository` |
| `CloneChartRepository()` | Clones a repo with depth-1, trying the configured ref as a branch then as a tag |
| `Cleanup()` | Removes the temporary clone directory; logs warnings via `pterm` instead of panicking |
| `CloneResult` | Returned on success; holds `TempDir` and resolved `ChartPath` |

Internal helpers:

- **`chartResult()`** — validates `chartSubPath` exists inside the cloned tree before returning `CloneResult`
- **`isBranchNotFound()`** — inspects go-git errors to distinguish a missing ref from auth/network failures, enabling the branch→tag retry loop
- **`maskToken()`** — redacts any credential from error strings surfaced to the caller

## Usage Example

```go
cfg := &models.AppOfAppsConfig{
    GitHubRepo:   "https://<token>@github.com/org/charts.git",
    GitHubBranch: "v1.2.3", // branch name or release tag
    ChartPath:    "charts/myapp",
}

repo := git.NewRepository()
result, err := repo.CloneChartRepository(context.Background(), cfg)
if err != nil {
    log.Fatal(err)
}
defer repo.Cleanup(result.TempDir)

fmt.Println("Chart available at:", result.ChartPath)
```

> **Security note:** Any token embedded in `GitHubRepo` is extracted via `extractGitAuth` and passed only through go-git's in-memory auth interface. It is stripped from the clone URL before the call and masked in any returned error messages.
