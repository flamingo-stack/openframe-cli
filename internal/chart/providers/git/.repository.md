# repository.go

Implements Git operations for chart repositories using `go-git` — no dependency on an external `git` binary, and no writing of credentials to disk or the URL. Handles cloning of Helm chart repositories and pre-flight validation of git refs (branches/tags) before cluster mutation begins.

## Key Components

- **`Repository`** — struct handling git operations; instantiated via `NewRepository()`.
- **`NewRepository() *Repository`** — constructor.
- **`(*Repository) CloneChartRepository(ctx, config) (*CloneResult, error)`** — performs a shallow, single-ref clone of a chart repository to a temp directory. Tries `config.GitHubBranch` first as a branch, then as a tag, so both branch names and release tags work. Credentials are extracted from the URL and passed via in-memory auth (never in the URL/argv/disk).
- **`(*Repository) ValidateRef(ctx, config) error`** — performs a lightweight `ls-remote`-style check to confirm the configured ref exists, before any cluster changes happen. Returns a `*sharedErrors.BranchNotFoundError` listing available branches/tags if the ref is missing.
- **`(*Repository) Cleanup(tempDir string)`** — removes a temporary clone directory, logging (not failing) on error.
- **`chartResult`** (internal) — validates the chart subpath exists post-clone and builds the `CloneResult`.
- **`isBranchNotFound(err error) bool`** (internal) — detects go-git's "ref not found" conditions to decide whether to retry as tag vs. surface a real failure.

## Usage Example

```go
repo := git.NewRepository()

config := &models.AppOfAppsConfig{
    GitHubRepo:   "https://github.com/flamingo-stack/openframe-charts.git",
    GitHubBranch: "v1.2.3", // branch or tag
    ChartPath:    "charts/app-of-apps",
}

// Fail fast before touching the cluster.
if err := repo.ValidateRef(ctx, config); err != nil {
    log.Fatalf("invalid ref: %v", err)
}

result, err := repo.CloneChartRepository(ctx, config)
if err != nil {
    log.Fatalf("clone failed: %v", err)
}
defer repo.Cleanup(result.TempDir)

fmt.Println("Chart available at:", result.ChartPath)
```

Note: private repository tokens should be embedded in the `GitHubRepo` URL's userinfo component (extracted internally via `extractGitAuth`), not passed as separate config fields.
