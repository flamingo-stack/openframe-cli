This file implements git operations for cloning and validating chart repositories used in the App-of-Apps deployment pattern, using the pure-Go `go-git` library (no external `git` binary dependency) with in-memory credential handling for security.

## Key Components

- **`Repository`** — struct providing git operation methods; created via `NewRepository()`.
- **`CloneChartRepository(ctx, config)`** — performs a shallow, single-ref clone of a chart repository to a temporary directory. Tries the configured `GitHubBranch` first as a branch, then as a tag, so both branch names and release tags work. Returns a `*CloneResult` with the temp directory and resolved chart path.
- **`ValidateRef(ctx, config)`** — performs a lightweight `ls-remote`-style check (via `gogit.NewRemote(...).ListContext`) to confirm the configured ref exists as a branch or tag *before* any cluster mutation occurs. On failure, returns a `*sharedErrors.BranchNotFoundError` populated with the actual available branches/tags.
- **`chartResult(tempDir, chartSubPath)`** — validates the chart subdirectory exists within the cloned repo and builds the `CloneResult`, cleaning up the temp directory on failure.
- **`isBranchNotFound(err)`** — detects go-git's "ref not found" error conditions (including string-matching fallbacks) to distinguish retryable ref lookups from real auth/network failures.
- **`Cleanup(tempDir)`** — removes the temporary clone directory, logging failures via `pterm.Warning` (respects `--silent`) rather than aborting.

Credentials embedded in the repository URL are extracted via `extractGitAuth` (defined elsewhere in the package) and passed only through go-git's in-memory `Auth` option — never in the URL, process arguments, or an on-disk credentials file. Error messages are passed through `maskToken` to prevent token leakage in output.

## Usage Example

```go
repo := git.NewRepository()

config := &models.AppOfAppsConfig{
    GitHubRepo:   "https://github.com/flamingo-stack/openframe-cli.git",
    GitHubBranch: "main",
    ChartPath:    "charts/app-of-apps",
}

// Validate the ref exists before touching the cluster.
if err := repo.ValidateRef(ctx, config); err != nil {
    log.Fatalf("invalid ref: %v", err)
}

// Clone the repository and locate the chart.
result, err := repo.CloneChartRepository(ctx, config)
if err != nil {
    log.Fatalf("clone failed: %v", err)
}
defer repo.Cleanup(result.TempDir)

fmt.Println("Chart available at:", result.ChartPath)
```
