Handles credential extraction and masking for Git HTTP authentication, separating tokens from clone URLs so they are never exposed in process arguments, files, or log output.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `GitTokenUser` | `const` | Conventional username (`"x-access-token"`) used for GitHub PAT auth |
| `gitAuth` | `struct` | Holds a credential-stripped URL, an optional username, and the extracted token |
| `extractGitAuth` | `func` | Parses a raw clone URL, separates any embedded credentials, and returns a `gitAuth` |
| `buildAuth` | `method` | Returns a go-git `transport.AuthMethod` (HTTP Basic) for private repos, or `nil` for public |
| `maskToken` | `func` | Redacts all occurrences of a token in a string with `***` for safe logging |

## Usage Example

```go
// Parse a URL that embeds a PAT (common GitHub shorthand)
auth := extractGitAuth("https://ghp_mytoken@github.com/org/repo.git")

// auth.cleanURL → "https://github.com/org/repo.git"
// auth.token    → "ghp_mytoken"

// Use the in-memory auth with go-git — token never touches argv or disk
_, err := git.PlainClone("/tmp/repo", false, &git.CloneOptions{
    URL:  auth.cleanURL,
    Auth: auth.buildAuth(),
})

// Safe to log — token is redacted
fmt.Println(maskToken(auth.cleanURL, auth.token))
```

> **Security note:** `extractGitAuth` handles the single-field userinfo shorthand (`https://<token>@host`) by promoting the username field to the token role, ensuring PATs in that common format are masked and used for auth rather than silently dropped.
