Defines data models for Helm chart management, providing structured types for chart metadata and chart type classification used across the OpenFrame CLI.

## Key Components

| Component | Type | Description |
|-----------|------|-------------|
| `ChartInfo` | struct | Holds metadata for an installed Helm chart |
| `ChartType` | type | String alias for classifying chart types |
| `ChartTypeArgoCD` | constant | Identifies ArgoCD chart deployments |
| `ChartTypeAppOfApps` | constant | Identifies App-of-Apps pattern chart deployments |

### `ChartInfo` Fields

| Field | Type | Description |
|-------|------|-------------|
| `Name` | string | Chart release name |
| `Namespace` | string | Kubernetes namespace of the chart |
| `Status` | string | Current deployment status |
| `Version` | string | Helm chart version |
| `AppVersion` | string | Application version bundled in the chart |

## Usage Example

```go
// Create a ChartInfo instance for an installed ArgoCD chart
chart := models.ChartInfo{
    Name:       "argocd",
    Namespace:  "argocd",
    Status:     "deployed",
    Version:    "5.51.0",
    AppVersion: "2.9.0",
}

// Check chart type using constants
var chartType models.ChartType = models.ChartTypeArgoCD

switch chartType {
case models.ChartTypeArgoCD:
    fmt.Println("Managing ArgoCD chart:", chart.Name)
case models.ChartTypeAppOfApps:
    fmt.Println("Managing App-of-Apps chart:", chart.Name)
}
```
