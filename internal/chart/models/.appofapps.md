Defines the `AppOfAppsConfig` model for configuring ArgoCD app-of-apps Helm chart installations via the helm-git plugin, including repository, branch, chart path, and deployment settings.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `AppOfAppsConfig` | struct | Holds all configuration fields for an app-of-apps installation (repo URL, branch, chart path, namespace, timeout, TLS certs) |
| `NewAppOfAppsConfig()` | constructor | Returns a new `AppOfAppsConfig` pre-filled with defaults (`RepoOSSTenant`, `DefaultGitBranch`, `manifests/app-of-apps`, namespace `argocd`, timeout `60m`) |
| `GetGitURL()` | method | Builds the helm-git plugin URL in `git+https://…@<path>?ref=<branch>` format, stripping any embedded credentials to prevent token leakage |
| `stripURLCredentials()` | helper | Parses a raw URL and removes any userinfo (username/password) component; returns input unchanged if parsing fails or no credentials are present |

## Usage Example

```go
cfg := models.NewAppOfAppsConfig()

// Override defaults for a specific deployment
cfg.GitHubBranch = "v1.3.0"
cfg.Namespace    = "argocd-staging"
cfg.Timeout      = "30m"

// Returns: git+https://github.com/flamingo-stack/openframe-oss-tenant@manifests/app-of-apps?ref=v1.3.0
helmGitURL := cfg.GetGitURL()
```

> **Security note:** `GetGitURL()` always strips any `x-access-token:PAT@` or other credential from the repository URL before it is passed to Helm. Authenticate via Git credentials or environment variables instead.
