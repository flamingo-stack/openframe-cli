Defines the canonical repository URL and default Git branch constants used by the CLI when referencing the OSS platform deployment.

## Key Components

| Constant | Value | Description |
|---|---|---|
| `RepoOSSTenant` | `https://github.com/flamingo-stack/openframe-oss-tenant` | Canonical URL for the OSS platform app-of-apps repository |
| `DefaultGitBranch` | `"main"` | Default Git branch for the platform repository |

## Usage Example

```go
import "github.com/flamingo-stack/openframe-cli/models"

// Reference the OSS tenant repo in a Git operation
repoURL := models.RepoOSSTenant
branch := models.DefaultGitBranch

fmt.Printf("Cloning %s @ %s\n", repoURL, branch)
```

## Notes

- `RepoOSSTenant` is the **single source of truth** for the app-of-apps repository URL — renaming the upstream repo requires only updating this constant.
- The CLI exclusively targets the OSS (`oss-tenant`) deployment; no other deployment variants are defined here.
