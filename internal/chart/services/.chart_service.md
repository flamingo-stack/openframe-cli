## chart_service.go

Implements `ChartService`, the high-level orchestrator for chart installation operations in the OpenFrame CLI. It coordinates Helm, ArgoCD, Git repository, and configuration collaborators to execute cluster chart installations (interactive, non-interactive, and dry-run modes), while exposing seams for dependency injection in tests.

## Key Components

- **`ChartService`** — Central struct wrapping the command executor, cluster access, config service, Helm manager, Git repository, and the `rest.Config` used as the single install target (audit rule "F4: one target").
- **`NewChartService`** / **`NewChartServiceDeferred`** — Constructors. The former eagerly initializes `HelmManager` with a `rest.Config`; the latter defers Helm initialization until after cluster selection (used for standalone `app install` flows).
- **`initializeHelmManager`** — Lazily wires up `HelmManager` post cluster-selection, reusing the service's existing executor to preserve dry-run/verbose semantics.
- **`InstallWithContext`** / **`InstallWithContextDeferred`** — Entry points that build a temp-file cleanup handler and delegate to `InstallationWorkflow`.
- **`InstallationWorkflow`** — Orchestrates the installation lifecycle: resolves configuration (dry-run, non-interactive, or interactive wizard), registers temp Helm values files for cleanup, and executes with a cancellable context derived from the parent (supports Ctrl-C/SIGTERM cancellation).
- **Collaborator seams** (`installFileCleanup`, `installServicesFactory`, `installRefValidatorOrDefault`, `fileCleanupOrDefault`, `installServicesOrDefault`, `installRetryPolicyOrDefault`) — Interfaces and accessor methods allowing production defaults (`files.NewFileCleanup`, `defaultInstallServices`, `sharedErrors.InstallationRetryPolicy`) to be swapped for test doubles without changing public constructor signatures.
- **`defaultInstallServices`** — Production wiring that builds the ArgoCD and App-of-Apps services from the *same* `rest.Config` used to build `HelmManager`, avoiding accidental cross-cluster operations.

## Usage Example

```go
clusterAccess := cluster.NewAccess()
kubeConfig, _ := clientcmd.BuildConfigFromFlags("", kubeconfigPath)

// Eager initialization (kubeConfig known upfront)
chartService, err := services.NewChartService(clusterAccess, kubeConfig, false, true)
if err != nil {
    log.Fatal(err)
}

req := types.InstallationRequest{
    NonInteractive: true,
    RequireExistingValues: false,
}

ctx := context.Background()
if err := chartService.InstallWithContext(ctx, req); err != nil {
    log.Fatalf("installation failed: %v", err)
}
```

For deferred initialization (cluster selected later):

```go
chartService, err := services.NewChartServiceDeferred(clusterAccess, false, true)
// ... after cluster selection resolves kubeConfig internally via workflow
err = chartService.InstallWithContextDeferred(ctx, req)
```
