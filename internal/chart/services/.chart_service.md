## Chart Service

Implements the core chart installation orchestration for OpenFrame, wiring together Helm, ArgoCD, Git, and cluster access to install applications onto a Kubernetes cluster. It exposes `ChartService`, the main entry point used by CLI commands, and `InstallationWorkflow`, which drives the multi-step install process (configuration resolution, temp file cleanup, ArgoCD readiness) with support for interactive, non-interactive, and dry-run modes.

## Key Components

- **`ChartService`** — Central service holding the executor, cluster access, config service, Helm manager, Git repository, and `rest.Config` used for all cluster operations. Internal collaborator seams (`newFileCleanup`, `installServices`, `installRetryPolicy`, `installRefValidator`) allow test doubles to be injected while production code uses `*OrDefault` accessor methods.
- **`NewChartService`** — Constructs a fully initialized service, including an eagerly-built `HelmManager` from a supplied `rest.Config`.
- **`NewChartServiceDeferred`** — Constructs a service without a `HelmManager`, for flows where the target cluster/kubeconfig isn't known yet (e.g., standalone `app install`); `initializeHelmManager` completes setup later.
- **`InstallWithContext` / `InstallWithContextDeferred`** — Public API to run an installation given a `types.InstallationRequest`, respecting context cancellation.
- **`InstallationWorkflow`** — Orchestrates the install: chooses between dry-run, non-interactive, and interactive configuration paths, registers temporary Helm values files for cleanup, and (in later workflow steps) drives ArgoCD app-of-apps deployment and readiness waiting.
- **`defaultInstallServices`** — Production wiring that builds the ArgoCD and app-of-apps services bound to the exact `rest.Config` used by the `HelmManager`, ensuring all operations target the same cluster.

## Usage Example

```go
kubeConfig, _ := clientcmd.BuildConfigFromFlags("", kubeconfigPath)

svc, err := services.NewChartService(clusterAccess, kubeConfig, false, true)
if err != nil {
    log.Fatalf("failed to create chart service: %v", err)
}

req := types.InstallationRequest{
    NonInteractive: true,
}

ctx, cancel := context.WithCancel(context.Background())
defer cancel()

if err := svc.InstallWithContext(ctx, req); err != nil {
    log.Fatalf("installation failed: %v", err)
}
```

For deferred cluster selection (e.g., standalone chart install before a cluster is chosen):

```go
svc, err := services.NewChartServiceDeferred(clusterAccess, false, false)
if err != nil {
    log.Fatal(err)
}
// ... later, after cluster/kubeconfig is resolved
err = svc.InstallWithContextDeferred(ctx, req)
```
