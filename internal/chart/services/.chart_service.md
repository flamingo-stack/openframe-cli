## Overview

`chart_service.go` defines the `ChartService` type — the high-level orchestrator for installing OpenFrame Helm charts onto a Kubernetes cluster. It wires together the executor, Helm manager, Git repository, ArgoCD provider, and configuration/UI services, then drives the multi-step installation workflow (interactive, non-interactive, and dry-run modes) with proper temp-file cleanup and retry policies.

## Key Components

- **`ChartService`** — Core struct holding the executor, cluster access, config service, Helm manager, Git repository, `rest.Config`, and injectable test seams (`newFileCleanup`, `installServices`, `installRetryPolicy`, `installRefValidator`).
- **`NewChartService` / `NewChartServiceDeferred`** — Constructors; the former eagerly builds the `HelmManager` from a `rest.Config`, the latter defers it until a cluster is selected (via `initializeHelmManager`).
- **`installFileCleanup`** — Interface seam over `shared/files.FileCleanup`, allowing tests to verify which cleanup path (forced restore vs. success-only) runs.
- **`installServicesFactory`** — Factory type producing the ArgoCD and App-of-Apps services for a resolved `ChartInstallConfig`, ensuring both watch the same target cluster.
- **`defaultInstallServices`** — Production wiring that builds `ArgoCDService` and `AppOfAppsService` from the shared `kubeConfig`.
- **`InstallWithContext` / `InstallWithContextDeferred`** — Entry points that set up cleanup policy and delegate to `InstallationWorkflow`.
- **`InstallationWorkflow`** — Orchestrates the install steps: configuration resolution (dry-run, non-interactive, or interactive wizard), temp file registration, and execution against the target cluster.

## Usage Example

```go
kubeConfig, _ := clientcmd.BuildConfigFromFlags("", kubeconfigPath)

chartService, err := services.NewChartService(clusterAccess, kubeConfig, false, true)
if err != nil {
    log.Fatalf("failed to init chart service: %v", err)
}

req := types.InstallationRequest{
    NonInteractive:        true,
    RequireExistingValues: true,
}

if err := chartService.InstallWithContext(context.Background(), req); err != nil {
    log.Fatalf("installation failed: %v", err)
}
```

For deferred cluster selection (e.g., when the kubeconfig context isn't known upfront):

```go
chartService, err := services.NewChartServiceDeferred(clusterAccess, false, true)
// ... later, after cluster selection resolves a rest.Config ...
err = chartService.InstallWithContextDeferred(ctx, req)
```
