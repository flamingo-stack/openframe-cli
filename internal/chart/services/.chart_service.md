Orchestrates the full lifecycle of OpenFrame Helm chart installations, from configuration collection and pre-flight validation through cluster selection, HelmManager initialization, and ArgoCD-backed deployment.

## Key Components

### Types

- **`ChartService`** — Core service struct holding executor, cluster access, config service, UI components, HelmManager, git repository, and the target `*rest.Config`.
- **`InstallationWorkflow`** — Orchestrates the sequential installation steps; wraps `ChartService`, `ClusterAccess`, and file cleanup.

### Constructors

- **`NewChartService(clusterAccess, kubeConfig, dryRun, verbose)`** — Builds a fully initialized `ChartService` including `HelmManager`. Use when the target kube config is known upfront (e.g., `--context` flag).
- **`NewChartServiceDeferred(clusterAccess, dryRun, verbose)`** — Builds a `ChartService` with a `nil` HelmManager. HelmManager is lazily initialized after cluster selection inside the workflow.

### Key Methods

| Method | Description |
|---|---|
| `InstallWithContext(ctx, req)` | Primary install entry point; creates workflow and delegates to `ExecuteWithContext`. |
| `InstallWithContextDeferred(ctx, req)` | Alias for `InstallWithContext`; used when `KubeConfig` is not available upfront. |
| `initializeHelmManager(kubeConfig, verbose)` | Lazily wires the `HelmManager` after cluster selection in deferred mode. |
| `ExecuteWithContext(parentCtx, req)` | Runs the full installation sequence: configuration → pre-flight → cluster selection → HelmManager init → confirmation → certificates → build config. |

## Usage Example

```go
// Upfront kubeConfig known (e.g., --context flag provided)
svc, err := services.NewChartService(clusterAccess, kubeConfig, false, true)
if err != nil {
    log.Fatal(err)
}

req := types.InstallationRequest{
    KubeConfig:  kubeConfig,
    KubeContext: "my-context",
    Verbose:     true,
}

if err := svc.InstallWithContext(ctx, req); err != nil {
    log.Fatal(err)
}

// Deferred mode — cluster selected interactively
svc, err := services.NewChartServiceDeferred(clusterAccess, false, false)
if err != nil {
    log.Fatal(err)
}
if err := svc.InstallWithContextDeferred(ctx, req); err != nil {
    log.Fatal(err)
}
```
