Orchestrates the installation and status management of the "app-of-apps" Helm chart by cloning a Git repository, resolving local paths, and delegating to the Helm manager.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `AppOfApps` | Struct | Core service holding references to the Helm manager, Git repository, and path resolver |
| `NewAppOfApps` | Constructor | Initializes an `AppOfApps` service with its required dependencies |
| `Install` | Method | Clones the chart repository, resolves values/cert paths, and invokes Helm installation |
| `IsInstalled` | Method | Delegates to `HelmManager` to check whether the `app-of-apps` release exists in a namespace |
| `GetStatus` | Method | Returns a `models.ChartInfo` struct describing the current release state |

## Usage Example

```go
helmMgr := helm.NewHelmManager(...)
repo := git.NewRepository(...)
resolver := config.NewPathResolver(...)

svc := services.NewAppOfApps(helmMgr, repo, resolver)

cfg := config.ChartInstallConfig{
    ClusterName: "prod-cluster",
    AppOfApps: &config.AppOfAppsConfig{
        GitHubRepo:   "https://github.com/flamingo-stack/openframe-charts",
        GitHubBranch: "main",
    },
}

if err := svc.Install(ctx, cfg); err != nil {
    log.Fatal(err)
}

installed, _ := svc.IsInstalled(ctx, "openframe")
status, _    := svc.GetStatus(ctx, "openframe")
```

## Notes

- **Branch defaulting** — if `GitHubBranch` is empty, it falls back to `"main"`.
- **Cleanup** — the cloned temp directory is always removed via `defer` regardless of install outcome.
- **Spinner suppression** — progress indicators are skipped when `Silent` or `NonInteractive` flags are set.
- **Branch-not-found detection** — inspects the raw error string and re-wraps it as a typed `sharedErrors.BranchNotFoundError` for structured handling upstream.
