Orchestrates ArgoCD installation and lifecycle management via Helm, targeting a specific Kubernetes cluster to avoid context-mismatch issues during multi-cluster operations.

## Key Components

| Symbol | Description |
|---|---|
| `ArgoCD` | Service struct wrapping Helm, ArgoCD, and command executor dependencies |
| `NewArgoCDForTarget` | Constructor that pins the wait manager to the correct cluster using a `rest.Config`, named cluster context, or current kubeconfig context |
| `Install` | Installs or upgrades ArgoCD via Helm with progress output |
| `WaitForApplications` | Blocks until all ArgoCD applications report ready, returning a recoverable error with a 60-second retry hint on failure |
| `IsInstalled` | Returns whether the ArgoCD Helm release exists in the target namespace |
| `GetStatus` | Returns the current `ChartInfo` for the ArgoCD release |

## Usage Example

```go
helmMgr, _ := helm.NewHelmManager(kubeConfig)
pathResolver := config.NewPathResolver("/opt/openframe")
exec := executor.NewRealCommandExecutor(true, false)

svc, err := services.NewArgoCDForTarget(helmMgr, pathResolver, exec, kubeConfig, "")
if err != nil {
    log.Fatal(err)
}

installCfg := config.ChartInstallConfig{
    ClusterName: "prod-cluster",
    Verbose:     true,
}

if err := svc.Install(ctx, installCfg); err != nil {
    log.Fatal(err)
}

if err := svc.WaitForApplications(ctx, installCfg); err != nil {
    log.Fatal(err)
}

installed, _ := svc.IsInstalled(ctx)
fmt.Println("ArgoCD installed:", installed)

info, _ := svc.GetStatus(ctx)
fmt.Printf("Release: %s, Status: %s\n", info.Name, info.Status)
```

## Notes

- Pass a non-nil `rest.Config` to `NewArgoCDForTarget` when targeting a cluster that differs from the active kubeconfig context — this prevents wait operations from resolving against the wrong cluster.
- Internal ArgoCD operations always use a non-verbose executor regardless of the caller's verbosity setting.
