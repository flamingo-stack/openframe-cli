Provides configuration validation logic for non-interactive CLI deployments, implementing a no-op validator for the OSS (`oss-tenant`) deployment type.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `ConfigurationValidator` | struct | Validator for `openframe-helm-values.yaml` in non-interactive mode |
| `NewConfigurationValidator` | constructor | Returns a new `ConfigurationValidator` instance |
| `ValidateConfiguration` | method | Accepts a `*types.ChartConfiguration` and always returns `nil` |

## Usage Example

```go
validator := services.NewConfigurationValidator()

cfg := &types.ChartConfiguration{ /* ... */ }

if err := validator.ValidateConfiguration(cfg); err != nil {
    log.Fatal(err)
}
// Always passes for the public OSS deployment — no credentials required
```

## Notes

The OSS (`oss-tenant`) deployment pulls from a public repository and requires no credentials, so `ValidateConfiguration` intentionally performs no checks and returns `nil`. If additional deployment types requiring credential validation are added in the future, this is the extension point.
