## Overview

Defines the `Installer` type, which orchestrates the end-to-end chart installation workflow: validating the app-of-apps Git reference, installing ArgoCD, installing the app-of-apps chart, and waiting for resulting ArgoCD applications to become ready.

## Key Components

- **`Installer`** — struct holding the `ArgoCDService`, `AppOfAppsService`, and an optional `GitRefValidator`.
  - `argoCDService` — installs and monitors ArgoCD.
  - `appOfAppsService` — installs the app-of-apps chart from a GitHub repository.
  - `refValidator` — optional preflight check for the Git ref; `nil` skips validation (useful for tests).
- **`InstallChartsWithContext(ctx, config)`** — the main orchestration method:
  1. If app-of-apps is configured and a ref validator is set, validates the Git branch/ref *before* touching the cluster, defaulting `GitHubBranch` to `main` if unset. `BranchNotFoundError` is returned unwrapped (it renders its own error panel); other errors are wrapped as chart errors.
  2. Installs ArgoCD via `argoCDService.Install`.
  3. If app-of-apps is configured, installs it via `appOfAppsService.Install`, again passing through `BranchNotFoundError` unwrapped.
  4. Waits for ArgoCD applications to become ready via `argoCDService.WaitForApplications`. Failures here are treated as **non-retryable** (`WithNonRetryable()`) since ArgoCD and app-of-apps are already installed — retrying would cause unnecessary reinstallation. The wrapped cause is unwrapped from the service layer's `ChartError` to avoid duplicated error messages.

## Usage Example

```go
installer := &services.Installer{
    argoCDService:    argoCDSvc,
    appOfAppsService: appOfAppsSvc,
    refValidator:     gitRefValidator, // or nil to skip preflight
}

cfg := config.ChartInstallConfig{
    ClusterName: "my-cluster",
    AppOfApps: &config.AppOfAppsConfig{
        GitHubBranch: "main",
    },
}

if err := installer.InstallChartsWithContext(ctx, cfg); err != nil {
    log.Fatalf("chart installation failed: %v", err)
}
```
