## Installer

Orchestrates the complete chart installation workflow, coordinating ArgoCD installation, app-of-apps deployment, and pre-flight validation of Git references before any cluster changes are made.

## Key Components

- **`Installer`** — struct holding the services needed to perform installation:
  - `argoCDService` (`types.ArgoCDService`) — installs ArgoCD and waits for applications to become ready.
  - `appOfAppsService` (`types.AppOfAppsService`) — installs the app-of-apps configuration from a GitHub repository.
  - `refValidator` (`types.GitRefValidator`) — optional preflight validator for the Git ref/branch; if `nil`, preflight is skipped (useful in tests).

- **`InstallChartsWithContext(ctx, config) error`** — main orchestration method that:
  1. Validates the app-of-apps Git ref **before** touching the cluster, failing fast on typos (e.g. bad `--ref`) instead of after ArgoCD is already installed.
  2. Installs ArgoCD.
  3. If app-of-apps is configured, installs it and waits for all ArgoCD applications to become ready.
  4. Wraps errors as `*errors.ChartError` with cluster context, while passing through `*sharedErrors.BranchNotFoundError` unwrapped so it can render its own actionable message.
  5. Marks application-wait failures as non-retryable via `WithNonRetryable()`, since retrying would just reinstall an already-successful ArgoCD/app-of-apps setup, and because wait diagnostics may contain log text that could falsely match transient-error patterns.

## Usage Example

```go
installer := &services.Installer{
    argoCDService:    argoCDSvc,
    appOfAppsService: appOfAppsSvc,
    refValidator:     gitRefValidator, // or nil to skip preflight
}

cfg := config.ChartInstallConfig{
    ClusterName: "my-cluster",
    AppOfApps: &config.AppOfAppsConfig{
        GitHubRepo:   "flamingo-stack/openframe-apps",
        GitHubBranch: "main",
    },
}

if err := installer.InstallChartsWithContext(ctx, cfg); err != nil {
    log.Fatalf("chart installation failed: %v", err)
}
```
