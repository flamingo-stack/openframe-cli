## Overview

Defines the `Installer` type, which orchestrates the full chart installation workflow for OpenFrame clusters: validating the app-of-apps Git ref, installing ArgoCD, installing the app-of-apps manifest, and waiting for resulting ArgoCD applications to become ready. It centralizes error wrapping so failures are correctly classified as recoverable/non-recoverable and attributed to the responsible component.

## Key Components

- **`Installer` struct** – Holds the dependencies needed to perform an installation:
  - `argoCDService types.ArgoCDService` – installs ArgoCD and waits for applications.
  - `appOfAppsService types.AppOfAppsService` – installs the app-of-apps from a GitHub repo.
  - `refValidator types.GitRefValidator` – optional preflight check for the configured Git ref/branch (nil skips validation, e.g., in tests).

- **`InstallChartsWithContext(ctx context.Context, config config.ChartInstallConfig) error`** – Main entry point that:
  1. Preflights the Git ref (if `HasAppOfApps()` and a validator is set), defaulting branch to `"main"`.
  2. Installs ArgoCD via `argoCDService.Install`.
  3. Installs app-of-apps via `appOfAppsService.Install`, if configured.
  4. Waits for ArgoCD applications via `argoCDService.WaitForApplications`, marking failures as non-retryable and unwrapping duplicate error messages.
  - Propagates `sharedErrors.BranchNotFoundError` unwrapped (it renders its own actionable panel), and wraps other failures with `errors.WrapAsChartError` or `errors.NewChartError`, attaching cluster context via `WithCluster`.

## Usage Example

```go
installer := &Installer{
    argoCDService:    argoCDSvc,
    appOfAppsService: appOfAppsSvc,
    refValidator:     gitRefValidator, // optional; pass nil to skip preflight
}

cfg := config.ChartInstallConfig{
    ClusterName: "my-cluster",
    AppOfApps: &config.AppOfAppsConfig{
        GitHubBranch: "feature/my-branch",
    },
}

if err := installer.InstallChartsWithContext(context.Background(), cfg); err != nil {
    log.Fatalf("chart installation failed: %v", err)
}
```

Callers should inspect returned errors for `sharedErrors.BranchNotFoundError` or `*errors.ChartError` (via `errors.As`) to render appropriate diagnostics or decide on retry logic.
