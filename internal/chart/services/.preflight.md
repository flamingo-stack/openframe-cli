Performs an early validation of the `openframe-helm-values.yaml` file before cluster creation, acting as the cheapest gate to catch malformed Helm values without incurring the cost of a full k3d cluster setup.

## Key Components

- **`ValidateHelmValuesFile()`** — Resolves the default Helm values file path via `config.NewPathResolver()`, then delegates validation to `argocd.ValidateUserValuesFile()`. Returns a wrapped error if validation fails.

## Usage Example

```go
if err := services.ValidateHelmValuesFile(); err != nil {
    log.Fatalf("Pre-flight check failed: %v", err)
}
// Proceed with cluster creation...
```

## Notes

- Called during bootstrap **before** cluster creation to fail fast on invalid `argocd:` overrides.
- The install workflow performs a second validation against the temp values file it passes to Helm — this is the earlier, cheaper counterpart to that check.
