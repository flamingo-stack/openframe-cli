Manages cluster selection logic for chart operations, providing both interactive and non-interactive modes for selecting a target cluster.

## Key Components

- **`ClusterSelector`** — Struct that orchestrates cluster listing and selection using a `ClusterLister` service and `OperationsUI`.
- **`NewClusterSelector`** — Constructor that injects a `ClusterLister` and `OperationsUI` dependency.
- **`SelectCluster`** — Core method that lists available clusters and either prompts interactively or resolves from CLI args; fails fast in non-interactive mode (e.g., CI) if no cluster name is provided.

## Usage Example

```go
selector := services.NewClusterSelector(clusterService, operationsUI)

// Interactive mode (prompts user to pick a cluster)
clusterName, err := selector.SelectCluster([]string{}, false, true)

// Non-interactive mode (CI pipelines) — requires cluster name as argument
clusterName, err := selector.SelectCluster([]string{"my-cluster"}, true, false)
if err != nil {
    // Returns actionable error listing available cluster names
    log.Fatal(err)
}
```

## Behavior Notes

| Mode | Args Provided | Result |
|------|--------------|--------|
| Interactive | Any | Falls through to UI picker |
| Non-interactive | Cluster name | Resolves directly |
| Non-interactive | Empty | Fails with available cluster list |
| Any | No clusters found | Shows no-cluster message, returns `""` |
