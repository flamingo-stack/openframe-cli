## cluster.go

Provides cluster selection logic for chart operations, handling both interactive and non-interactive cluster selection workflows with appropriate CI-safe fallback behavior.

## Key Components

- **`ClusterSelector`** - Struct that encapsulates cluster listing and selection UI dependencies.
- **`NewClusterSelector(clusterService, operationsUI)`** - Constructor that wires a `types.ClusterLister` and `chartUI.OperationsUI` into a new `ClusterSelector`.
- **`(*ClusterSelector) SelectCluster(args, nonInteractive, verbose)`** - Core method that lists available clusters, logs verbose diagnostics, guards against hanging in non-interactive/CI environments, and delegates to the interactive picker when appropriate.

## Usage Example

```go
package main

import (
	chartUI "github.com/flamingo-stack/openframe-cli/internal/chart/ui"
	"github.com/flamingo-stack/openframe-cli/internal/chart/utils/services"
)

func main() {
	clusterService := someClusterListerImpl{}
	operationsUI := chartUI.NewOperationsUI()

	selector := services.NewClusterSelector(clusterService, operationsUI)

	// Non-interactive mode requires a cluster name argument.
	clusterName, err := selector.SelectCluster([]string{"my-cluster"}, true, false)
	if err != nil {
		panic(err)
	}

	// Interactive mode without args triggers an interactive picker.
	clusterName, err = selector.SelectCluster(nil, false, true)
	if err != nil {
		panic(err)
	}

	_ = clusterName
}
```

**Behavior notes:**
- If no clusters exist or listing fails, it shows a "no cluster" message and returns an empty result without erroring.
- In `nonInteractive` mode with no cluster name provided, it returns an actionable error listing available cluster names instead of blocking on interactive input.
- Verbose mode prints diagnostic output about discovered clusters via `pterm`.
