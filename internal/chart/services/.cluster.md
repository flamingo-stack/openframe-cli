## Overview

`cluster.go` provides the `ClusterSelector` type, which encapsulates the logic for resolving which Kubernetes cluster a chart operation should target. It bridges cluster listing (via a `ClusterLister` interface) with interactive or argument-based selection, while guarding against hangs when running in non-interactive (CI) mode.

## Key Components

- **`ClusterSelector`** — struct combining a `types.ClusterLister` (to fetch available clusters) and a `chartUI.OperationsUI` (for user prompts/messages).
- **`NewClusterSelector(clusterService, operationsUI)`** — constructor that wires the dependencies together.
- **`(*ClusterSelector) SelectCluster(args []string, nonInteractive, verbose bool) (string, error)`** — main entry point:
  - Lists clusters and shows a "no cluster" message if listing fails or returns empty.
  - Logs verbose output listing found clusters.
  - In `nonInteractive` mode, requires a cluster name in `args`; returns an actionable error listing available clusters if missing, preventing an interactive prompt from blocking CI.
  - Otherwise delegates to `operationsUI.SelectClusterForInstall` for interactive or argument-based selection.

## Usage Example

```go
selector := services.NewClusterSelector(clusterService, operationsUI)

// Interactive mode - prompts user if no args provided
clusterName, err := selector.SelectCluster(args, false, verbose)
if err != nil {
    return err
}

// Non-interactive mode - requires cluster name in args
clusterName, err := selector.SelectCluster([]string{"my-cluster"}, true, false)
if err != nil {
    // Fails fast with available cluster names if args are missing
    log.Fatal(err)
}

fmt.Printf("Selected cluster: %s\n", clusterName)
```
