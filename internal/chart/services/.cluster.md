## Overview

`cluster.go` provides the `ClusterSelector` type, which encapsulates the logic for resolving which Kubernetes cluster a chart operation should target. It supports both interactive selection (via a UI prompt) and non-interactive usage (via CLI arguments), guarding against scenarios where a non-interactive invocation would otherwise hang waiting for user input.

## Key Components

- **`ClusterSelector`** - Struct combining a `types.ClusterLister` (to fetch available clusters) and a `chartUI.OperationsUI` (to drive interactive prompts).
- **`NewClusterSelector(clusterService, operationsUI)`** - Constructor that wires up the cluster lister and operations UI dependencies.
- **`SelectCluster(args, nonInteractive, verbose bool) (string, error)`** - Core method that:
  - Lists available clusters, showing a "no cluster" message if listing fails or returns empty.
  - Logs verbose details about discovered clusters when `verbose` is true.
  - Fails fast with an actionable error (listing available cluster names) when `nonInteractive` is true and no cluster name was supplied in `args`.
  - Otherwise delegates to `operationsUI.SelectClusterForInstall` for interactive or argument-based selection.

## Usage Example

```go
package main

import (
	"fmt"
	"os"

	chartUI "github.com/flamingo-stack/openframe-cli/internal/chart/ui"
	"github.com/flamingo-stack/openframe-cli/internal/chart/utils/services"
)

func main() {
	clusterLister := /* implementation of types.ClusterLister */ nil
	operationsUI := chartUI.NewOperationsUI()

	selector := services.NewClusterSelector(clusterLister, operationsUI)

	clusterName, err := selector.SelectCluster(os.Args[1:], false, true)
	if err != nil {
		fmt.Println("Error selecting cluster:", err)
		os.Exit(1)
	}

	fmt.Println("Selected cluster:", clusterName)
}
```

This is typically invoked from a chart command (e.g., `install`, `uninstall`) prior to performing operations that require a target cluster context.
