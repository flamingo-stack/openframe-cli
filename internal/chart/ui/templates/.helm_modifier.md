Handles reading, modifying, and writing Helm values YAML files for OpenFrame chart configurations, including secure secret registration and temporary file management.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `HelmValuesModifier` | struct | Core type for all Helm values file operations |
| `NewHelmValuesModifier()` | constructor | Returns a new `HelmValuesModifier` instance |
| `LoadExistingValues()` | method | Reads and parses a Helm values YAML file, registering secrets with the redactor |
| `RegisterValueSecrets()` | func | Registers sensitive fields (Docker password, ngrok API key/authtoken) with the shared `redact` package |
| `LoadOrCreateBaseValues()` | method | Loads values from the default path or returns an empty map if not found |
| `CreateTemporaryValuesFile()` | method | Writes values to a uniquely named OS temp file (`0600`) to avoid path collisions and secret exposure |
| `ApplyConfiguration()` | method | Applies a `ChartConfiguration` (branch, Docker registry) onto a values map |
| `SetRepositoryBranch()` | method | Pins `repository.branch` in the values map |
| `WriteValues()` | method | Marshals and writes a values map to disk with `0600` permissions |
| `GetCurrentOSSBranch()` | method | Reads `repository.branch`, defaulting to `"main"` |
| `GetCurrentDockerSettings()` | method | Extracts Docker registry config from `registry.docker.*` |
| `GetCurrentIngressSettings()` | method | Detects active ingress type (`"ngrok"` or `"localhost"`) |

## Usage Example

```go
modifier := templates.NewHelmValuesModifier()

// Load existing values (secrets auto-registered with redactor)
values, err := modifier.LoadExistingValues("/path/to/helm-values.yaml")
if err != nil {
    log.Fatal(err)
}

// Apply chart configuration changes
cfg := &types.ChartConfiguration{
    Branch: ptr("main"),
    DockerRegistry: &types.DockerRegistryConfig{
        Username: "myuser",
        Password: "s3cr3t",
        Email:    "myuser@example.com",
    },
}
if err := modifier.ApplyConfiguration(values, cfg); err != nil {
    log.Fatal(err)
}

// Write to a secure temporary file for use with helm install
tmpPath, err := modifier.CreateTemporaryValuesFile(values)
if err != nil {
    log.Fatal(err)
}
defer os.Remove(tmpPath)

// Inspect current settings
branch := modifier.GetCurrentOSSBranch(values)        // "main"
ingress := modifier.GetCurrentIngressSettings(values) // "ngrok" or "localhost"
docker := modifier.GetCurrentDockerSettings(values)
```

> **Security note:** All writes use `0600` permissions and sensitive values (Docker password, ngrok credentials) are automatically registered with [`redact.RegisterSecret`](https://github.com/flamingo-stack/openframe-cli/blob/main/internal/shared/redact) on every load to prevent leaking secrets in logs or error output.
