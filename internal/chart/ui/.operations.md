Provides the user interface layer for Helm chart installation operations, handling cluster selection, confirmation prompts, and error messaging.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `OperationsUI` | struct | Main UI service that wraps chart operation interactions |
| `NewOperationsUI()` | constructor | Initializes `OperationsUI` with a cluster selector scoped to "chart installation" |
| `SelectClusterForInstall()` | method | Delegates cluster selection to the shared `clusterUI.Selector`, supporting both interactive and argument-based selection |
| `ShowNoClusterMessage()` | method | Displays a formatted error prompting the user to create a cluster first |
| `ConfirmInstallationOnCluster()` | method | Renders an interactive yes/no confirmation before triggering a potentially long-running install |

## Usage Example

```go
clusters := []models.ClusterInfo{
    {Name: "prod-cluster"},
    {Name: "staging-cluster"},
}

ops := ui.NewOperationsUI()

// Select a cluster interactively (or use args to skip prompt)
clusterName, err := ops.SelectClusterForInstall(clusters, []string{})
if err != nil {
    log.Fatal(err)
}

// Confirm before installing
confirmed, err := ops.ConfirmInstallationOnCluster(clusterName)
if err != nil || !confirmed {
    fmt.Println("Installation cancelled.")
    return
}

// Proceed with chart installation...
```

If no clusters exist, call `ops.ShowNoClusterMessage()` to surface a user-friendly error directing them to run `openframe cluster create`.
