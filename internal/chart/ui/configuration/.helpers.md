Helper methods for the `ConfigurationWizard` that manage Helm values files during the configuration process.

## Key Components

| Function | Description |
|---|---|
| `loadBaseValues()` | Loads existing Helm values from the current directory (or creates defaults) and returns a `ChartConfiguration` struct |
| `createTemporaryValuesFile()` | Applies pending configuration changes and writes a temporary Helm values file, updating `TempHelmValuesPath` on the config |

## Usage Example

```go
wizard := &ConfigurationWizard{modifier: myModifier}

// Load or initialize base configuration
chartConfig, err := wizard.loadBaseValues()
if err != nil {
    log.Fatal(err)
}

// Modify chartConfig.ExistingValues or sections as needed...

// Write a temporary values file for Helm installation
if err := wizard.createTemporaryValuesFile(chartConfig); err != nil {
    log.Fatal(err)
}

fmt.Println("Temp values file:", chartConfig.TempHelmValuesPath)
```

## Notes

- `loadBaseValues` initializes `ModifiedSections` as an empty slice and leaves `TempHelmValuesPath` empty until `createTemporaryValuesFile` is called.
- `createTemporaryValuesFile` delegates to `modifier.ApplyConfiguration` before writing, ensuring all wizard-collected changes are reflected in the output file.
- Both methods are private to the `configuration` package. See [`types.ChartConfiguration`](https://github.com/flamingo-stack/openframe-cli/blob/main/internal/chart/utils/types) for the full configuration shape.
