Orchestrates the Helm values configuration workflow for OpenFrame chart deployments, coordinating branch, Docker, and ingress configuration steps through either a default or interactive wizard mode.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `ConfigurationWizard` | struct | Root wizard struct holding references to all sub-configurators and the Helm values modifier |
| `NewConfigurationWizard()` | constructor | Initializes the wizard with a shared `HelmValuesModifier` and wires up all sub-configurators |
| `ConfigureHelmValues()` | method | Entry point for the configuration flow; prompts for mode selection then delegates to default or interactive configuration |

## Usage Example

```go
wizard := configuration.NewConfigurationWizard()

chartConfig, err := wizard.ConfigureHelmValues()
if err != nil {
    log.Fatalf("configuration failed: %v", err)
}

// chartConfig holds the resolved *types.ChartConfiguration
// ready to be applied to the Helm release
```

## Notes

- The wizard uses a shared [`HelmValuesModifier`](https://github.com/flamingo-stack/openframe-cli/blob/main/internal/chart/ui/templates) instance passed down to all sub-configurators, ensuring consistent state across the configuration steps.
- `ConfigureHelmValues` branches on a user-selected mode (`"default"` vs interactive), delegating to `configureWithDefaults()` or `configureInteractive()` respectively — both returning a `*types.ChartConfiguration`.
- Deployment mode is always OSS; only configuration details (branch, Docker registry, ingress) are user-configurable.
