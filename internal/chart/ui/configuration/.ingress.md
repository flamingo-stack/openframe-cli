Manages ingress configuration for Helm chart deployments, supporting both localhost and Ngrok-based external access with interactive CLI prompts for credential collection and IP allowlist management.

## Key Components

- **`IngressConfigurator`** — Core struct wrapping a `HelmValuesModifier` to read and write ingress settings
- **`NewIngressConfigurator`** — Constructor accepting a `HelmValuesModifier` dependency
- **`Configure`** — Entry point; prompts the user to choose between localhost or Ngrok ingress, then applies the selection to `ChartConfiguration`
- **`configureNgrok`** — Orchestrates the full Ngrok setup flow: credential collection and IP allowlist configuration
- **`collectNgrokCredentials`** — Interactively collects Ngrok domain, API key, and auth token (masked inputs); registers secrets with `redact.RegisterSecret` to prevent leakage in logs
- **`configureNgrokIPAllowlist`** — Prompts for IP restriction preferences and collects CIDR addresses
- **`applyLocalhostConfig`** / **`applyNgrokConfig`** — Write the resolved ingress settings into the Helm values map, disabling conflicting ingress types

## Usage Example

```go
modifier := templates.NewHelmValuesModifier()
configurator := configuration.NewIngressConfigurator(modifier)

chartConfig := &types.ChartConfiguration{
    ExistingValues: existingHelmValues,
}

if err := configurator.Configure(chartConfig); err != nil {
    log.Fatalf("ingress configuration failed: %v", err)
}

// chartConfig.IngressConfig now holds the selected ingress type
// chartConfig.ExistingValues is updated with the applied Helm values
```

> **Security note:** Ngrok API keys and auth tokens are masked during input and immediately registered with `redact.RegisterSecret`, ensuring they are scrubbed from any subsequent log or error output.
