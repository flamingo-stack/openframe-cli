Handles interactive Docker registry credential configuration for Helm chart deployments, prompting users for username, password, and email while redacting secrets from logs.

## Key Components

- **`DockerConfigurator`** — Struct that wraps a `HelmValuesModifier` to read and update Docker registry settings within Helm values.
- **`NewDockerConfigurator`** — Constructor that initializes a `DockerConfigurator` with a given `HelmValuesModifier`.
- **`Configure`** — Presents a selection menu to skip or input Docker credentials; only marks the config as modified if values actually changed.
- **`promptForDockerSettings`** — Collects username, masked password, and email via interactive text prompts, trims whitespace, and registers the password with the secret redactor.

## Usage Example

```go
modifier := templates.NewHelmValuesModifier(valuesData)
configurator := configuration.NewDockerConfigurator(modifier)

config := &types.ChartConfiguration{
    ExistingValues: existingHelmValues,
}

if err := configurator.Configure(config); err != nil {
    log.Fatalf("Docker configuration failed: %v", err)
}

// config.DockerRegistry is populated if the user chose custom credentials
// config.ModifiedSections includes "docker" if values changed
```

## Notes

- The password field is masked (`*`) during input to prevent shoulder-surfing.
- `redact.RegisterSecret` is called on the trimmed password immediately after input, ensuring it never appears in verbose logs or error output downstream.
- Credential updates are only written to `config.DockerRegistry` if at least one field differs from the current values, avoiding unnecessary Helm value diffs.
