Provides the two top-level configuration workflows for the chart installation wizard: prompting the user to choose a configuration mode, and executing either a default (non-interactive) or fully interactive configuration flow.

## Key Components

- **`showConfigurationModeSelection()`** — Prompts the user via `sharedUI.SelectOption` to choose between "Default configuration" and "Interactive configuration", returning `"default"` or `"interactive"`.
- **`configureWithDefaults()`** — Loads base Helm values (existing `openframe-helm-values.yaml` or defaults), writes them to a temporary values file, and returns the resulting `*types.ChartConfiguration` without prompting the user further.
- **`configureInteractive()`** — Loads base values, then walks the user through branch, Docker registry, and ingress configuration sections in sequence (`branchConfig`, `dockerConfig`, `ingressConfig`), finally persisting the result to a temporary values file.

Both configuration functions are methods on `ConfigurationWizard` and rely on shared helpers `loadBaseValues()` and `createTemporaryValuesFile()` defined elsewhere in the package.

## Usage Example

```go
wizard := &ConfigurationWizard{
    branchConfig:  branchConfigurator,
    dockerConfig:  dockerConfigurator,
    ingressConfig: ingressConfigurator,
}

mode, err := wizard.showConfigurationModeSelection()
if err != nil {
    return err
}

var config *types.ChartConfiguration
if mode == "default" {
    config, err = wizard.configureWithDefaults()
} else {
    config, err = wizard.configureInteractive()
}
if err != nil {
    return fmt.Errorf("configuration failed: %w", err)
}
```

## Notes

- Errors from each configuration section are wrapped with context (e.g., `"branch configuration failed: %w"`) to aid debugging.
- The default mode is intended for quick OSS deployments without prompting for branch, registry, or ingress details.
