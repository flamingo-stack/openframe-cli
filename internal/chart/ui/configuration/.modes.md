Provides configuration mode handling for the chart installation wizard, letting users choose between a default (non-interactive) setup or a fully interactive configuration flow.

## Key Components

- **showConfigurationModeSelection** - Prompts the user to select between "Default configuration" and "Interactive configuration" modes using a selectable menu, returning `"default"` or `"interactive"`.
- **configureWithDefaults** - Builds a `ChartConfiguration` using existing/default Helm values without any user prompts, then writes it to a temporary values file.
- **configureInteractive** - Runs the full interactive wizard, sequentially invoking branch, Docker registry, and ingress configuration steps before persisting the final result to a temporary values file.

Both configuration methods rely on `w.loadBaseValues()` to load or initialize the base `ChartConfiguration`, and `w.createTemporaryValuesFile(config)` to persist the resulting configuration for later use by the chart installation process.

## Usage Example

```go
wizard := &ConfigurationWizard{
    branchConfig:  branchConfigurer,
    dockerConfig:  dockerConfigurer,
    ingressConfig: ingressConfigurer,
}

mode, err := wizard.showConfigurationModeSelection()
if err != nil {
    log.Fatal(err)
}

var config *types.ChartConfiguration
switch mode {
case "default":
    config, err = wizard.configureWithDefaults()
case "interactive":
    config, err = wizard.configureInteractive()
}
if err != nil {
    log.Fatal(err)
}

fmt.Printf("Chart configured: %+v\n", config)
```

This is typically invoked as part of the larger `ConfigurationWizard` flow when installing or updating a Helm chart, allowing users to quickly bootstrap with defaults or fine-tune settings interactively.
