This file implements the configuration mode selection and execution logic for the OpenFrame CLI's chart configuration wizard, offering users a choice between default and interactive Helm values configuration.

## Key Components

- **`showConfigurationModeSelection()`** — Prompts the user via an interactive selector to choose between "Default configuration" and "Interactive configuration" modes, returning `"default"` or `"interactive"`.
- **`configureWithDefaults()`** — Builds a `types.ChartConfiguration` using the existing base values (loaded via `loadBaseValues`) without prompting the user, then writes it to a temporary values file.
- **`configureInteractive()`** — Runs the full interactive wizard flow, sequentially configuring branch, Docker registry, and ingress settings via `branchConfig`, `dockerConfig`, and `ingressConfig` sub-configurators, then persists the result to a temporary values file.

Both configuration functions rely on `w.loadBaseValues()` to seed the configuration and `w.createTemporaryValuesFile(config)` to persist the final result for later use by the chart installation process.

## Usage Example

```go
wizard := &ConfigurationWizard{
    branchConfig:  branch.NewConfigurator(),
    dockerConfig:  docker.NewConfigurator(),
    ingressConfig: ingress.NewConfigurator(),
}

mode, err := wizard.showConfigurationModeSelection()
if err != nil {
    log.Fatalf("mode selection failed: %v", err)
}

var config *types.ChartConfiguration
if mode == "default" {
    config, err = wizard.configureWithDefaults()
} else {
    config, err = wizard.configureInteractive()
}
if err != nil {
    log.Fatalf("configuration failed: %v", err)
}

fmt.Printf("Chart configured: %+v\n", config)
```

These functions are typically invoked as part of the larger `ConfigurationWizard` flow used during `openframe chart install` operations to prepare Helm values before deployment.
