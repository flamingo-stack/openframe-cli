Handles Git branch configuration for Helm chart deployments, allowing users to keep the current OSS repository branch or specify a custom one.

## Key Components

- **`BranchConfigurator`** — Struct that wraps a `HelmValuesModifier` to read and update branch values
- **`NewBranchConfigurator`** — Constructor that accepts a `*templates.HelmValuesModifier`
- **`Configure`** — Prompts the user to keep the current branch or enter a custom branch name; updates `config.Branch` and appends `"branch"` to `config.ModifiedSections` only when the value changes

## Usage Example

```go
modifier := templates.NewHelmValuesModifier()
configurator := configuration.NewBranchConfigurator(modifier)

config := &types.ChartConfiguration{
    ExistingValues: existingHelmValues,
}

if err := configurator.Configure(config); err != nil {
    log.Fatalf("branch configuration failed: %v", err)
}

if config.Branch != nil {
    fmt.Printf("Branch updated to: %s\n", *config.Branch)
}
```
