Provides a minimal UI display service for chart-related operations within the `ui` package.

## Key Components

- **`DisplayService`** — Struct that serves as the foundation for chart-related UI display operations.
- **`NewDisplayService()`** — Constructor that initializes and returns a new `DisplayService` instance.

## Usage Example

```go
import "github.com/flamingo-stack/openframe-cli/ui"

svc := ui.NewDisplayService()
_ = svc // use svc to invoke display operations
```
