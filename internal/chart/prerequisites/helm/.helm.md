Manages Helm installation detection and automated setup across macOS and Linux, with Windows routing handled via WSL2.

## Key Components

| Symbol | Type | Description |
|---|---|---|
| `HelmInstaller` | struct | Primary installer struct implementing the tool installer interface |
| `NewHelmInstaller()` | constructor | Returns a new `*HelmInstaller` instance |
| `IsInstalled()` | method | Detects if Helm is available; on Windows, delegates to `wsllauncher.CommandAvailable` |
| `GetInstallHelp()` | method | Returns platform-specific install hint via `platform.InstallHint` |
| `Install()` | method | Dispatches to `installMacOS` or `installLinux` based on `runtime.GOOS` |
| `installMacOS()` | method | Installs Helm via Homebrew; errors if `brew` is not found |
| `installVerified()` | method | Downloads a pinned, SHA256-verified Helm tarball into `~/.openframe/bin` without requiring sudo |

## Usage Example

```go
installer := helm.NewHelmInstaller()

if !installer.IsInstalled() {
    fmt.Println(installer.GetInstallHelp())

    if err := installer.Install(); err != nil {
        log.Fatalf("helm install failed: %v", err)
    }
}
```

## Notes

- **Windows**: Native installation is intentionally unsupported — the CLI forwards execution into WSL2, so `Install()` runs as Linux in practice.
- **Linux**: Uses `installVerified()` to fetch a pinned release with SHA256 verification into `~/.openframe/bin`, avoiding unverified `curl | bash` patterns.
- **Helm detection** applies a 5-second context timeout when running `helm version` to prevent hangs on broken installations.
