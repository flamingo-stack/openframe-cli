Orchestrates the detection and installation of OpenFrame CLI prerequisites (Helm, certificates, memory), supporting both interactive and non-interactive (CI) modes.

## Key Components

| Export | Description |
|--------|-------------|
| `Installer` | Main struct that wraps a `PrerequisiteChecker` and drives the install flow |
| `NewInstaller()` | Constructor that initializes `Installer` with a default `PrerequisiteChecker` |
| `CheckAndInstallNonInteractive(nonInteractive bool)` | Primary entrypoint — checks all prerequisites, prompts user or auto-approves, and installs missing tools |
| `RegenerateCertificatesOnly()` | Standalone certificate refresh, intended for the `install` command only |
| `installMissingToolsNonInteractive(tools, nonInteractive)` | Iterates missing tools, skips uninstallable ones (memory, certs in CI), and verifies post-install |
| `installToolNonInteractive(tool, nonInteractive)` | Dispatches single-tool installation to the appropriate sub-installer (`helm`, `certificates`) |

## Behavior Notes

- **Memory** is treated as a warning only — it cannot be auto-installed and is excluded from failure checks.
- **Certificates** are skipped in non-interactive mode because `mkcert -install` requires interactive sudo/trust-store access. Localhost HTTPS will be untrusted in this case.
- Both interactive and non-interactive paths **fail fast** if installable tools remain missing after the install pass, avoiding deferred failures during Helm deployment.

## Usage Example

```go
installer := prerequisites.NewInstaller()

// Interactive mode (prompts user for confirmation)
if err := installer.CheckAndInstallNonInteractive(false); err != nil {
    log.Fatalf("prerequisite check failed: %v", err)
}

// CI / non-interactive mode (auto-approves, skips certs)
if err := installer.CheckAndInstallNonInteractive(true); err != nil {
    log.Fatalf("prerequisite check failed: %v", err)
}

// Refresh certificates only (install command)
installer.RegenerateCertificatesOnly()
```
