Manages TLS certificate installation and trust configuration for local development environments using `mkcert`, with cross-platform support for macOS, Linux, and Windows.

## Key Components

### `CertificateInstaller` struct
The primary type exposing three public methods:
- **`IsInstalled() bool`** — checks if `mkcert` is present on `PATH`
- **`GetInstallHelp() string`** — returns platform-specific installation hints
- **`Install() error`** — installs `mkcert` if missing, then generates certificates
- **`ForceRegenerate() error`** — regenerates certificates unconditionally (requires `mkcert` to already be installed)

### Internal helpers
| Function | Purpose |
|---|---|
| `installMkcertLinux()` | Downloads a pinned, SHA256-verified `mkcert` binary to `~/.openframe/bin` |
| `installMkcertMacOS()` | Installs `mkcert` via Homebrew |
| `generateCertificates()` | Runs `mkcert` to produce `localhost.pem` / `localhost-key.pem` in `~/.config/openframe/certs/` |
| `trustCADarwin()` | Adds the mkcert root CA to the macOS login keychain, removing stale entries first |
| `resolveLoginKeychain()` | Pure helper — resolves the active macOS keychain path; testable without a real keychain |
| `parseMkcertCertSHAs()` | Parses SHA-1 hashes from `security find-certificate` output; testable in isolation |

## Usage Example

```go
installer := certificates.NewCertificateInstaller()

// First-time install: installs mkcert + generates certs
if err := installer.Install(); err != nil {
    log.Fatalf("certificate install failed: %v", err)
}

// Force regeneration (e.g. cert rotation)
if err := installer.ForceRegenerate(); err != nil {
    log.Fatalf("certificate regeneration failed: %v", err)
}
```

Certificates are written to `~/.config/openframe/certs/` and the local CA is trusted in system and browser (NSS) trust stores. On Linux, `mkcert` is fetched via [`download.Downloader`](https://github.com/flamingo-stack/openframe-cli/blob/main/internal/shared/download) with a pinned checksum rather than an unauthenticated curl pipe.
