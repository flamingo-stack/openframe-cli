## certificates.go

Implements local TLS certificate management for OpenFrame CLI using `mkcert`. Handles cross-platform installation of `mkcert` (via Homebrew on macOS, verified pinned binary download on Linux), CA trust store setup (Keychain on macOS, NSS/system trust on Linux), and generation of `localhost` development certificates.

## Key Components

- **`CertificateInstaller`** — struct implementing the installer interface for certificate provisioning.
  - **`NewCertificateInstaller()`** — constructor.
  - **`IsInstalled()`** — checks whether `mkcert` is available (certificates are always regenerated, so their existence isn't checked).
  - **`GetInstallHelp()`** — returns platform-specific install guidance via `platform.InstallHint`.
  - **`Install()`** — installs `mkcert` if missing, then generates certificates.
  - **`ForceRegenerate()`** — regenerates certificates without reinstalling `mkcert`; errors if `mkcert` is absent.
- **`installMkcert()` / `installMkcertMacOS()` / `installMkcertLinux()`** — OS-specific installation logic; Homebrew on macOS, verified pinned download (SHA256-checked) on Linux via `download.Downloader`, unsupported on Windows.
- **`generateCertificates()`** — creates the cert directory, ensures the mkcert root CA is installed and trusted, cleans stale NSS entries, and generates `localhost.pem`/`localhost-key.pem` for `localhost`, `127.0.0.1`, and `::1`.
- **`trustCADarwin(caRoot, homeDir string) error`** — resolves the macOS login keychain, removes stale mkcert certs, and adds the mkcert root CA as trusted (falling back to interactive prompt if needed).
- **`resolveLoginKeychain(...)`** — pure helper to determine the correct macOS keychain path (testable without macOS).
- **`parseMkcertCertSHAs(...)`** — parses SHA-1 hashes from `security find-certificate` output for cleanup.
- **Helper functions** — `commandExists`, `fileExists`, `isMkcertInstalled`, `certificateInstallHelp`.

## Usage Example

```go
package main

import (
	"log"

	"github.com/flamingo-stack/openframe-cli/internal/platform/certificates"
)

func main() {
	installer := certificates.NewCertificateInstaller()

	if !installer.IsInstalled() {
		if err := installer.Install(); err != nil {
			log.Fatalf("certificate setup failed: %v\n%s", err, installer.GetInstallHelp())
		}
	}

	// Force regeneration of localhost certs (e.g., on every "install" command run)
	if err := installer.ForceRegenerate(); err != nil {
		log.Fatalf("failed to regenerate certificates: %v", err)
	}
}
```
