## Overview

`certificates.go` implements the `CertificateInstaller`, which manages installation of the `mkcert` tool and generation/trust of local TLS certificates (for `localhost`, `127.0.0.1`, `::1`) used by OpenFrame's local development environment. It handles cross-platform installation of `mkcert` (Homebrew on macOS, a pinned/verified binary download on Linux, manual instructions on Windows) and platform-specific CA trust store integration (macOS Keychain, Linux NSS/system trust stores).

## Key Components

- **`CertificateInstaller`** - Main struct exposing certificate lifecycle operations.
- **`NewCertificateInstaller()`** - Constructor.
- **`IsInstalled() bool`** - Checks whether `mkcert` is available on the system.
- **`GetInstallHelp() string`** - Returns platform-specific installation guidance.
- **`Install() error`** - Installs `mkcert` if missing, then generates certificates.
- **`ForceRegenerate() error`** - Regenerates certificates without reinstalling `mkcert`.
- **`installMkcert()` / `installMkcertMacOS()` / `installMkcertLinux()`** - Platform-specific `mkcert` installation logic (Homebrew, or verified pinned download via `download.Downloader`).
- **`generateCertificates()`** - Creates the certificate directory, installs the mkcert CA into trust stores, and generates `localhost.pem`/`localhost-key.pem`.
- **`trustCADarwin(caRoot, homeDir string) error`** - Adds the mkcert root CA to the macOS login keychain, removing stale mkcert certs first.
- **`resolveLoginKeychain(...)` / `parseMkcertCertSHAs(...)` / `classifyAddTrustedCert(...)`** - Pure helper functions supporting macOS keychain logic, designed for testability off macOS.
- **`commandExists`, `fileExists`, `isMkcertInstalled`, `certificateInstallHelp`** - Small utility helpers.

## Usage Example

```go
package main

import (
	"log"

	"github.com/flamingo-stack/openframe-cli/internal/certificates"
)

func main() {
	installer := certificates.NewCertificateInstaller()

	if !installer.IsInstalled() {
		log.Println(installer.GetInstallHelp())
	}

	if err := installer.Install(); err != nil {
		log.Fatalf("certificate setup failed: %v", err)
	}

	// Force regeneration of localhost certs (e.g., after CA changes)
	if err := installer.ForceRegenerate(); err != nil {
		log.Fatalf("certificate regeneration failed: %v", err)
	}
}
```

Generated certificates are stored at `~/.config/openframe/certs/localhost.pem` and `localhost-key.pem`, ready for use by local HTTPS services.
