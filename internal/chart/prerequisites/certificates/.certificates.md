## Overview

Implements automatic installation of `mkcert` and generation/trust of local TLS certificates for OpenFrame's local development environment. Handles platform-specific logic for macOS (Homebrew + Keychain trust) and Linux (verified pinned binary download + NSS/system trust stores), with certificates regenerated in `~/.config/openframe/certs`.

## Key Components

- **`CertificateInstaller`** — struct implementing an installer interface (`IsInstalled`, `GetInstallHelp`, `Install`) for the mkcert/certificate dependency.
- **`NewCertificateInstaller()`** — constructor returning a `*CertificateInstaller`.
- **`Install()`** — installs mkcert (if missing) then generates local certificates.
- **`ForceRegenerate()`** — regenerates certificates without reinstalling mkcert, failing if mkcert is absent.
- **`installMkcert()`** / **`installMkcertMacOS()`** / **`installMkcertLinux()`** — OS-specific mkcert installation (Homebrew on macOS, verified pinned binary download via `download.Downloader` on Linux; unsupported on Windows).
- **`generateCertificates()`** — creates the cert directory, ensures the mkcert CA is installed and trusted, cleans stale NSS entries, and generates `localhost.pem`/`localhost-key.pem`.
- **`trustCADarwin()`** — adds the mkcert root CA to the macOS login keychain, removing stale mkcert entries first, with interactive fallback if prompted.
- **`resolveLoginKeychain()`** / **`parseMkcertCertSHAs()`** — pure helper functions extracted for testability around keychain resolution and certificate parsing.
- **`commandExists()` / `fileExists()` / `isMkcertInstalled()`** — small utility predicates.

## Usage Example

```go
package main

import (
	"log"

	"github.com/flamingo-stack/openframe-cli/internal/platform/certificates"
)

func main() {
	installer := certificates.NewCertificateInstaller()

	if !installer.IsInstalled() {
		if err := installer.Install(); err != nil {
			log.Fatalf("certificate setup failed: %v\n%s", err, installer.GetInstallHelp())
		}
	}

	// Force regeneration of localhost certs (e.g., on every `install` run)
	if err := installer.ForceRegenerate(); err != nil {
		log.Fatalf("failed to regenerate certificates: %v", err)
	}
}
```

Generated certificates are written to `~/.config/openframe/certs/localhost.pem` and `localhost-key.pem`, ready for use by local TLS-enabled services.
