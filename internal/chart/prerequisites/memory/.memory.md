Cross-platform physical RAM checker that verifies whether the host meets OpenFrame's minimum memory requirements using `elastic/go-sysinfo` for OS-agnostic memory introspection.

## Key Components

| Symbol | Description |
|---|---|
| `MemoryChecker` | Struct implementing the prerequisite checker interface for memory validation |
| `RecommendedMemoryMB` | Constant set to `15360` (15 GB) — the recommended memory threshold |
| `NewMemoryChecker()` | Constructor returning a `*MemoryChecker` |
| `IsInstalled()` | Satisfies the checker interface; returns `true` if memory meets the threshold |
| `HasSufficientMemory()` | Returns `true` when total RAM ≥ `RecommendedMemoryMB` |
| `GetInstallHelp()` | Returns a human-readable diagnostic string with current vs. recommended values |
| `getTotalMemoryMB()` | Private; reads total physical RAM in MB cross-platform (procfs / sysctl / Win32) |
| `GetMemoryInfo()` | Returns `(current int, recommended int, sufficient bool)` for external consumers |

## Usage Example

```go
checker := memory.NewMemoryChecker()

current, recommended, ok := checker.GetMemoryInfo()
if !ok {
    fmt.Println(checker.GetInstallHelp())
    // Output example:
    // Memory: 8192 MB available, 15360 MB recommended.
    // Consider adding more RAM or increasing virtual memory
}

fmt.Printf("RAM: %d MB / %d MB — sufficient: %v\n", current, recommended, ok)
```

## Notes

- Falls back to `0` MB (treated as insufficient) if `go-sysinfo` cannot read host memory.
- Guards against `uint64` → `int` overflow on theoretical high-memory hosts by capping at `math.MaxInt`.
- No shell-outs: memory is read via native OS APIs, making it safe in restricted environments.
