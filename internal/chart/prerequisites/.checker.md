Orchestrates prerequisite validation for OpenFrame chart deployments by aggregating and running checks for Helm, memory, and certificate requirements.

## Key Components

### Types

- **`PrerequisiteChecker`** — Holds a slice of `Requirement` entries and exposes the `CheckAll` method.
- **`Requirement`** — Describes a single prerequisite with its `Name`, `Command`, and two function fields: `IsInstalled` (reports current state) and `InstallHelp` (returns remediation instructions).

### Functions

- **`NewPrerequisiteChecker() *PrerequisiteChecker`** — Constructs a checker pre-loaded with three built-in requirements: Helm, Memory, and Certificates.
- **`(pc *PrerequisiteChecker) CheckAll() (bool, []string)`** — Iterates over all requirements, returns `true` plus an empty slice when all pass, or `false` plus a slice of missing requirement names.

## Usage Example

```go
checker := prerequisites.NewPrerequisiteChecker()

allPresent, missing := checker.CheckAll()
if !allPresent {
    fmt.Println("Missing prerequisites:", missing)
    // Optionally surface install help per requirement
}
```

> **Extensibility:** Add custom requirements by appending to the `requirements` slice after calling `NewPrerequisiteChecker`, implementing both `IsInstalled` and `InstallHelp` callbacks.

```go
checker := prerequisites.NewPrerequisiteChecker()
checker.requirements = append(checker.requirements, prerequisites.Requirement{
    Name:        "kubectl",
    Command:     "kubectl",
    IsInstalled: func() bool { /* custom check */ return true },
    InstallHelp: func() string { return "Install kubectl from https://kubernetes.io/docs/tasks/tools/" },
})
```
