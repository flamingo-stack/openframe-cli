Brief description: Defines the `ChartInstallConfig` struct and its associated method for managing Helm chart installation configuration within the OpenFrame CLI.

## Key Components

### `ChartInstallConfig` struct
Holds all configuration options for a chart installation operation:

| Field | Type | Description |
|---|---|---|
| `ClusterName` | `string` | Target cluster name |
| `KubeContext` | `string` | Explicit kube-context for all Helm CLI calls; overrides the `ClusterName`-derived k3d context |
| `Force` | `bool` | Force installation |
| `DryRun` | `bool` | Simulate without applying changes |
| `Verbose` | `bool` | Enable verbose output |
| `Silent` | `bool` | Suppress all output |
| `NonInteractive` | `bool` | Suppress interactive UI elements and spinners |
| `SkipCRDs` | `bool` | Skip ArgoCD CRD installation |
| `SyncStragglersOnStall` | `bool` | Trigger one-shot sync of OutOfSync-but-healthy apps when progress stalls (upgrade path only) |
| `AppOfApps` | `*models.AppOfAppsConfig` | App-of-apps specific configuration |

### `HasAppOfApps() bool`
Returns `true` when a non-nil `AppOfApps` config is present and its `GitHubRepo` field is non-empty.

## Usage Example

```go
cfg := &config.ChartInstallConfig{
    ClusterName:           "my-cluster",
    KubeContext:           "k3d-my-cluster",
    DryRun:                true,
    SyncStragglersOnStall: true,
    AppOfApps: &models.AppOfAppsConfig{
        GitHubRepo: "flamingo-stack/openframe",
    },
}

if cfg.HasAppOfApps() {
    fmt.Println("App-of-apps deployment detected")
}
```
