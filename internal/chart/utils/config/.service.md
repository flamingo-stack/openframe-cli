Provides centralized configuration management for chart operations, handling initialization, path resolution, and installation config construction.

## Key Components

| Symbol | Type | Description |
|--------|------|-------------|
| `Service` | struct | Core config service wrapping a shared system service and path resolver |
| `NewService()` | constructor | Creates a `Service` with default `SystemService` and `PathResolver` |
| `Initialize()` | method | Bootstraps shared config and ensures the certificate directory exists |
| `GetCertificateDirectory()` | method | Returns the resolved certificate directory path |
| `GetPathResolver()` | method | Exposes the underlying `PathResolver` instance |
| `BuildInstallConfig()` | method | Assembles a `ChartInstallConfig` from install flags and app-of-apps config |

## Usage Example

```go
svc := config.NewService()

if err := svc.Initialize(); err != nil {
    log.Fatalf("config init failed: %v", err)
}

appCfg := &models.AppOfAppsConfig{
    RepoURL: "https://github.com/org/repo",
}

installCfg := svc.BuildInstallConfig(
    false,   // force
    false,   // dryRun
    true,    // verbose
    "prod-cluster",
    appCfg,
)

fmt.Println(installCfg.ClusterName)   // "prod-cluster"
fmt.Println(appCfg.CertDir)           // auto-populated by BuildInstallConfig
```

## Notes

- `Initialize()` creates the certificate directory with permissions `0750` if it does not already exist.
- `BuildInstallConfig()` automatically sets `AppOfAppsConfig.CertDir` to the resolved certificate path when the field is empty, preventing callers from needing to fetch it separately.
- [`PathResolver`](https://github.com/flamingo-stack/openframe-cli/blob/main/internal/chart/config/path_resolver.go) and [`sharedConfig.SystemService`](https://github.com/flamingo-stack/openframe-cli/blob/main/internal/shared/config/system_service.go) are injected at construction time and not swappable post-creation.
