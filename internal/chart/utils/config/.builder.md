Constructs `ChartInstallConfig` objects for OpenFrame CLI install operations, resolving Helm values, branch references, and app-of-apps configuration from CLI flags and on-disk YAML.

## Key Components

| Symbol | Description |
|---|---|
| `Builder` | Struct that composes a `Service` and `OperationsUI` to assemble install configs |
| `NewBuilder` | Constructor accepting a `chartUI.OperationsUI` instance |
| `helmValues` | Internal struct representing the flattened `repository.branch` schema from a Helm values file |
| `getBranchFromHelmValuesPath` | Reads a Helm values YAML file and returns the `repository.branch` value, or empty string on failure |
| `BuildInstallConfigWithCustomHelmPath` | Primary builder method; resolves cert dir, constructs `AppOfAppsConfig`, reconciles branch from file vs flag, and returns a `ChartInstallConfig` |

## Usage Example

```go
import (
    chartUI "github.com/flamingo-stack/openframe-cli/internal/chart/ui"
    "github.com/flamingo-stack/openframe-cli/internal/config"
)

opsUI := chartUI.NewOperationsUI()
builder := config.NewBuilder(opsUI)

installConfig, err := builder.BuildInstallConfigWithCustomHelmPath(
    false,                      // force
    false,                      // dryRun
    true,                       // verbose
    false,                      // nonInteractive
    "my-cluster",               // clusterName
    "flamingo-stack/openframe", // githubRepo
    "main",                     // githubBranch
    "",                         // certDir (resolved from config service)
    "/path/to/values.yaml",     // helmValuesPath
)
if err != nil {
    log.Fatal(err)
}
```

## Notes

- Branch resolution priority: if `repository.branch` is set in the Helm values file, it overrides the `githubBranch` flag. This ensures the ArgoCD clone and child `Application` `targetRevision` stay on the same ref.
- The legacy nested `deployment.oss.repository.branch` schema is intentionally unsupported to prevent stale files from silently overriding an explicit `--ref` flag.
- `SkipCRDs` is always set to `false`; CRD installation is delegated to the Argo CD Helm chart (`crds.install=true`).
