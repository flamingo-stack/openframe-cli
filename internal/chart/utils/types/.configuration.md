Defines the core configuration types used across the OpenFrame CLI for Docker registry credentials, deployment modes, ingress settings, and Helm chart configuration.

## Key Components

| Symbol | Kind | Description |
|---|---|---|
| `DockerRegistryConfig` | struct | Docker registry credentials (username, password, email) |
| `DeploymentMode` | string enum | Deployment mode; only `DeploymentModeOSS` (`"oss"`) is supported |
| `IngressType` | string enum | Ingress strategy: `localhost`, `ngrok`, or `gcp` |
| `NgrokConfig` | struct | Ngrok tunnel settings including auth token, API key, domain, and IP allowlist |
| `IngressConfig` | struct | Top-level ingress config wrapping `IngressType` and an optional `NgrokConfig` |
| `NgrokRegistrationURLs` | var | Package-level constant struct holding Ngrok dashboard/documentation URLs |
| `ChartConfiguration` | struct | Aggregates all Helm chart install options — paths, existing values, modified sections, branch, registry, and ingress |

## Usage Example

```go
cfg := &types.ChartConfiguration{
    BaseHelmValuesPath: "/etc/openframe/openframe-helm-values.yaml",
    TempHelmValuesPath: "/tmp/openframe-helm-values.yaml",
    ExistingValues:     map[string]interface{}{},
    IngressConfig: &types.IngressConfig{
        Type: types.IngressTypeNgrok,
        NgrokConfig: &types.NgrokConfig{
            AuthToken:     "2abc...",
            APIKey:        "ak_xyz",
            Domain:        "my-org.ngrok.app",
            UseAllowedIPs: true,
            AllowedIPs:    []string{"203.0.113.10/32"},
        },
    },
    DockerRegistry: &types.DockerRegistryConfig{
        Username: "myuser",
        Password: "s3cr3t",
        Email:    "ops@example.com",
    },
}
```

> **Note:** `Branch`, `DockerRegistry`, and `IngressConfig` on `ChartConfiguration` are all pointer fields — a `nil` value signals "keep the existing value" rather than overwrite.
