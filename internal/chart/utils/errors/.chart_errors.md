## chart_errors.go

Defines a structured error type for chart/Helm-related operations, providing context (operation, component, cluster) and retry semantics used throughout chart installation and management workflows.

## Key Components

- **`ChartError`** – struct capturing `Operation`, `Component`, `ClusterName`, `Cause`, `Timestamp`, `Recoverable`, `NonRetryable`, and `RetryAfter`. Implements `Error()` and `Unwrap()` for standard error interoperability.
- **`IsRecoverable()` / `GetRetryAfter()`** – accessors used by retry logic to decide whether/when to retry an operation.
- **`WithCluster()`, `WithRecovery()`, `WithNonRetryable()`** – fluent builder methods to enrich an existing `ChartError`.
- **`IsNonRetryable()`** – implements a shared `NonRetryableError` marker interface so retry policies can hard-skip errors whose message may falsely look transient (e.g., embedded pod logs/events).
- **`NewChartError()` / `NewRecoverableChartError()`** – constructors for creating base and retryable chart errors.
- **Sentinel errors** – predefined package-level errors like `ErrChartNotFound`, `ErrClusterNotReady`, `ErrHelmNotAvailable`, `ErrAuthenticationFailed`, etc., for common failure conditions.
- **`ValidationError`** – embeds `ChartError` and adds `Field`, `Value`, `Constraint` for configuration validation failures. Created via `NewValidationError()`.
- **`WrapAsChartError()`** – wraps any generic error into a `ChartError`, preserving an existing `ChartError` if already present via `errors.As`.

## Usage Example

```go
// Create a basic chart error
err := errors.NewChartError("install", "ArgoCD", ErrHelmNotAvailable)

// Add cluster context and mark as recoverable
err = err.WithCluster("dev-cluster").WithRecovery(30 * time.Second)

if err.IsRecoverable() {
    time.Sleep(err.GetRetryAfter())
    // retry operation
}

// Validation error usage
valErr := errors.NewValidationError("replicaCount", "-1", "must be non-negative")
fmt.Println(valErr.Error())

// Wrap a generic error, marking it non-retryable since the message
// embeds pod logs that could falsely match transient patterns
wrapped := errors.WrapAsChartError("waiting", "applications", genericErr).
    WithNonRetryable()
```
