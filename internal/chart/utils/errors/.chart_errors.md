Defines structured error types for chart-related operations, providing rich context including operation name, component, cluster, recoverability, and retry hints.

## Key Components

| Export | Type | Description |
|--------|------|-------------|
| `ChartError` | struct | Core error type with operation, component, cluster, timestamp, and retry metadata |
| `ValidationError` | struct | Embeds `ChartError`; adds field-level validation context (`Field`, `Value`, `Constraint`) |
| `NewChartError` | func | Creates a basic `ChartError` |
| `NewRecoverableChartError` | func | Creates a `ChartError` pre-marked as recoverable with a retry delay |
| `NewValidationError` | func | Creates a `ValidationError` for a specific field constraint violation |
| `WrapAsChartError` | func | Wraps a generic error as `ChartError`; unwraps existing `ChartError` transparently |
| `WithCluster` / `WithRecovery` | methods | Fluent builder methods on `ChartError` |
| Sentinel errors | `var` | `ErrChartNotFound`, `ErrClusterNotReady`, `ErrHelmNotAvailable`, and five others |

## Usage Example

```go
// Basic chart error with cluster context
err := errors.NewChartError("install", "ArgoCD", someErr).
    WithCluster("prod")
// → "install failed for ArgoCD on cluster prod: <someErr>"

// Recoverable error with retry hint
err := errors.NewRecoverableChartError(
    "waiting", "ArgoCD applications", someErr, 30*time.Second,
)
if err.IsRecoverable() {
    time.Sleep(err.GetRetryAfter())
    // retry logic
}

// Validation error for a specific field
err := errors.NewValidationError("replicas", "0", "must be >= 1")
// → "validation failed for field 'replicas': must be >= 1 (value: '0')"

// Wrap an unknown error; returns existing ChartError if already wrapped
chartErr := errors.WrapAsChartError("deploy", "Helm release", rawErr)
```

## Error Unwrapping

`ChartError` implements `Unwrap()`, making it compatible with `errors.Is` and `errors.As` from the standard library. `WrapAsChartError` uses this to avoid double-wrapping.
