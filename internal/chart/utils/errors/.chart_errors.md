Defines a structured error type for chart-related operations (Helm charts, cluster components), providing consistent formatting, retry semantics, and validation error support across the CLI's chart management code.

## Key Components

- **`ChartError`** — struct capturing `Operation`, `Component`, `ClusterName`, `Cause`, `Timestamp`, `Recoverable`, `NonRetryable`, and `RetryAfter`. Implements `error` (`Error()`), `Unwrap()`, `IsRecoverable()`, `GetRetryAfter()`, and `IsNonRetryable()`.
- **`NewChartError(operation, component, cause)`** — constructs a basic, non-recoverable `ChartError`.
- **`NewRecoverableChartError(operation, component, cause, retryAfter)`** — constructs a `ChartError` explicitly marked recoverable with a suggested retry delay.
- **`(*ChartError) WithCluster(clusterName)`** — attaches cluster context (chainable).
- **`(*ChartError) WithRecovery(retryAfter)`** — marks error recoverable and sets retry delay (chainable).
- **`(*ChartError) WithNonRetryable()`** — explicitly forbids retrying, overriding retry-policy inference from the cause (chainable).
- **Sentinel errors** — `ErrChartNotFound`, `ErrChartAlreadyInstalled`, `ErrInvalidConfiguration`, `ErrClusterNotReady`, `ErrHelmNotAvailable`, `ErrInsufficientResources`, `ErrAuthenticationFailed`, `ErrPermissionDenied`.
- **`ValidationError`** — embeds `*ChartError`, adds `Field`, `Value`, `Constraint`, with its own `Error()` formatting.
- **`NewValidationError(field, value, constraint)`** — builds a `ValidationError` wrapping a constraint-violation cause.
- **`WrapAsChartError(operation, component, err)`** — wraps any error as a `ChartError`, unwrapping via `errors.As` if it's already one (avoids double-wrapping).

## Usage Example

```go
// Creating a recoverable error with retry context
err := NewRecoverableChartError("install", "ArgoCD", ErrHelmNotAvailable, 5*time.Second).
    WithCluster("dev-cluster")

if chartErr, ok := err.(interface{ IsRecoverable() bool }); ok && chartErr.IsRecoverable() {
    // retry logic using err.(*ChartError).GetRetryAfter()
}

// Marking an error as never-retryable (e.g. message embeds pod logs)
err = NewChartError("waiting", "applications", cause).
    WithCluster("dev").
    WithNonRetryable()

// Validation error
verr := NewValidationError("replicaCount", "-1", "must be >= 0")
fmt.Println(verr.Error())
// "validation failed for field 'replicaCount': must be >= 0 (value: '-1')"

// Wrapping a generic error without double-wrapping
wrapped := WrapAsChartError("upgrade", "chart", someErr)
```
