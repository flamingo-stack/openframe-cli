Defines structured error types for chart-related operations, providing rich context (operation, component, cluster, timing) and retry semantics for the errors package.

## Key Components

- **`ChartError`** - Core struct capturing `Operation`, `Component`, `ClusterName`, `Cause`, `Timestamp`, `Recoverable`, `NonRetryable`, and `RetryAfter`. Implements `error` via `Error()` and supports unwrapping via `Unwrap()`.
- **`NewChartError(operation, component string, cause error) *ChartError`** - Creates a basic, non-recoverable chart error.
- **`NewRecoverableChartError(operation, component string, cause error, retryAfter time.Duration) *ChartError`** - Creates an error marked recoverable with a suggested retry delay.
- **`(*ChartError).WithCluster(clusterName string) *ChartError`** - Fluent setter attaching cluster context.
- **`(*ChartError).WithRecovery(retryAfter time.Duration) *ChartError`** - Fluent setter marking the error recoverable.
- **`(*ChartError).WithNonRetryable() *ChartError`** - Explicitly forbids retries (stronger than `Recoverable=false`), useful when the error message embeds diagnostics that could falsely pattern-match as transient.
- **`(*ChartError).IsRecoverable() / GetRetryAfter() / IsNonRetryable()`** - Accessors used by retry policies.
- **`ValidationError`** - Embeds `*ChartError` and adds `Field`, `Value`, `Constraint` for configuration validation failures.
- **`NewValidationError(field, value, constraint string) *ValidationError`** - Constructs a validation error with a descriptive cause.
- **`WrapAsChartError(operation, component string, err error) *ChartError`** - Wraps any error as a `ChartError`, reusing the existing one if `err` already is (or wraps) a `*ChartError`.
- Sentinel errors: `ErrChartNotFound`, `ErrChartAlreadyInstalled`, `ErrInvalidConfiguration`, `ErrClusterNotReady`, `ErrHelmNotAvailable`, `ErrInsufficientResources`, `ErrAuthenticationFailed`, `ErrPermissionDenied`.

## Usage Example

```go
err := installChart()
if err != nil {
    chartErr := errors.WrapAsChartError("install", "ArgoCD", err).
        WithCluster("dev").
        WithRecovery(5 * time.Second)

    if chartErr.IsRecoverable() {
        time.Sleep(chartErr.GetRetryAfter())
        // retry logic
    }
    return chartErr
}

// Validation example
if invalidField {
    return errors.NewValidationError("replicas", "-1", "must be >= 0")
}
```
