# OpenFrame CLI Documentation

Welcome to the documentation for **OpenFrame CLI** — the Go-based command-line tool for provisioning Kubernetes clusters (local `k3d`, or cloud `EKS`/`GKE` via Terraform) and deploying the [OpenFrame](https://openframe.ai) platform onto them via ArgoCD's app-of-apps pattern.

### CLI Tools

OpenFrame CLI is the operator-facing tool for the OpenFrame platform. The platform itself (charts, services, app-of-apps) is maintained in a separate repository:

- **Repository**: [flamingo-stack/openframe-oss-tenant](https://github.com/flamingo-stack/openframe-oss-tenant)
- **Documentation**: [Platform Documentation](https://github.com/flamingo-stack/openframe-oss-tenant/tree/main/docs)

**Note**: The OpenFrame platform is NOT located in this repository. Always refer to the external repository for platform-level installation and usage details.
