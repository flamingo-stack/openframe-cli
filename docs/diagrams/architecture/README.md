# Architecture Diagrams

This directory contains Mermaid diagrams generated from architecture analysis.

## Diagrams

- **[Architecture Diagram](./architecture-diagram.mmd)** - `.mmd` file
- **[Dependency Diagram](./dependency-diagram.mmd)** - `.mmd` file
- **[Bootstrap Sequence](./bootstrap-sequence.mmd)** - `.mmd` file
- **[App Status Aggregation](./app-status-aggregation.mmd)** - `.mmd` file

## Viewing Diagrams

These `.mmd` files can be viewed:
- In VS Code with Mermaid extension
- On GitHub (renders inline)
- Via [Mermaid Live Editor](https://mermaid.live)
- In documentation tools that support Mermaid
